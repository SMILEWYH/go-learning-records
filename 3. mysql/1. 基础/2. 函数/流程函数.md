# 流程函数

MySQL中内置了很多流程函数，常用的几个如下：

```sql
IF(value, t, f)
```

如果value为true，则返回t，否则返回f。

示例：判断分数是否及格。

```sql
SET @score = 78;

SELECT IF(@score >= 60, '及格', '不及格') AS result;
-- 预期结果：及格
```

```sql
IFNULL(value1, value2)
```

如果value1不为NULL，则返回value1，否则返回value2（空字符串不等于NULL）。

示例：昵称为 NULL 时显示默认名称。

```sql
SELECT IFNULL(NULL, '未设置昵称') AS nickname;
-- 预期结果：未设置昵称

SELECT IFNULL('小明', '未设置昵称') AS nickname;
-- 预期结果：小明

SELECT IFNULL('', '未设置昵称') AS nickname;
-- 预期结果：空字符串，不会返回“未设置昵称”
```

```sql
CASE WHEN val1 THEN res1 ... ELSE default END
```

按顺序判断条件，返回第一个为true的条件对应的结果；如果都不满足，则返回default默认值。

示例：根据分数判断等级（假设分数为 0～100 的非 NULL 数值）。

- 分数 >= 85：优秀。
- 分数 >= 60 且 < 85：及格。
- 分数 < 60：不及格。

```sql
SET @score = 78;

SELECT CASE
           WHEN @score >= 85 THEN '优秀'
           WHEN @score >= 60 THEN '及格'
           ELSE '不及格'
       END AS grade;
-- 预期结果：及格
-- 将 @score 改为 90，预期返回“优秀”；改为 50，预期返回“不及格”。
```

第二个条件不需要再写 `@score < 85`，因为只有第一个条件不成立时，才会继续判断第二个条件。

```sql
CASE expr WHEN val1 THEN res1 ... ELSE default END
```

按顺序比较expr与各个值，返回第一个相等的值对应的结果；如果都不匹配，则返回default默认值。

示例：把等级编号转换成对应名称。

```sql
SET @grade_code = 2;

SELECT CASE @grade_code
           WHEN 1 THEN '优秀'
           WHEN 2 THEN '及格'
           WHEN 3 THEN '不及格'
           ELSE '未知等级'
       END AS grade;
-- 预期结果：及格
```

这里比较的是 `@grade_code` 是否等于 `1`、`2`、`3`；上面的 `CASE WHEN` 则可以判断分数范围。

以上示例仅用于说明，预期结果不代表已经执行 SQL。







这个流程函数和储存过程的有什么区别？

答：主要区别是：**流程函数用来“返回一个值”，存储过程里的流程控制语句用来“决定执行哪些 SQL”**
