# 事务简介

事务是一组操作的集合，它是一个不可分割的工作单位。

事务会把所有的操作作为一个整体一起向系统提交或撤销操作请求，即这些操作要么同时成功，要么同时失败。

## 转账示例：张三向李四转账 1000。

初始账户数据：

| id | name | money |
| --- | --- | --- |
| 1 | 张三 | 2000 |
| 2 | 李四 | 2000 |

操作流程：

1. 开启事务。

2. 查询张三账户余额。

3. 张三账户余额 -1000。

4. 李四账户余额 +1000。

5. 操作全部成功，提交事务；

6. 而如果中途抛异常，回滚事务。

所以自定义事务主要有三个时间点：开启事务、提交事务、回滚事务

默认情况下 MySQL 的事务是自动提交的，也就是说当执行一条 DML 语句，MySQL 会立即隐式地提交事务。
