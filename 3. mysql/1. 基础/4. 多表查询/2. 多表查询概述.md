# 多表查询概述

多表查询概述：

概述：指从多张表中查询数据。

例如：员工姓名存储在员工表中，部门名称存储在部门表中，查询员工及其所属部门时就需要多表查询。

## 笛卡尔积：

笛卡尔乘积是指在数学中，两个集合 A 和 B 的所有组合情况。

在多表查询时，需要消除无效的笛卡尔积，即通过判断条件过滤掉不符合关联关系的组合。

例如：员工表有 4 条记录，部门表有 4 条记录，不加连接条件时会得到 4 × 4 = 16 条记录。

每个员工都会与每个部门组合，其中只有符合员工所属部门的组合才是本次查询需要的数据。

示例：假设已有员工表 emp（id、name、dept_id）和部门表 dept（id、name）。

## 1. 不加连接条件：得到两张表的笛卡尔积。

```sql
SELECT * FROM emp, dept;
```

## 2. 添加连接条件：员工的部门编号 = 部门的主键，过滤无效组合。

```sql
SELECT *
FROM emp, dept
WHERE emp.dept_id = dept.id;
```

这个就相当于内连接的隐式内连接

## 多表查询分类：

### 一、连接查询

## 1. 内连接：相当于查询 A、B 交集部分数据，即两张表中满足连接条件的记录。

## 2. 外连接：

左外连接：查询左表所有数据，以及两张表交集部分数据。

右外连接：查询右表所有数据，以及两张表交集部分数据。

补充：未匹配到另一张表的记录，另一张表对应的字段用 NULL 填充。

## 3. 自连接：当前表与自身的连接查询，自连接必须使用表别名。

例如：同一张员工表中，查询员工及其直属领导，需要用不同别名区分员工和领导。

自连接可以使用内连接，也可以使用外连接。

### 二、子查询

在一条 SQL 语句中嵌套 SELECT 查询，嵌套的查询称为子查询。

例如：先查询某个部门的编号，再用该编号查询这个部门的员工。
