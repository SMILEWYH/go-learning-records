# 自连接

## 自连接查询语法：

```sql
SELECT 字段列表 FROM 表A 别名A JOIN 表A 别名B ON 条件 ...;
```

自连接查询，可以是内连接查询，也可以是外连接查询。

自连接就是同一张表与自身连接，需要使用不同的表别名区分角色。

## 例子：查询员工姓名及其直属领导姓名。

假设员工表 emp 有以下数据（仅用于说明，不包含建表和插入语句）：

| id | name | manager_id |
| --- | --- | --- |
| 1 | 张无忌 | NULL |
| 2 | 赵敏 | 1 |
| 3 | 小昭 | 1 |
| 4 | 周芷若 | 2 |

manager_id 表示直属领导的员工 id，NULL 表示没有直属领导。

e、m 都是 emp 的别名：e 代表员工，m 代表领导。

e.manager_id = m.id 表示用员工的领导编号匹配领导的员工编号。

### 1. 自连接 + 内连接：查询有匹配直属领导的员工及其领导。

```sql
SELECT e.name AS 员工姓名, m.name AS 领导姓名
FROM emp e
INNER JOIN emp m ON e.manager_id = m.id
ORDER BY e.id;
```

按上述示例数据，预期结果：

| 员工姓名 | 领导姓名 |
| --- | --- |
| 赵敏 | 张无忌 |
| 小昭 | 张无忌 |
| 周芷若 | 赵敏 |

张无忌没有直属领导，不满足连接条件，因此不会出现在结果中。

### 2. 自连接 + 左外连接：查询所有员工及其领导，包括没有直属领导的员工。

```sql
SELECT e.name AS 员工姓名, m.name AS 领导姓名
FROM emp e
LEFT JOIN emp m ON e.manager_id = m.id
ORDER BY e.id;
```

按上述示例数据，预期结果：

| 员工姓名 | 领导姓名 |
| --- | --- |
| 张无忌 | NULL |
| 赵敏 | 张无忌 |
| 小昭 | 张无忌 |
| 周芷若 | 赵敏 |

保留左侧 e 中的所有员工；没有匹配领导时，领导姓名用 NULL 填充。
