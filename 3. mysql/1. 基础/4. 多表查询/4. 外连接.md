# 外连接

## 外连接查询语法：

### 一、左外连接

```sql
SELECT 字段列表 FROM 表1 LEFT [OUTER] JOIN 表2 ON 条件 ...;
```

相当于查询表1（左表）的所有数据，包含表1和表2交集部分的数据。

### 二、右外连接

```sql
SELECT 字段列表 FROM 表1 RIGHT [OUTER] JOIN 表2 ON 条件 ...;
```

相当于查询表2（右表）的所有数据，包含表1和表2交集部分的数据。

说明：[OUTER] 表示 OUTER 关键字可以省略，实际编写 SQL 时不需要输入方括号。

## 例子：沿用内连接笔记中的员工表和部门表。

假设已有以下数据（仅用于说明，不包含建表和插入语句）：

```text
员工表 emp：                     部门表 dept：
id    name　　　    dept_id　    id    name
1     张无忌        1　          1     研发部
2     赵敏　        2　          2     市场部
3     小昭　        NULL　       3     财务部
```

### 1. 左外连接：查询所有员工及其部门，包括没有所属部门的员工。

```sql
SELECT e.name AS 员工姓名, d.name AS 部门名称
FROM emp e
LEFT JOIN dept d ON e.dept_id = d.id;
```

按上述示例数据，结果包含以下记录（未指定 ORDER BY，不保证顺序）：

| 员工姓名 | 部门名称 |
| --- | --- |
| 张无忌 | 研发部 |
| 赵敏 | 市场部 |
| 小昭 | NULL |

emp 是左表，保留所有员工；小昭没有匹配的部门，部门名称用 NULL 填充。

### 2. 右外连接：查询所有部门及其员工，包括没有员工的部门。

```sql
SELECT e.name AS 员工姓名, d.name AS 部门名称
FROM emp e
RIGHT JOIN dept d ON e.dept_id = d.id;
```

按上述示例数据，结果包含以下记录（未指定 ORDER BY，不保证顺序）：

| 员工姓名 | 部门名称 |
| --- | --- |
| 张无忌 | 研发部 |
| 赵敏 | 市场部 |
| NULL | 财务部 |

dept 是右表，保留所有部门；财务部没有匹配的员工，员工姓名用 NULL 填充。

## 多对多例子：通过选课中间表连接学生表和课程表。

一个学生可以选多门课，一门课也可以被多个学生选择。

沿用内连接笔记中的示例数据（仅用于说明，不包含建表和插入语句）：

```text
学生表 student：      课程表 course：        选课中间表 student_course：
id    name　　　　    id    name　　　　     student_id    course_id
1     张三　　        10    MySQL　　　　    1             10
2     李四　　        20    Go　　　　       1             20
3     王五　　        30    Java　　　　     2             10
```

### 1. 左外连接：保留所有学生，包括没有选课的学生。

```sql
SELECT s.name AS 学生姓名, c.name AS 课程名称
FROM student s
LEFT JOIN student_course sc ON s.id = sc.student_id
LEFT JOIN course c ON sc.course_id = c.id;
```

按上述示例数据，结果包含以下记录（未指定 ORDER BY，不保证顺序）：

| 学生姓名 | 课程名称 |
| --- | --- |
| 张三 | MySQL |
| 张三 | Go |
| 李四 | MySQL |
| 王五 | NULL |

连续使用两个 LEFT JOIN，保留没有选课的王五，课程名称用 NULL 填充。

此处若将第二个 LEFT JOIN 改为 INNER JOIN，王五这一行会被过滤掉。

### 2. 右外连接：保留所有课程，包括没有学生选择的课程。

```sql
SELECT s.name AS 学生姓名, c.name AS 课程名称
FROM student s
RIGHT JOIN student_course sc ON s.id = sc.student_id
RIGHT JOIN course c ON sc.course_id = c.id;
```

按上述示例数据，结果包含以下记录（未指定 ORDER BY，不保证顺序）：

| 学生姓名 | 课程名称 |
| --- | --- |
| 张三 | MySQL |
| 李四 | MySQL |
| 张三 | Go |
| NULL | Java |

保留所有课程；Java 没有学生选择，学生姓名用 NULL 填充。

### 3. 等价写法：把课程表放在最左边，使用左外连接保留所有课程。

```sql
SELECT s.name AS 学生姓名, c.name AS 课程名称
FROM course c
LEFT JOIN student_course sc ON c.id = sc.course_id
LEFT JOIN student s ON sc.student_id = s.id;
```
