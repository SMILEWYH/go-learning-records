# 联合查询 union

联合查询：UNION、UNION ALL

把多次查询的结果合并起来，形成一个新的查询结果集。

语法：

```sql
SELECT 字段列表 FROM 表A ...
UNION [ALL]
SELECT 字段列表 FROM 表B ...;
```

注意：

### 1. 各次查询返回的列数必须一致，对应位置的字段类型应保持一致。

这里指 SELECT 的结果列，不要求原表的总列数相同；MySQL 也允许兼容的类型进行转换。

### 2. UNION ALL 将全部数据直接合并在一起，保留重复行。

### 3. UNION 对合并后的数据去重，只有所选各列都相同的行才算重复行。

说明：[ALL] 表示 ALL 可以省略，实际编写 SQL 时不输入方括号。

联合查询既可以查询不同表，也可以合并同一张表的多次查询结果。

## 例子：沿用内连接笔记中的员工表 emp。

假设已有以下数据（仅用于说明，不包含建表和插入语句）：

| id | name | dept_id |
| --- | --- | --- |
| 1 | 张无忌 | 1 |
| 2 | 赵敏 | 2 |
| 3 | 小昭 | NULL |

合并 id <= 2 和 id >= 2 的查询结果，赵敏同时满足两个条件。

### 1. UNION ALL：保留重复行。

```sql
SELECT id, name FROM emp WHERE id <= 2
UNION ALL
SELECT id, name FROM emp WHERE id >= 2;
```

按上述示例数据，结果包含以下记录（未指定 ORDER BY，不保证顺序）：

| id | name |
| --- | --- |
| 1 | 张无忌 |
| 2 | 赵敏 |
| 2 | 赵敏 |
| 3 | 小昭 |

赵敏出现两次，共 4 行。

### 2. UNION：去除重复行。

```sql
SELECT id, name FROM emp WHERE id <= 2
UNION
SELECT id, name FROM emp WHERE id >= 2;
```

按上述示例数据，结果包含以下记录（未指定 ORDER BY，不保证顺序）：

| id | name |
| --- | --- |
| 1 | 张无忌 |
| 2 | 赵敏 |
| 3 | 小昭 |

赵敏只保留一次，共 3 行。
