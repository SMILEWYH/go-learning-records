# SQL 通用语法及分类

## SQL 通用语法：

1. SQL语句可以单行或多行书写，以分号结尾。

2. SQL语句可以使用空格和缩进来增强语句的可读性。

3. MySQL数据库的SQL语句不区分大小写，关键字建议使用大写。

4. 注释：

   ```sql
   -- 单行注释（-- 后需要空格）
   # 单行注释（MySQL 特有）
   
   /* 多行注释内容 */
   ```

## SQL 分类

1. DDL：数据定义语言，用来定义数据库对象(数据库本身，表，字段)。

2. DML：数据操作语言，用来对数据库表中的数据进行增删改。

3. DQL：数据查询语言，用来查询数据库中表的数据记录。

4. DCL：数据控制语言，用来创建数据库用户、控制数据库的访问权限。

注意：DDL 命令针对的是数据库对象(数据库本身、表，字段)，而 DML、DQL 命令针对的是数据库表中字段的数据。
