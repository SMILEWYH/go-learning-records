# DQL 语句

## SELECT 语句结构:

```sql
SELECT
    字段列表
FROM
    表名列表
WHERE
    条件列表
GROUP BY
    分组字段列表
HAVING
    分组后条件列表
ORDER BY
    排序字段列表
LIMIT
    分页参数;
```

当前只有单表查询, 多表查询后续再学

## 第一部分：基本查询

### 1. 查询多个字段

```sql
SELECT 字段1, 字段2, 字段3 ... FROM 表名;
```

```sql
SELECT * FROM 表名;
```

实际开发环境中,一般不建议使用SELECT * FROM 表名;这种方式查询所有字段,因为会增加网络传输的负担,而且不利于数据库的优化, 并且代码不够直观。

### 2. 设置别名

```sql
SELECT 字段1 [ AS 别名1 ], 字段2 [ AS 别名2 ] ... FROM 表名;
```

### 3. 去除重复记录

```sql
SELECT DISTINCT 字段列表 FROM 表名;
```

DISTINCT 会对查询结果中所选字段的组合去重, 只有这些字段的值都相同, 才会合并为一条结果。

去重只影响查询结果, 不会删除表中的数据。

例如: SELECT DISTINCT id, name FROM students LIMIT 100;

这条语句按 id 和 name 的组合去重。即使 name 相同, 只要 id 不同, 两条记录都会保留。

如 (1, '张三') 和 (2, '张三') 是不同的组合, 都会出现在查询结果中。

如果 id 是主键, 每行的 id 都不同, 这条语句就不会去掉任何重复名字。

如果只想查询不重复的名字, 只选择 name 字段:

```sql
SELECT DISTINCT name FROM students LIMIT 100;
```

先对 name 去重, 再返回最多 100 条结果。

## 第二部分：条件查询

### 1. 语法

```sql
SELECT 字段列表 FROM 表名 WHERE 条件列表;
```

### 2. 条件

| 项目 | 说明 |
| --- | --- |
| > | 大于 |
| >= | 大于等于 |
| < | 小于 |
| <= | 小于等于 |
| = | 等于 |
| != | 不等于 |
| BETWEEN ... AND ... | 在某个范围之内 (左边为最小值、右边为最大值) |
| 字段名 IN(...) | 在 IN 后的列表中的值, 多选一 |
| LIKE 占位符 | 模糊匹配 (_ 匹配单个字符, % 匹配零个或多个字符) |
| IS (NOT) NULL | 是 NULL |

注意后四种条件, 需要使用逻辑运算符的关键字方式, 不能使用符号。

多个条件需要使用逻辑运算符连接, 逻辑运算符有三种:

| 项目 | 说明 |
| --- | --- |
| AND 或 && | 并且 (多个条件同时成立) |
| OR 或 \|\| | 或者 (多个条件任意一个成立) |
| NOT 或 ! | 非, 不是 |

## 第三部分：聚合函数

语法:

```sql
SELECT 聚合函数(字段列表), 字段列表 FROM 表名;
```

聚合函数是对表中列的值进行计算, 返回一个单一的值, 主要有以下几种:

| 项目 | 说明 |
| --- | --- |
| COUNT() | 计数 |
| SUM() | 求和 |
| AVG() | 平均值 |
| MAX() | 最大值 |
| MIN() | 最小值 |

聚合函数一般和 GROUP BY 分组查询一起使用, 也可以单独使用。

所有的聚合函数都可以使用 DISTINCT 去重, 例如: COUNT(DISTINCT 字段名)。

所有的聚合函数都可以使用 WHERE 条件查询, 例如: SELECT COUNT(*) FROM 表名 WHERE 条件。

null值不会被聚合函数计算, 例如: SELECT COUNT(字段名) FROM 表名; 会统计字段名不为null的记录数。

## 第四部分：分组查询

### 1. 语法

```sql
SELECT 字段列表 FROM 表名 [ WHERE 条件 ] GROUP BY 分组字段名 [ HAVING 分组后过滤条件 ];
```

使用例子：

```sql
SELECT COUNT(*), sex FROM students GROUP BY sex;
```

```sql
SELECT COUNT(*), sex FROM students WHERE age > 18 GROUP BY sex;
```

```sql
SELECT COUNT(*), sex FROM students GROUP BY sex HAVING COUNT(*) > 10;
```

```sql
SELECT COUNT(*), sex FROM students WHERE age > 18 GROUP BY sex HAVING COUNT(*) > 10;
```

WHERE 与 HAVING 的区别

执行时机不同: WHERE 是分组之前进行过滤, 不满足 WHERE 条件的记录不参与分组; HAVING 是分组之后对结果进行过滤。

判断条件不同: WHERE 不能对聚合函数进行判断, 而 HAVING 可以。

注意

执行顺序: WHERE > 聚合函数 > HAVING。

分组之后, 查询的字段一般为聚合函数和分组字段, 查询其他字段无任何意义。

## 第五部分：排序查询

### 1. 语法

```sql
SELECT 字段列表 FROM 表名 ORDER BY 字段1 排序方式1, 字段2 排序方式2;
```

排序方式

| 项目 | 说明 |
| --- | --- |
| ASC | 升序 (默认值) |
| DESC | 降序 |

如果是多字段排序, 当第一个字段值相同时, 才会根据第二个字段进行排序。

## 第六部分：分页查询

### 1. 语法

```sql
SELECT 字段列表 FROM 表名 LIMIT 起始索引, 查询记录数;
```

注意

起始索引从 0 开始, 起始索引 = (查询页码 - 1) * 每页显示记录数。

分页查询是数据库的方言, 不同的数据库有不同的实现, MySQL 中是 LIMIT。

如果查询的是第一页数据, 起始索引可以省略, 例如每页显示 10 条记录时, 可以简写为 LIMIT 10。

## 第七部分：综合练习

### 1. 查询年龄为20,21,22,23岁的员工信息。

```sql
SELECT * FROM students WHERE age IN(20, 21, 22, 23) && gender = "女";
```

### 2. 查询性别为男, 并且年龄在20-40岁(含)以内的姓名为三个字的员工。

```sql
SELECT * FROM students WHERE gender = "男" && age BETWEEN 20 AND 40 && name LIKE "___";
```

### 3. 统计员工表中, 年龄小于60岁的, 男性员工和女性员工的人数。

```sql
SELECT gender, COUNT(*) FROM students WHERE age < 60 GROUP BY gender;
```

### 4. 查询所有年龄小于等于35岁员工的姓名和年龄, 并对查询结果按年龄升序排序, 如果年龄相同按入职时间降序排序。

```sql
SELECT name, age FROM students WHERE age <= 35 ORDER BY age ASC, enterTime DESC;
```

### 5. 查询性别为男, 且年龄在20-40岁(含)以内的前5个员工信息, 对查询的结果按年龄升序排序, 年龄相同按入职时间升序排序。

```sql
SELECT * FROM students WHERE gender = "男" && age BETWEEN 20 AND 40 ORDER BY age, enterTime LIMIT 0, 5;
```

## 第八部分：DQL 语句执行顺序

1. FROM 表名列表

2. WHERE 条件列表

3. GROUP BY 分组字段名

4. HAVING 分组后过滤条件

5. SELECT 字段列表

6. ORDER BY 排序字段列表

7. LIMIT 起始索引, 查询记录数;

可以通过不同执行时期的别名来检验执行顺序
