# DML 语句

## 第一部分：添加表数据

### 1. 给指定字段添加数据：

```sql
INSERT INTO 表名(字段1,字段2,字段3,...) VALUES(值1,值2,值3,...);
```

指定字段插入数据时，插入的值和指定字段顺序是一一对应的。

### 2. 给所有字段添加数据：

```sql
INSERT INTO 表名 VALUES(值1,值2,值3,...);
```

不指定字段插入数据时，插入的值顺序必须和表中字段顺序一一对应的。

### 3. 批量添加数据：VALUES 后的数据使用逗号分隔

```sql
INSERT INTO 表名(字段1,字段2,字段3,...) VALUES(值1,值2,值3,...),(值1,值2,值3,...),(值1,值2,值3,...),...;
```

```sql
INSERT INTO 表名 VALUES(值1,值2,值3,...),(值1,值2,值3,...),(值1,值2,值3,...),...;
```

注意：

​	字符串和日期型数据应该包含在引号中。

​	插入的数据类型与大小，应该在字段的规定范围内。



## 第二部分：修改表数据

### 1.  修改指定条件的字段的数据：

```sql
UPDATE 表名 SET 字段名1=值1，字段名2=值2,...[WHERE 条件];
```

注意:修改语句的条件可以有，也可以没有，如果没有条件，则会修改整张表对应字段下的所有数据。



## 第三部分：删除表数据

### 1. 删除指定条件的表数据：

```sql
DELETE FROM 表名 [WHERE 条件];
```

注意:删除语句的条件可以有，也可以没有，如果没有条件，则会删除整张表的所有数据。



DELETE语句不能删除某一个字段的值(可以使用UPDATE)。

说明：`DELETE` 删除的是整行记录；如果只想清空某一行中某个字段的内容，同时保留这一行的其他数据，可以使用 `UPDATE` 将该字段设为 `NULL`（前提是字段允许为 `NULL`）。

假设 `student` 表中有以下数据，下面两个示例分别基于这份初始数据：

| id | name | age |
| --- | --- | --- |
| 1 | 张三 | 20 |
| 2 | 李四 | 22 |

```sql
-- 删除张三整行记录，执行后表中只剩李四。
DELETE FROM student WHERE id = 1;
```

```sql
-- 只清空张三的年龄，张三的 id、name 以及李四的数据都保留。
UPDATE student SET age = NULL WHERE id = 1;
```

第二个示例的预期结果：

| id | name | age |
| --- | --- | --- |
| 1 | 张三 | NULL |
| 2 | 李四 | 22 |

补充：如果要从表结构中删除整个 `age` 字段，应使用下面的 DDL 语句，执行后整张表都不再有这一列：

```sql
ALTER TABLE student DROP COLUMN age;
```
