# 存储引擎选择

在选择存储引擎时，应该根据应用系统的特点选择合适的存储引擎。
对于复杂的应用系统，还可以根据实际情况选择多种存储引擎进行组合。

## 1. InnoDB

如果应用对事务的完整性要求较高，在并发条件下要求数据的一致性，
数据操作除了插入和查询之外，还包含很多更新、删除操作，那么 InnoDB 是比较合适的选择。

## 2. MyISAM

如果应用以读操作和插入操作为主，只有很少的更新和删除操作，
并且对事务的完整性、并发性要求不高，可以考虑选择 MyISAM 存储引擎。

## 3. MEMORY

将所有数据保存在内存中，访问速度快，通常用于存放临时数据及缓存。
缺点是对表的大小有限制，太大的表无法缓存在内存中，而且无法保障数据的持久性。
