# 存储过程中的变量

语法中的 `[]` 表示可选内容，`|` 表示二选一，实际编写 SQL 时不写这些符号。以下示例均为学习示例，预期结果不代表已经执行。

## 1. 系统变量

系统变量是 MySQL 服务器提供的，不是用户定义的，属于服务器层面。分为全局变量（GLOBAL）和会话变量（SESSION）。

- **GLOBAL**：全局值；对于同时支持全局和会话作用域的变量，新连接通常用全局值初始化自己的会话值。
- **SESSION**：当前连接的会话值，只影响当前连接。

### 1.1 查看系统变量

**（1）查看所有系统变量**

```sql
-- 语法
SHOW [SESSION | GLOBAL] VARIABLES;

-- 示例：查看当前会话的所有系统变量
SHOW SESSION VARIABLES;

-- 示例：查看所有全局系统变量
SHOW GLOBAL VARIABLES;

-- 示例：省略作用域，默认查看会话值
SHOW VARIABLES;
```

预期返回变量名称及对应值，具体内容取决于当前服务器配置。

**（2）通过 LIKE 模糊匹配查找变量**

```sql
-- 语法
SHOW [SESSION | GLOBAL] VARIABLES LIKE '匹配模式';

-- 示例：查看当前会话中名称以 auto 开头的系统变量
SHOW SESSION VARIABLES LIKE 'auto%';

-- 示例：查看全局自动提交开关
SHOW GLOBAL VARIABLES LIKE 'autocommit';
```

`%` 可以匹配任意数量的字符；第二条示例返回 `autocommit` 及其全局值，通常显示为 `ON` 或 `OFF`。

**（3）查看指定系统变量的值**

```sql
-- 语法：作用域省略时，连同点号一起省略
SELECT @@[SESSION. | GLOBAL.]系统变量名;

-- 示例：查看当前会话的自动提交开关
SELECT @@SESSION.autocommit;

-- 示例：查看全局自动提交开关
SELECT @@GLOBAL.autocommit;

-- 示例：不指定作用域，优先读取会话值
SELECT @@autocommit;
```

对于 `autocommit`，返回 `1` 表示开启，`0` 表示关闭。

### 1.2 设置系统变量

**（1）使用 SESSION / GLOBAL 关键字设置**

```sql
-- 语法
SET [SESSION | GLOBAL] 系统变量名 = 值;

-- 示例：开启当前会话的自动提交
SET SESSION autocommit = 1;

-- 示例：把全局自动提交默认值设为开启，供后续新连接使用
SET GLOBAL autocommit = 1;
```

第一条示例执行成功后，当前连接的 `@@SESSION.autocommit` 为 `1`；第二条设置全局值，不会同步修改已有连接的会话值。

**（2）使用 @@ 设置**

```sql
-- 语法
SET @@[SESSION. | GLOBAL.]系统变量名 = 值;

-- 示例：开启当前会话的自动提交
SET @@SESSION.autocommit = 1;

-- 示例：开启全局自动提交默认值
SET @@GLOBAL.autocommit = 1;

-- 示例：省略作用域，设置当前会话的自动提交
SET @@autocommit = 1;
```

这些写法与上一组对应作用域的 `SET` 写法效果相同。

### 1.3 注意事项

- 截图中的 `@@` 写法省略了作用域后面的点号，实际应写成 `@@SESSION.变量名` 或 `@@GLOBAL.变量名`。
- `SHOW VARIABLES` 和设置系统变量的 `SET` 未指定作用域时，默认使用 SESSION；`SELECT @@变量名` 优先读取会话值，没有会话值时读取全局值。
- 并非每个系统变量都同时支持两种作用域，也不是所有系统变量都能动态修改；设置全局变量通常需要管理权限。
- 普通 `SET GLOBAL` 修改不会在 MySQL 重启后保留。截图提到可写入 `/etc/my.cnf`，实际配置文件路径取决于安装方式；MySQL 8.4 也支持对适用变量使用 `SET PERSIST` 持久化。

作用域和持久化说明参见 [MySQL 官方文档：系统变量](https://dev.mysql.com/doc/refman/8.4/en/using-system-variables.html)。

## 2. 用户定义变量

用户定义变量是用户根据需要自行定义的变量，不用提前声明，使用 `@变量名` 访问。其作用域为当前连接，其他连接不能直接使用本连接的变量。

### 2.1 赋值

**（1）使用 SET 和 = 赋值**

```sql
-- 语法
SET @var_name = expr [, @var_name = expr] ...;

-- 示例：把学生姓名设为张三，年龄设为 18
SET @student_name = '张三', @student_age = 18;
```

赋值后，`@student_name` 为 `'张三'`，`@student_age` 为 `18`。`expr` 表示值或表达式。

**（2）使用 SET 和 := 赋值**

```sql
-- 语法
SET @var_name := expr [, @var_name := expr] ...;

-- 示例：把学生姓名设为李四，年龄设为 20
SET @student_name := '李四', @student_age := 20;
```

赋值后，`@student_name` 为 `'李四'`，`@student_age` 为 `20`。在 `SET` 中，`=` 和 `:=` 都可以用于赋值。

**（3）使用 SELECT 和 := 赋值**

```sql
-- 语法
SELECT @var_name := expr [, @var_name := expr] ...;

-- 示例：设置学生姓名和年龄，同时返回赋值结果
SELECT @student_name := '王五', @student_age := 22;
```

预期返回 `'王五'` 和 `22`，并保存到对应变量中。这里的 `:=` 表示赋值，不能直接换成用于比较的 `=`。

> 该写法按截图保留。MySQL 8.4 中，在 `SELECT` 表达式内用 `:=` 给用户变量赋值已被弃用，新代码优先使用 `SET` 或 `SELECT ... INTO`。参见 [MySQL 官方文档：用户定义变量](https://dev.mysql.com/doc/refman/8.4/en/user-variables.html)。

**（4）使用 SELECT ... INTO 保存查询结果**

以下用户变量与局部变量查询示例共用一张临时表。在已选择的练习数据库中，使用同一连接先准备数据：

```sql
-- 示例：创建用于变量练习的临时学生表
CREATE TEMPORARY TABLE variable_demo_student (
    id INT PRIMARY KEY,
    name VARCHAR(20),
    age INT
);

-- 示例：插入两名学生，供后续查询赋值
INSERT INTO variable_demo_student (id, name, age)
VALUES (1, '张三', 18), (2, '李四', 20);
```

赋值语法与示例：

```sql
-- 语法
SELECT 字段名 INTO @var_name FROM 表名;

-- 示例：查询编号为 1 的学生姓名，保存到用户变量中
SELECT s.name INTO @student_name
FROM variable_demo_student AS s
WHERE s.id = 1;
```

赋值后，`@student_name` 为 `'张三'`。这里通过主键条件保证只查询一行。

### 2.2 使用

```sql
-- 语法
SELECT @var_name;

-- 示例：在上一条查询赋值后，读取学生姓名
SELECT @student_name;
-- 预期结果：张三

-- 示例：读取当前连接中从未赋值的用户变量
SELECT @variable_demo_uninitialized;
-- 预期结果：NULL（前提是该变量之前未被赋值）
```

用户定义变量无需提前声明或初始化；未赋值时读取到的值为 `NULL`。

## 3. 局部变量

局部变量是在局部范围内生效的变量，使用前需要通过 `DECLARE` 声明。其作用域是声明它的 `BEGIN ... END` 块，也可在该块的嵌套块中访问，除非被同名变量遮蔽。

截图把局部变量与输入参数放在一起介绍；两者都可以在存储过程中使用，但输入参数在存储过程的参数列表中定义，不使用 `DECLARE` 声明。

### 3.1 声明

```sql
-- 语法
DECLARE 变量名 变量类型 [DEFAULT 默认值];

-- 示例：声明整数变量 v_age，默认值为 18
DECLARE v_age INT DEFAULT 18;

-- 示例：声明姓名变量，不指定默认值时初始值为 NULL
DECLARE v_name VARCHAR(20);
```

变量类型就是数据库字段类型，例如 `INT`、`BIGINT`、`CHAR`、`VARCHAR`、`DATE`、`TIME` 等。

`DECLARE` 必须放在所属块的开头、可执行语句之前。上述片段需要写在存储程序的 `BEGIN ... END` 中，不能直接作为普通独立 SQL 执行。参见 [MySQL 官方文档：局部变量声明](https://dev.mysql.com/doc/refman/8.4/en/declare-local-variable.html)。

### 3.2 赋值

**（1）使用 SET 和 = 赋值**

```sql
-- 语法
SET 变量名 = 值;

-- 示例：把已经声明的局部变量 v_age 设为 20
SET v_age = 20;
```

**（2）使用 SET 和 := 赋值**

```sql
-- 语法
SET 变量名 := 值;

-- 示例：把已经声明的局部变量 v_age 设为 22
SET v_age := 22;
```

两种 `SET` 写法都可以给局部变量赋值。参见 [MySQL 官方文档：SET 赋值语法](https://dev.mysql.com/doc/refman/8.4/en/set-variable.html)。

**（3）使用 SELECT ... INTO 保存查询结果**

```sql
-- 语法
SELECT 字段名 INTO 变量名 FROM 表名 ...;

-- 示例：查询编号为 1 的学生姓名，保存到已声明的局部变量 v_name 中
SELECT s.name INTO v_name
FROM variable_demo_student AS s
WHERE s.id = 1;
```

赋值后，`v_name` 为 `'张三'`。局部变量直接使用变量名，不加 `@`。

### 3.3 完整存储过程示例

先在同一连接中准备第 2.1 节的临时表及数据，再创建并调用下面的存储过程。`DELIMITER` 是 mysql 命令行客户端的分隔符命令，用于让客户端完整提交包含分号的存储过程定义。

```sql
DELIMITER $$

-- 示例：创建一个演示局部变量声明、赋值和查询的存储过程
CREATE PROCEDURE demo_local_variables()
BEGIN
    -- 声明局部变量，必须放在可执行语句之前
    DECLARE v_age INT DEFAULT 18;
    DECLARE v_name VARCHAR(20);

    -- 示例：读取默认值，预期返回 18 和 NULL
    SELECT v_age AS initial_age, v_name AS initial_name;

    -- 示例：使用 = 把年龄设为 20
    SET v_age = 20;

    -- 示例：读取赋值后的年龄，预期返回 20
    SELECT v_age AS age_after_equal;

    -- 示例：使用 := 把年龄设为 22
    SET v_age := 22;

    -- 示例：从临时表中查询张三的姓名，保存到局部变量
    SELECT s.name INTO v_name
    FROM variable_demo_student AS s
    WHERE s.id = 1;

    -- 示例：返回最终姓名和年龄，预期返回 张三、22
    SELECT v_name AS student_name, v_age AS student_age;
END$$

DELIMITER ;

-- 示例：调用存储过程，依次返回上述三个查询结果集
CALL demo_local_variables();
```

过程结束后，不能在外部通过 `SELECT v_age` 读取这个局部变量；而用户定义变量 `@student_name` 在当前连接中仍然可以使用。
