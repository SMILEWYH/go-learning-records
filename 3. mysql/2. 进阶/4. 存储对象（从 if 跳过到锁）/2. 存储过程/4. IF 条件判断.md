# IF 条件判断

## 1. 语法

```sql
IF 条件1 THEN
    -- 条件1成立时执行的 SQL 语句
    ......
ELSEIF 条件2 THEN    -- 可选
    -- 条件1不成立、条件2成立时执行的 SQL 语句
    ......
ELSE                -- 可选
    -- 以上条件都不成立时执行的 SQL 语句
    ......
END IF;
```

- 从上到下判断条件，只执行第一个条件成立的分支。
- `ELSEIF` 可以省略，也可以有多个；`ELSE` 可以省略。
- 如果所有条件都不成立，且没有 `ELSE`，则不执行任何分支。
- 分支中的每条 SQL 语句需要以分号结束，整个判断以 `END IF;` 结束。
- 这里的 `IF` 是存储程序中的流程控制语句，需要放在存储过程等存储程序中使用。

## 2. 示例：根据分数判断成绩等级

假设传入的分数为 0～100 的整数，判断规则如下：

- 大于等于 90 分：优秀。
- 大于等于 60 分且小于 90 分：及格。
- 小于 60 分：不及格。

在已选择的练习数据库中创建存储过程。`IN p_score INT` 表示接收一个整数类型的输入参数；`DELIMITER` 是 mysql 命令行客户端用于切换语句分隔符的命令。

```sql
DELIMITER $$

-- 示例：创建根据分数返回成绩等级的存储过程
CREATE PROCEDURE demo_if_grade(IN p_score INT)
BEGIN
    IF p_score >= 90 THEN
        SELECT '优秀' AS grade;
    ELSEIF p_score >= 60 THEN
        SELECT '及格' AS grade;
    ELSE
        SELECT '不及格' AS grade;
    END IF;
END$$

DELIMITER ;

-- 示例：95 分满足第一个条件，返回“优秀”
CALL demo_if_grade(95);

-- 示例：75 分不满足第一个条件，但满足第二个条件，返回“及格”
CALL demo_if_grade(75);

-- 示例：50 分不满足前两个条件，执行 ELSE，返回“不及格”
CALL demo_if_grade(50);
```

预期结果：

| 调用语句 | grade |
| --- | --- |
| `CALL demo_if_grade(95);` | 优秀 |
| `CALL demo_if_grade(75);` | 及格 |
| `CALL demo_if_grade(50);` | 不及格 |

95 分虽然也满足 `p_score >= 60`，但第一个分支已经成立，因此不会再执行 `ELSEIF` 分支。第二个条件无需重复写 `p_score < 90`。
