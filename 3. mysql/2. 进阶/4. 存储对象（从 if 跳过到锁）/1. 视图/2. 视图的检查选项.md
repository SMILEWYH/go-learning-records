# 视图的检查选项

## 1. 介绍

当使用 `WITH CHECK OPTION` 子句创建视图时，MySQL 会通过视图检查正在更改的每个行，例如插入、更新，以使其符合视图的定义。MySQL 允许基于另一个视图创建视图，它还会检查依赖视图中的规则以保持一致性。

为了确定检查的范围，MySQL 提供了两个选项：`CASCADED` 和 `LOCAL`，默认值为 `CASCADED`。

## 2. CASCADED

总结：视图带 CASCADED，那么当前这个视图就会检查条件，并且依赖的视图无论带不带 CASCADED 都要检查条件。视图不带 CASCADED，那么当前这个视图不会检查条件，而依赖的视图要看它带不带 CASCADED。

## 3. LOCAL

总结：视图带 LOCAL，那么当前这个视图就会检查条件，而依赖的视图检不检查条件看它带不带`WITH CHECK OPTION`。视图不带 LOCAL，那么当前这个视图不会检查条件，而依赖的视图检不检查条件看它带不带`WITH CHECK OPTION`。





总结从最顶层的视图出发的视角：

> **CASCADED：**检查当前视图的条件，并强行检查所有依赖视图的条件，无论依赖视图有没有检查选项。
>
> **LOCAL：**检查当前视图的条件，再继续按依赖视图各自的检查选项处理。
>
> **不写 WITH CHECK OPTION：**跳过当前视图自身的条件检查，再继续按依赖视图各自的检查选项处理。
