# Gin 升级验收记录

验证日期：2026-09-28。环境：macOS arm64，Go 1.27.1，Gin v1.12.0；模块声明 go 1.27.0。

## 检查结果

- `go test -race -cover ./...`：通过，执行路径未发现数据竞争。
- `go vet ./...`：通过。
- `go build -trimpath -ldflags '-X main.version=gin-v1.0.0' -o <临时程序路径> .`：通过。
- Gin 路由 404/405 和 panic 恢复返回 JSON；405 包含 Allow，panic 细节不写入响应。

本轮语句覆盖率：业务包 74.3%，文件包 77.6%，Web 包 85.9%。main 和 demo 通过实际进程验证，不计入单元测试覆盖率。覆盖率只说明本轮运行到的代码，不代表全部行为都得到证明。

## 实际进程验证

实际启动后验证商品创建、补货、下单、重复请求、订单详情、取消、状态筛选和 405。使用同一临时状态文件重启，确认取消状态保留。原 `go run ./cmd/demo` 通过。

所有临时服务接收 SIGTERM 后正常退出，退出码为 0。测试使用临时目录和本机随机端口，没有写入项目正式 data 或 reports 目录。

## 文件与范围

升级在独立副本中完成。对原文件夹的 58 个文件执行 SHA-256 前后对照，内容一致。交付包含源码、go.mod、go.sum、请求示例和文档，不复制原版二进制。

本次未进行公网部署或 Linux 实机验证。项目按本机学习场景运行，业务继续使用 JSON 文件。原版历史记录见 [原版验收记录](原版验收记录.md)。
