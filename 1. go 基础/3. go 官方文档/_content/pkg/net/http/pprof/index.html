pprof 包通过 HTTP 服务器提供运行时性能分析数据，格式符合 pprof 可视化工具的要求。

通常仅为注册 HTTP 处理器这一副作用而导入本包。它处理的路径均以 /debug/pprof/ 开头。从 Go 1.22 起，所有这些路径都必须使用 GET 请求。

使用 pprof 时，将本包链接到程序中： 

import _ "net/http/pprof"

如果应用尚未运行 HTTP 服务器，需要启动一个。将“net/http”和“log”加入导入列表，并在 main 函数中添加以下代码： 

go func() {
	log.Println(http.ListenAndServe("localhost:6060", nil))
}()

默认情况下，runtime/pprof.Profile 中列出的全部分析数据（通过 Handler 提供）均可访问；本包还提供 Cmdline、Profile、Symbol 和 Trace 分析端点。如果没有使用 DefaultServeMux，则必须将处理器注册到所使用的 mux 上。

参数

参数可以通过 GET 查询参数传入：

  • debug=N（所有分析数据）：响应格式；N = 0：二进制（默认），N > 0：纯文本
  • gc=N（heap 分析）：N > 0：分析前执行一次垃圾回收
  • seconds=N（allocs、block、goroutine、heap、mutex、threadcreate 分析）：返回增量分析数据
  • seconds=N（cpu（profile）、trace 分析）：采集指定时长的数据

用法示例

使用 pprof 工具查看堆分析数据： 

go tool pprof http://localhost:6060/debug/pprof/heap

或者查看 30 秒的 CPU 分析数据： 

go tool pprof http://localhost:6060/debug/pprof/profile?seconds=30

或者在程序中调用 runtime.SetBlockProfileRate 后，查看 goroutine 阻塞分析数据： 

go tool pprof http://localhost:6060/debug/pprof/block

或者在程序中调用 runtime.SetMutexProfileFraction 后，查看发生竞争的互斥锁由谁持有： 

go tool pprof http://localhost:6060/debug/pprof/mutex

本包还导出一个处理器，为“go tool trace”命令提供执行跟踪数据。采集 5 秒的执行跟踪： 

curl -o trace.out http://localhost:6060/debug/pprof/trace?seconds=5
go tool trace trace.out

要查看所有可用的分析数据，请在浏览器中打开 http://localhost:6060/debug/pprof/。

关于这些功能的实际应用案例，请访问 https://go.dev/blog/pprof。

func Cmdline 

func Cmdline(w http.ResponseWriter, r *http.Request)

Cmdline 返回正在运行程序的命令行，参数以 NUL 字节分隔。包初始化时将它注册到 /debug/pprof/cmdline。

func Handler 

func Handler(name string) http.Handler

Handler 返回一个提供指定名称分析数据的 HTTP 处理器。可用的分析类型见 runtime/pprof.Profile。

func Index 

func Index(w http.ResponseWriter, r *http.Request)

Index 返回请求指定名称的 pprof 格式分析数据。例如，“/debug/pprof/heap”提供“heap”分析数据。对于“/debug/pprof/”请求，Index 返回列出所有可用分析数据的 HTML 页面。

func Profile 

func Profile(w http.ResponseWriter, r *http.Request)

Profile 返回 pprof 格式的 CPU 分析数据。采集时长由 GET 参数 seconds 指定，未指定时为 30 秒。包初始化时将它注册到 /debug/pprof/profile。

func Symbol 

func Symbol(w http.ResponseWriter, r *http.Request)

Symbol 查找请求中列出的程序计数器，并返回程序计数器到函数名的映射表。包初始化时将它注册到 /debug/pprof/symbol。

func Trace 1.5 

func Trace(w http.ResponseWriter, r *http.Request)

Trace 返回二进制形式的执行跟踪数据。跟踪时长由 GET 参数 seconds 指定，未指定时为 1 秒。包初始化时将它注册到 /debug/pprof/trace。
