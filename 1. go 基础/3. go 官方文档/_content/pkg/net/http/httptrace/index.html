func WithClientTrace
				
				1.7
			

			
func WithClientTrace(ctx context.Context, trace *ClientTrace) context.Context

			
WithClientTrace 基于给定的父上下文 ctx 返回新上下文。使用该新上下文发起的 HTTP 客户端请求，除了使用先前注册到 ctx 的钩子，还会使用给定的跟踪钩子。所提供 trace 中定义的钩子会先被调用。

			
		
		
			
			
type ClientTrace
				
				1.7
			

			
ClientTrace 是一组在传出 HTTP 请求各阶段运行的钩子。任意钩子都可以为 nil。这些函数可能从不同的 goroutine 并发调用，其中一些可能在请求完成或失败后才被调用。

ClientTrace 目前跟踪单次往返中的一个 HTTP 请求及其响应，没有跨越一系列重定向请求的钩子。

更多信息见 https://go.dev/blog/http-tracing。

			
type ClientTrace struct {
    // GetConn 在创建连接或从空闲池获取连接
    // 之前调用。hostPort 是目标或代理的
    // "host:port"。即使已有缓存的空闲连接
    // 可用，也会调用 GetConn。
    GetConn func(hostPort string)

    // GotConn 在成功获取连接后调用。
    // 没有专门用于获取连接失败的钩子；
    // 应当使用 Transport.RoundTrip
    // 返回的错误。
    GotConn func(GotConnInfo)

    // PutIdleConn 在连接放回空闲池时调用。
    // 如果 err 为 nil，表示连接已成功
    // 放回空闲池；如果 err 非 nil，
    // 则说明未放回的原因。如果通过
    // Transport.DisableKeepAlives 禁用了连接复用，则不会调用它。
    // PutIdleConn 会在调用者的 Response.Body.Close
    // 调用返回之前执行。
    // 对于 HTTP/2，目前不会使用此钩子。
    PutIdleConn func(err error)

    // GotFirstResponseByte 在响应头部的第一个字节
    // 可用时调用。
    GotFirstResponseByte func()

    // Got100Continue 在服务器回复 "100
    // Continue" 响应时调用。
    Got100Continue func()

    // Got1xxResponse 对最终非 1xx 响应之前返回的每个 1xx 信息响应头部
    // 各调用一次。即使同时定义了 Got100Continue，
    // 对于 "100 Continue" 响应也会调用 Got1xxResponse。
    // 如果它返回错误，客户端请求会以该错误值中止。
    Got1xxResponse func(code int, header textproto.MIMEHeader) error // Go 1.11

    // DNSStart 在 DNS 查询开始时调用。
    DNSStart func(DNSStartInfo)

    // DNSDone 在 DNS 查询结束时调用。
    DNSDone func(DNSDoneInfo)

    // ConnectStart 在新连接的 Dial 开始时调用。
    // 如果启用了 net.Dialer.DualStack（IPv6 "Happy Eyeballs"）
    // 支持，它可能被调用多次。
    ConnectStart func(network, addr string)

    // ConnectDone 在新连接的 Dial
    // 完成时调用。给定的 err 表示
    // 连接是否成功建立。
    // 如果启用了 net.Dialer.DualStack（"Happy Eyeballs"）
    // 支持，它可能被调用多次。
    ConnectDone func(network, addr string, err error)

    // TLSHandshakeStart 在 TLS 握手开始时调用。通过 HTTP 代理
    // 连接 HTTPS 站点时，握手发生在代理
    // 处理 CONNECT 请求之后。
    TLSHandshakeStart func() // Go 1.8

    // TLSHandshakeDone 在 TLS 握手结束后调用；握手成功时，
    // 传入连接状态，握手失败时，
    // 传入非 nil 错误。
    TLSHandshakeDone func(tls.ConnectionState, error) // Go 1.8

    // WroteHeaderField 在 Transport 写入每个请求头部后
    // 调用。调用时，这些值可能仍在
    // 缓冲区中，尚未写入网络。
    WroteHeaderField func(key string, value []string) // Go 1.11

    // WroteHeaders 在 Transport 写入所有
    // 请求头部后调用。
    WroteHeaders func()

    // 如果 Request 指定了 "Expect: 100-continue"，
    // 且 Transport 已写入请求头部，
    // 正在等待服务器的 "100 Continue" 后再写入请求体，
    // 则调用 Wait100Continue。
    Wait100Continue func()

    // WroteRequest 以写入请求及其请求体的
    // 结果为参数调用。请求重试时，
    // 它可能被调用多次。
    WroteRequest func(WroteRequestInfo)
}

type DNSDoneInfo
				
				1.7
			

			
DNSDoneInfo 包含 DNS 查询结果的信息。

			
type DNSDoneInfo struct {
    // Addrs 是 DNS 查询找到的 IPv4 和/或 IPv6
    // 地址。不得修改此切片的内容。
    Addrs []net.IPAddr

    // Err 是 DNS 查询期间发生的错误（如果有）。
    Err error

    // Coalesced 表示 Addrs 是否与另一个同时
    // 执行相同 DNS 查询的调用者共享。
    Coalesced bool
}

type GotConnInfo
				
				1.7
			

			
GotConnInfo 是 ClientTrace.GotConn 函数的参数，包含所获取连接的信息。

			
type GotConnInfo struct {
    // Conn 是所获取的连接。它由 http.Transport
    // 拥有，ClientTrace 的使用者不得读取、写入
    // 或关闭它。
    Conn net.Conn

    // Reused 表示此连接以前是否已用于
    // 其他 HTTP 请求。
    Reused bool

    // WasIdle 表示此连接是否从
    // 空闲池获取。
    WasIdle bool

    // 如果 WasIdle 为 true，IdleTime 表示连接
    // 此前处于空闲状态的时长。
    IdleTime time.Duration
}
