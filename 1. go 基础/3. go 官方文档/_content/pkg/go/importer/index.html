func Default 1.5 

func Default() types.Importer

Default 返回适用于构建当前运行二进制文件的编译器的 Importer。如果支持，返回值会实现 types.ImporterFrom。

Default 在最简单的场景中可能很方便，但大多数调用方应改用 ForCompiler，它接受调用方提供的 token.FileSet；没有 FileSet，通过 Importer 得到的所有位置信息都会不正确，并产生误导。另见包文档。

func ForCompiler 1.12 

func ForCompiler(fset *token.FileSet, compiler string, lookup Lookup) types.Importer

ForCompiler 返回一个 Importer：对于“gc”和“gccgo”编译器，从已安装的包导入；如果 compiler 参数为“source”，则直接从源代码导入。后一种情况下，如果导出的 API 并非完全由纯 Go 源代码定义，导入可能失败；例如，包 API 依赖 cgo 定义的实体时，类型检查器无法访问这些实体。

每当返回的导入器需要解析导入路径时，都会调用 lookup 函数。在这种模式下，只能使用规范导入路径（不能使用相对路径或绝对路径）调用导入器；假定调用方已经完成向规范导入路径的转换。

要正确支持模块，必须提供 lookup 函数。将 lookup 设为 nil 的做法已弃用，但为保持向后兼容，此时导入器会尝试在 $GOPATH 工作区中解析导入。

type Lookup 1.5

Lookup 函数返回一个读取器，用于访问给定导入路径对应的包数据；如果找不到匹配的包，则返回错误。
