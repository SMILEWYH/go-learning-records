constraint 包实现构建约束行的解析与求值。构建约束本身的文档见 https://golang.org/cmd/go/#hdr-Build_constraints。

本包同时解析原来的“// +build”语法和 Go 1.17 新增的“//go:build”语法。有关“//go:build”语法的细节，参见 https://golang.org/design/draft-gobuild。

func GoVersion 1.21 

func GoVersion(x Expr) string

GoVersion 返回给定构建表达式隐含要求的最低 Go 版本。如果不依赖任何 Go 版本标签也能满足该表达式，则返回空字符串。

例如：

GoVersion(linux && go1.22) = "go1.22"
GoVersion((linux && go1.22) || (windows && go1.20)) = "go1.20" => go1.20
GoVersion(linux) = ""
GoVersion(linux || (windows && go1.22)) = ""
GoVersion(!go1.22) = ""

GoVersion 假设任何标签及其否定都可能独立为真，因此只需进行结构分析，无需解决布尔可满足性（SAT）问题。由此，“不可能成立”的子表达式也可能影响结果。

例如：

GoVersion((linux && !linux && go1.20) || go1.21) = "go1.20"

type Expr 1.16

Expr 是构建标签约束表达式。其底层具体类型为 *AndExpr、*OrExpr、*NotExpr 或 *TagExpr。

type Expr interface {
    // String 返回表达式的字符串形式，
    // 使用 //go:build 行中的布尔语法。
    String() string

    // Eval 报告表达式的求值结果是否为 true。
    // 它按需调用 ok(tag)，判断给定的构建标签
    // 是否被当前构建配置满足。
    Eval(ok func(tag string) bool) bool
    // 包含已过滤或未导出的方法
}
