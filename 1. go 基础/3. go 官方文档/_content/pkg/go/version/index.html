func Compare 1.22 

func Compare(x, y string) int

Compare 将 x 和 y 解释为 Go 版本，根据 x < y、x == y 或 x > y，分别返回 -1、0 或 +1。x 和 y 必须以“go”为前缀，例如“go1.21”，而不是“1.21”。无效版本（包括空字符串）小于任何有效版本，彼此之间则相等。语言版本“go1.21”小于候选发布版“go1.21rc1”和最终发布版“go1.21.0”。

func Lang 1.22 

func Lang(x string) string

Lang 返回版本 x 对应的 Go 语言版本。如果 x 不是有效版本，则返回空字符串。例如：

Lang("go1.21rc2") = "go1.21"
Lang("go1.21.2") = "go1.21"
Lang("go1.21") = "go1.21"
Lang("go1") = "go1"
Lang("bad") = ""
Lang("1.21") = ""
