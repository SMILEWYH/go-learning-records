func Fprint 

func Fprint(output io.Writer, fset *token.FileSet, node any) error

Fprint 将 AST 节点以易读的格式写入 output。它使用默认设置调用 Config.Fprint。注意，gofmt 使用制表符缩进、空格对齐；如需与 gofmt 一致的输出，请使用 go/format 包中的 format.Node。

▾ 示例

funcAST, fset := parseFunc("example_test.go", "printSelf")

var buf bytes.Buffer
printer.Fprint(&buf, fset, funcAST.Body)

s := buf.String()
s = s[1 : len(s)-1]
s = strings.TrimSpace(strings.ReplaceAll(s, "\n\t", "\n"))

fmt.Println(s)

type CommentedNode

CommentedNode 将 AST 节点与对应的注释组合在一起，可以作为任意 Fprint 函数的实参。

type CommentedNode struct {
    Node     any // *ast.File，或 ast.Expr、ast.Decl、ast.Spec、ast.Stmt
    Comments []*ast.CommentGroup
}

type Config

Config 节点控制 Fprint 的输出。

type Config struct {
    Mode     Mode // 默认值：0
    Tabwidth int  // 默认值：8
    Indent   int  // 默认值：0（所有代码至少缩进此数量）；Go 1.1 新增
}

func (*Config) Fprint 

func (cfg *Config) Fprint(output io.Writer, fset *token.FileSet, node any) error

Fprint 根据给定配置 cfg，将 AST 节点以易读的格式写入 output。位置信息相对于文件集 fset 解释。node 的类型必须是 *ast.File、*CommentedNode、[]ast.Decl、[]ast.Stmt，或可赋值给 ast.Expr、ast.Decl、ast.Spec 或 ast.Stmt。

type Mode

Mode 值是一组标志（也可以为 0），用于控制打印行为。

type Mode uint
const (
    RawFormat Mode = 1 << iota // 不使用 tabwriter；若设置此标志，则忽略 UseSpaces
    TabIndent                  // 使用制表符缩进，不受 UseSpaces 影响
    UseSpaces                  // 使用空格而非制表符对齐
    SourcePos                  // 输出 //line 指令，以保留原始源代码位置
)
