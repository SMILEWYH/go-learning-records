Scanner 保存处理给定文本时词法分析器的内部状态。它可以作为其他数据结构的一部分分配，但使用前必须通过 Scanner.Init 初始化。

func (*Scanner) End 1.27 

func (s *Scanner) End() token.Pos

End 返回最近一次扫描所得词法单元之后紧邻的位置。如果尚未调用 Scanner.Scan，则返回 token.NoPos。

func (*Scanner) Init 

func (s *Scanner) Init(file *token.File, src []byte, err ErrorHandler, mode Mode)

Init 将扫描器 s 定位到 src 的开头，为其对文本 src 进行词法分析做准备。扫描器使用文件集中的 file 记录位置信息，并为每行添加行信息。重新扫描同一个文件时可以复用 file，因为已有的行信息会被忽略。如果 file 的大小与 src 大小不匹配，Init 会触发 panic。

调用 Scanner.Scan 时，如果遇到语法错误且 err 非 nil，就会调用错误处理器 err。每遇到一个错误，Scanner 的 ErrorCount 字段还会加一。mode 参数决定如何处理注释。

如果文件的第一个字符就存在错误，Init 也可能调用 err。

func (*Scanner) Scan 

func (s *Scanner) Scan() (pos token.Pos, tok token.Token, lit string)

Scan 扫描下一个词法单元，返回其位置、词法单元类型，以及适用时的字面量字符串。源文本结束以 token.EOF 表示。

如果返回的是字面量词法单元（token.IDENT、token.INT、token.FLOAT、token.IMAG、token.CHAR、token.STRING）或 token.COMMENT，字面量字符串就是其对应的值。

如果返回的是关键字，字面量字符串就是该关键字。

如果返回的词法单元为 token.SEMICOLON，当源代码中实际存在分号时，字面量字符串为“;”；如果分号是因为换行或 EOF 而自动插入的，则为“\n”。如果换行位于 /*...*/ 注释内，SEMICOLON 会紧接 COMMENT 词法单元之后合成，其位置是注释内实际换行的位置。

如果返回的词法单元为 token.ILLEGAL，字面量字符串就是出错字符。

其他情况下，Scan 返回空的字面量字符串。

为提高解析容错能力，即使遇到语法错误，Scan 也会尽可能返回有效词法单元。因此，即使得到的词法单元序列中没有非法单元，调用方也不能假定未发生错误，而必须检查扫描器的 ErrorCount，或者已设置的错误处理器被调用的次数。

Scan 将行信息添加到通过 Init 加入文件集的文件中。词法单元位置相对于该文件，因此也相对于文件集。
