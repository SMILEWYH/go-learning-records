flag 包实现命令行标志解析。

用法

使用 flag.String、Bool、Int 等函数定义标志。

下面声明了一个整数标志 -n，其值存储在指针 nFlag 指向的位置，nFlag 的类型为 *int： 

import "flag"
var nFlag = flag.Int("n", 1234, "help message for flag n")

也可以使用 Var() 系列函数将标志绑定到变量。 

var flagvar int
func init() {
	flag.IntVar(&flagvar, "flagname", 1234, "help message for flagname")
}

还可以创建满足 Value 接口的自定义标志（使用指针接收者），然后将其接入标志解析流程： 

flag.Var(&flagVal, "name", "help message for flagname")

对于这样的标志，默认值就是变量的初始值。

定义完所有标志后，调用 

flag.Parse()

将命令行解析为已定义标志的值。

之后便可以直接使用这些标志。如果直接使用定义函数返回的标志，它们都是指针；如果绑定到了变量，则使用变量的值。 

fmt.Println("ip has value ", *ip)
fmt.Println("flagvar has value ", flagvar)

解析后，标志之后的参数可以通过切片 flag.Args 获取，也可以通过 flag.Arg(i) 逐个获取。参数索引从 0 到 flag.NArg-1。

命令行标志语法

允许以下形式： 

-flag
--flag   // 也允许使用两个连字符
-flag=x
-flag x  // 仅适用于非布尔标志

可以使用一个或两个连字符，两者等价。最后一种形式不适用于布尔标志，因为下面命令的含义 

cmd -x *

会因存在名为 0、false 等文件而改变，其中 * 是 Unix shell 通配符。必须使用 -flag=false 形式关闭布尔标志。

标志解析会在第一个非标志参数之前停止（"-" 是非标志参数），或者在终止符 "--" 之后停止。

整数标志接受 1234、0664、0x1234 等形式，也可以是负数。布尔标志可以是： 

1, 0, t, f, T, F, true, false, TRUE, FALSE, True, False

时长标志接受任何对 time.ParseDuration 有效的输入。

默认的命令行标志集合由包级函数管理。FlagSet 类型允许定义相互独立的标志集合，例如用于实现命令行界面的子命令。FlagSet 的方法与管理默认命令行标志集合的包级函数相对应。

当使用了 -help 或 -h 标志，但并未定义相应标志时，会返回 ErrHelp 错误。

				
var ErrHelp = errors.New("flag: help requested")

			
				
Usage 将说明所有已定义命令行标志的用法信息写入 CommandLine 的输出，默认输出为 os.Stderr。解析标志时发生错误会调用它。该函数本身是一个变量，可以将其改为指向自定义函数。默认情况下，它打印简单的标题，然后调用 PrintDefaults；输出格式及其控制方式请参阅 PrintDefaults 文档。自定义用法函数可以自行退出程序；默认情况下，由于命令行错误处理策略设为 ExitOnError，程序无论如何都会退出。

				
var Usage = func() {
    fmt.Fprintf(CommandLine.Output(), "Usage of %s:\n", os.Args[0])
    PrintDefaults()
}

func PrintDefaults
				
				
			

			
func PrintDefaults()

			
PrintDefaults 打印用法信息，显示所有已定义命令行标志的默认设置。除非另行配置，否则写入标准错误。对于整数类型的标志 x，默认输出形式为：

-x int
	usage-message-for-x (default 7)



除名称只有一个字节的布尔标志外，用法信息都显示在单独一行。对于布尔标志，省略类型；如果标志名称只有一个字节，用法信息显示在同一行。如果默认值是该类型的零值，则省略括号中的默认值。可以在标志的用法字符串中放入一个以反引号括起的名称，以更改显示的类型（此处为 int）：用法信息中的第一个此类名称被视为要显示的参数名，显示时会去掉反引号。例如，给定

flag.String("I", "", "search `directory` for include files")



输出为

-I directory
	search directory for include files.



若要更改标志消息的输出目标，请调用 CommandLine.SetOutput。

type FlagSet
				
				
			

			
FlagSet 表示一组已定义的标志。FlagSet 的零值没有名称，采用 ContinueOnError 错误处理方式。

Flag 的名称在同一个 FlagSet 中必须唯一。尝试定义名称已被使用的标志会触发 panic。

			
type FlagSet struct {
    // Usage 是解析标志时发生错误所调用的函数。
    // 此字段是函数（不是方法），可以改为指向
    // 自定义错误处理函数。调用 Usage 之后的行为取决于
    // ErrorHandling 设置；对于命令行，默认设置
    // 为 ExitOnError，即调用 Usage 后退出程序。
    Usage func()
    // 包含已过滤或未导出的字段
}

type Getter
				
				1.2
			

			
Getter 是用于获取 Value 内容的接口。它嵌入 Value 接口，而不是成为后者的一部分，因为它是在 Go 1 及其兼容性规则确定之后才引入的。本包提供的所有 Value 类型都满足 Getter 接口，唯有 Func 使用的类型例外。

			
type Getter interface {
    Value
    Get() any
}


			

			

			

			

			
		
			
			
type Value
				
				
			

			
Value 是访问标志所存储动态值的接口。（默认值用字符串表示。）

如果某个 Value 具有返回 true 的 IsBoolFlag() bool 方法，命令行解析器会将 -name 视为等价于 -name=true，而不会使用下一个命令行参数。

对于命令行中每次出现的标志，都会按命令行顺序调用一次 Set。flag 包可能使用零值接收者（例如 nil 指针）调用 String 方法。

			
type Value interface {
    String() string
    Set(string) error
}
