bufio 包实现带缓冲的 I/O。它包装 io.Reader 或 io.Writer 对象，创建一个同样实现相应接口的 Reader 或 Writer，并提供缓冲能力和一些方便文本 I/O 的辅助功能。

ErrFinalToken 是一个特殊的哨兵错误值。分割函数可返回它，表示扫描应当正常停止，不报告错误。如果同时返回的 token 非 nil，它就是最后一个 token。

这个值适用于提前结束处理，或需要返回最后一个空 token 的情况；空 token 与 nil token 不同。虽然自定义错误值也能实现相同效果，但在这里统一提供更简洁。使用示例见 emptyFinalToken。

func ScanLines 1.1 

func ScanLines(data []byte, atEOF bool) (advance int, token []byte, err error)

ScanLines 是用于 Scanner 的分割函数，返回每行文本，并去掉末尾的行结束标记。返回的行可以为空。行结束标记由一个可选的回车符和一个必需的换行符组成，用正则表达式表示为 `\r?\n`。输入的最后一个非空行即使没有换行符，也会被返回。

func ScanRunes 1.1 

func ScanRunes(data []byte, atEOF bool) (advance int, token []byte, err error)

ScanRunes 是用于 Scanner 的分割函数，将每个 UTF-8 编码的 rune 作为一个 token 返回。返回的 rune 序列，与将输入视为字符串进行 range 循环得到的序列相同，因此错误的 UTF-8 编码会被转换为 U+FFFD = "\xef\xbf\xbd"。受 Scan 接口的限制，调用方无法区分编码正确的替换字符与编码错误。

func ScanWords 1.1 

func ScanWords(data []byte, atEOF bool) (advance int, token []byte, err error)

ScanWords 是用于 Scanner 的分割函数，返回文本中由空白分隔的每个单词，并去掉两侧的空白。它永远不会返回空字符串。空白的定义由 unicode.IsSpace 决定。

func (*Reader) Discard 1.5 

func (b *Reader) Discard(n int) (discarded int, err error)

Discard 跳过接下来的 n 个字节，返回实际丢弃的字节数。

如果 Discard 跳过的字节数少于 n，还会返回错误。如果 0 <= n <= b.Buffered()，Discard 保证成功，并且不会读取底层 io.Reader。

func (*Reader) Peek 

func (b *Reader) Peek(n int) ([]byte, error)

Peek 返回接下来的 n 个字节，但不推进读取位置。返回的字节只在下一次读取调用之前有效。必要时，Peek 会向缓冲区读取更多数据，尽量凑足 n 个字节。如果返回的字节数少于 n，还会返回错误以说明原因。如果 n 大于 b 的缓冲区大小，该错误为 ErrBufferFull。

调用 Peek 后，在下一次读取操作之前，Reader.UnreadByte 和 Reader.UnreadRune 都无法成功。

func (*Reader) Read 

func (b *Reader) Read(p []byte) (n int, err error)

Read 将数据读入 p，返回读入 p 的字节数。它最多对底层 Reader 调用一次 Read，因此 n 可能小于 len(p)。要恰好读取 len(p) 个字节，请使用 io.ReadFull(b, p)。如果底层 Reader 可以同时返回非零字节数和 io.EOF，那么此 Read 方法也可能这样返回；详见 io.Reader 文档。

func (*Reader) ReadByte 

func (b *Reader) ReadByte() (byte, error)

ReadByte 读取并返回一个字节。如果没有字节可读，返回错误。

func (*Reader) ReadBytes 

func (b *Reader) ReadBytes(delim byte) ([]byte, error)

ReadBytes 读取输入，直到第一次遇到 delim，并返回包含截至该分隔符的全部数据的切片，分隔符也包含在内。如果在找到分隔符前遇到错误，ReadBytes 会返回错误发生前已读取的数据以及错误本身（通常是 io.EOF）。当且仅当返回的数据不以 delim 结尾时，err != nil。对于简单场景，Scanner 可能更方便。

func (*Reader) ReadLine 

func (b *Reader) ReadLine() (line []byte, isPrefix bool, err error)

ReadLine 是一个底层的逐行读取原语。大多数调用方应改用 Reader.ReadBytes('\n')、Reader.ReadString('\n')，或使用 Scanner。

ReadLine 尝试返回一行文本，不包含行结束字节。如果一行长于缓冲区，就将 isPrefix 设为 true，并返回该行的开头部分；剩余部分将在后续调用中返回。返回该行的最后一段时，isPrefix 为 false。返回的缓冲区只在下一次 ReadLine 调用之前有效。ReadLine 要么返回非 nil 的 line，要么返回错误，不会同时返回两者。

ReadLine 返回的文本不包含行结束符（"\r\n" 或 "\n"）。如果输入结束时没有末尾行结束符，不会给出提示或错误。在 ReadLine 后调用 Reader.UnreadByte，总是会回退最后一个实际读取的字节，即使该字节不属于 ReadLine 返回的行（它可能是行结束符中的一个字节）。

func (*Reader) ReadRune 

func (b *Reader) ReadRune() (r rune, size int, err error)

ReadRune 读取一个 UTF-8 编码的 Unicode 字符，返回对应的 rune 及其占用的字节数。如果编码无效，就消耗一个字节，并返回 unicode.ReplacementChar（U+FFFD），大小为 1。

func (*Reader) ReadSlice 

func (b *Reader) ReadSlice(delim byte) (line []byte, err error)

ReadSlice 读取输入，直到第一次遇到 delim，返回一个指向缓冲区中字节的切片。返回的字节只在下一次读取之前有效。如果在找到分隔符前遇到错误，ReadSlice 返回缓冲区中的全部数据和错误本身（通常是 io.EOF）。如果缓冲区已满但仍未找到 delim，ReadSlice 返回 ErrBufferFull 错误。由于返回的数据会被下一次 I/O 操作覆盖，大多数调用方应改用 Reader.ReadBytes 或 ReadString。当且仅当 line 不以 delim 结尾时，err != nil。

func (*Reader) ReadString 

func (b *Reader) ReadString(delim byte) (string, error)

ReadString 读取输入，直到第一次遇到 delim，返回包含截至该分隔符的全部数据的字符串，分隔符也包含在内。如果在找到分隔符前遇到错误，ReadString 返回错误发生前已读取的数据和错误本身（通常是 io.EOF）。当且仅当返回的数据不以 delim 结尾时，err != nil。对于简单场景，Scanner 可能更方便。

func (*Reader) Reset 1.2 

func (b *Reader) Reset(r io.Reader)

Reset 丢弃缓冲区中的全部数据，重置所有状态，并让这个带缓冲的读取器改为从 r 读取。对 Reader 的零值调用 Reset，会将内部缓冲区初始化为默认大小。调用 b.Reset(b)，即将 Reader 重置为自身，不执行任何操作。

func (*Reader) Size 1.10 

func (b *Reader) Size() int

Size 返回底层缓冲区的大小，单位为字节。

func (*Reader) UnreadByte 

func (b *Reader) UnreadByte() error

UnreadByte 回退最后读取的一个字节。只能回退最近一次读取的字节。

如果最近对 Reader 调用的方法不是读取操作，UnreadByte 返回错误。特别注意，Reader.Peek、Reader.Discard 和 Reader.WriteTo 不被视为读取操作。

func (*Reader) UnreadRune 

func (b *Reader) UnreadRune() error

UnreadRune 回退最后读取的一个 rune。如果最近对 Reader 调用的方法不是 Reader.ReadRune，Reader.UnreadRune 就会返回错误。（这一点比 Reader.UnreadByte 更严格，后者可回退任何读取操作所读取的最后一个字节。）

func (*Reader) WriteTo 1.1 

func (b *Reader) WriteTo(w io.Writer) (n int64, err error)

WriteTo 实现 io.WriterTo，可能多次调用底层 Reader 的 Reader.Read 方法。如果底层读取器支持 Reader.WriteTo 方法，则直接调用底层 Reader.WriteTo，不经过缓冲。

type Scanner 1.1

Scanner 提供便于读取数据的接口，例如读取以换行符分隔的文本文件。连续调用 Scanner.Scan 会依次读取文件中的 token，并跳过 token 之间的字节。token 的划分规则由 SplitFunc 类型的分割函数定义；默认分割函数按行拆分输入，并去掉行结束符。本包提供可通过 Scanner.Split 设置的分割函数，支持按行、字节、UTF-8 编码的 rune，以及空白分隔的单词扫描文件。调用方也可以提供自定义分割函数。

遇到 EOF、第一个 I/O 错误，或 token 大到无法装入 Scanner.Buffer 时，扫描会停止，而且无法恢复。扫描停止时，底层读取器可能已经向前读过最后一个 token 很远。如果程序需要更精细的错误处理、处理大 token，或必须对同一个读取器连续执行多轮扫描，应改用 bufio.Reader。

func (*Scanner) Buffer
					
					1.6
				

				
func (s *Scanner) Buffer(buf []byte, max int)

				
Buffer 控制 Scanner 的内存分配：设置扫描使用的初始缓冲区，以及扫描期间允许分配的缓冲区最大大小。缓冲区中原有的内容会被忽略。

token 的最大大小必须小于 max 和 cap(buf) 中的较大值。如果 max <= cap(buf)，Scanner.Scan 只使用这个缓冲区，不会再分配内存。

默认情况下，Scanner.Scan 使用内部缓冲区，并将 token 的最大大小设为 MaxScanTokenSize。

扫描开始后再调用 Buffer，会触发 panic。

type SplitFunc
				
				1.1
			

			
SplitFunc 是用于将输入切分为 token 的分割函数签名。参数包括剩余未处理数据的起始片段，以及表示 Reader 是否已无更多数据可读的标志 atEOF。返回值依次为输入应前进的字节数、下一个应返回给用户的 token（如果有），以及错误（如果有）。

函数返回错误时，扫描会停止，此时部分输入可能被丢弃。如果错误为 ErrFinalToken，扫描会正常停止，不报告错误。与 ErrFinalToken 一同返回的非 nil token 将作为最后一个 token；如果返回的 token 为 nil 且错误为 ErrFinalToken，扫描立即停止。

否则，Scanner 会推进输入。如果 token 非 nil，Scanner 将其返回给用户。如果 token 为 nil，Scanner 会读取更多数据并继续扫描；如果已经没有更多数据，即 atEOF 为 true，Scanner 就会返回。如果 data 还不包含完整的 token，例如逐行扫描时尚未找到换行符，SplitFunc 可以返回 (0, nil, nil)，通知 Scanner 向切片读取更多数据，再用从输入中同一位置开始的更长切片重试。

除非 atEOF 为 true，否则函数不会收到空的 data 切片。不过，即使 atEOF 为 true，data 也可能非空，并且仍然包含尚未处理的文本。

type SplitFunc func(data []byte, atEOF bool) (advance int, token []byte, err error)

Reset 丢弃所有尚未刷出的缓冲数据，清除错误，并重置 b，使其输出改为写入 w。对 Writer 的零值调用 Reset，会将内部缓冲区初始化为默认大小。调用 w.Reset(w)，即将 Writer 重置为自身，不执行任何操作。

func (b *Writer) Size() int

				
Size 返回底层缓冲区的大小，单位为字节。

func (*Writer) Write
					
					
				

				
func (b *Writer) Write(p []byte) (nn int, err error)

				
Write 将 p 的内容写入缓冲区，返回写入的字节数。如果 nn < len(p)，还会返回错误，说明未能写入全部数据的原因。

WriteByte 写入一个字节。

func (*Writer) WriteRune
					
					
				

				
func (b *Writer) WriteRune(r rune) (size int, err error)

				
WriteRune 写入一个 Unicode 码点，返回写入的字节数及可能发生的错误。

func (*Writer) WriteString
					
					
				

				
func (b *Writer) WriteString(s string) (int, error)

				
WriteString 写入一个字符串，返回写入的字节数。如果字节数小于 len(s)，还会返回错误，说明未能写入全部数据的原因。
