embed 包提供对嵌入到运行中的 Go 程序内的文件的访问。

导入“embed”的 Go 源文件可以使用 //go:embed 指令，在编译时读取包目录或其子目录中的文件内容，并用这些内容初始化 string、[]byte 或 FS 类型的变量。

例如，以下三种方式都可以嵌入名为 hello.txt 的文件，并在运行时打印其内容。

将一个文件嵌入字符串： 

import _ "embed"

//go:embed hello.txt
var s string
print(s)

将一个文件嵌入字节切片： 

import _ "embed"

//go:embed hello.txt
var b []byte
print(string(b))

将一个或多个文件嵌入文件系统： 

import "embed"

//go:embed hello.txt
var f embed.FS
data, _ := f.ReadFile("hello.txt")
print(string(data))

指令

变量声明上方的 //go:embed 指令，使用一个或多个 path.Match 模式指定要嵌入的文件。

该指令必须紧接在仅声明一个变量的代码行之前。指令与声明之间只允许出现空行和“//”行注释。

变量类型必须是字符串类型、字节类型的切片，或 FS（或 FS 的别名）。

例如： 

package server

import "embed"

// content 保存静态 Web 服务器的内容。
//go:embed image/* template/*
//go:embed html/index.html
var content embed.FS

Go 构建系统会识别这些指令，并将文件系统中匹配的文件填入所声明的变量（上例中的 content）。

为简洁起见，//go:embed 指令接受多个以空格分隔的模式；模式较多时也可以重复使用指令，避免单行过长。模式以包含源文件的包目录为基准解析。即使在 Windows 上，路径分隔符也使用正斜杠。模式不能包含“.”、“..”或空的路径分量，也不能以斜杠开头或结尾。要匹配当前目录中的所有内容，应使用“*”而不是“.”。为支持名称中包含空格的文件，模式可以写成 Go 的双引号或反引号字符串字面量。

如果模式指定一个目录，则递归嵌入以该目录为根的子树中的所有文件，但排除名称以“.”或“_”开头的文件。因此，上例中的变量几乎等价于： 

// content 是静态 Web 服务器的内容。
//go:embed image template html/index.html
var content embed.FS

区别在于，“image/*”会嵌入“image/.tempfile”，而“image”不会。两者都不会嵌入“image/dir/.tempfile”。

如果模式以“all:”为前缀，目录遍历规则就会改变，包含名称以“.”或“_”开头的文件。例如，“all:image”既会嵌入“image/.tempfile”，也会嵌入“image/dir/.tempfile”。

//go:embed 指令既可用于导出变量，也可用于未导出变量，取决于包是否希望将数据提供给其他包。它只能用于包作用域内的变量，不能用于局部变量。

模式不得匹配包所属模块之外的文件，例如“.git/*”、符号链接、“vendor/”，或任何包含 go.mod 的目录（这些目录属于独立模块）。模式不得匹配名称中包含特殊标点字符 " * < > ? ` ' | / \ 和 : 的文件。空目录匹配会被忽略；忽略之后，//go:embed 行中的每个模式都必须匹配至少一个文件或非空目录。

如果任何模式无效或匹配到无效内容，构建都会失败。

字符串与字节切片

对于 string 或 []byte 类型的变量，//go:embed 行只能包含一个模式，且该模式只能匹配一个文件。该文件的内容用于初始化 string 或 []byte。

使用 //go:embed 指令必须导入“embed”，即使变量类型为 string 或 []byte 也是如此。在不引用 embed.FS 的源文件中，应使用空白导入（import _ "embed"）。

文件系统

嵌入单个文件时，通常最好使用 string 或 []byte 类型的变量。FS 类型可以嵌入整个文件树，例如上例中存放 Web 服务器静态内容的目录。

FS 实现 io/fs 包的 FS 接口，因此可以用于任何支持文件系统的包，包括 net/http、text/template 和 html/template。

例如，给定上例中的 content 变量，可以这样写： 

http.Handle("/static/", http.StripPrefix("/static/", http.FileServer(http.FS(content))))

template.ParseFS(content, "*.tmpl")

工具

为支持分析 Go 包的工具，//go:embed 行中的模式可以从“go list”输出中取得。参见“go help list”输出中的 EmbedPatterns、TestEmbedPatterns 和 XTestEmbedPatterns 字段。

type FS
				
				1.16
			

			
FS 是一组只读文件，通常通过 //go:embed 指令初始化。如果声明时没有 //go:embed 指令，FS 就是一个空文件系统。

FS 是只读值，因此多个 goroutine 同时使用它是安全的，FS 类型的值之间相互赋值也是安全的。

FS 实现 fs.FS，因此可以用于任何支持文件系统接口的包，包括 net/http、text/template 和 html/template。

有关初始化 FS 的更多细节，参见包文档。

			
type FS struct {
    // 包含已过滤或未导出的字段
}

如果文件不是目录，返回的文件还实现 io.Seeker 和 io.ReaderAt。
