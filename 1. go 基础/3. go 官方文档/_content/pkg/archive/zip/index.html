zip 包提供读取和写入 ZIP 归档的支持。

详见 ZIP 规范。

本包不支持跨磁盘分卷。

关于 ZIP64 的说明：

为保持向后兼容，FileHeader 同时具有 32 位和 64 位的 Size 字段。64 位字段始终包含正确值；对于普通归档，两种字段的值相同。对于需要 ZIP64 格式的文件，32 位字段为 0xffffffff，此时必须使用 64 位字段。

type Compressor 1.2

Compressor 返回一个向 w 写入的新压缩写入器。必须调用 WriteCloser 的 Close 方法，将待输出的数据刷新到 w。Compressor 本身必须能由多个 goroutine 同时安全调用，但每个返回的写入器同一时刻只会由一个 goroutine 使用。

type Compressor func(w io.Writer) (io.WriteCloser, error)

type Decompressor 1.2

Decompressor 返回一个从 r 读取的新解压缩读取器。必须调用 io.ReadCloser 的 Close 方法释放关联资源。Decompressor 本身必须能由多个 goroutine 同时安全调用，但每个返回的读取器同一时刻只会由一个 goroutine 使用。

type Decompressor func(r io.Reader) io.ReadCloser

type FileHeader

FileHeader 描述 ZIP 文件中的一个文件。详见 ZIP 规范。

type FileHeader struct {
    // Name 是文件名称。
    //
    // 它必须是相对路径，不能以驱动器盘符（如 "C:"）开头，
    // 且必须使用正斜杠而非反斜杠。末尾的斜杠
    // 表示该文件是目录，不应包含数据。
    Name string

    // Comment 是用户定义的任意字符串，长度小于 64KiB。
    Comment string

    // NonUTF8 表示 Name 和 Comment 不是以 UTF-8 编码的。
    //
    // 根据规范，唯一允许的其他编码应为 CP-437，
    // 但历史上许多 ZIP 读取器会将 Name 和 Comment
    // 按系统当前的本地字符编码解释。
    //
    // 只有在用户打算为某个特定本地区域编码不可移植的
    // ZIP 文件时，才应设置此标志。否则，Writer 会为
    // 有效的 UTF-8 字符串自动设置 ZIP 格式的 UTF-8 标志。
    NonUTF8 bool // Go 1.10

    CreatorVersion uint16
    ReaderVersion  uint16
    Flags          uint16

    // Method 是压缩方法。为零时使用 Store。
    Method uint16

    // Modified 是文件的修改时间。
    //
    // 读取时，扩展时间戳优先于旧的 MS-DOS
    // 日期字段，两者的时间偏移用于确定时区。
    // 如果只有 MS-DOS 日期，则假定时区为 UTC。
    //
    // 写入时，始终输出不依赖时区的扩展时间戳。
    // 旧的 MS-DOS 日期字段则根据 Modified 时间
    // 所属的时区进行编码。
    Modified time.Time // Go 1.10

    // ModifiedTime 是采用 MS-DOS 编码的时间。
    //
    // 已弃用：请改用 Modified。
    ModifiedTime uint16

    // ModifiedDate 是采用 MS-DOS 编码的日期。
    //
    // 已弃用：请改用 Modified。
    ModifiedDate uint16

    // CRC32 是文件内容的 CRC32 校验和。
    CRC32 uint32

    // CompressedSize 是文件压缩后的字节大小。
    // 如果文件压缩前或压缩后的大小
    // 不能用 32 位表示，则将 CompressedSize 设为 ^uint32(0)。
    //
    // 已弃用：请改用 CompressedSize64。
    CompressedSize uint32

    // UncompressedSize 是文件未压缩时的字节大小。
    // 如果文件压缩前或压缩后的大小
    // 不能用 32 位表示，则将 UncompressedSize 设为 ^uint32(0)。
    //
    // 已弃用：请改用 UncompressedSize64。
    UncompressedSize uint32

    // CompressedSize64 是文件压缩后的字节大小。
    CompressedSize64 uint64 // Go 1.1

    // UncompressedSize64 是文件未压缩时的字节大小。
    UncompressedSize64 uint64 // Go 1.1

    // Extra 是可扩展数据字段。必要时，写入器会自动包含
    // 适当的 Zip64 字段，而 [Writer.Close] 会将
    // Zip64 字段的中央目录版本追加到 Extra。
    Extra []byte

    ExternalAttrs uint32 // 含义取决于 CreatorVersion
}

func OpenReader 

func OpenReader(name string) (*ReadCloser, error)

OpenReader 打开 name 指定的 Zip 文件，并返回 ReadCloser。

如果归档中的任何文件使用非本地名称（按 filepath.IsLocal 的定义）或包含反斜杠的名称，且 GODEBUG 环境变量包含 `zipinsecurepath=0`，OpenReader 会在返回读取器的同时返回 ErrInsecurePath 错误。未来的 Go 版本可能默认启用此行为。希望接受非本地名称的程序可以忽略 ErrInsecurePath 错误并使用返回的读取器。

func (*ReadCloser) Close 

func (rc *ReadCloser) Close() error

Close 关闭 Zip 文件，使其无法再用于 I/O。

func (*Writer) Create
					
					
				

				
func (w *Writer) Create(name string) (io.Writer, error)

				
Create 使用提供的名称向 zip 文件添加文件。它返回一个 Writer，应将文件内容写入其中。文件内容将使用 Deflate 方法压缩。名称必须是相对路径：不能以驱动器盘符（例如 C:）或斜杠开头，且只允许使用正斜杠。要创建目录而不是文件，请在名称末尾添加斜杠。重名条目不会覆盖之前的条目，而会追加到 zip 文件。必须在下一次调用 Writer.Create、Writer.CreateHeader 或 Writer.Close 之前，将文件内容写入该 io.Writer。
func (*Writer) CreateHeader
					
					
				

				
func (w *Writer) CreateHeader(fh *FileHeader) (io.Writer, error)

				
CreateHeader 使用提供的 FileHeader 作为文件元数据，向 zip 归档添加文件。Writer 接管 fh 的所有权，并可能修改其字段。调用方在调用 Writer.CreateHeader 之后不得再修改 fh。
此方法返回一个 Writer，应将文件内容写入其中。必须在下一次调用 Writer.Create、Writer.CreateHeader、Writer.CreateRaw 或 Writer.Close 之前，将文件内容写入该 io.Writer。
func (*Writer) CreateRaw
					
					1.17
				

				
func (w *Writer) CreateRaw(fh *FileHeader) (io.Writer, error)

				
CreateRaw 使用提供的 FileHeader 向 zip 归档添加文件，并返回一个 Writer，应将文件内容写入其中。必须在下一次调用 Writer.Create、Writer.CreateHeader、Writer.CreateRaw 或 Writer.Close 之前，将文件内容写入该 io.Writer。
与 Writer.CreateHeader 不同，传给 Writer 的字节不会被压缩。
CreateRaw 的实参会存储在 w 中。如果实参是指向某个 File 中嵌入的 FileHeader 的指针，且该 File 来自由内存数据创建的 Reader，那么 w 将引用那一整块内存。
