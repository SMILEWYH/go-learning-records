buildinfo 包用于读取嵌入 Go 二进制文件的构建信息，包括 Go 工具链版本，以及构建时使用的模块集合（适用于以模块模式构建的二进制文件）。

当前运行的二进制文件的构建信息，可通过 runtime/debug.ReadBuildInfo 获取。

func Read(r io.ReaderAt) (*BuildInfo, error)

Read 通过给定的 ReaderAt 访问 Go 二进制文件，并返回其中嵌入的构建信息。大多数信息仅适用于启用了模块支持时构建的二进制文件。
