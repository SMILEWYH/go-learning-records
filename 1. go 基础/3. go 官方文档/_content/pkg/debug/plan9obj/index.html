plan9obj 包用于访问 Plan 9 a.out 目标文件。

安全性

本包并未针对恶意输入进行安全加固，因此不在 https://go.dev/security/policy 的适用范围内。尤其是，解析目标文件时只会进行基本校验。处理不可信输入时应当谨慎，因为解析格式错误的文件可能消耗大量资源，或引发 panic。

type Section 1.3

Section 表示 Plan 9 a.out 文件中的一个节。

type Section struct {
    SectionHeader

    // 嵌入 ReaderAt 以提供 ReadAt 方法。
    // 不要直接嵌入 SectionReader，
    // 以免同时引入 Read 和 Seek。
    // 如果调用方需要 Read 和 Seek，必须使用
    // Open()，以避免与其他调用方
    // 争用定位偏移量。
    io.ReaderAt
    // 包含已过滤或未导出的字段
}

type SectionHeader 1.3

SectionHeader 表示单个 Plan 9 a.out 节头。磁盘上并不存在这种结构，但它便于在目标文件中定位和浏览。

type SectionHeader struct {
    Name   string
    Size   uint32
    Offset uint32
}
