概览 ▾

dwarf 包提供对从可执行文件加载的 DWARF 调试信息的访问，其定义见 DWARF 2.0 标准：http://dwarfstd.org/doc/dwarf-2.0.0.pdf。

安全性

本包未针对恶意输入进行安全加固，也不属于 https://go.dev/security/policy 的适用范围。特别是，解析目标文件时只会进行基本验证。因此，解析不可信输入时应保持谨慎，因为解析格式错误的文件可能消耗大量资源，或引发 panic。

type Class 1.5

Class 是属性值在 DWARF 4 中的类别。

一般而言，给定属性的值可以属于 DWARF 定义的若干可能类别之一，每种类别对该属性的解释略有不同。

DWARF 版本 4 对属性值类别的区分比早期版本更细。读取器会将早期 DWARF 版本中较粗的类别细分为适当的 DWARF 4 类别。例如，DWARF 2 对常量和所有类型的节偏移量都使用 "constant"，但对于 DWARF 2 文件中引用节偏移量的属性，读取器会将其规范化为某个 Class*Ptr 类别，即使这些类别直到 DWARF 3 才定义。

type Class int
const (
    // ClassUnknown 表示 DWARF 类别未知的值。
    ClassUnknown Class = iota

    // ClassAddress 表示 uint64 类型的值，
    // 它们是目标机器上的地址。
    ClassAddress

    // ClassBlock 表示 []byte 类型的值，
    // 其解释方式取决于属性。
    ClassBlock

    // ClassConstant 表示 int64 类型的
    // 常量值。此常量的解释方式取决于
    // 属性。
    ClassConstant

    // ClassExprLoc 表示 []byte 类型的值，其中包含
    // 编码后的 DWARF 表达式或位置描述。
    ClassExprLoc

    // ClassFlag 表示 bool 类型的值。
    ClassFlag

    // ClassLinePtr 表示 int64 类型的偏移量，
    // 指向 "line" 节。
    ClassLinePtr

    // ClassLocListPtr 表示 int64 类型的偏移量，
    // 指向 "loclist" 节。
    ClassLocListPtr

    // ClassMacPtr 表示 int64 类型的偏移量，指向
    // "mac" 节。
    ClassMacPtr

    // ClassRangeListPtr 表示 int64 类型的偏移量，指向
    // "rangelist" 节。
    ClassRangeListPtr

    // ClassReference 表示 Offset 类型的偏移量，
    // 指向 info 节中的 Entry（供 Reader.Seek 使用）。
    // DWARF 规范将 ClassReference 和
    // ClassReferenceSig 合并为 "reference" 类别。
    ClassReference

    // ClassReferenceSig 表示 uint64 类型的
    // 类型签名，引用某个类型 Entry。
    ClassReferenceSig

    // ClassString 表示字符串值。如果
    // 编译单元指定了 AttrUseUTF8 标志（强烈建议），
    // 字符串值将采用 UTF-8 编码。
    // 否则，编码方式未指定。
    ClassString

    // ClassReferenceAlt 表示 int64 类型的值，
    // 它是另一个目标文件的 DWARF "info" 节
    // 中的偏移量。
    ClassReferenceAlt

    // ClassStringAlt 表示 int64 类型的值，
    // 它是另一个目标文件的 DWARF 字符串节
    // 中的偏移量。
    ClassStringAlt

    // ClassAddrPtr 表示 int64 类型的偏移量，
    // 指向 "addr" 节。
    ClassAddrPtr

    // ClassLocList 表示 int64 类型的偏移量，
    // 指向 "loclists" 节。
    ClassLocList

    // ClassRngList 表示 uint64 类型的偏移量，
    // 相对于 "rnglists" 节的基准位置。
    ClassRngList

    // ClassRngListsPtr 表示 int64 类型的偏移量，
    // 指向 "rnglists" 节。这些值用作
    // ClassRngList 值的基准。
    ClassRngListsPtr

    // ClassStrOffsetsPtr 表示 int64 类型的
    // 偏移量，指向 "str_offsets" 节。
    ClassStrOffsetsPtr
)

type LineEntry 1.5

LineEntry 是 DWARF 行表中的一行。

type LineEntry struct {
    // Address 是编译器生成的某条机器指令的
    // 程序计数器值。此 LineEntry
    // 适用于从 Address 起到下一个 LineEntry 的
    // Address 之前为止的每条指令。
    Address uint64

    // OpIndex 是 VLIW 指令中某个操作的
    // 索引。第一个操作的索引为 0。对于
    // 非 VLIW 架构，它始终为 0。Address 和
    // OpIndex 共同组成操作指针，能够
    // 引用指令流中的任意
    // 单个操作。
    OpIndex int

    // File 是这些指令所对应的
    // 源文件。
    File *LineFile

    // Line 是这些指令所对应的源代码
    // 行号。行号从 1 开始。如果无法将这些指令
    // 归属于任何源代码行，
    // 它可以为 0。
    Line int

    // Column 是这些指令在源代码行中的
    // 列号。列号从 1 开始。它可以
    // 为 0，表示该行的“左边缘”。
    Column int

    // IsStmt 表示 Address 是建议设置断点的
    // 位置，例如某一行、语句或
    // 语句中某个独立部分的起点。
    IsStmt bool

    // BasicBlock 表示 Address 是一个
    // 基本块的起点。
    BasicBlock bool

    // PrologueEnd 表示 Address 是以下 PC 之一（可能有多个）：
    // 在相应断点处，应在该 PC 暂停执行，
    // 以表示进入所属函数。
    //
    // DWARF 3 中加入。
    PrologueEnd bool

    // EpilogueBegin 表示 Address 是以下 PC 之一（可能有多个）：
    // 在相应断点处，应在该 PC 暂停执行，
    // 以表示退出此函数。
    //
    // DWARF 3 中加入。
    EpilogueBegin bool

    // ISA 是这些指令的指令集
    // 架构。可能的 ISA 值应由
    // 适用的 ABI 规范定义。
    //
    // DWARF 3 中加入。
    ISA int

    // Discriminator 是任意整数，标识这些指令
    // 所属的块。它用于区分
    // 源文件、行号和列号可能完全相同的
    // 多个块。对于给定的源代码位置，如果仅有一个
    // 块，则此值应为 0。
    //
    // DWARF 3 中加入。
    Discriminator int

    // EndSequence 表示 Address 是一段目标机器指令
    // 序列结束后的第一个字节。如果
    // 设置了此字段，则仅此字段和 Address 字段有意义。
    // 行号表可以包含多个可能互不相交的
    // 指令序列的信息。行表的最后一个条目
    // 应始终设置 EndSequence。
    EndSequence bool
}

func (*LineReader) Files 1.14 

func (r *LineReader) Files() []*LineFile

Files 返回此编译单元在行表当前位置处的文件名表。该编译单元中的属性（例如 AttrDeclFile）可以引用文件名表。

条目 0 始终为 nil，因为文件索引 0 表示“无文件”。

编译单元的文件名表并非固定不变。Files 返回截至行表当前位置的文件表。与行表中更早位置的文件表相比，它可能包含更多条目，但已有条目永远不会改变。

func (*LineReader) Next 1.5 

func (r *LineReader) Next(entry *LineEntry) error

Next 将 *entry 设置为行表中的下一行，并移动到下一行。如果没有更多条目且行表正常终止，则返回 io.EOF。

各行始终按 entry.Address 递增顺序排列，但 entry.Line 可以向前也可以向后变化。

func (*LineReader) Reset 1.5 

func (r *LineReader) Reset()

Reset 将行表读取器重新定位到行表开头。

func (*LineReader) Seek 1.5 

func (r *LineReader) Seek(pos LineReaderPos)

Seek 将行表读取器恢复到 LineReader.Tell 返回的位置。

参数 pos 必须由针对此行表调用 LineReader.Tell 得到。

func (*LineReader) SeekPC 1.5 

func (r *LineReader) SeekPC(pc uint64, entry *LineEntry) error

SeekPC 将 *entry 设置为包含 pc 的 LineEntry，并将读取器定位到行表中的下一个条目。必要时，它会向后定位以查找 pc。

如果此行表中没有任何条目覆盖 pc，SeekPC 返回 ErrUnknownPC。在这种情况下，*entry 和最终定位位置均未指定。

注意，DWARF 行表只允许顺序向前扫描。因此，最坏情况下所需时间与行表大小呈线性关系。如果调用方需要反复快速查找 PC，应为行表建立适当的索引。

func (*Reader) SeekPC 1.7

SeekPC 返回包含 pc 的编译单元的 Entry，并将读取器定位到可读取该单元子条目的位置。如果没有任何单元覆盖 pc，SeekPC 返回 ErrUnknownPC，读取器位置未定义。

type StructField

StructField 表示结构体、联合体或 C++ 类类型中的字段。

位域

BitSize、BitOffset 和 DataBitOffset 字段描述 C/C++ 的结构体、联合体或类类型中声明为位域的数据成员的位大小和偏移量。

BitSize 是位域中的位数。

如果 DataBitOffset 非零，它表示从外围实体（例如所属结构体、类或联合体）的起点到位域起点的位数。这对应 DWARF 4 引入的 DW_AT_data_bit_offset 属性。

如果 BitOffset 非零，它表示从容纳该位域的存储单元的最高有效位，到该位域最高有效位之间的位数。这里的“存储单元”是位域前面的类型名（对于字段 "unsigned x:17"，存储单元为 "unsigned"）。BitOffset 的值可能随系统字节序变化。BitOffset 对应 DW_AT_bit_offset 属性，该属性在 DWARF 4 中弃用，并在 DWARF 5 中移除。

DataBitOffset 和 BitOffset 至多有一个非零；只有 BitSize 非零时，DataBitOffset 或 BitOffset 才可能非零。C 编译器使用哪一种，取决于编译器版本年代及命令行选项。

下面给出一个 C/C++ 位域用法示例，以及预期的 DWARF 位偏移信息。考虑以下代码：

struct S {
	int q;
	int j:5;
	int k:6;
	int m:5;
	int n:8;
} s;

对于以上代码，预期得到以下 DW_AT_bit_offset 值（使用 GCC 8）：

       小端序   |    大端序
                |
"j":     27     |     0
"k":     21     |     5
"m":     16     |     11
"n":     8      |     16

注意，上述偏移量完全相对于容纳 j、k、m、n 的存储单元；这些值不会随所属结构体中前面数据成员的大小而改变。

如果编译器输出 DW_AT_data_bit_offset，预期值为：

"j":     32
"k":     37
"m":     43
"n":     48

这里 "j" 的值 32 反映了该位域之前还有其他数据成员（记住，DW_AT_data_bit_offset 的值相对于所属结构体的起点）。因此，对于包含许多字段的结构体，DW_AT_data_bit_offset 的值可能相当大。

DWARF 也允许基本类型具有非零的位大小和位偏移量，因此基本类型也会记录这些信息，不过主流语言无法触发这种行为。

type StructField struct {
    Name          string
    Type          Type
    ByteOffset    int64
    ByteSize      int64 // 通常为零；普通字段请使用 Type.Size()
    BitOffset     int64
    DataBitOffset int64 // Go 1.18
    BitSize       int64 // 不是位域时为零
}
