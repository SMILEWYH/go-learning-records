func (*Writer) Close 1.5 

func (w *Writer) Close() error

Close 关闭 Writer，将所有尚未写出的数据刷新到底层 io.Writer，但不关闭底层 io.Writer。

func (*Writer) Write 1.5 

func (w *Writer) Write(p []byte) (n int, err error)

Write 使用 quoted-printable 编码对 p 进行编码，并将其写入底层 io.Writer。它将行长限制为 76 个字符。编码后的字节可能要等到 Writer 关闭时才会刷新。
