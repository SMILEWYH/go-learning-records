multipart 包实现 RFC 2046 定义的 MIME 多部分内容解析。

此实现足以处理 HTTP（RFC 2388）以及常见浏览器生成的多部分消息体。

限制

为防范恶意输入，本包对所处理的 MIME 数据大小设有限制。

Reader.NextPart 和 Reader.NextRawPart 将单个部分中的首部数量限制为 10000，Reader.ReadForm 将所有 FileHeader 中的首部总数限制为 10000。可使用 GODEBUG=multipartmaxheaders=<values> 设置调整这些限制。

Reader.ReadForm 还将表单中的部分数量限制为 1000。可使用 GODEBUG=multipartmaxparts=<value> 设置调整此限制。

type File

File 是访问 multipart 消息中文件部分的接口。其内容可以存储在内存或磁盘上。如果存储在磁盘上，File 的底层具体类型为 *os.File。

type File interface {
    io.Reader
    io.ReaderAt
    io.Seeker
    io.Closer
}

type Form

Form 是已解析的 multipart 表单。其 File 部分存储在内存或磁盘上，可通过 *FileHeader 的 Open 方法访问。其 Value 部分存储为字符串。二者都以字段名为键。

type Form struct {
    Value map[string][]string
    File  map[string][]*FileHeader
}

type Reader

Reader 是遍历 MIME 多部分消息体中各部分的迭代器。Reader 的底层解析器按需消费输入，不支持定位（seek）。

type Reader struct {
    // 包含已过滤或未导出的字段

func NewReader 

func NewReader(r io.Reader, boundary string) *Reader

NewReader 创建一个使用给定 MIME 边界、从 r 读取的新 multipart Reader。

边界通常来自消息的 "Content-Type" 首部中的 "boundary" 参数。可使用 mime.ParseMediaType 解析此类首部。

func (*Reader) NextPart 

func (r *Reader) NextPart() (*Part, error)

NextPart 返回 multipart 中的下一个部分或一个错误。没有更多部分时，返回 io.EOF 错误。

有一种特殊情况：如果 "Content-Transfer-Encoding" 首部的值为 "quoted-printable"，则此首部会被隐藏，并在 Read 调用期间透明地解码正文。

func (*Reader) NextRawPart 1.14 

func (r *Reader) NextRawPart() (*Part, error)

NextRawPart 返回 multipart 中的下一个部分或一个错误。没有更多部分时，返回 io.EOF 错误。

与 Reader.NextPart 不同，它不会对 "Content-Transfer-Encoding: quoted-printable" 做特殊处理。

func (*Reader) ReadForm 

func (r *Reader) ReadForm(maxMemory int64) (*Form, error)

ReadForm 解析整个 multipart 消息，其中各部分的 Content-Disposition 为 "form-data"。它在内存中最多存储 maxMemory 字节加 10MB（为非文件部分预留）。无法存入内存的文件部分会存入磁盘临时文件。如果无法将所有非文件部分存入内存，则返回 ErrMessageTooLarge。

CreatePart 使用提供的首部创建新的 multipart 部分。该部分的正文应写入返回的 Writer。调用 CreatePart 之后，不得再向之前的任何部分写入。

func (*Writer) SetBoundary 1.1 

func (w *Writer) SetBoundary(boundary string) error

SetBoundary 使用显式值覆盖 Writer 默认随机生成的边界分隔符。

SetBoundary 必须在创建任何部分之前调用。边界只能包含特定的 ASCII 字符，必须非空，且长度最多为 70 字节。

func (*Writer) WriteField 

func (w *Writer) WriteField(fieldname, value string) error

WriteField 调用 Writer.CreateFormField，随后写入给定的值。
