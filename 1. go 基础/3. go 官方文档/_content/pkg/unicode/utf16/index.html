func AppendRune 1.20 

func AppendRune(a []uint16, r rune) []uint16

AppendRune 将 Unicode 码点 r 的 UTF-16 编码追加到 p 末尾，并返回扩展后的缓冲区。如果该 rune 不是有效的 Unicode 码点，则追加 U+FFFD 的编码。

func DecodeRune

DecodeRune 对一个 UTF-16 代理对进行解码并返回结果。如果该对不是有效的 UTF-16 代理对，DecodeRune 返回 Unicode 替换码点 U+FFFD。

func Encode 

func Encode(s []rune) []uint16

func EncodeRune 

func EncodeRune(r rune) (r1, r2 rune)

EncodeRune 返回给定 rune 对应的 UTF-16 代理对 r1、r2。如果该 rune 不是有效的 Unicode 码点，或不需要编码为代理对，则 EncodeRune 返回 U+FFFD、U+FFFD。

func IsSurrogate 

func IsSurrogate(r rune) bool

IsSurrogate 报告指定的 Unicode 码点是否可以出现在代理对中。

func RuneLen 1.23 

func RuneLen(r rune) int

RuneLen 返回该 rune 的 UTF-16 编码包含的 16 位字的数量。如果该 rune 不是可编码为 UTF-16 的有效值，则返回 -1。
