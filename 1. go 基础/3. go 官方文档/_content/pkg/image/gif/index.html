gif 包实现 GIF 图像的解码器和编码器。

GIF 规范位于 https://www.w3.org/Graphics/GIF/spec-gif89a.txt。

解码不可信输入时，应在调用 Decode 或 DecodeAll 之前使用 DecodeConfig 读取尺寸；参见这些函数的说明，以及 image 包文档中的“安全注意事项”一节。

func Decode 

func Decode(r io.Reader) (image.Image, error)

Decode 从 r 读取 GIF 图像，并将其中的第一幅图像作为 image.Image 返回。

解码来自不可信来源的图像时，最安全的做法是先调用 DecodeConfig 并检查图像大小，以避免意料之外的大量内存分配。

func DecodeConfig 

func DecodeConfig(r io.Reader) (image.Config, error)

DecodeConfig 返回 GIF 图像的全局颜色模型和尺寸，而不解码整个图像。

它只读取逻辑屏幕描述符和全局颜色表，不为帧分配像素缓冲区。在调用 Decode 或 DecodeAll 之前，可用它检查宽度和高度。

type GIF

GIF 表示 GIF 文件中存储的图像，可能包含多幅。

type GIF struct {
    Image []*image.Paletted // 按顺序排列的图像。
    Delay []int             // 按顺序排列的延迟时间，每帧一个，单位为百分之一秒。
    // LoopCount 控制动画在显示期间
    // 重新开始播放的次数。
    // LoopCount 为 0 表示无限循环。
    // LoopCount 为 -1 表示每帧仅显示一次。
    // 否则，动画循环播放 LoopCount+1 次。
    LoopCount int
    // Disposal 是按顺序排列的帧处置方法，每帧一个。
    // 为向后兼容，可以向 EncodeAll 传入 nil 的 Disposal，
    // 这意味着每帧的处置方法均为 0（未指定
    // 处置方法）。
    Disposal []byte // Go 1.5
    // Config 包含全局颜色表（调色板）、宽度和高度。
    // Config.ColorModel 为 nil 或空的 color.Palette 时，表示每帧有各自的
    // 颜色表，不存在全局颜色表。每帧的边界都必须位于
    // 由 (0, 0) 与
    // (Config.Width, Config.Height) 两点定义的矩形内。
    //
    // 为向后兼容，可以向 EncodeAll 传入零值 Config，
    // 这意味着整个 GIF 的宽度和高度等于
    // 第一帧边界的 Rectangle.Max 点。
    Config image.Config // Go 1.5
    // BackgroundIndex 是全局颜色表中的背景索引，
    // 供 DisposalBackground 处置方法使用。
    BackgroundIndex byte // Go 1.5
}

func DecodeAll 

func DecodeAll(r io.Reader) (*GIF, error)

DecodeAll 从 r 读取 GIF 图像，返回按顺序排列的帧和时间信息。

与 Decode 一样，此函数会根据图像描述符中的宽度和高度，为每帧分配一个调色板像素缓冲区。DecodeAll 会将每个已解码的帧保留在内存中。对于不可信输入，应先调用 DecodeConfig 验证逻辑屏幕大小，并拒绝需要过多内存的输入。

type Options 1.2

Options 表示编码参数。

type Options struct {
    // NumColors 是图像使用的最大颜色数量。
    // 其取值范围为 1 到 256。
    NumColors int

    // Quantizer 用于生成大小为 NumColors 的调色板。
    // Quantizer 为 nil 时使用 palette.Plan9。
    Quantizer draw.Quantizer

    // Drawer 用于将源图像转换为所需的调色板。
    // Drawer 为 nil 时使用 draw.FloydSteinberg。
    Drawer draw.Drawer
}
