parse 包为 text/template 和 html/template 定义的模板构建语法树。使用者应通过这两个包构建模板；本包提供的是共享的内部数据结构，不供一般用途使用。

type Node

Node 是语法树中的元素。该接口很简单，其中包含一个未导出的方法，因此只有本包中的类型才能满足它。

type Node interface {
    Type() NodeType
    String() string
    // Copy 深拷贝 Node 及其所有组成部分。
    // 为避免类型断言，某些 XxxNode 还提供专用的
    // CopyXxx 方法，返回 *XxxNode。
    Copy() Node
    Position() Pos // 节点在完整原始输入字符串中的起始字节位置
    // 包含已过滤或未导出的方法
}

type NodeType

NodeType 标识语法树节点的类型。

type NodeType int
const (
    NodeText    NodeType = iota // 普通文本。
    NodeAction                  // 字段求值等非控制动作。
    NodeBool                    // 布尔常量。
    NodeChain                   // 字段访问序列。
    NodeCommand                 // 流水线中的元素。
    NodeDot                     // 游标，即 dot。

    NodeField      // 字段或方法名。
    NodeIdentifier // 标识符；始终是函数名。
    NodeIf         // if 动作。
    NodeList       // Node 列表。
    NodeNil        // 无类型 nil 常量。
    NodeNumber     // 数值常量。
    NodePipe       // 命令流水线。
    NodeRange      // range 动作。
    NodeString     // 字符串常量。
    NodeTemplate   // 模板调用动作。
    NodeVariable   // $ 变量。
    NodeWith       // with 动作。
    NodeComment    // 注释。
    NodeBreak      // break 动作。
    NodeContinue   // continue 动作。
)

type NumberNode

NumberNode 保存数值：有符号或无符号整数、浮点数或复数。该值会被解析，并以所有能够表示它的类型存储。这样用少量代码模拟了 Go 理想常量的行为。

type NumberNode struct {
    NodeType
    Pos

    IsInt      bool       // 数值具有整数值。
    IsUint     bool       // 数值具有无符号整数值。
    IsFloat    bool       // 数值具有浮点值。
    IsComplex  bool       // 数值是复数。
    Int64      int64      // 有符号整数值。
    Uint64     uint64     // 无符号整数值。
    Float64    float64    // 浮点值。
    Complex128 complex128 // 复数值。
    Text       string     // 输入中的原始文本表示。
    // 包含已过滤或未导出的字段
}
