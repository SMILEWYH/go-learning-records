template 包实现用于生成文本输出的数据驱动模板。

要生成 HTML 输出，请参见 html/template。它的接口与本包相同，但会自动保护 HTML 输出，防范某些攻击。

模板通过应用到某个数据结构上来执行。模板中的标注引用该数据结构的元素（通常是结构体字段或映射键），以控制执行过程并获取待显示的值。执行模板时会遍历该结构，并随着执行推进，将以句点“.”表示、称为“dot”的游标设置为结构中当前位置的值。

本包采用的安全模型假定模板作者可信。本包不会自动转义输出，因此，如果不可信来源执行被注入代码的模板，可能导致任意代码执行。

模板输入可以是任意格式的 UTF-8 编码文本。“动作”是数据求值或控制结构，用 "{{" 和 "}}" 分隔；动作之外的所有文本都会原样复制到输出。

解析完成后，模板可以安全地并行执行，不过，如果并行执行共享同一个 Writer，输出可能交错。

下面是一个简单示例，输出 "17 items are made of wool"。

type Inventory struct {
	Material string
	Count    uint
}
sweaters := Inventory{"wool", 17}
tmpl, err := template.New("test").Parse("{{.Count}} items are made of {{.Material}}")
if err != nil { panic(err) }
err = tmpl.Execute(os.Stdout, sweaters)
if err != nil { panic(err) }

更复杂的示例见下文。

文本与空白

默认情况下，执行模板时，动作之间的所有文本都会原样复制。例如，上例中的字符串 " items are made of " 会在程序运行时出现在标准输出中。

不过，为了便于排版模板源代码，如果动作的左分隔符（默认为 "{{"）后紧跟减号和空白，就会移除紧邻其前的文本末尾的所有空白。同样，如果右分隔符（"}}"）前紧邻空白和减号，就会移除紧邻其后的文本开头的所有空白。修剪标记中的空白不可省略："{{- 3}}" 类似于 "{{3}}"，但会修剪其前的文本；而 "{{-3}}" 会被解析为包含数值 -3 的动作。

例如，执行源文本为以下内容的模板：

"{{23 -}} < {{- 45}}"

生成的输出为：

"23<45"

这里用于修剪的空白字符定义与 Go 相同：空格、水平制表符、回车和换行。

动作

下面列出所有动作。“参数”和“流水线”都是对数据的求值，后续相应小节会详细说明。

{{/* a comment */}}
{{- /* a comment with white space trimmed from preceding and following text */ -}}
	注释，会被丢弃。可包含换行。
	注释不能嵌套，必须紧接分隔符开始和结束，
	如这里所示。

{{pipeline}}
	将流水线值的默认文本表示（与 fmt.Print
	输出的表示相同）复制到输出中。

{{if pipeline}} T1 {{end}}
	如果流水线的值为空，不产生输出；否则执行 T1。
	空值包括 false、0、任意 nil 指针或接口值，
	以及长度为零的数组、切片、映射或字符串。
	dot 不受影响。

{{if pipeline}} T1 {{else}} T0 {{end}}
	如果流水线的值为空，执行 T0；否则执行 T1。
	dot 不受影响。

{{if pipeline}} T1 {{else if pipeline}} T0 {{end}}
	为简化 if-else 链的写法，if 的 else 动作
	可以直接包含另一个 if；效果与以下写法完全相同：
		{{if pipeline}} T1 {{else}}{{if pipeline}} T0 {{end}}{{end}}

{{range pipeline}} T1 {{end}}
	流水线的值必须是数组、切片、映射、iter.Seq、
	iter.Seq2、整数或通道。
	如果流水线的值长度为零，不产生输出；
	否则，dot 依次设置为数组、切片或映射的各个元素，
	并执行 T1。如果值是映射，且键为具有明确顺序的基本类型，
	则按键排序后的顺序访问元素。

{{range pipeline}} T1 {{else}} T0 {{end}}
	流水线的值必须是数组、切片、映射、iter.Seq、
	iter.Seq2、整数或通道。
	如果流水线的值长度为零，dot 不受影响，
	并执行 T0；否则，dot 依次设置为数组、切片或映射的
	各个元素，并执行 T1。

{{break}}
	提前结束最内层 {{range pipeline}} 循环，停止
	当前迭代，并跳过所有剩余迭代。

{{continue}}
	停止最内层 {{range pipeline}} 循环的当前迭代，
	随后开始下一次迭代。

{{template "name"}}
	以 nil 数据执行指定名称的模板。

{{template "name" pipeline}}
	将 dot 设置为流水线的值，执行指定名称的模板。

{{block "name" pipeline}} T1 {{end}}
	block 是以下操作的简写：先定义模板
		{{define "name"}} T1 {{end}}
	然后在当前位置执行该模板
		{{template "name" pipeline}}
	典型用法是定义一组根模板，随后通过重新定义其中的
	块模板来定制这些根模板。

{{with pipeline}} T1 {{end}}
	如果流水线的值为空，不产生输出；否则将 dot
	设置为流水线的值，并执行 T1。

{{with pipeline}} T1 {{else}} T0 {{end}}
	如果流水线的值为空，dot 不受影响，并执行 T0；
	否则将 dot 设置为流水线的值，并执行 T1。

{{with pipeline}} T1 {{else with pipeline}} T0 {{end}}
	为简化 with-else 链的写法，with 的 else 动作
	可以直接包含另一个 with；效果与以下写法完全相同：
		{{with pipeline}} T1 {{else}}{{with pipeline}} T0 {{end}}{{end}}

参数

参数是一个简单值，可用以下任一形式表示。

  • 采用 Go 语法的布尔、字符串、字符、整数、浮点、虚数或复数常量。其行为与 Go 的无类型常量相同。注意，与 Go 一样，将大整数常量赋值或传给函数时是否溢出，可能取决于宿主机器上的 int 是 32 位还是 64 位。

  • 关键字 nil，表示 Go 的无类型 nil。

  • 字符“.”（句点）：

    .

    结果是 dot 的值。

  • 变量名，即美元符号后接字母数字字符串（可以为空），例如

    $piOver2

    或

    $

    结果是该变量的值。变量将在下文说明。

  • 数据的字段名，前面加句点；此时数据必须是结构体，例如

    .Field

    结果是该字段的值。字段访问可以连用：

    .Field1.Field2

    也可以对变量进行字段求值，包括链式访问：

    $x.Field1.Field2

  • 数据的键名，前面加句点；此时数据必须是映射，例如

    .Key

    结果是通过该键索引得到的映射元素值。键访问可以连用，并与字段组合成任意深度：

    .Field1.Key1.Field2.Key2

    键必须是由字母和数字组成的标识符，但与字段名不同，它不必以大写字母开头。也可以对变量进行键求值，包括链式访问：

    $x.key1.key2

  • 数据的无参方法名，前面加句点，例如

    .Method

    结果是以 dot 为接收者调用该方法的值，即 dot.Method()。这样的方法必须有一个返回值（可为任意类型），或两个返回值，其中第二个为 error。如果有两个返回值，且返回的 error 非 nil，则执行终止，错误通过 Execute 的返回值交给调用方。方法调用可以连用，并与字段和键组合成任意深度：

    .Field1.Key1.Method1.Field2.Key2.Method2

    也可以对变量调用方法，包括链式调用：

    $x.Method1.Field

  • 无参函数的名称，例如

    fun

    结果是调用函数 fun() 的值。返回类型和值的行为与方法相同。函数及函数名将在下文说明。

  • 以上任一形式加上括号，用于分组。可以对结果进行字段访问或映射键访问。

    print (.F1 arg1) (.F2 arg2) (.StructValuedMethod "arg").Field

参数可以求值得到任意类型；如果是指针，实现会在需要时自动解引用到基础类型。如果求值结果是函数值，例如结构体中的函数值字段，不会自动调用该函数，但可以将它用作 if 等动作的真值。要调用它，请使用下文定义的 call 函数。

流水线

流水线是可串联的“命令”序列。命令可以是简单值（参数），也可以是函数或方法调用，后者可能带多个参数：

Argument
	结果是对参数求值所得的值。
.Method [Argument...]
	方法可以单独出现，也可以是链中的最后一个元素；
	与链中间的方法不同，它可以接受参数。
	结果是以这些参数调用该方法所得的值：
		dot.Method(Argument1, etc.)
functionName [Argument...]
	结果是调用该名称对应函数所得的值：
		function(Argument1, etc.)
	函数及函数名将在下文说明。

用管道字符“|”分隔一系列命令，可以将流水线“串联”起来。在串联流水线中，每个命令的结果作为下一个命令的最后一个参数传入。流水线最后一个命令的输出就是流水线的值。

命令的输出可以是一个值，也可以是两个值；如果有两个，第二个的类型必须为 error。如果存在第二个值且求值结果非 nil，执行就会终止，并将该错误返回给 Execute 的调用方。

变量

动作中的流水线可以初始化变量以保存结果。初始化语法为

$variable := pipeline

其中 $variable 是变量名。声明变量的动作不产生输出。

也可以为先前声明的变量赋值，语法为

$variable = pipeline

如果 “range” 动作初始化一个变量，该变量会依次设置为迭代的各个元素。“range” 还可以声明两个变量，以逗号分隔：

range $index, $element := pipeline

此时，$index 和 $element 分别依次设置为数组/切片索引或映射键，以及对应元素。注意，如果只有一个变量，它会被赋予元素值；这与 Go 的 range 子句惯例相反。

变量的作用域延伸到声明它的控制结构（“if”、“with” 或 “range”）的 “end” 动作；如果没有这样的控制结构，则延伸到模板末尾。模板调用不会继承调用位置的变量。

执行开始时，$ 被设置为传给 Execute 的 data 参数，即 dot 的初始值。

示例

下面是演示流水线和变量的单行模板示例。它们都输出带引号的单词 "output"：

{{"\"output\""}}
	字符串常量。
{{`"output"`}}
	原始字符串常量。
{{printf "%q" "output"}}
	函数调用。
{{"output" | printf "%q"}}
	最后一个参数来自前一个命令的函数调用。
{{printf "%q" (print "out" "put")}}
	带括号的参数。
{{"put" | printf "%s%s" "out" | printf "%q"}}
	更复杂的调用。
{{"output" | printf "%s" | printf "%q"}}
	更长的调用链。
{{with "output"}}{{printf "%q" .}}{{end}}
	使用 dot 的 with 动作。
{{with $x := "output" | printf "%q"}}{{$x}}{{end}}
	创建并使用变量的 with 动作。
{{with $x := "output"}}{{printf "%q" $x}}{{end}}
	在另一个动作中使用该变量的 with 动作。
{{with $x := "output"}}{{$x | printf "%q"}}{{end}}
	与上例相同，但采用流水线。

函数

执行期间，会在两个函数映射中查找函数：先查模板中的函数映射，再查全局函数映射。默认情况下，模板中没有定义函数，但可以通过 Funcs 方法添加。

预定义的全局函数如下。

and
	返回参数的布尔与：返回第一个空参数，或者最后一个参数。
	也就是说，"and x y" 的行为相当于 "if x then y else x."。
	从左到右对参数求值，一旦确定结果就返回。
call
	以其余参数为实参调用第一个参数，并返回结果；
	第一个参数必须是函数。因此，"call .X.Y 1 2"
	用 Go 表示就是 dot.X.Y(1, 2)，其中 Y 是函数值字段、
	映射元素等。第一个参数必须是求值后得到函数类型值的结果
	（与 print 这样的预定义函数不同）。
	该函数必须返回一个或两个结果；如果有两个，
	第二个必须是 error 类型。如果参数与函数不匹配，
	或者返回的错误值非 nil，执行就会停止。
html
	返回各参数文本表示对应的 HTML 转义结果。
	除少数例外情况，此函数在 html/template 中不可用。
index
	以之后的参数依次对第一个参数执行索引操作，并返回结果。
	因此，"index x 1 2 3" 用 Go 语法表示就是 x[1][2][3]。
	每个被索引的值都必须是映射、切片或数组。
slice
	slice 使用其余参数对第一个参数执行切片操作，并返回结果。
	因此，"slice x 1 2" 用 Go 语法表示就是 x[1:2]，
	"slice x" 是 x[:]，"slice x 1" 是 x[1:]，
	"slice x 1 2 3" 是 x[1:2:3]。
	第一个参数必须是字符串、切片或数组。
js
	返回各参数文本表示对应的 JavaScript 转义结果。
len
	返回参数的整数长度。
not
	返回单个参数的布尔非。
or
	返回参数的布尔或：返回第一个非空参数，或者最后一个参数。
	也就是说，"or x y" 的行为相当于 "if x then x else y"。
	从左到右对参数求值，一旦确定结果就返回。
print
	fmt.Sprint 的别名
printf
	fmt.Sprintf 的别名
println
	fmt.Sprintln 的别名
urlquery
	返回各参数文本表示的转义结果，采用适合嵌入 URL 查询的形式。
	除少数例外情况，此函数在 html/template 中不可用。

布尔函数将所有零值视为 false，将非零值视为 true。

此外，还以函数形式定义了一组二元比较运算符：

eq
	返回以下比较的布尔结果：arg1 == arg2
ne
	返回以下比较的布尔结果：arg1 != arg2
lt
	返回以下比较的布尔结果：arg1 < arg2
le
	返回以下比较的布尔结果：arg1 <= arg2
gt
	返回以下比较的布尔结果：arg1 > arg2
ge
	返回以下比较的布尔结果：arg1 >= arg2

为简化多值相等测试，只有 eq 接受两个或更多参数，将第二个及后续参数逐个与第一个比较，返回的结果实际相当于

arg1==arg2 || arg1==arg3 || arg1==arg4 ...

（不过，与 Go 中的 || 不同，eq 是函数调用，因此所有参数都会求值。）

比较函数适用于 Go 定义为可比较类型的任意值。对于整数等基本类型，规则有所放宽：忽略大小和具体类型，因此任意整数值，无论有无符号，都可以与其他整数值比较。（比较的是算术值，而不是位模式，因此所有负整数都小于所有无符号整数。）不过，与通常情况一样，不能将 int 与 float32 等不同类别的值比较。

关联模板

每个模板都以创建时指定的字符串命名。此外，每个模板与零个或多个其他模板关联，可以按名称调用它们；这种关联具有传递性，构成模板的命名空间。

模板可以通过模板调用来实例化另一个关联模板；参见前文对 “template” 动作的说明。名称必须属于与包含调用的模板相关联的某个模板。

嵌套模板定义

解析模板时，可以定义另一个模板，并将其与正在解析的模板关联。模板定义必须出现在模板顶层，类似于 Go 程序中的全局变量。

这种定义的语法是用 “define” 和 “end” 动作包围每个模板声明。

define 动作通过字符串常量为正在创建的模板命名。下面是一个简单示例：

{{define "T1"}}ONE{{end}}
{{define "T2"}}TWO{{end}}
{{define "T3"}}{{template "T1"}} {{template "T2"}}{{end}}
{{template "T3"}}

这段代码定义了 T1、T2 两个模板，以及执行时调用这两个模板的第三个模板 T3。最后调用 T3。执行该模板将产生文本

ONE TWO

按其构造方式，一个模板只能属于一个关联集合。如果需要从多个关联集合访问同一模板，就必须多次解析模板定义，创建不同的 *Template 值，或者使用 Template.Clone 或 Template.AddParseTree 复制。

可以多次调用 Parse 来组合各个关联模板；对于保存在文件中的相关模板，ParseFiles、ParseGlob、Template.ParseFiles 和 Template.ParseGlob 提供了简单的解析方式。

可以直接执行模板，也可以通过 Template.ExecuteTemplate 按名称执行关联模板。要调用上面的示例，可以写成：

err := tmpl.Execute(os.Stdout, "no data needed")
if err != nil {
	log.Fatalf("execution failed: %s", err)
}

也可以按名称显式调用某个模板：

err := tmpl.ExecuteTemplate(os.Stdout, "T2", "no data needed")
if err != nil {
	log.Fatalf("execution failed: %s", err)
}

FuncMap 是定义从名称到函数映射的 map 类型。每个函数必须有一个返回值，或两个返回值且第二个为 error 类型。后一种情况下，如果执行期间第二个返回值（error）非 nil，就会终止执行，Execute 返回该错误。

Execute 返回的错误会包装底层错误；可调用 errors.AsType 解包。

模板执行时，调用函数所用的实参列表必须可赋值给该函数的形参类型。希望接受任意类型实参的函数，可以使用 interface{} 或 reflect.Value 类型的形参。同样，希望返回任意类型结果的函数，可以返回 interface{} 或 reflect.Value。

func Must 

func Must(t *Template, err error) *Template

Must 是辅助函数，包装返回 (*Template, error) 的函数调用，并在 error 非 nil 时引发 panic。它用于变量初始化，例如

var t = template.Must(template.New("name").Parse("text"))

func New 

func New(name string) *Template

New 分配具有指定名称、尚未定义的新模板。

func ParseFS 1.16 

func ParseFS(fsys fs.FS, patterns ...string) (*Template, error)

ParseFS 类似于 Template.ParseFiles 或 Template.ParseGlob，但从文件系统 fsys 读取，而非宿主操作系统的文件系统。它接受一组 glob 模式（参见 path.Match）。（注意，大多数文件名可以作为只匹配自身的 glob 模式。）

func ParseFiles 

func ParseFiles(filenames ...string) (*Template, error)

ParseFiles 创建新 Template，并解析指定文件中的模板定义。返回模板的名称是第一个文件的基本名称，内容是该文件解析后的内容。必须至少提供一个文件。如果发生错误，解析停止，返回的 *Template 为 nil。

解析不同目录中的多个同名文件时，以最后列出的文件为准。例如，ParseFiles("a/foo", "b/foo") 将 "b/foo" 保存为名为 "foo" 的模板，而 "a/foo" 不再可用。

func ParseGlob 

func ParseGlob(pattern string) (*Template, error)

ParseGlob 创建新 Template，并解析 pattern 所指定文件中的模板定义。文件按 filepath.Match 的语义匹配，pattern 必须至少匹配一个文件。返回模板的名称是 pattern 匹配的第一个文件的 filepath.Base 名称，内容是该文件解析后的内容。ParseGlob 等价于用 pattern 匹配的文件列表调用 ParseFiles。

解析不同目录中的多个同名文件时，以最后列出的文件为准。

func (*Template) AddParseTree 

func (t *Template) AddParseTree(name string, tree *parse.Tree) (*Template, error)

AddParseTree 将参数语法树与模板 t 关联，并赋予指定名称。如果模板尚未定义，该树就成为其定义。如果模板已定义且名称相同，则替换原定义；否则创建、定义并返回一个新模板。

func (*Template) Clone 

func (t *Template) Clone() (*Template, error)

Clone 返回模板的副本，包括所有关联模板。它不复制实际表示，而是复制关联模板的命名空间，因此之后在副本上调用 Template.Parse，会向副本添加模板，不影响原模板。可以使用 Clone 预先准备公共模板，在克隆后添加其他模板的变体定义，从而配合使用。

func (*Template) DefinedTemplates 1.5 

func (t *Template) DefinedTemplates() string

DefinedTemplates 返回列出已定义模板的字符串，前缀为 "; defined templates are: "。如果没有模板，则返回空字符串。用于本包及 html/template 生成错误消息。

func (*Template) Delims 

func (t *Template) Delims(left, right string) *Template

Delims 将动作分隔符设置为指定字符串，用于之后对 Template.Parse、Template.ParseFiles 或 Template.ParseGlob 的调用。嵌套模板定义会继承该设置。空分隔符表示相应默认值：{{ 或 }}。返回值为模板本身，因此可以链式调用。

func (*Template) Execute 

func (t *Template) Execute(wr io.Writer, data any) error

Execute 将已解析的模板应用于指定数据对象，并将输出写入 wr。如果执行模板或写入输出时发生错误，执行停止，但可能已有部分结果写入输出 writer。模板可以安全地并行执行，不过，如果并行执行共享同一个 Writer，输出可能交错。

如果 data 是 reflect.Value，模板会应用于 reflect.Value 持有的具体值，与 fmt.Print 相同。

func (*Template) ExecuteTemplate 

func (t *Template) ExecuteTemplate(wr io.Writer, name string, data any) error

ExecuteTemplate 将与 t 关联且具有指定名称的模板应用于指定数据对象，并将输出写入 wr。如果执行模板或写入输出时发生错误，执行停止，但可能已有部分结果写入输出 writer。模板可以安全地并行执行，不过，如果并行执行共享同一个 Writer，输出可能交错。

func (*Template) Funcs 

func (t *Template) Funcs(funcMap FuncMap) *Template

Funcs 将参数 map 中的元素加入模板的函数映射。模板中使用的任何函数都必须在解析模板之前添加。Funcs 可以多次调用，包括在解析后调用（例如在 Template.Clone 之后），以替换同名函数；执行模板时会使用替换后的函数。如果 map 中的值不是具有适当返回类型的函数，或者其名称在语法上不能用作模板函数名，就会引发 panic。返回值为模板本身，因此可以链式调用。

func (*Template) Lookup 

func (t *Template) Lookup(name string) *Template

Lookup 返回与 t 关联且具有指定名称的模板。如果不存在这样的模板，或者模板没有定义，则返回 nil。

func (*Template) Name 

func (t *Template) Name() string

Name 返回模板名称。

func (*Template) New 

func (t *Template) New(name string) *Template

New 分配一个尚未定义的新模板，与给定模板关联，并采用相同的分隔符。这种关联具有传递性，使一个模板可以通过 {{template}} 动作调用另一个模板。

由于关联模板共享底层数据，模板构建不能安全地并行进行。构建完成后，模板可以并行执行。

func (*Template) Option 1.5 

func (t *Template) Option(opt ...string) *Template

Option 设置模板选项。选项用字符串描述，可以是简单字符串，也可以是 "key=value"。选项字符串中最多只能有一个等号。如果选项字符串无法识别或以其他方式无效，Option 会引发 panic。

已知选项：

missingkey：控制执行期间使用映射中不存在的键进行索引时的行为。

"missingkey=default" 或 "missingkey=invalid"
	默认行为：不做任何处理，继续执行。
	如果输出索引操作的结果，会得到字符串
	"<no value>"。
"missingkey=zero"
	操作返回映射元素类型的零值。
"missingkey=error"
	执行立即停止并返回错误。

func (*Template) Parse 

func (t *Template) Parse(text string) (*Template, error)

Parse 将 text 解析为 t 的模板体。text 中的具名模板定义（{{define ...}} 或 {{block ...}} 语句）会定义与 t 关联的额外模板，并从 t 自身的定义中移除。

可以通过连续调用 Parse 重新定义模板。如果模板体只包含空白和注释，则视为空定义，不会替换已有模板体。这样就能使用 Parse 添加新的具名模板定义，而不覆盖主模板体。

func (*Template) ParseFS 1.16 

func (t *Template) ParseFS(fsys fs.FS, patterns ...string) (*Template, error)

ParseFS 类似于 Template.ParseFiles 或 Template.ParseGlob，但从文件系统 fsys 读取，而非宿主操作系统的文件系统。它接受一组 glob 模式（参见 path.Match）。（注意，大多数文件名可以作为只匹配自身的 glob 模式。）

func (*Template) ParseFiles 

func (t *Template) ParseFiles(filenames ...string) (*Template, error)

ParseFiles 解析指定文件，并将得到的模板与 t 关联。如果发生错误，解析停止，返回的模板为 nil；否则返回 t。必须至少提供一个文件。由于 ParseFiles 创建的模板以参数文件的基本名称命名（参见 filepath.Base），t 通常应与其中某个文件的基本名称同名。如果不同名，则取决于调用 ParseFiles 前 t 的内容，t.Execute 可能失败。此时应使用 t.ExecuteTemplate 执行有效模板。

解析不同目录中的多个同名文件时，以最后列出的文件为准。

func (*Template) ParseGlob 

func (t *Template) ParseGlob(pattern string) (*Template, error)

ParseGlob 解析 pattern 所指定文件中的模板定义，并将得到的模板与 t 关联。文件按 filepath.Match 的语义匹配，pattern 必须至少匹配一个文件。ParseGlob 等价于用 pattern 匹配的文件列表调用 Template.ParseFiles。

解析不同目录中的多个同名文件时，以最后列出的文件为准。

func (*Template) Templates 

func (t *Template) Templates() []*Template

Templates 返回与 t 关联的已定义模板组成的切片。
