arena 实验包概述

译注：arena 受 goexperiment.arenas 构建约束控制，未包含在默认 go list std 的公开包列表中。本页翻译工具链默认文档视图提供的概述；该视图不展示 API 声明。实验包源码见 arena.go。

arena 包可以为一组 Go 值分配内存，并以安全的方式一次性手动释放全部空间。此功能旨在提高效率：在垃圾回收前手动释放内存，可以推迟该轮垃圾回收。回收周期减少，垃圾回收器消耗 CPU 的频率也随之降低。

本包的主要功能由 Arena 类型提供。Arena 为 Go 值分配较大的内存块，因此只分配少量小型 Go 值时可能并不高效。它最适合批量分配，每次使用的内存量应达到 MiB 级别。

需要注意，允许这种受限的手动内存分配后，普通 Go 值也可能出现释放后使用的问题。为限制此类问题的影响，本包在垃圾回收器确认安全之前，会阻止已释放内存区域被重新使用。通常，释放后使用会导致故障，并给出有用的错误消息；但本包不保证对访问已释放内存强制触发故障。这意味着，本包的一种有效实现可以完全按运行时通常的方式分配内存；事实上，本包保留偶尔对某些 Go 值采用这种方式的可能。
