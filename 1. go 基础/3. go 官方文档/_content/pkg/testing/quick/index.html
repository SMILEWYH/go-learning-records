func Check 

func Check(f any, config *Config) error

Check 为任意返回 bool 的函数 f 寻找能使 f 返回 false 的输入。它反复调用 f，并为每个实参使用任意值。如果 f 对某个给定输入返回 false，Check 将以 *CheckError 的形式返回该输入。例如：

func TestOddMultipleOfThree(t *testing.T) {
	f := func(x int) bool {
		y := OddMultipleOfThree(x)
		return y%2 == 1 && y%3 == 0
	}
	if err := quick.Check(f, nil); err != nil {
		t.Error(err)
	}
}

func CheckEqual 

func CheckEqual(f, g any, config *Config) error

CheckEqual 寻找能使 f 和 g 返回不同结果的输入。它反复调用 f 和 g，并为每个实参使用任意值。如果 f 和 g 返回不同结果，CheckEqual 将返回一个描述输入和输出的 *CheckEqualError。

type Config

Config 结构体包含运行测试的选项。

type Config struct {
    // MaxCount 设置最大迭代次数。
    // 为零时，使用 MaxCountScale。
    MaxCount int
    // MaxCountScale 是应用于默认最大次数的
    // 非负缩放因子。
    // 次数为零表示使用默认值，通常为 100，
    // 但可以通过 -quickchecks 标志设置。
    MaxCountScale float64
    // Rand 指定随机数源。
    // 为 nil 时，使用默认伪随机源。
    Rand *rand.Rand
    // Values 指定一个函数，用于生成
    // 任意 reflect.Value 组成的切片，
    // 这些值与被测函数的实参相匹配。
    // 为 nil 时，使用包级 Value 函数生成它们。
    Values func([]reflect.Value, *rand.Rand)
}

type Generator

type Generator interface {
