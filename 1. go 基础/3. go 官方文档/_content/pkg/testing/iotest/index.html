func DataErrReader 

func DataErrReader(r io.Reader) io.Reader

DataErrReader 改变 Reader 处理错误的方式。通常，Reader 会在读完最后一段数据后的第一次 Read 调用中返回错误（一般是 EOF）。DataErrReader 包装一个 Reader 并改变其行为，使最终错误与最后一段数据一起返回，而不是在最后一段数据之后的第一次调用中返回。

func HalfReader

func NewReadLogger 

func NewReadLogger(prefix string, r io.Reader) io.Reader

NewReadLogger 返回一个行为与 r 相同的读取器，但会使用 log.Printf 将每次读取记录到标准错误，打印前缀和读取数据的十六进制表示。

func NewWriteLogger 

func NewWriteLogger(prefix string, w io.Writer) io.Writer

NewWriteLogger 返回一个行为与 w 相同的写入器，但会使用 log.Printf 将每次写入记录到标准错误，打印前缀和写入数据的十六进制表示。

func OneByteReader 

func OneByteReader(r io.Reader) io.Reader

OneByteReader 返回一个 Reader，其每次非空 Read 调用都只从 r 读取一个字节。

func TestReader 1.16 

func TestReader(r io.Reader, content []byte) error

TestReader 测试从 r 读取是否得到预期的文件内容。它进行不同大小的读取，直到 EOF。如果 r 实现了 io.ReaderAt 或 io.Seeker，TestReader 还会检查这些操作的行为是否符合要求。

如果 TestReader 发现任何不正确的行为，会返回描述这些问题的错误。错误文本可能有多行。

func TimeoutReader 

func TimeoutReader(r io.Reader) io.Reader

TimeoutReader 在第二次读取时不返回数据，并返回 ErrTimeout。后续读取调用会成功。

func TruncateWriter 

func TruncateWriter(w io.Writer, n int64) io.Writer

TruncateWriter 返回一个向 w 写入的 Writer，但在写入 n 字节后会静默停止。
