func Fields
				
				
			

			
func Fields(s []byte) [][]byte

			
Fields 将 s 解释为 UTF-8 编码的码点序列。它在每段由一个或多个连续空白字符组成的序列处切分 s，空白字符由 unicode.IsSpace 定义。返回值是由 s 的子切片组成的切片；如果 s 只包含空白字符，则返回空切片。返回切片中的每个元素都非空。与 Split 不同，开头和结尾的连续空白字符会被丢弃。

			




  

    
▸ 示例

  

  

    
▾ 示例

    
    
    
      

        

        
Fields are: ["foo" "bar" "baz"]


        

          
          
          
            
          
        

      

    
  





		
			
			
func FieldsFunc
				
				
			

			
func FieldsFunc(s []byte, f func(rune) bool) [][]byte

			
FieldsFunc 将 s 解释为 UTF-8 编码的码点序列。它在每段满足 f(c) 的连续码点 c 处切分 s，并返回由 s 的子切片组成的切片。如果 s 中所有码点都满足 f(c)，或者 len(s) == 0，则返回空切片。返回切片中的每个元素都非空。与 Split 不同，开头和结尾满足 f(c) 的连续码点会被丢弃。

FieldsFunc 不保证调用 f(c) 的顺序，并假定对于给定的 c，f 始终返回相同的值。

			




  

    
▸ 示例

  

  

    
▾ 示例

    
    
    
      

        

        
Fields are: ["foo1" "bar2" "baz3"]

func NewBuffer
					
					
				

				
func NewBuffer(buf []byte) *Buffer

				
NewBuffer 创建并初始化一个新的 Buffer，以 buf 作为其初始内容。新的 Buffer 会取得 buf 的所有权，调用方在此调用之后不应再使用 buf。NewBuffer 用于创建一个 Buffer 来读取现有数据。它也可以用来设置内部缓冲区用于写入的初始大小：此时，buf 应具有所需容量，但长度应为零。

func (*Buffer) UnreadByte
					
					
				

				
func (b *Buffer) UnreadByte() error

				
UnreadByte 撤回最近一次成功且至少读取了一个字节的读操作所返回的最后一个字节。如果自上次读取后发生过写入、上次读取返回了错误，或者上次读取了零个字节，UnreadByte 就会返回错误。

				
			
				
func (*Buffer) UnreadRune
					
					
				

				
func (b *Buffer) UnreadRune() error

				
UnreadRune 撤回 Buffer.ReadRune 返回的最后一个 rune。如果缓冲区最近一次读写操作不是成功的 Buffer.ReadRune，UnreadRune 就会返回错误。（在这一点上，它比 Buffer.UnreadByte 更严格；后者可以撤回任意读操作返回的最后一个字节。）

				
			
				
func (*Buffer) Write
					
					
				

				
func (b *Buffer) Write(p []byte) (n int, err error)

				
Write 将 p 的内容追加到缓冲区中，并按需扩展缓冲区。返回值 n 为 p 的长度；err 始终为 nil。如果缓冲区变得过大，Write 会以 ErrTooLarge 触发 panic。

				
			
				
func (*Buffer) WriteByte
					
					
				

				
func (b *Buffer) WriteByte(c byte) error

				
WriteByte 将字节 c 追加到缓冲区中，并按需扩展缓冲区。返回的错误始终为 nil，保留此返回值是为了与 bufio.Writer 的 WriteByte 一致。如果缓冲区变得过大，WriteByte 会以 ErrTooLarge 触发 panic。

				
			
				
func (*Buffer) WriteRune
					
					
				

				
func (b *Buffer) WriteRune(r rune) (n int, err error)

				
WriteRune 将 Unicode 码点 r 的 UTF-8 编码追加到缓冲区中，返回写入的字节数和 nil 错误。保留 nil 错误返回值是为了与 bufio.Writer 的 WriteRune 一致。缓冲区按需扩展；如果变得过大，WriteRune 会以 ErrTooLarge 触发 panic。

				
			
				
func (*Buffer) WriteString
					
					
				

				
func (b *Buffer) WriteString(s string) (n int, err error)

				
WriteString 将 s 的内容追加到缓冲区中，并按需扩展缓冲区。返回值 n 为 s 的长度；err 始终为 nil。如果缓冲区变得过大，WriteString 会以 ErrTooLarge 触发 panic。

				
			
				
func (*Buffer) WriteTo
					
					
				

				
func (b *Buffer) WriteTo(w io.Writer) (n int64, err error)

				
WriteTo 向 w 写入数据，直到缓冲区耗尽或发生错误。返回值 n 是写入的字节数；它的值始终可以用 int 表示，但为与 io.WriterTo 接口一致，类型使用 int64。写入期间遇到的任何错误也会一并返回。

				
			
		
			
			
type Reader
				
				
			

			
Reader 通过读取字节切片，实现 io.Reader、io.ReaderAt、io.WriterTo、io.Seeker、io.ByteScanner 和 io.RuneScanner 接口。与 Buffer 不同，Reader 是只读的，并支持定位。Reader 的零值行为与读取空切片的 Reader 相同。
