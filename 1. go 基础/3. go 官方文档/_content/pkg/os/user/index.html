user 包支持按名称或 ID 查询用户账户。

对于大多数 Unix 系统，本包内部提供两种实现，用于将用户和组 ID 解析为名称，以及列出附加组 ID。一种使用纯 Go 编写，解析 /etc/passwd 和 /etc/group；另一种基于 cgo，依赖标准 C 库（libc）中的 getpwuid_r、getgrnam_r 和 getgrouplist 等函数。

当 cgo 可用，且特定平台的 libc 实现了所需函数时，会使用基于 cgo（由 libc 支持）的代码。可以使用 osusergo 构建标签覆盖此选择，强制使用纯 Go 实现。

type User

User 表示用户账户。

type User struct {
    // Uid 是用户 ID。
    // 在 POSIX 系统上，这是表示 uid 的十进制数。
    // 在 Windows 上，这是字符串形式的安全标识符（SID）。
    // 在 Plan 9 上，这是 /dev/user 的内容。
    Uid string
    // Gid 是主组 ID。
    // 在 POSIX 系统上，这是表示 gid 的十进制数。
    // 在 Windows 上，这是字符串形式的 SID。
    // 在 Plan 9 上，这是 /dev/user 的内容。
    Gid string
    // Username 是登录名。
    Username string
    // Name 是用户的真实姓名或显示名称。
    // 它可能为空。
    // 在 POSIX 系统上，这是 GECOS 字段列表中的第一个
    // （或唯一一个）条目。
    // 在 Windows 上，这是用户的显示名称。
    // 在 Plan 9 上，这是 /dev/user 的内容。
    Name string
    // HomeDir 是用户主目录的路径（如果用户有主目录）。
    HomeDir string
}

func Current 

func Current() (*User, error)

Current 返回当前用户。

第一次调用会缓存当前用户信息。后续调用返回缓存值，不会反映当前用户的变化。
