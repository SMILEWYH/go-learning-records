suffixarray 包使用内存中的后缀数组，实现对数时间的子串查找。

用法示例：

// 为一些数据创建索引
index := suffixarray.New(data)

// 查找字节切片 s
offsets1 := index.Lookup(s, -1) // s 在 data 中出现的所有索引的列表
offsets2 := index.Lookup(s, 3)  // s 在 data 中出现的至多 3 个索引的列表

func New 

func New(data []byte) *Index

New 为 data 创建一个新的 Index。Index 的创建时间为 O(N)，其中 N = len(data)。

func (*Index) Bytes 

func (x *Index) Bytes() []byte

Bytes 返回用于创建索引的数据。不得修改这些数据。

func (*Index) FindAllIndex 

func (x *Index) FindAllIndex(r *regexp.Regexp, n int) (result [][]int)

FindAllIndex 返回正则表达式 r 的不重叠匹配的有序列表，其中每个匹配由一对索引表示，指定 x.Bytes() 中匹配的切片。如果 n < 0，则按连续顺序返回所有匹配。否则，最多返回 n 个匹配，它们可能不是连续的。如果没有匹配，或者 n == 0，则结果为 nil。

func (*Index) Lookup 

func (x *Index) Lookup(s []byte, n int) (result []int)

Lookup 返回一个未排序的索引列表，至多包含 n 个索引，表示字节串 s 在被索引数据中出现的位置。如果 n < 0，则返回所有出现位置。如果 s 为空、未找到 s 或 n == 0，则结果为 nil。查找时间为 O(log(N)*len(s) + len(result))，其中 N 为被索引数据的大小。
