func Clone 1.18 

func Clone(s string) string

Clone 返回 s 的一份新副本。它保证新分配内存并将 s 复制进去；当只需保留一个很大字符串中的一小段子串时，这一点可能很重要，使用 Clone 有助于减少这类程序的内存占用。当然，Clone 会进行复制，过度使用也可能增加内存占用。通常应少用 Clone，并且只在性能剖析表明有必要时使用。对于长度为零的字符串，返回 ""，不分配内存。

func Compare 1.5 

func Compare(a, b string) int

Compare 按字典序比较两个字符串，并返回整数结果：a == b 时返回 0，a < b 时返回 -1，a > b 时返回 +1。

需要三路比较时使用 Compare，例如与 slices.SortFunc 配合使用。其他情况下，使用内置字符串比较运算符 ==、<、> 等通常更清晰，而且总是更快。

func Fields 

func Fields(s string) []string

Fields 在每段连续空白字符处拆分 s，并返回子串切片。空白字符由 unicode.IsSpace 定义。如果 s 只包含空白，返回空切片。结果中的每个元素都非空。与 Split 不同，开头和末尾的连续空白字符会被丢弃。

▸ 示例

▾ 示例

Fields are: ["foo" "bar" "baz"]

func FieldsFunc 

func FieldsFunc(s string, f func(rune) bool) []string

FieldsFunc 在每段连续满足 f(c) 的 Unicode 码点 c 处拆分 s，并返回子串切片。如果 s 的所有码点都满足 f(c)，或者 s 为空，返回空切片。结果中的每个元素都非空。与 Split 不同，开头和末尾连续满足 f(c) 的码点会被丢弃。

FieldsFunc 不保证调用 f(c) 的顺序，并假定对于给定的 c，f 始终返回相同结果。

▸ 示例

▾ 示例

Fields are: ["foo1" "bar2" "baz3"]

func Split 

func Split(s, sep string) []string

Split 按 sep 拆分 s，返回由各分隔符之间的子串组成的切片。

如果 s 不包含 sep 且 sep 非空，Split 返回长度为 1 的切片，唯一元素为 s。

如果 sep 为空，Split 在每个 UTF-8 序列之后拆分。如果 s 和 sep 都为空，返回空切片。

它等价于以 -1 作为数量参数调用 SplitN。

如果只想在分隔符第一次出现的位置切分，请参阅 Cut。

▸ 示例

▾ 示例

["a" "b" "c"]
["" "man " "plan " "canal panama"]
[" " "x" "y" "z" " "]
[""]

func SplitAfterN 

func SplitAfterN(s, sep string, n int) []string

SplitAfterN 在 s 中每次出现 sep 的位置之后拆分，返回由这些子串组成的切片。

数量参数决定返回的子串个数：

  • n > 0：最多返回 n 个子串；最后一个子串是尚未拆分的剩余部分。
  • n == 0：结果为 nil，即零个子串。
  • n < 0：返回全部子串。

s 和 sep 的边界情况（例如空字符串），按 SplitAfter 文档所述方式处理。

▸ 示例

▾ 示例

["a," "b,c"]
