sql 包为 SQL（或类似 SQL）的数据库提供通用接口。

sql 包必须配合数据库驱动使用。驱动列表见 https://golang.org/s/sqldrivers。

不支持上下文取消的驱动，只有在查询完成后才会返回。

使用示例见 Wiki 页面：https://golang.org/s/sqlwiki。

type Conn
				
				1.9
			

			
Conn 表示单个数据库连接，而非数据库连接池。除非确实需要持续使用同一个数据库连接，否则应优先通过 DB 执行查询。
使用 Conn 后，必须调用 Conn.Close 将连接归还到数据库连接池；该调用可以与正在运行的查询并发进行。
调用 Conn.Close 后，对此连接的所有操作都会以 ErrConnDone 失败。

func (*Conn) BeginTx
					
					1.9
				

				
func (c *Conn) BeginTx(ctx context.Context, opts *TxOptions) (*Tx, error)

				
BeginTx 开始一个事务。
所提供的上下文会一直使用到事务提交或回滚。如果上下文被取消，sql 包会回滚事务。如果传给 BeginTx 的上下文被取消，Tx.Commit 会返回错误。
TxOptions 是可选参数；使用默认选项时可以传入 nil。如果指定了非默认的隔离级别，而驱动不支持该级别，则返回错误。
func (*Conn) Close
					
					1.9
				

				
func (c *Conn) Close() error

				
Close 将连接归还到连接池。Close 之后的所有操作都会返回 ErrConnDone。Close 可以与其他操作安全地并发调用，并会阻塞，直到其他所有操作完成。先取消所用的上下文，再紧接着调用 Close，可能更为合适。

type DB
				
				
			

			
DB 是一个数据库句柄，表示由零个或多个底层连接组成的连接池。多个 goroutine 可以安全地并发使用它。
sql 包自动创建和释放连接，同时维护一个空闲连接池。如果数据库具有连接级别的状态，可以在事务（Tx）或连接（Conn）中可靠地访问该状态。调用 DB.Begin 后，返回的 Tx 会绑定到单个连接。对该事务调用 Tx.Commit 或 Tx.Rollback 后，其连接会归还到 DB 的空闲连接池。可以通过 DB.SetMaxIdleConns 控制池大小。

func Open
					
					
				

				
func Open(driverName, dataSourceName string) (*DB, error)

				
Open 根据数据库驱动名称和特定于驱动的数据源名称打开数据库。数据源名称通常至少包含数据库名和连接信息。
大多数使用者会通过驱动提供的连接辅助函数打开数据库，该函数返回 *DB。Go 标准库不包含任何数据库驱动。第三方驱动列表见 https://golang.org/s/sqldrivers。
Open 可能只验证实参，而不真正建立数据库连接。要确认数据源名称有效，请调用 DB.Ping。
返回的 DB 可由多个 goroutine 安全地并发使用，并维护自己的空闲连接池。因此，Open 通常只应调用一次。很少需要关闭 DB。

func (*DB) Close
					
					
				

				
func (db *DB) Close() error

				
Close 关闭数据库，并阻止新的查询开始。随后，Close 会等待服务器上已经开始处理的所有查询完成。
通常很少关闭 DB，因为 DB 句柄设计为长期存活，并由多个 goroutine 共享。
func (*DB) Conn
					
					1.9
				

				
func (db *DB) Conn(ctx context.Context) (*Conn, error)

				
Conn 通过打开新连接或从连接池取出已有连接，返回一个数据库连接。Conn 会一直阻塞，直到返回连接或 ctx 被取消。同一个 Conn 上的查询会在同一个数据库会话中执行。
每个 Conn 使用完后，都必须通过调用 Conn.Close 归还到数据库连接池。

func (*Rows) Scan
					
					
				

				
func (rs *Rows) Scan(dest ...any) error

				
Scan 将当前行的各列复制到 dest 指向的值中。dest 中值的个数必须与 Rows 中的列数相同。
Scan 将从数据库读取的列值转换为以下常用 Go 类型，以及 sql 包提供的特殊类型：
*string
*[]byte
*int, *int8, *int16, *int32, *int64
*uint, *uint8, *uint16, *uint32, *uint64
*bool
*float32, *float64
*any
*RawBytes
*Rows (cursor value)
*time.Time
*uuid.UUID
any type implementing Scanner (see Scanner docs)



最简单的情况是：源列值属于整数、bool 或 string 类型 T，而 dest 的类型是 *T，此时 Scan 直接通过指针赋值。
只要不会丢失信息，Scan 也可以在字符串和数值类型之间转换。将数据库数值列读入 *string 时，Scan 会把所有数值转换为字符串；读入数值类型时则会检查溢出。例如，值为 300 的 float64 或值为“300”的字符串可以读入 uint16，但不能读入 uint8；float64(255) 或“255”则可以读入 uint8。有一个例外：某些 float64 数值转换为字符串时可能丢失信息。通常应将浮点数列读入 *float64。
如果某个 dest 实参的类型为 *[]byte，Scan 会将对应数据的副本保存到该实参中。副本归调用方所有，可以修改并无限期保留。改用 *RawBytes 类型的实参可以避免复制；使用限制见 RawBytes 文档。
如果某个实参的类型为 *any，Scan 会直接复制底层驱动提供的值，不做转换。将 []byte 类型的源值读入 *interface{} 时，会复制该切片，结果归调用方所有。
time.Time 类型的源值可以读入 *time.Time、*interface{}、*string 或 *[]byte。转换为后两种类型时，使用 time.RFC3339Nano 格式。
字符串和字节类型的源值可以读入 *uuid.UUID。源值可以是 UUID 的字符串表示，也可以是包含 16 字节的 []byte。
bool 类型的源值可以读入 *bool、*interface{}、*string、*[]byte 或 *RawBytes。
读入 *bool 时，源值可以是 true、false、1、0，或可被 strconv.ParseBool 解析的字符串。
Scan 还可以将查询返回的游标（例如“select cursor(select * from my_table) from dual”）转换为一个自身也可以被读取的 *Rows 值。父级 SELECT 查询的 *Rows 关闭时，也会关闭其所有游标 *Rows。
如果前面的某个实现了 Scanner 的实参返回错误，该错误会被包装在最终返回的错误中。
type Scanner

type Scanner interface {
    // Scan 接收并赋入数据库驱动提供的值。
    //
    // src 值属于以下类型之一：
    //
    //    int64
    //    float64
    //    bool
    //    []byte
    //    string
    //    time.Time
    //    nil - 表示 NULL 值
    //
    // 如果无法在不丢失信息的情况下存储该值，
    // 应返回错误。
    //
    // []byte 等引用类型仅在下一次调用 Scan 之前有效，
    // 不应保留它们。其底层内存由驱动拥有。
    // 如果需要保留，应在下一次调用 Scan 之前复制它们的值。
    Scan(src any) error
}

func (*Tx) QueryRow
					
					
				

				
func (tx *Tx) QueryRow(query string, args ...any) *Row

				
QueryRow 执行一个预期最多返回一行的查询。QueryRow 始终返回非 nil 值，错误会推迟到调用 Row 的 Scan 方法时报告。如果查询没有选中任何行，*Row.Scan 返回 ErrNoRows。否则，*Row.Scan 读取第一条选中的行，并丢弃其余行。
QueryRow 内部使用 context.Background；如需指定上下文，请使用 Tx.QueryRowContext。

Stmt 根据已有语句，返回一个专用于当前事务的预处理语句。
示例：
updateMoney, err := db.Prepare("UPDATE balance SET money=money+? WHERE id=?")

tx, err := db.Begin()
...
res, err := tx.Stmt(updateMoney).Exec(123.45, 98293203)
