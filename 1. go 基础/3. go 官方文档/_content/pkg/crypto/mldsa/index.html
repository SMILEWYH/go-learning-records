mldsa 包实现 FIPS 204 规定的后量子 ML-DSA 签名方案。

使用 FIPS 140-3 Go 密码模块 v1.0.0 时，本包不可用；此时 GenerateKey、NewPrivateKey、NewPublicKey 和 Verify 都会返回错误。使用 v1.26.0 或更高版本时，本包可用。

type Parameters 1.27

Parameters 表示 FIPS 204 定义的固定参数集之一。

多数应用程序应使用 MLDSA44。

多次调用 MLDSA44、MLDSA65 或 MLDSA87 时，各函数都返回各自相同的值，可用于相等性检查和 switch 语句。返回的值可以安全地并发使用。

func (*PrivateKey) Sign 1.27 

func (sk *PrivateKey) Sign(_ io.Reader, message []byte, opts crypto.SignerOpts) (signature []byte, err error)

Sign 使用此私钥返回给定消息的签名。

如果 opts 为 nil，或 opts.HashFunc 返回零，则直接对消息签名。如果 opts.HashFunc 返回 crypto.MLDSAMu，给定消息必须是预先哈希的 μ 消息代表值。如果希望在直接对消息签名时附带上下文字符串，opts 可以使用 *Options 类型。io.Reader 参数会被忽略。

func (*PrivateKey) SignDeterministic 1.27 

func (sk *PrivateKey) SignDeterministic(message []byte, opts crypto.SignerOpts) (signature []byte, err error)

SignDeterministic 的行为与 PrivateKey.Sign 相同，但生成的签名是确定性的。
