mlkem 包实现 NIST FIPS 203 规定的抗量子密钥封装方法 ML-KEM（原名 Kyber）。

多数应用程序应使用由 DecapsulationKey768 和 EncapsulationKey768 实现的 ML-KEM-768 参数集。

const (
    // SharedKeySize 是 ML-KEM 生成的共享密钥的大小。
    SharedKeySize = 32

    // SeedSize 是用于生成解封装密钥的种子的大小。
    SeedSize = 64

    // CiphertextSize768 是 ML-KEM-768 生成的密文的大小。
    CiphertextSize768 = 1088

    // EncapsulationKeySize768 是 ML-KEM-768 封装密钥的大小。
    EncapsulationKeySize768 = 1184

    // CiphertextSize1024 是 ML-KEM-1024 生成的密文的大小。
    CiphertextSize1024 = 1568

    // EncapsulationKeySize1024 是 ML-KEM-1024 封装密钥的大小。
    EncapsulationKeySize1024 = 1568
)

			
		
		
		
		
			
			
type DecapsulationKey1024
				
				1.24
			

			
DecapsulationKey1024 是用于从密文中解封装共享密钥的秘密密钥，包含各种预计算值。

			
type DecapsulationKey1024 struct {
    // 包含已过滤或未导出的字段
}



			

			

			

			
				
func GenerateKey1024
					
					1.24
				

				
func GenerateKey1024() (*DecapsulationKey1024, error)

				
GenerateKey1024 从安全来源获取随机字节，生成新的解封装密钥。解封装密钥必须保密。

				
			
				
func NewDecapsulationKey1024
					
					1.24
				

				
func NewDecapsulationKey1024(seed []byte) (*DecapsulationKey1024, error)

				
NewDecapsulationKey1024 从 "d || z" 形式的 64 字节种子扩展出解封装密钥。种子必须均匀随机。

				
			

			
				
func (*DecapsulationKey1024) Bytes
					
					1.24
				

				
func (dk *DecapsulationKey1024) Bytes() []byte

				
Bytes 将解封装密钥以 "d || z" 形式的 64 字节种子返回。

解封装密钥必须保密。

				
			
				
func (*DecapsulationKey1024) Decapsulate
					
					1.24
				

				
func (dk *DecapsulationKey1024) Decapsulate(ciphertext []byte) (sharedKey []byte, err error)

				
Decapsulate 根据密文和解封装密钥生成共享密钥。如果密文长度不正确，Decapsulate 返回错误。如果密文长度正确但在其他方面无效，则不会返回错误；而是按照 FIPS 203，生成一个与发送方不同的共享密钥。

共享密钥必须保密。

				
			
				
func (*DecapsulationKey1024) EncapsulationKey
					
					1.24
				

				
func (dk *DecapsulationKey1024) EncapsulationKey() *EncapsulationKey1024

				
EncapsulationKey 返回生成密文所需的公开封装密钥。

				
			
				
func (*DecapsulationKey1024) Encapsulator
					
					1.26
				

				
func (dk *DecapsulationKey1024) Encapsulator() crypto.Encapsulator

				
Encapsulator 返回封装密钥，与 DecapsulationKey1024.EncapsulationKey 相同。

它实现 crypto.Decapsulator。
