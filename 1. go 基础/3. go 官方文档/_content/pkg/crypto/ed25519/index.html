ed25519 包实现 Ed25519 签名算法。参见 https://ed25519.cr.yp.to/。

这些函数也兼容 RFC 8032 定义的“Ed25519”函数。不过，与 RFC 8032 的表述不同，本包的私钥表示在末尾附带公钥，以提高使用同一密钥多次签名的效率。本包将 RFC 8032 中的私钥称为“种子”。

涉及私钥的操作使用常量时间算法实现。

▸ 示例 (Ed25519ctx)

▾ 示例 (Ed25519ctx)

代码：

pub, priv, err := GenerateKey(nil)
if err != nil {
    log.Fatal(err)
}

msg := []byte("The quick brown fox jumps over the lazy dog")

sig, err := priv.Sign(nil, msg, &Options{
    Context: "Example_ed25519ctx",
})
if err != nil {
    log.Fatal(err)
}

if err := VerifyWithOptions(pub, msg, sig, &Options{
    Context: "Example_ed25519ctx",
}); err != nil {
    log.Fatal("invalid signature")
}

func GenerateKey 1.13 

func GenerateKey(random io.Reader) (PublicKey, PrivateKey, error)

GenerateKey 使用 random 提供的熵生成一对公钥和私钥。

如果 random 为 nil，则使用安全的随机源。（在 Go 1.26 之前，如果应用程序设置了自定义 crypto/rand.Reader，就会使用它。可以通过 GODEBUG=cryptocustomrand=1 恢复该行为。此设置将在未来的 Go 版本中移除。请改用 testing/cryptotest.SetGlobalRandom。）

此函数的输出是确定性的，等价于从 random 读取 SeedSize 个字节，再将它们传给 NewKeyFromSeed。

func Sign 1.13 

func Sign(privateKey PrivateKey, message []byte) []byte

Sign 使用 privateKey 对 message 签名，并返回签名。如果 len(privateKey) 不等于 PrivateKeySize，则触发 panic。

func Verify 1.13 

func Verify(publicKey PublicKey, message, sig []byte) bool

Verify 报告 sig 是否是 publicKey 对 message 的有效签名。如果 len(publicKey) 不等于 PublicKeySize，则触发 panic。

输入不被视为机密信息，可能通过计时侧信道泄露，或在攻击者能够控制部分输入时泄露。

func VerifyWithOptions 1.20 

func VerifyWithOptions(publicKey PublicKey, message, sig []byte, opts *Options) error

VerifyWithOptions 报告 sig 是否是 publicKey 对 message 的有效签名。返回 nil 错误表示签名有效。如果 len(publicKey) 不等于 PublicKeySize，则触发 panic。

如果 opts.Hash 为 crypto.SHA512，则使用预先哈希的变体 Ed25519ph，并要求 message 为 SHA-512 哈希值。否则，opts.Hash 必须为 crypto.Hash(0)，且消息不得预先哈希，因为 Ed25519 会对待签名消息处理两遍。

输入不被视为机密信息，可能通过计时侧信道泄露，或在攻击者能够控制部分输入时泄露。

type Options 1.20

Options 可与 PrivateKey.Sign 或 VerifyWithOptions 一起使用，以选择 Ed25519 的变体。 

type Options struct {
    // Hash 为零时使用普通 Ed25519，为 crypto.SHA512 时使用 Ed25519ph。
    Hash crypto.Hash

    // Context 非空时，选择 Ed25519ctx 或为 Ed25519ph 提供
    // 上下文字符串。长度最多为 255 字节。
    Context string
}

func (PrivateKey) Sign 1.13 

func (priv PrivateKey) Sign(rand io.Reader, message []byte, opts crypto.SignerOpts) (signature []byte, err error)

Sign 使用 priv 对给定消息签名。rand 被忽略，可以为 nil。

如果 opts.HashFunc() 为 crypto.SHA512，则使用预先哈希的变体 Ed25519ph，并要求 message 为 SHA-512 哈希值。否则，opts.HashFunc() 必须为 crypto.Hash(0)，且消息不得预先哈希，因为 Ed25519 会对待签名消息处理两遍。

可以将 Options 类型的值用作 opts，也可以直接使用 crypto.Hash(0) 或 crypto.SHA512，分别选择普通 Ed25519 或 Ed25519ph。
