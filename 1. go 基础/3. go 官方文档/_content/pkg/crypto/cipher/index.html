type AEAD 1.2

AEAD 是提供带关联数据的认证加密的密码模式。关于此方法的说明，参见 https://en.wikipedia.org/wiki/Authenticated_encryption。 

type AEAD interface {
    // NonceSize 返回传给 Seal 和 Open 的 nonce
    // 必须具有的长度。
    NonceSize() int

    // Overhead 返回明文长度与其密文长度之间
    // 差值的上限。
    Overhead() int

    // Seal 对 plaintext 加密并认证，对附加数据进行
    // 认证，将结果追加到 dst，并返回更新后的
    // 切片。nonce 的长度必须为 NonceSize() 字节，且对于给定密钥，
    // 必须始终唯一，绝不重复。
    //
    // 若要复用 plaintext 的存储空间保存加密结果，请使用 plaintext[:0]
    // 作为 dst。否则，dst 的剩余容量区域不得与 plaintext 重叠。
    // dst 与 additionalData 不得重叠。
    Seal(dst, nonce, plaintext, additionalData []byte) []byte

    // Open 对 ciphertext 解密并认证，对附加数据进行
    // 认证；成功时将得到的明文追加到 dst，
    // 并返回更新后的切片。nonce 的长度必须为 NonceSize()
    // 字节，并且它与附加数据都必须与
    // 传给 Seal 的值一致。
    //
    // 若要复用 ciphertext 的存储空间保存解密结果，请使用 ciphertext[:0]
    // 作为 dst。否则，dst 的剩余容量区域不得与 ciphertext 重叠。
    // dst 与 additionalData 不得重叠。
    //
    // 即使函数失败，dst 容量范围内的内容
    // 也可能被覆盖。
    Open(dst, nonce, ciphertext, additionalData []byte) ([]byte, error)
}

func NewGCMWithNonceSize
					
					1.5
				

				
func NewGCMWithNonceSize(cipher Block, size int) (AEAD, error)

				
NewGCMWithNonceSize 将给定的 128 位分组密码封装为伽罗瓦计数器模式并返回，该模式接受指定长度的 nonce。长度不得为零。

仅在需要兼容使用非标准 nonce 长度的现有密码系统时才使用此函数。其他情况下都应使用 NewGCM，它速度更快，也更不容易被误用。

				
			
				
func NewGCMWithRandomNonce
					
					1.24
				

				
func NewGCMWithRandomNonce(cipher Block) (AEAD, error)

				
NewGCMWithRandomNonce 将给定密码封装为使用随机生成 nonce 的伽罗瓦计数器模式并返回。该密码必须由 crypto/aes.NewCipher 创建。

它生成随机的 96 位 nonce，由 Seal 添加到密文前面，并由 Open 从密文中提取。该 AEAD 的 NonceSize 为零，而 Overhead 为 28 字节（nonce 大小与标签大小之和）。

同一个密钥绝不能用于加密超过 2^32 条消息，以将随机 nonce 碰撞的风险控制在可忽略的水平。

				
			
				
func NewGCMWithTagSize

NewGCMWithTagSize 将给定的 128 位分组密码封装为伽罗瓦计数器模式并返回，该模式生成指定长度的认证标签。

仅在需要兼容使用非标准标签长度的现有密码系统时才使用此函数。其他情况下都应使用 NewGCM，它更不容易被误用。

				
			

			
		
			
			
type Block
				
				
			

			
Block 表示使用给定密钥的分组密码实现，提供加密或解密单个分组的能力。工作模式的实现将这种能力扩展到分组流。

			
type Block interface {
    // BlockSize 返回该密码的分组大小。
    BlockSize() int

    // Encrypt 将 src 中的第一个分组加密到 dst。
    // dst 和 src 必须完全重叠，或完全不重叠。
    Encrypt(dst, src []byte)

    // Decrypt 将 src 中的第一个分组解密到 dst。
    // dst 和 src 必须完全重叠，或完全不重叠。
    Decrypt(dst, src []byte)
}


			

			

			

			

			
		
			
			
type BlockMode
				
				
			

			
BlockMode 表示运行于分组工作模式（CBC、ECB 等）的分组密码。

			
type BlockMode interface {
    // BlockSize 返回该模式的分组大小。
    BlockSize() int

    // CryptBlocks 加密或解密若干个分组。src 的长度
    // 必须是分组大小的整数倍。dst 和 src 必须
    // 完全重叠，或完全不重叠。
    //
    // 如果 len(dst) < len(src)，CryptBlocks 应触发 panic。允许
    // 传入比 src 更大的 dst；此时，CryptBlocks
    // 只更新 dst[:len(src)]，不会修改 dst 的其余部分。
    //
    // 多次调用 CryptBlocks 的行为，等同于将各个 src
    // 缓冲区拼接后一次传入。也就是说，BlockMode
    // 会保留状态，不会在每次 CryptBlocks 调用时重置。
    CryptBlocks(dst, src []byte)
}

type Stream
				
				
			

			
Stream 表示流密码。

			
type Stream interface {
    // XORKeyStream 将给定切片的每个字节与密码密钥流
    // 中的一个字节进行异或。dst 和 src 必须完全重叠，或完全不重叠。
    //
    // 如果 len(dst) < len(src)，XORKeyStream 应触发 panic。允许
    // 传入比 src 更大的 dst；此时，XORKeyStream
    // 只更新 dst[:len(src)]，不会修改 dst 的其余部分。
    //
    // 多次调用 XORKeyStream 的行为，等同于将各个 src
    // 缓冲区拼接后一次传入。也就是说，Stream
    // 会保留状态，不会在每次 XORKeyStream 调用时重置。
    XORKeyStream(dst, src []byte)
}

type StreamWriter
				
				
			

			
StreamWriter 将 Stream 封装为 io.Writer。它调用 XORKeyStream 处理流经的每个数据切片。如果任何一次 StreamWriter.Write 调用返回短写，StreamWriter 就已失去同步，必须丢弃。StreamWriter 没有内部缓冲区，无需调用 StreamWriter.Close 来刷新写入的数据。

			
type StreamWriter struct {
    S   Stream
    W   io.Writer
    Err error // 未使用
}
