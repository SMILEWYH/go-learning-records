ecdsa 包实现 FIPS 186-5 定义的椭圆曲线数字签名算法。

本包生成的签名不是确定性的，但会将熵与私钥及消息混合，因此在随机源失效时仍可达到相同的安全级别。

只要使用的 elliptic.Curve 来自 elliptic.P224、elliptic.P256、elliptic.P384 或 elliptic.P521，涉及私钥的操作就使用常量时间算法实现。

func Sign
				
				
			

			
func Sign(rand io.Reader, priv *PrivateKey, hash []byte) (r, s *big.Int, err error)

			
Sign 使用私钥 priv 对哈希值签名（此值应由较长的消息经哈希计算得到）。如果哈希值长度超过私钥所用曲线的阶的位数，就将其截断到该长度。签名以一对整数返回。多数应用程序应使用 SignASN1，而不是直接处理 r、s。

签名是随机化的。自 Go 1.26 起，始终使用安全的随机字节源；除非设置 GODEBUG=cryptocustomrand=1，否则会忽略 Reader。此设置将在未来的 Go 版本中移除。请改用 testing/cryptotest.SetGlobalRandom。

func Verify
				
				
			

			
func Verify(pub *PublicKey, hash []byte, r, s *big.Int) bool

			
Verify 使用公钥 pub 验证 r、s 所表示的 hash 的签名，返回值表示签名是否有效。多数应用程序应使用 VerifyASN1，而不是直接处理 r、s。

输入不被视为机密信息，可能通过计时侧信道泄露，或在攻击者能够控制部分输入时泄露。

type PrivateKey struct {
    PublicKey

    // D 是私钥的标量值。
    //
    // 已弃用：修改原始值可能产生无效密钥，
    // 并使内部优化失效；此外，[big.Int] 方法

    // 对于 ECDH，请使用 [crypto/ecdh]。

}

func GenerateKey(c elliptic.Curve, r io.Reader) (*PrivateKey, error)

				
GenerateKey 为指定曲线生成新的 ECDSA 私钥。

自 Go 1.26 起，始终使用安全的随机字节源；除非设置 GODEBUG=cryptocustomrand=1，否则会忽略 Reader。此设置将在未来的 Go 版本中移除。请改用 testing/cryptotest.SetGlobalRandom。

				
			
				
func ParseRawPrivateKey
					
					1.25
				

				
func ParseRawPrivateKey(curve elliptic.Curve, data []byte) (*PrivateKey, error)

				
ParseRawPrivateKey 解析按 SEC 1 第 2.0 版第 2.3.6 节编码为定长大端整数的私钥（有时称为原始格式）。如果该值未约减到曲线阶的模范围内，或为零，则返回错误。

curve 必须是 elliptic.P224、elliptic.P256、elliptic.P384 或 elliptic.P521 之一，否则 ParseRawPrivateKey 返回错误。

ParseRawPrivateKey 接受的格式与 ecdh.Curve.NewPrivateKey 对 NIST 曲线接受的格式相同，但返回 PrivateKey，而非 ecdh.PrivateKey。

注意，私钥更常使用 ASN.1 或 PKCS#8 格式编码，可以用 crypto/x509.ParseECPrivateKey 或 crypto/x509.ParsePKCS8PrivateKey（配合 encoding/pem）解析。

				
			

			
				
func (*PrivateKey) Bytes
					
					1.25
				

				
func (priv *PrivateKey) Bytes() ([]byte, error)

				
Bytes 按 SEC 1 第 2.0 版第 2.3.6 节将私钥编码为定长大端整数（有时称为原始格式）。私钥无效时返回错误。

PrivateKey.Curve 必须是 elliptic.P224、elliptic.P256、elliptic.P384 或 elliptic.P521 之一，否则 Bytes 返回错误。

Bytes 返回的格式与 ecdh.PrivateKey.Bytes 对 NIST 曲线返回的格式相同。

注意，私钥更常使用 ASN.1 或 PKCS#8 格式编码，可以用 crypto/x509.MarshalECPrivateKey 或 crypto/x509.MarshalPKCS8PrivateKey（配合 encoding/pem）生成。

func (*PrivateKey) Sign
					
					1.4
				

				
func (priv *PrivateKey) Sign(random io.Reader, digest []byte, opts crypto.SignerOpts) ([]byte, error)

				
Sign 使用私钥 priv 对哈希值签名（此值应由较长消息经 opts.HashFunc() 计算得到）。如果哈希值长度超过私钥所用曲线的阶的位数，就将其截断到该长度。与 SignASN1 一样，它返回 ASN.1 编码的签名。

如果 random 非 nil，签名就是随机化的。多数应用程序应将 crypto/rand.Reader 作为 random；但除非设置 GODEBUG=cryptocustomrand=1，否则始终使用安全的随机字节源，忽略实际传入的 Reader。此 GODEBUG 设置将在未来的 Go 版本中移除。请改用 testing/cryptotest.SetGlobalRandom。

如果 random 为 nil，Sign 将按照 RFC 6979 生成确定性签名。生成确定性签名时，opts.HashFunc() 必须是用于生成 digest 的函数，且 priv.Curve 必须是 elliptic.P224、elliptic.P256、elliptic.P384 或 elliptic.P521 之一。

				
			
		
			
			
type PublicKey
				
				
			

			
PublicKey 表示 ECDSA 公钥。

			
type PublicKey struct {
    elliptic.Curve

    // X、Y 是公钥点的坐标。
    //
    // 已弃用：修改原始坐标可能产生无效密钥，
    // 并使内部优化失效；此外，[big.Int] 方法
    // 不适合处理密码学值。要编码和解码
    // PublicKey 值，请使用 [PublicKey.Bytes] 和 [ParseUncompressedPublicKey]，
    // 或 [crypto/x509.MarshalPKIXPublicKey] 和 [crypto/x509.ParsePKIXPublicKey]。
    // 对于 ECDH，请使用 [crypto/ecdh]。对于更底层的椭圆曲线运算，
    // 请使用 filippo.io/nistec 等第三方模块。
    X, Y *big.Int
}



			

			

			

			
				
func ParseUncompressedPublicKey
					
					1.25
				

				
func ParseUncompressedPublicKey(curve elliptic.Curve, data []byte) (*PublicKey, error)

				
ParseUncompressedPublicKey 解析按 SEC 1 第 2.0 版第 2.3.3 节编码为未压缩点的公钥（也称为 X9.62 未压缩格式）。如果点不是未压缩形式、不在曲线上，或为无穷远点，则返回错误。

curve 必须是 elliptic.P224、elliptic.P256、elliptic.P384 或 elliptic.P521 之一，否则 ParseUncompressedPublicKey 返回错误。

ParseUncompressedPublicKey 接受的格式与 ecdh.Curve.NewPublicKey 对 NIST 曲线接受的格式相同，但返回 PublicKey，而非 ecdh.PublicKey。

注意，公钥更常使用 DER（或 PEM）格式编码，可以用 crypto/x509.ParsePKIXPublicKey（配合 encoding/pem）解析。

PublicKey.Curve 必须是 elliptic.P224、elliptic.P256、elliptic.P384 或 elliptic.P521 之一，否则 Bytes 返回错误。

Bytes 返回的格式与 ecdh.PublicKey.Bytes 对 NIST 曲线返回的格式相同。

func (*PublicKey) Equal
					
					1.15
				

				
func (pub *PublicKey) Equal(x crypto.PublicKey) bool

				
Equal 报告 pub 和 x 是否具有相同的值。

只有具有相同 Curve 值的两个密钥才被视为值相同。例如，elliptic.P256 和 elliptic.P256().Params() 是不同的值，因为后者是通用的非常量时间实现。
