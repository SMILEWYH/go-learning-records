hkdf 包实现 RFC 5869 定义的基于 HMAC 的提取与扩展密钥派生函数（HKDF）。

HKDF 是密码学密钥派生函数（KDF），旨在将有限的输入密钥材料扩展为一个或多个具有密码学强度的秘密密钥。

func Expand 

func Expand[H hash.Hash](h func() H, pseudorandomKey []byte, info string, keyLength int) ([]byte, error)

Expand 根据给定的哈希函数、密钥及可选上下文信息 info 派生密钥，返回长度为 keyLength 的 []byte，可用作密码学密钥。此过程跳过提取步骤。

key 应由 Extract 生成，或者是均匀随机或伪随机、具有密码学强度的密钥。参见 RFC 5869 第 3.3 节。多数常见场景应改用 Key。

func Extract 

func Extract[H hash.Hash](h func() H, secret, salt []byte) ([]byte, error)

Extract 根据输入秘密和可选的独立盐值生成伪随机密钥，供 Expand 使用。

只有需要在多次 Expand 调用中搭配不同上下文值复用提取出的密钥时，才应使用此函数。多数常见场景（包括生成多个密钥）都应改用 Key。

func Key 

func Key[Hash hash.Hash](h func() Hash, secret, salt []byte, info string, keyLength int) ([]byte, error)

Key 根据给定的哈希函数、secret、salt 和上下文信息 info 派生密钥，返回长度为 keyLength 的 []byte，可用作密码学密钥。salt 和 info 可以为 nil。
