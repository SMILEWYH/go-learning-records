func SignMessage 1.25

SignMessage 使用 signer 对 msg 签名。如果 signer 实现了 MessageSigner，就直接调用 MessageSigner.SignMessage。否则，先用 opts.HashFunc() 对 msg 进行哈希，再通过 Signer.Sign 签名。

type Decapsulator 1.26

Decapsulator 是不透明 KEM 私钥的接口，可用于解封装操作，例如保存在硬件模块中的 ML-KEM 密钥。

例如，crypto/mlkem.DecapsulationKey768 实现了此接口。 

type Decapsulator interface {
    Encapsulator() Encapsulator
    Decapsulate(ciphertext []byte) (sharedKey []byte, err error)
}

type Decrypter 1.5

Decrypter 是不透明私钥的接口，可用于非对称解密操作，例如保存在硬件模块中的 RSA 密钥。 

type Decrypter interface {
    // Public 返回与此不透明私钥
    // 对应的公钥。
    Public() PublicKey

    // Decrypt 解密 msg。opts 参数应适合
    // 所使用的密码原语。详情请参阅各个实现
    // 的文档。
    Decrypt(rand io.Reader, msg []byte, opts DecrypterOpts) (plaintext []byte, err error)
}

type MessageSigner 1.25

MessageSigner 是不透明私钥的接口，可用于调用方不预先对消息进行哈希的签名操作。它是 Signer 接口的超集，因此可以传给接受 Signer 的 API，供这些 API 尝试通过类型断言使用此扩展接口。

在 opts 相同的情况下，MessageSigner.SignMessage 与 MessageSigner.Sign 应生成相同的结果。尤其是，只有当 Signer 也接受未经预先哈希的消息时，MessageSigner.SignMessage 才应接受值为零的 opts.HashFunc。

不提供预先哈希的 Sign API 的实现，应让 Signer.Sign 始终返回错误。 

type MessageSigner interface {
    Signer
    SignMessage(rand io.Reader, msg []byte, opts SignerOpts) (signature []byte, err error)
}

type PrivateKey

PrivateKey 表示算法未指定的私钥。

虽然出于向后兼容的原因，该类型是空接口，但标准库中的所有私钥类型都实现以下接口 

interface{
    Public() crypto.PublicKey
    Equal(x crypto.PrivateKey) bool
}

以及 Signer、Decrypter 等特定用途的接口，以便应用程序提高类型安全性。

type Signer 1.4

Signer 是不透明私钥的接口，可用于签名操作，例如保存在硬件模块中的 RSA 密钥。 

type Signer interface {
    // Public 返回与此不透明私钥
    // 对应的公钥。
    Public() PublicKey

    // Sign 使用私钥对 digest 签名，可能会使用 rand
    // 提供的熵。对于 RSA 密钥，结果应为
    // PKCS #1 v1.5 或 PSS 签名（由 opts 指定）。对于 (EC)DSA
    // 密钥，结果应为经过 DER 序列化的 ASN.1 签名结构。
    //
    // Hash 实现了 SignerOpts 接口，因此多数情况下，
    // 只需将所用的哈希函数作为 opts 传入。Sign 还可能
    // 尝试将 opts 类型断言为其他类型，以获取特定算法
    // 所需的值。详情请参阅各包的文档。
    //
    // 注意，需要对较长消息的哈希值签名时，
    // 调用方负责先对该消息进行哈希，再将哈希值（作为 digest）
    // 和哈希函数（作为 opts）传给 Sign。
    Sign(rand io.Reader, digest []byte, opts SignerOpts) (signature []byte, err error)
}

type SignerOpts 1.4

SignerOpts 包含使用 Signer 签名时的选项。 

type SignerOpts interface {
    // HashFunc 返回用于生成传给 Signer.Sign 的消息
    // 的哈希函数标识符；返回零则表示
    // 未进行哈希。
    HashFunc() Hash
}
