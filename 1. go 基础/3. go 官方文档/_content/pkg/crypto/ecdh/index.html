type Curve 1.20 

type Curve interface {
    // GenerateKey 生成随机的 PrivateKey。
    //
    // 自 Go 1.26 起，始终使用安全的随机字节源，除非设置
    // GODEBUG=cryptocustomrand=1，否则会忽略 rand。此设置将在
    // 未来的 Go 版本中移除。请改用 [testing/cryptotest.SetGlobalRandom]。
    GenerateKey(rand io.Reader) (*PrivateKey, error)

    // NewPrivateKey 检查 key 是否有效，并返回 PrivateKey。
    //
    // 对于 NIST 曲线，此方法遵循 SEC 1 第 2.0 版第 2.3.6 节，
    // 即将字节解码为定长大端整数，
    // 并检查结果是否小于曲线的阶。它也会拒绝
    // 零值私钥，因为对应公钥的编码
    // 不符合常规形式。
    //
    // 对于 X25519，只检查标量的长度。
    NewPrivateKey(key []byte) (*PrivateKey, error)

    // NewPublicKey 检查 key 是否有效，并返回 PublicKey。
    //
    // 对于 NIST 曲线，此方法按 SEC 1
    // 第 2.0 版第 2.3.4 节解码未压缩点。压缩编码和
    // 无穷远点会被拒绝。
    //
    // 对于 X25519，只检查 u 坐标的长度。恶意选择的
    // 公钥可能导致 ECDH 返回错误。
    NewPublicKey(key []byte) (*PublicKey, error)
    // 包含已过滤或未导出的方法
}

func P256 1.20 

func P256() Curve

P256 返回实现 NIST P-256（FIPS 186-3 第 D.2.3 节）的 Curve，该曲线也称为 secp256r1 或 prime256v1。

多次调用此函数会返回相同的值，可用于相等性检查和 switch 语句。

type KeyExchanger 1.26

KeyExchanger 是不透明私钥的接口，可用于密钥交换操作，例如保存在硬件模块中的 ECDH 密钥。

func (*PrivateKey) ECDH 1.20 

func (k *PrivateKey) ECDH(remote *PublicKey) ([]byte, error)

ECDH 执行 ECDH 密钥交换并返回共享秘密。PrivateKey 与 PublicKey 必须使用同一条曲线。

对于 NIST 曲线，此方法按照 SEC 1 第 2.0 版第 3.3.1 节执行 ECDH，并返回按 SEC 1 第 2.0 版第 2.3.5 节编码的 x 坐标。结果绝不会是无穷远点。这也称为 NIST SP 800-56A 修订版 3 第 6.1.2.2 节规定的临时统一模型方案的共享秘密计算。

对于 X25519，此方法按照 RFC 7748 第 6.1 节执行 ECDH。如果结果为全零值，ECDH 返回错误。

func (*PrivateKey) Equal 1.20 

func (k *PrivateKey) Equal(x crypto.PrivateKey) bool

Equal 返回 x 是否表示与 k 相同的私钥。

注意，可能存在编码不同但等价的私钥：此检查对它们返回 false，但它们作为 [ECDH] 的输入时行为相同。

只要密钥类型及其曲线匹配，此检查就以常量时间执行。
