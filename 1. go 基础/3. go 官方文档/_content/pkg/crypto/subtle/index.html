func ConstantTimeCompare 

func ConstantTimeCompare(x, y []byte) int

如果两个切片 x 和 y 的内容相等，ConstantTimeCompare 返回 1；否则返回 0。耗时只取决于切片长度，与内容无关。如果 x 与 y 长度不同，则立即返回 0。

func ConstantTimeCopy 

func ConstantTimeCopy(v int, x, y []byte)

如果 v == 1，ConstantTimeCopy 将 y 的内容复制到等长切片 x。如果 v == 0，则保持 x 不变。如果 v 为其他值，则行为未定义。

func ConstantTimeLessOrEq 1.2 

func ConstantTimeLessOrEq(x, y int) int

如果 x <= y，ConstantTimeLessOrEq 返回 1；否则返回 0。如果 x 或 y 为负数，或 > 2**31 - 1，则行为未定义。

func ConstantTimeSelect 

func ConstantTimeSelect(v, x, y int) int

如果 v == 1，ConstantTimeSelect 返回 x；如果 v == 0，则返回 y。如果 v 为其他值，则行为未定义。

func WithDataIndependentTiming 1.24 

func WithDataIndependentTiming(f func())

WithDataIndependentTiming 在执行 f 之前，启用特定架构的功能，以确保某些指令的执行时间与其输入无关；f 返回后，再禁用这些功能。

f 启动的任何 goroutine 及其后代 goroutine，都会在整个生命周期中启用数据无关计时。

从 f 内部或 f 启动的 goroutine 中通过 cgo 调用的 C 代码，也会在调用期间启用数据无关计时。如果 C 代码禁用了数据无关计时，返回 Go 时会重新启用。

如果从 f 或其他位置通过 cgo 调用的 C 代码启用或禁用了数据无关计时，那么它再调用 Go 时，此状态会在调用期间保留。

只有在 f 的实现确实使用常量时间操作时，才应使用 WithDataIndependentTiming。WithDataIndependentTiming 不会将变时执行的代码变为常量时间代码。

WithDataIndependentTiming 的调用可以嵌套。

在支持 FEAT_DIT 的 Arm64 处理器上，WithDataIndependentTiming 会启用 PSTATE.DIT。参见 https://developer.arm.com/documentation/ka005181/1-0/?lang=en。

目前，在所有其他架构上，WithDataIndependentTiming 会立即执行 f，不产生其他副作用。

func XORBytes 1.20 

func XORBytes(dst, x, y []byte) int

XORBytes 对所有 i < n = min(len(x), len(y)) 设置 dst[i] = x[i] ^ y[i]，并返回写入 dst 的字节数 n。

如果 dst 的长度小于 n，XORBytes 会在不向 dst 写入任何内容的情况下触发 panic。

dst 与 x 或 y 只能完全重叠或完全不重叠，否则 XORBytes 可能触发 panic。
