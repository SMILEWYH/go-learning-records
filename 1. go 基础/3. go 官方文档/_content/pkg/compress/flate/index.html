flate 包实现 RFC 1951 描述的 DEFLATE 压缩数据格式。compress/gzip 和 compress/zlib 包实现对基于 DEFLATE 的文件格式的访问。

const (
    NoCompression      = 0
    BestSpeed          = 1
    BestCompression    = 9
    DefaultCompression = -1

    // HuffmanOnly 禁用 Lempel-Ziv 匹配搜索，只执行 Huffman
    // 熵编码。此模式适用于压缩已由缺少熵编码器的
    // LZ 类算法（例如 Snappy 或 LZ4）
    // 压缩过的数据。当输入流中某些字节
    // 比其他字节出现得更频繁时，就可以获得压缩收益。
    //
    // 注意，HuffmanOnly 产生的压缩输出
    // 符合 RFC 1951。也就是说，任何有效的 DEFLATE 解压缩器
    // 仍然可以解压缩该输出。
    HuffmanOnly = -2
)

func NewReader 

func NewReader(r io.Reader) io.ReadCloser

NewReader 返回一个新的 ReadCloser，可用于读取 r 的解压缩版本。如果 r 没有同时实现 io.ByteReader，解压缩器从 r 读取的数据可能多于实际所需的数据。读取器在遇到 DEFLATE 流的最后一个块后返回 io.EOF。最后一个块之后的所有尾随数据均被忽略。

NewReader 返回的 io.ReadCloser 还实现了 Resetter。

func NewReaderDict 

func NewReaderDict(r io.Reader, dict []byte) io.ReadCloser

NewReaderDict 类似于 NewReader，但使用预设字典初始化读取器。返回的读取器的行为，就像未压缩数据流以给定字典开头，且该字典已被读取一样。NewReaderDict 通常用于读取由 NewWriterDict 压缩的数据。

NewReaderDict 返回的 ReadCloser 还实现了 Resetter。

func NewWriter 

func NewWriter(w io.Writer, level int) (*Writer, error)

NewWriter 返回一个按给定级别压缩数据的新 Writer。与 zlib 一致，级别范围为 1（BestSpeed）到 9（BestCompression）；较高级别通常速度更慢，但压缩率更高。级别 0（NoCompression）不尝试压缩，只添加必要的 DEFLATE 帧结构。级别 -1（DefaultCompression）使用默认压缩级别。级别 -2（HuffmanOnly）仅使用 Huffman 压缩，对所有类型的输入都能进行非常快速的压缩，但会牺牲相当多的压缩效率。

如果 level 在 [-2, 9] 范围内，则返回的错误为 nil。否则返回非 nil 错误。

注意，写入 w 的确切字节内容不在 Go 1 兼容性承诺范围内。调用方（包括测试）不应依赖实际写入的精确字节内容。

func NewWriterDict 

func NewWriterDict(w io.Writer, level int, dict []byte) (*Writer, error)

NewWriterDict 类似于 NewWriter，但使用预设字典初始化新的 Writer。返回的 Writer 的行为，就像字典已经写入其中，但没有产生任何压缩输出一样。写入 w 的压缩数据只能由使用相同字典初始化的读取器解压缩（参见 NewReaderDict）。

注意，写入 w 的确切字节内容不在 Go 1 兼容性承诺范围内。调用方（包括测试）不应依赖实际写入的精确字节内容。

func (*Writer) Flush 

func (w *Writer) Flush() error

Flush 将所有待输出的数据刷新到底层写入器。它主要用于压缩网络协议，以确保远端读取器有足够的数据重建一个数据包。Flush 在数据写入完成之前不会返回。即使没有待输出数据，调用 Flush 仍会使 Writer 输出至少 4 字节的同步标记。如果底层写入器返回错误，Flush 返回该错误。

用 zlib 库的术语来说，Flush 等价于 Z_SYNC_FLUSH。

func (*Writer) Reset 1.2 

func (w *Writer) Reset(dst io.Writer)

Reset 丢弃写入器的状态，使其等价于使用 dst 以及 w 的压缩级别和字典调用 NewWriter 或 NewWriterDict 所得到的结果。

func (w *Writer) Write(data []byte) (n int, err error)

Write 将 data 写入 w，w 最终会将 data 的压缩形式写入其底层写入器。
