type Header

gzip 文件存储一个包含压缩文件元数据的头部。该头部通过 Writer 和 Reader 结构体的字段暴露。

由于 GZIP 文件格式的限制，字符串必须以 UTF-8 编码，且只能包含 U+0001 到 U+00FF 范围内的 Unicode 码点。

type Header struct {
    Comment string    // 注释
    Extra   []byte    // “额外数据”
    ModTime time.Time // 修改时间
    Name    string    // 文件名
    OS      byte      // 操作系统类型
}

type Reader

Reader 是一个 io.Reader，可以通过读取它从 gzip 格式的压缩文件中获取未压缩数据。

一般而言，gzip 文件可以由多个 gzip 文件拼接而成，每个文件有各自的头部。从 Reader 读取时，会返回各段解压缩数据拼接后的结果。Reader 字段中只记录第一个头部。

Gzip 文件存储未压缩数据的长度和校验和。如果数据的长度或校验和与预期不符，则当 Reader.Read 到达未压缩数据的末尾时，Reader 返回 ErrChecksum。调用方应将 Reader.Read 返回的数据视为尚待验证，直到收到表示数据结束的 io.EOF。

type Reader struct {
    Header // 在 NewReader 或 Reader.Reset 之后有效
    // 包含已过滤或未导出的字段
}

func NewReader 

func NewReader(r io.Reader) (*Reader, error)

NewReader 创建一个读取给定读取器的新 Reader。如果 r 没有同时实现 io.ByteReader，解压缩器从 r 读取的数据可能多于实际所需的数据。

调用方有责任在使用结束后调用 Reader.Close。

返回的 Reader 中，Reader.Header 的各字段均有效。

func (*Reader) Close 

func (z *Reader) Close() error

Close 关闭 Reader。它不会关闭底层读取器。为验证 GZIP 校验和，必须完整读取到 io.EOF。

func (*Reader) Multistream 1.4 

func (z *Reader) Multistream(ok bool)

Multistream 控制读取器是否支持多流文件。

启用时（默认行为），Reader 预期输入为一系列单独经过 gzip 压缩的数据流，每个都有各自的头部和尾部，整个序列在 EOF 处结束。其效果是将一系列 gzip 文件的拼接，视为等价于对这些文件原始数据的拼接结果进行 gzip 压缩。这是 gzip 读取器的标准行为。

调用 Multistream(false) 会禁用此行为；在读取需要区分单独 gzip 数据流，或者将 gzip 数据流与其他数据流混合的文件格式时，禁用此行为可能有用。在此模式下，当 Reader 到达数据流末尾时，Reader.Read 返回 io.EOF。为使底层读取器的位置恰好停留在 gzip 流之后，底层读取器必须实现 io.ByteReader。要开始读取下一个流，应先调用 z.Reset(r)，再调用 z.Multistream(false)。如果没有下一个流，z.Reset(r) 将返回 io.EOF。

type Writer

Writer 是一个 io.WriteCloser。写入 Writer 的数据会被压缩并写入 w。

type Writer struct {
    Header // 在第一次调用 Write、Flush 或 Close 时写入
    // 包含已过滤或未导出的字段
}

func NewWriter 

func NewWriter(w io.Writer) *Writer

NewWriter 返回一个新的 Writer。写入返回的写入器的数据会被压缩并写入 w。

调用方有责任在使用结束后调用 Writer 的 Close。写入的数据可能被缓冲，直到 Close 才刷新。

希望设置 Writer.Header 字段的调用方，必须在第一次调用 Write、Flush 或 Close 之前完成设置。

注意，写入 w 的确切字节内容不在 Go 1 兼容性承诺范围内。调用方（包括测试）不应依赖实际写入的精确字节内容。

func NewWriterLevel 

func NewWriterLevel(w io.Writer, level int) (*Writer, error)

NewWriterLevel 类似于 NewWriter，但可以指定压缩级别，而不是采用 DefaultCompression。

压缩级别可以是 DefaultCompression、NoCompression、HuffmanOnly，或者 BestSpeed 与 BestCompression 之间的任意整数（含两端）。如果级别有效，返回的错误为 nil。

注意，写入 w 的确切字节内容不在 Go 1 兼容性承诺范围内。调用方（包括测试）不应依赖实际写入的精确字节内容。

func (*Writer) Close 

func (z *Writer) Close() error

Close 将所有尚未写出的数据刷新到底层 io.Writer，并写入 GZIP 尾部，从而关闭 Writer。它不会关闭底层 io.Writer。

func (*Writer) Flush 1.1 

func (z *Writer) Flush() error

Flush 将所有待输出的压缩数据刷新到底层写入器。

它主要用于压缩网络协议，以确保远端读取器有足够的数据重建一个数据包。Flush 在数据写入完成之前不会返回。如果底层写入器返回错误，Flush 返回该错误。

用 zlib 库的术语来说，Flush 等价于 Z_SYNC_FLUSH。

func (*Writer) Reset 1.2 

func (z *Writer) Reset(w io.Writer)

Reset 丢弃 Writer z 的状态，使其等价于由 NewWriter 或 NewWriterLevel 创建时的初始状态，但改为向 w 写入。这样可以复用 Writer，无须分配新的实例。

func (*Writer) Write 

func (z *Writer) Write(p []byte) (int, error)

Write 将 p 的压缩形式写入底层 io.Writer。压缩后的字节可能要等到 Writer 关闭时才会刷新。
