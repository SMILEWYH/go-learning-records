asn1 包实现了对 DER 编码的 ASN.1 数据结构的解析，其定义见 ITU-T Rec X.690。

另见《ASN.1、BER 和 DER 子集入门指南》（A Layman's Guide to a Subset of ASN.1, BER, and DER）：http://luca.ntop.org/Teaching/Appunti/asn1.html。

func Unmarshal 

func Unmarshal(b []byte, val any) (rest []byte, err error)

Unmarshal 解析 DER 编码的 ASN.1 数据结构 b，并使用 reflect 包填充 val 指向的任意值。由于 Unmarshal 使用 reflect 包，写入的结构体必须使用大写字母开头的字段名。如果 val 为 nil 或不是指针，Unmarshal 会返回错误。

解析 b 后，剩余的、未用于填充 val 的字节会通过 rest 返回。将 SEQUENCE 解析到结构体时，SEQUENCE 末尾在 val 中没有对应字段的元素不会包含在 rest 中，因为它们被视为 SEQUENCE 的有效元素，而非尾随数据。

  • ASN.1 INTEGER 可以写入 int、int32、int64 或 *big.Int。如果编码的值超出 Go 类型的表示范围，Unmarshal 会返回解析错误。

  • ASN.1 BIT STRING 可以写入 BitString。

  • ASN.1 OCTET STRING 可以写入 []byte。

  • ASN.1 OBJECT IDENTIFIER 可以写入 ObjectIdentifier。

  • ASN.1 ENUMERATED 可以写入 Enumerated。

  • ASN.1 UTCTIME 或 GENERALIZEDTIME 可以写入 time.Time。

  • ASN.1 PrintableString、IA5String 或 NumericString 可以写入 string。

  • 上述任意 ASN.1 值均可写入 interface{}。接口中保存的值具有对应的 Go 类型。对于整数，该类型为 int64。

  • 如果 x 可以写入切片的元素类型，则 ASN.1 SEQUENCE OF x 或 SET OF x 可以写入该切片。

  • 如果序列中的每个元素都能写入结构体中对应的元素，则 ASN.1 SEQUENCE 或 SET 可以写入该结构体。

Unmarshal 对结构体字段上的以下标签有特殊解释： 

application 指定使用 APPLICATION 标签
private     指定使用 PRIVATE 标签
default:x   为可选的整数字段设置默认值（仅在同时指定 optional 时生效）
explicit    指定在隐式标签外再包裹一个显式标签
optional    将字段标记为 ASN.1 OPTIONAL
set         预期类型为 SET，而非 SEQUENCE
tag:x       指定 ASN.1 标签编号；隐含 ASN.1 CONTEXT SPECIFIC 类别

将带有 IMPLICIT 标签的 ASN.1 值解码到字符串字段时，Unmarshal 默认采用 PrintableString，它不支持 '@' 和 '&' 等字符。若要强制采用其他编码，请使用以下标签： 

ia5     将字符串按 ASN.1 IA5String 值反序列化
numeric 将字符串按 ASN.1 NumericString 值反序列化
utf8    将字符串按 ASN.1 UTF8String 值反序列化

将带有 IMPLICIT 标签的 ASN.1 值解码到 time.Time 字段时，Unmarshal 默认采用 UTCTime，它不支持时区或小数秒。若要强制采用 GeneralizedTime，请使用以下标签： 

generalized 将 time.Time 按 ASN.1 GeneralizedTime 值反序列化

如果结构体第一个字段的类型为 RawContent，则该结构体的原始 ASN1 内容会保存在此字段中。

如果切片类型的名称以“SET”结尾，则会按带有“set”标签的方式处理。此时该类型会被解释为 SET OF x，而非 SEQUENCE OF x。这可用于无法指定结构体标签的嵌套切片。

不支持其他 ASN.1 类型；如果遇到它们，Unmarshal 会返回解析错误。

type BitString

BitString 是表示 ASN.1 BIT STRING 类型时使用的结构。位串在内存中填充到整字节边界，同时记录有效位数。填充位为零。 

type BitString struct {
    Bytes     []byte // 按字节打包的位。
    BitLength int    // 以位为单位的长度。
}

func (BitString) At 

func (b BitString) At(i int) int

At 返回给定索引处的位。如果索引越界，则返回 0。

func (BitString) RightAlign 

func (b BitString) RightAlign() []byte

RightAlign 返回一个填充位位于开头的切片。该切片可能与 BitString 共享内存。

type RawContent

RawContent 用于指示需要为结构体保留尚未解码的 DER 数据。使用时，结构体的第一个字段必须具有此类型。如果其他字段使用该类型，则会产生错误。 

type RawContent []byte

RawValue 表示一个尚未解码的 ASN.1 对象。

}
