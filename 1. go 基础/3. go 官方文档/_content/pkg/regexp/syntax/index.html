syntax 包将正则表达式解析为语法树，并将语法树编译成程序。大多数正则表达式使用者会使用 regexp 包提供的功能（例如 regexp.Compile 和 regexp.Match），而不是本包。

语法

使用 Perl 标志解析时，本包支持的正则表达式语法如下。向 Parse 传入其他标志可以禁用部分语法。

单个字符：

.              任意字符，可以包含换行符（标志 s=true）
[xyz]          字符类
[^xyz]         取反的字符类
\d             Perl 字符类
\D             取反的 Perl 字符类
[[:alpha:]]    ASCII 字符类
[[:^alpha:]]   取反的 ASCII 字符类
\pN            Unicode 字符类（单字母名称）
\p{Greek}      Unicode 字符类
\PN            取反的 Unicode 字符类（单字母名称）
\P{Greek}      取反的 Unicode 字符类

组合：

xy             x 后接 y
x|y            x 或 y（优先 x）

重复：

x*             零个或多个 x，优先更多
x+             一个或多个 x，优先更多
x?             零个或一个 x，优先一个
x{n,m}         n、n+1、… 或 m 个 x，优先更多
x{n,}          n 个或更多 x，优先更多
x{n}           恰好 n 个 x
x*?            零个或多个 x，优先更少
x+?            一个或多个 x，优先更少
x??            零个或一个 x，优先零个
x{n,m}?        n、n+1、… 或 m 个 x，优先更少
x{n,}?         n 个或更多 x，优先更少
x{n}?          恰好 n 个 x

实现限制：计数形式 x{n,m}、x{n,} 和 x{n} 不允许最小或最大重复次数超过 1000。不限定次数的重复不受此限制。

分组：

(re)           带编号的捕获组（子匹配）
(?P<name>re)   带名称和编号的捕获组（子匹配）
(?<name>re)    带名称和编号的捕获组（子匹配）
(?:re)         非捕获组
(?flags)       设置当前组内的标志；不捕获
(?flags:re)    设置 re 内的标志；不捕获

标志的语法是 xyz（设置）、-xyz（清除）或 xy-z（设置 xy，清除 z）。可用标志如下：

i              不区分大小写（默认为 false）
m              多行模式：^ 和 $ 除匹配文本开头/结尾外，还匹配行首/行尾（默认为 false）
s              让 . 匹配 \n（默认为 false）
U              非贪婪：交换 x* 与 x*?、x+ 与 x+? 等的含义（默认为 false）

空字符串：

^              位于文本开头，或行首（标志 m=true）
$              位于文本结尾（类似 \z 而不是 \Z），或行尾（标志 m=true）
\A             位于文本开头
\b             位于 ASCII 单词边界（一侧是 \w，另一侧是 \W、\A 或 \z）
\B             不位于 ASCII 单词边界
\z             位于文本结尾

转义序列：

\a             响铃符(== \007)
\f             换页符(== \014)
\t             水平制表符(== \011)
\n             换行符(== \012)
\r             回车符(== \015)
\v             垂直制表符(== \013)
\*             字面字符 *，其中 * 可以是任意标点字符
\123           八进制字符编码（最多三位）
\x7F           十六进制字符编码（恰好两位）
\x{10FFFF}     十六进制字符编码
\Q...\E        字面文本 ...，即使 ... 包含标点

字符类元素：

x              单个字符
A-Z            字符范围（含两端）
\d             Perl 字符类
[:foo:]        ASCII 字符类 foo
\p{Foo}        Unicode 字符类 Foo
\pF            Unicode 字符类 F（单字母名称）

用作字符类元素的具名字符类：

[\d]           数字 (== \d)
[^\d]          非数字 (== \D)
[\D]           非数字 (== \D)
[^\D]          非“非数字” (== \d)
[[:name:]]     字符类中的具名 ASCII 类 (== [:name:])
[^[:name:]]    取反字符类中的具名 ASCII 类 (== [:^name:])
[\p{Name}]     字符类中的具名 Unicode 属性 (== \p{Name})
[^\p{Name}]    取反字符类中的具名 Unicode 属性 (== \P{Name})

Perl 字符类（均仅限 ASCII）：

\d             数字 (== [0-9])
\D             非数字 (== [^0-9])
\s             空白字符 (== [\t\n\f\r ])
\S             非空白字符 (== [^\t\n\f\r ])
\w             单词字符 (== [0-9A-Za-z_])
\W             非单词字符 (== [^0-9A-Za-z_])

ASCII 字符类：

[[:alnum:]]    字母或数字 (== [0-9A-Za-z])
[[:alpha:]]    字母 (== [A-Za-z])
[[:ascii:]]    ASCII (== [\x00-\x7F])
[[:blank:]]    空白 (== [\t ])
[[:cntrl:]]    控制字符 (== [\x00-\x1F\x7F])
[[:digit:]]    数字 (== [0-9])
[[:graph:]]    图形字符 (== [!-~] == [A-Za-z0-9!"#$%&'()*+,\-./:;<=>?@[\\\]^_`{|}~])
[[:lower:]]    小写字母 (== [a-z])
[[:print:]]    可打印字符 (== [ -~] == [ [:graph:]])
[[:punct:]]    标点 (== [!-/:-@[-`{-~])
[[:space:]]    空白字符 (== [\t\n\v\f\r ])
[[:upper:]]    大写字母 (== [A-Z])
[[:word:]]     单词字符 (== [0-9A-Za-z_])
[[:xdigit:]]   十六进制数字 (== [0-9A-Fa-f])

Unicode 字符类包括 unicode.Categories、unicode.CategoryAliases 和 unicode.Scripts 中的类。

type Flags

Flags 控制解析器行为，并记录正则表达式上下文的信息。

type Flags uint16
const (
    FoldCase      Flags = 1 << iota // 不区分大小写的匹配
    Literal                         // 将模式作为字面字符串处理
    ClassNL                         // 允许 [^a-z] 和 [[:space:]] 等字符类匹配换行符
    DotNL                           // 允许 . 匹配换行符
    OneLine                         // 使 ^ 和 $ 仅匹配文本开头和结尾
    NonGreedy                       // 使重复运算符默认为非贪婪
    PerlX                           // 允许 Perl 扩展
    UnicodeGroups                   // 允许用 \p{Han}、\P{Han} 表示 Unicode 组及其取反
    WasDollar                       // 正则表达式中的 OpEndText 原为 $，而不是 \z
    Simple                          // 正则表达式不包含计数重复

    MatchNL = ClassNL | DotNL

    Perl        = ClassNL | OneLine | PerlX | UnicodeGroups // 尽可能接近 Perl
    POSIX Flags = 0                                         // POSIX 语法
)

type Op

Op 是单个正则表达式运算符。

type Op uint8
const (
    OpNoMatch        Op = 1 + iota // 不匹配任何字符串
    OpEmptyMatch                   // 匹配空字符串
    OpLiteral                      // 匹配 Runes 序列
    OpCharClass                    // 将 Runes 解释为范围对列表并匹配
    OpAnyCharNotNL                 // 匹配换行符以外的任意字符
    OpAnyChar                      // 匹配任意字符
    OpBeginLine                    // 匹配行首的空字符串
    OpEndLine                      // 匹配行尾的空字符串
    OpBeginText                    // 匹配文本开头的空字符串
    OpEndText                      // 匹配文本结尾的空字符串
    OpWordBoundary                 // 匹配单词边界 `\b`
    OpNoWordBoundary               // 匹配非单词边界 `\B`
    OpCapture                      // 索引为 Cap、可选名称为 Name 的捕获子表达式
    OpStar                         // 匹配 Sub[0] 零次或多次
    OpPlus                         // 匹配 Sub[0] 一次或多次
    OpQuest                        // 匹配 Sub[0] 零次或一次
    OpRepeat                       // 匹配 Sub[0] 至少 Min 次，至多 Max 次（Max == -1 表示无限制）
    OpConcat                       // 匹配 Subs 的串联
    OpAlternate                    // 匹配 Subs 中的任一分支
)

type Regexp

Regexp 是正则表达式语法树中的节点。

type Regexp struct {
    Op       Op // 运算符
    Flags    Flags
    Sub      []*Regexp  // 子表达式（如果有）
    Sub0     [1]*Regexp // 用于较短 Sub 的存储空间
    Rune     []rune     // 匹配的 rune，用于 OpLiteral、OpCharClass
    Rune0    [2]rune    // 用于较短 Rune 的存储空间
    Min, Max int        // OpRepeat 的最小值、最大值
    Cap      int        // OpCapture 的捕获索引
    Name     string     // OpCapture 的捕获名称
}

func (*Regexp) Simplify 

func (re *Regexp) Simplify() *Regexp

Simplify 返回与 re 等价的正则表达式，但消除计数重复，并执行其他简化，例如将 /(?:a+)+/ 改写为 /a+/。结果正则表达式能正确执行，但由于捕获括号可能被复制或移除，其字符串表示不会产生相同的语法树。例如，/(x){1,2}/ 简化后为 /(x)(x)?/，但两对括号都捕获为 $1。返回的正则表达式可能与原表达式共享结构，也可能就是原表达式本身。
