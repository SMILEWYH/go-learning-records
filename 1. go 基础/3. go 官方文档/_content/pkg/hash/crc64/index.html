func Checksum 

func Checksum(data []byte, tab *Table) uint64

Checksum 使用 Table 表示的多项式，返回 data 的 CRC-64 校验和。

func New 

func New(tab *Table) hash.Hash64

New 创建一个新的 hash.Hash64，使用 Table 表示的多项式计算 CRC-64 校验和。其 Sum 方法按大端字节序排列结果值。返回的 Hash64 还实现了 encoding.BinaryMarshaler 和 encoding.BinaryUnmarshaler，以序列化和反序列化哈希的内部状态。

func Update 

func Update(crc uint64, tab *Table, p []byte) uint64

Update 返回将 p 中的字节加入 crc 后的结果。

type Table

Table 是一个含 256 个字的表，用于表示多项式以便高效处理。
