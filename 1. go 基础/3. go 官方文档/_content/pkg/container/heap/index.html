heap 包为任何实现 heap.Interface 的类型提供堆操作。堆是一棵树，其中每个节点都是其子树中值最小的节点。

树中的最小元素是根节点，位于索引 0。

堆是实现优先队列的常用方式。要构建优先队列，应实现 Heap 接口，并以优先级的负值作为 Less 方法的排序依据；这样 Push 会添加元素，而 Pop 会从队列中移除优先级最高的元素。示例中包含这样的实现；完整源代码位于 example_pq_test.go 文件中。

func Fix 1.2 

func Fix(h Interface, i int)

Fix 在索引 i 处元素的值改变后重新建立堆序。修改索引 i 处元素的值后调用 Fix，等价于先调用 Remove(h, i) 再 Push 新值，但开销更小。复杂度为 O(log n)，其中 n = h.Len()。

func Init 

func Init(h Interface)

Init 建立本包其他函数所要求的堆不变量。就堆不变量而言，Init 是幂等的，可以在堆不变量可能已失效时调用。复杂度为 O(n)，其中 n = h.Len()。

func Pop 

func Pop(h Interface) any

Pop 从堆中移除并返回最小元素（根据 Less 判断）。复杂度为 O(log n)，其中 n = h.Len()。Pop 等价于 Remove(h, 0)。

func Push 

func Push(h Interface, x any)

Push 将元素 x 压入堆中。复杂度为 O(log n)，其中 n = h.Len()。

func Remove 

func Remove(h Interface, i int) any

Remove 从堆中移除并返回索引 i 处的元素。复杂度为 O(log n)，其中 n = h.Len()。

type Interface

Interface 类型描述了使用本包函数的类型必须满足的要求。任何实现此接口的类型都可用作最小堆，并满足以下不变量（在调用 Init 后，或数据为空或已排序时成立）：

!h.Less(j, i) for 0 <= i < h.Len() and 2*i+1 <= j <= 2*i+2 and j < h.Len()

注意，此接口中的 Push 和 Pop 供 heap 包的实现调用。要向堆中添加或移除元素，请使用 heap.Push 和 heap.Pop。

type Interface interface {
    sort.Interface
    Push(x any) // 将 x 添加为索引 Len() 处的元素
    Pop() any   // 移除并返回索引 Len() - 1 处的元素。
}
