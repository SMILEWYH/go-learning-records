objdump 命令

Objdump 对可执行文件进行反汇编。

用法： 

go tool objdump [-s symregexp] binary

Objdump 输出二进制文件中所有代码符号的反汇编结果。如果指定 -s 选项，则只反汇编名称匹配给定正则表达式的符号。

另一种用法： 

go tool objdump binary start end

在此模式下，objdump 从 start 地址开始反汇编，到 end 地址停止。start 和 end 是以十六进制表示的程序计数器地址，可带 0x 前缀。输出由一系列如下形式的段落组成： 

file:line
 address: assembly
 address: assembly
 ...

每个段落给出一段连续地址范围的反汇编结果，这些地址都映射到原始源文件中的同一行。此模式供 pprof 使用。
