trace 命令

Trace 是用于查看执行追踪文件的工具。

可以通过以下方式生成追踪文件：

  • runtime/trace.Start
  • net/http/pprof 包
  • go test -trace

用法示例：使用“go test”生成追踪文件： 

go test -trace trace.out pkg

在网页浏览器中查看追踪结果： 

go tool trace trace.out

从追踪数据生成类似 pprof 的性能剖析数据： 

go tool trace -pprof=TYPE trace.out > TYPE.pprof

支持的剖析类型如下：

  • net：网络阻塞剖析
  • sync：同步阻塞剖析
  • syscall：系统调用阻塞剖析
  • sched：调度器延迟剖析

然后可以使用 pprof 工具分析这些数据： 

go tool pprof TYPE.pprof

注意，启动“go tool trace”后提供的各类剖析视图适用于所有浏览器，但追踪查看器本身（“view trace”页面）来自 Chrome/Chromium 项目，目前仅在该浏览器中持续进行测试。
