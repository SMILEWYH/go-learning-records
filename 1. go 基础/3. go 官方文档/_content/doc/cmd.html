Go 提供了一组用于构建和处理 Go 源代码的工具程序。这些工具通常由 go 程序调用，而不是直接运行。

最常见的使用方式是将它们作为 go 程序的子命令运行，例如 go fmt。以这种方式运行时，命令处理的是完整的 Go 源码包，go 程序会将适用于包级处理的参数传给底层可执行文件。

这些程序也可以通过 go 的 tool 子命令作为独立可执行文件运行，参数会原样传递，例如 go tool cgo。对大多数命令而言，这主要用于调试。pprof 等部分命令只能通过 go 的 tool 子命令调用。

由于格式化工具使用频繁，Go 安装过程还会安装名为 gofmt 的可执行文件，对应 go fmt 的格式化功能。

点击链接，查看各工具的文档、调用方式和具体用法。

名称      简介
go      go 程序管理 Go 源代码，并运行此处列出的其他命令。具体用法见命令文档。
cgo      cgo 用于创建可调用 C 代码的 Go 包。
cover      cover 用于创建和分析由 "go test -coverprofile" 生成的覆盖率数据文件。
fix      fix 查找使用旧版语言和库特性的 Go 程序，并将其改写为使用新特性。
fmt      fmt 格式化 Go 包；也可以使用独立的 gofmt 命令，它提供更通用的选项。
doc      doc 提取并生成 Go 包文档。
vet      vet 检查 Go 源代码并报告可疑结构，例如参数与格式字符串不匹配的 Printf 调用。

这里只列出部分工具。有关编译器等其他工具的文档，请参阅完整命令参考。
