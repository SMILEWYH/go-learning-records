  • 从源代码安装 Go —— 如何获取源代码，在本机上构建并运行。

安装多个 Go 版本

可以在同一台机器上安装多个 Go 版本，例如用不同版本测试代码。可通过此方法安装的版本列表见下载页面。

注意：使用本文介绍的方法安装之前，需要先安装 Git。

要安装其他 Go 版本，请运行 go install 命令，指定所需版本的下载位置。以下以 1.10.7 为例： 

$ go install golang.org/dl/go1.10.7@latest
$ go1.10.7 download

要使用刚下载的版本运行 go 命令，请在 go 命令名称后附加版本号，如下所示： 

$ go1.10.7 version
go version go1.10.7 linux/amd64

安装多个版本后，可以查看各版本的 GOROOT 值来确定安装位置。例如，运行： 

$ go1.10.7 env GOROOT

要卸载下载的某个版本，删除其 GOROOT 环境变量指定的目录，以及对应的 goX.Y.Z 可执行文件即可。

卸载 Go

可以按照本节步骤从系统中移除 Go。

移除用户配置和数据

Go 将用户配置保存在用户配置目录下的 go 子目录中，用户配置目录由 os.UserConfigDir 返回。也可以运行 go env GOENV，通过返回的配置文件路径找到该目录。

Go 将构建过程的中间产物保存在 go env GOCACHE 返回的目录中，可使用 go clean -cache 清理。

Go 将下载的依赖保存在 go env GOMODCACHE 返回的目录中，可使用 go clean -modcache 清理。

通过 go install 安装的可执行文件保存在 Go 的 bin 目录中，可通过 go env GOBIN 查询配置；默认安装位置为 $HOME/go/bin。删除该目录即可移除这些文件。如果曾将此目录添加到 PATH 环境变量，也应移除相应配置。

  1. 删除 /usr/local/go。

    这是默认安装目录。

  2. 从 PATH 环境变量中移除 /usr/local/go 对应的 Go 路径配置。

    在 Linux 和 FreeBSD 上，编辑 /etc/profile 或 $HOME/.profile。

  3. 如果曾在 shell 配置文件中手动添加 Go 的 bin 目录（通常为 $HOME/go/bin），例如添加了 export PATH="$PATH:$(go env GOPATH)/bin"，请移除对应配置项。

  4. 重新打开所有已打开的终端会话，使更改生效。

在 Windows 上，可以通过以下任一方式卸载 Go：

方法一：控制面板（最简单）

  1. 打开控制面板，双击添加或删除程序。
  2. 选择 Go Programming Language，单击“卸载”，然后按照提示操作。

方法二：命令行

运行以下命令，从命令行卸载：

msiexec /x go{{version}}.windows-{{cpu-arch}}.msi /q

注意：此过程会自动移除首次安装时创建的 Windows 环境变量。
