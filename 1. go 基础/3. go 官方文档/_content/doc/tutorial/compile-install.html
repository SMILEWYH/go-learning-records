在最后这一节中，你将学习另外两个 go 命令。频繁修改程序时，go run 命令可以方便地编译和运行代码，但它不会留下可供以后直接运行的二进制可执行文件。

本节介绍另外两个构建代码的命令：

  • go build 命令编译包及其依赖，但不会安装构建结果。
  • go install 命令编译并安装包。
注意：本文是系列教程的一部分，起点是创建 Go 模块。
  1. 在 hello 目录的命令行中运行 go build 命令，将代码编译成可执行文件。 
    $ go build
  2. 在 hello 目录的命令行中运行新生成的 hello 可执行文件，确认代码能正常工作。

    注意，如果在测试后修改过 greetings.go 中的代码，运行结果可能会有所不同。

    • 在 Linux 或 Mac 上： 
      $ ./hello
map[Darrin:Great to see you, Darrin! Gladys:Hail, Gladys! Well met! Samantha:Hail, Samantha! Well met!]
    • 在 Windows 上： 
      $ hello.exe
map[Darrin:Great to see you, Darrin! Gladys:Hail, Gladys! Well met! Samantha:Hail, Samantha! Well met!]

    你已经将应用程序编译成了可运行的可执行文件。不过，目前运行它时，需要先切换到可执行文件所在的目录，或者指定可执行文件的路径。

    接下来将安装可执行文件，以便不指定路径也能运行它。

  3. 查找 Go 的安装目标路径，即 go 命令安装当前包时使用的位置。

    可以运行 go list 命令查找安装路径，如下所示： 

    $ go list -f '{{.Target}}'

    例如，命令可能输出 /home/gopher/bin/hello，表示二进制文件会安装到 /home/gopher/bin。下一步将用到这个安装目录。

  4. 将 Go 的安装目录添加到系统 shell 的 PATH 环境变量中。

    这样就可以直接运行程序，而不必指定可执行文件的位置。

    • 在 Linux 或 Mac 上，运行以下命令： 
      $ export PATH=$PATH:/path/to/your/install/directory
    • 在 Windows 上，运行以下命令： 
      $ set PATH=%PATH%;C:\path\to\your\install\directory

    也可以采用另一种方式：如果 shell 的 PATH 中已经包含 $HOME/bin 这样的目录，并且希望将 Go 程序安装到那里，可以设置 GOBIN 变量来更改安装目标，具体使用 go env 命令： 

    $ go env -w GOBIN=/path/to/your/bin

    或者 

    $ go env -w GOBIN=C:\path\to\your\bin
  5. 更新 shell 的 PATH 后，运行 go install 命令编译并安装包。 
    $ go install
  6. 现在只需输入应用程序的名称就能运行它。可以打开一个新的命令行终端，切换到其他目录，再输入 hello 这个可执行文件名来运行程序，验证效果。 
    $ hello
map[Darrin:Hail, Darrin! Well met! Gladys:Great to see you, Gladys! Samantha:Hail, Samantha! Well met!]

本篇 Go 教程到这里就完成了！
