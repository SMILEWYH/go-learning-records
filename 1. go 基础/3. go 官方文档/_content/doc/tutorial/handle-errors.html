完善的错误处理是健壮代码的重要组成部分。本节将在 greetings 模块中添加返回错误的代码，并在调用方处理这个错误。

注意：本文是系列教程的一部分，起点是创建 Go 模块。
  1. 在 greetings/greetings.go 中添加下方高亮显示的代码。

    如果不知道向谁问候，返回问候语就没有意义。因此，当姓名为空时，应向调用方返回错误。将以下代码复制到 greetings.go 中，然后保存。 

    package greetings

import (
    "errors"
    "fmt"
)

// Hello returns a greeting for the named person.
func Hello(name string) (string, error) {
    // If no name was given, return an error with a message.
    if name == "" {
        return "", errors.New("empty name")
    }

    // If a name was received, return a value that embeds the name
    // in a greeting message.
    message := fmt.Sprintf("Hi, %v. Welcome!", name)
    return message, nil
}

    在这段代码中，你完成了以下操作：

    • 修改函数，使其返回两个值：一个 string 和一个 error。调用方将检查第二个值，判断是否发生了错误。（Go 中的任何函数都可以返回多个值。更多说明请参阅《高效 Go 编程》。）
    • 导入 Go 标准库中的 errors 包，以便使用其中的 errors.New 函数。
    • 添加 if 语句，检查请求是否合法（姓名不应为空字符串），并在请求不合法时返回错误。errors.New 函数会返回一个包含指定消息的 error。
    • 在执行成功时，将 nil 作为第二个返回值，表示没有错误。这样，调用方就能判断函数执行成功。
  2. 在 hello/hello.go 文件中，同时处理 Hello 函数现在返回的错误值和正常结果。

    将以下代码粘贴到 hello.go 中。 

    package main

import (
    "fmt"
    "log"

    "example.com/greetings"
)

func main() {
    // Set properties of the predefined Logger, including
    // the log entry prefix and a flag to disable printing
    // the time, source file, and line number.
    log.SetPrefix("greetings: ")
    log.SetFlags(0)

    // Request a greeting message.
    message, err := greetings.Hello("")
    // If an error was returned, print it to the console and
    // exit the program.
    if err != nil {
        log.Fatal(err)
    }

    // If no error was returned, print the returned message
    // to the console.
    fmt.Println(message)
}

    在这段代码中，你完成了以下操作：

    • 配置 log 包，使日志消息以命令名称（"greetings: "）开头，并且不包含时间戳或源文件信息。
    • 将 Hello 的两个返回值分别赋给变量，其中包括 error 值。
    • 将传给 Hello 的实参从 Gladys 的姓名改为空字符串，以便验证错误处理代码。
    • 检查 error 值是否非 nil。如果发生了错误，继续执行就没有意义。
    • 使用标准库中 log package（log 包）的函数输出错误信息。如果出现错误，就调用 log 包的 Fatal 函数输出错误并终止程序。
  3. 在 hello 目录的命令行中运行 hello.go，确认代码能正常工作。

    现在传入的姓名为空，因此会得到一个错误。 

    $ go run .
greetings: empty name
exit status 1

这就是 Go 中常见的错误处理方式：将错误作为值返回，由调用方进行检查。
