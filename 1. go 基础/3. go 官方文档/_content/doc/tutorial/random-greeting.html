本节将修改代码，使其每次从几条预定义的问候语中返回一条，而不再总是返回同一句问候语。

注意：本文是系列教程的一部分，起点是创建 Go 模块。

为此，你将使用 Go 切片。切片类似数组，不过其长度可以随着元素的添加和移除而动态变化。切片是 Go 中最实用的类型之一。

你将添加一个包含三条问候语的小切片，然后让代码随机返回其中一条。有关切片的更多说明，请参阅 Go 博客中的Go 切片。

  1. 将 greetings/greetings.go 中的代码修改为如下内容。 
    package greetings

import (
    "errors"
    "fmt"
    "math/rand"
)

// Hello returns a greeting for the named person.
func Hello(name string) (string, error) {
    // If no name was given, return an error with a message.
    if name == "" {
        return name, errors.New("empty name")
    }
    // Create a message using a random format.
    message := fmt.Sprintf(randomFormat(), name)
    return message, nil
}

// randomFormat returns one of a set of greeting messages. The returned
// message is selected at random.
func randomFormat() string {
    // A slice of message formats.
    formats := []string{
        "Hi, %v. Welcome!",
        "Great to see you, %v!",
        "Hail, %v! Well met!",
    }

    // Return a randomly selected message format by specifying
    // a random index for the slice of formats.
    return formats[rand.Intn(len(formats))]
}

    在这段代码中，你完成了以下操作：

    • 添加 randomFormat 函数，用于随机返回一个问候语格式字符串。注意，randomFormat 以小写字母开头，因此只有同一个包内的代码可以访问它，也就是说，它没有被导出。
    • 在 randomFormat 中声明 formats 切片，包含三种消息格式。声明切片时，方括号中不填写长度，例如 []string。这表示声明的是切片，其长度可以动态变化；需要扩容时，Go 可以为它分配新的底层数组。
    • 使用 math/rand 包生成随机数，用于从切片中选择一个元素。
    • 在 Hello 中调用 randomFormat 函数，获取要返回的消息的格式，再将这个格式与 name 的值组合起来生成消息。
    • 和之前一样，返回消息或错误。
  2. 将 hello/hello.go 中的代码修改为如下内容。

    你只需要将 Gladys 的姓名（也可以换成其他姓名）作为实参，传给 hello.go 中调用的 Hello 函数。

    package main

import (
    "fmt"
    "log"

    "example.com/greetings"
)

func main() {
    // Set properties of the predefined Logger, including
    // the log entry prefix and a flag to disable printing
    // the time, source file, and line number.
    log.SetPrefix("greetings: ")
    log.SetFlags(0)

    // Request a greeting message.
    message, err := greetings.Hello("Gladys")
    // If an error was returned, print it to the console and
    // exit the program.
    if err != nil {
        log.Fatal(err)
    }

    // If no error was returned, print the returned message
    // to the console.
    fmt.Println(message)
}
  3. 在 hello 目录的命令行中运行 hello.go，确认代码能正常工作。多运行几次，观察问候语的变化。 
    $ go run .
Great to see you, Gladys!

$ go run .
Hi, Gladys. Welcome!

$ go run .
Hail, Gladys! Well met!
