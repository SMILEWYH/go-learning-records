Go 商标和 Go 标志（<img src="/images/go-logo-blue.svg" height="12"></img>）统称为“Go 商标”，是 Google 的商标。如下文所述，对这些商标的使用授权与采用 BSD 许可证的 Go 代码仓库所授予的著作权许可分别处理。

Go Gopher 吉祥物由 Renee French 创作，采用 [知识共享署名 4.0 许可协议](https://creativecommons.org/licenses/by/4.0/)授权。

## 商标指南 {#guidelines}

本指南未允许的任何 Go 商标使用方式，都必须事先获得批准。

总体而言，我们希望大家可以自由使用“Go”文字商标和 Go 标志来指代 Go 编程语言。

我们不希望这些商标被用于：

- 指代任何其他编程语言。
- 以误导性的方式使用，或暗示无关的项目、公司、软件、文档或其他资源与 Go 编程语言项目有关联。
- 使社区对 Go 编程语言是否开源、是否可免费使用产生混淆。

本指南旨在确保 Go 编程语言可以继续以开源许可证发布，同时按照商标法的要求，保护 Go 商标作为具有实际意义的来源标识。

## Go 商标的使用 {#use}

### 无需授权的使用 {#no-authorization-needed}

#### 指示性合理使用 {#nominative-fair-use}

为了准确标识 Go 编程语言或任何兼容的应用，可能需要提及该语言的名称（“指示性合理使用”）。Go 商标指示性合理使用的基本规则如下：

- 仅以文字商标形式使用 Go 商标，即纯文本。未经许可，不得使用 Go 标志或经过艺术化处理的 Go 字样。
- 仅在必要限度内使用 Go 商标。用途应限于客观的事实陈述。
- 不得以任何方式暗示与社区或 Google 存在关联，或获得其认可。

教育场景，或介绍 Go 编程语言及其衍生作品的书籍、博客中，可能会出现属于合理使用的指示性或描述性使用。

### 已获授权的软件用途 {#authorized-software-uses-of-the-go-trademarks}

#### 未经修改的分支 {#unmodified-forks}

在未经修改的 Go 开源编程语言版本中（即未经修改的分支），通常可以保留 Go 商标。这种使用必须遵循[“已获授权用途的命名约定”](#naming)，不得不实地暗示关联或认可，也不得在来源方面造成误导。

#### 基本未经修改的发行版 {#substantially-unmodified-distributions}

如果衍生作品遵守 Go 编程语言开源许可证的条款，并以善意努力保持原项目的质量和实质内容，那么基本未经修改的发行版可以使用 Go 商标。

可被认定为基本未经修改的改动包括语言翻译与本地化、缺陷与安全补丁，以及必要的互操作性或兼容性修改。

此类基本未经修改的发行版可以按照[“已获授权用途的命名约定”](#naming)使用 Go 商标。

### 需要审核批准才能获得授权的软件用途 {#software-uses-requiring-review-and-approval-for-authorization}

#### 经过实质性修改的发行版 {#substantially-modified-distributions}

经过实质性修改的发行版，必须经过 _trademark@golang.org_ 审核并批准，才能使用 Go 商标。

实质性修改可能包括对功能、接口或特性的明确变更。

如果经过实质性修改的发行版获得批准，则可按照[“已获授权用途的命名约定”](#naming)使用 Go 商标。（原文在本句后半部分使用了“基本未经修改的发行版”这一表述。）

### 未获授权的软件用途 {#unauthorized-software-uses-of-the-go-trademarks}

#### 贬损性修改 {#disparaging-modifications}

贬损 Go 编程语言或其声誉、又不属于合理使用的修改，例如引入恶意代码，不得使用 Go 商标。

### 已获授权的非软件用途 {#authorized-non-software-uses-of-the-go-trademarks}

#### 活动与社区团体 {#use-for-events-and-community-groups}

与该编程语言相关的活动、社区团体或其他聚会，可以使用 Go 文字商标来指代 Go，但不得以暗示官方身份或认可的方式使用。

未经许可，不得在与该编程语言相关的活动、社区团体或其他聚会中使用 Go 标志。

活动和社区团体必须遵循[“已获授权用途的命名约定”](#naming)。

活动和社区团体可能需要遵守 Go 编程语言的行为准则；违反行为准则的行为可能被认定为不符合 Go 商标的使用要求。

#### 周边产品 {#swag}

可按照[“已获授权用途的命名约定”](#naming)和[“Go 标志的使用”](#logo)，使用 Go 商标制作 T 恤、笔、贴纸、帽子等周边产品，用于商业或非商业目的。

不得将这些周边产品宣传为“官方”周边，也不得声称 Go 编程语言项目认可其使用或购买。

对于销售使用 Go 商标的周边产品所产生的收入，没有其他限制。不过，我们鼓励卖家在作出这一决定时考虑开源运动的精神。如果售价中的一部分将捐赠给开源或社区事业，卖家必须如实向消费者说明具体金额；如果没有捐赠，也不得作误导性宣传。

### 未获授权的非软件用途 {#unauthorized-non-software-uses-of-the-go-trademarks}

#### 域名与社交媒体账号 {#use-in-domain-names-and-social-media-accounts}

不得将 Go 商标的全部或一部分用作域名、社交媒体账号名称或账号标识，或包含在其中，从而暗示官方身份或认可。

#### 公司名、商号、产品名或功能名 {#use-in-a-company-name-trade-name-product-name-or-feature-name}

不得将 Go 商标用作公司名、商号、产品名或功能名的全部或一部分，或与这些名称组合使用，从而暗示官方身份或认可。

## 已获授权用途的命名约定 {#naming}

当某项用途属于[“Go 商标的使用”](#use)中列出的已获授权类别时，可以在遵守以下命名约定的前提下使用 Go 商标。这些约定旨在避免暗示赞助、批准或认可，以免使相关商品或服务的来源产生混淆。

### 已获授权的命名约定 {#auth}

- [新名称／公司] 托管的 Go（[New Name/Company] managed Go）
- [新名称]，Go 的一个分支（[New Name], a fork of Go）
- 用于 Go 的 [新名称和／或交互方式说明]（[New Name and/or description of interaction] for Go）

### 未获授权的命名约定 {#unauth}

贬损 Go 编程语言、又不属于合理使用的命名方式，均未获授权。例如，以下命名方式未获授权：

- 改进版 Go（Improved Go）
- 更好的 Go（The Better Go）
- 任何违反 Go 编程语言行为准则的命名方式，例如使用不包容的语言。
- 任何以误导性方式修改或改变 Go 商标的命名方式。

### 需要审核批准才能获得授权的命名约定 {#approval}

任何不属于[“已获授权的命名约定”](#auth)或[“未获授权的命名约定”](#unauth)的命名方式，都需要提交 _trademark@golang.org_ 审核批准。

## Go 标志的使用 {#logo}

除了上述适用于 Go 文字商标的相关规则之外，使用 Go 标志（<img src="/images/go-logo-blue.svg" height="12"></img>）还须遵守以下规则。

Go 标志在任何情况下都不得用于：

- 贬损 Go 编程语言或其声誉；或
- 违反 Go 编程语言的行为准则。

未经审核批准，不得以下列方式使用 Go 标志：

- 将其用作商业产品的标志，或纳入商业产品的标志；
- 以任何形式修改它；或
- 将其放置在其他标志、徽章或艺术化商标的紧邻位置、内部，或包围这些图形。

请使用[“Go 的新品牌”](/blog/go-brand)中提供的 Go 标志和 Gopher 吉祥物品牌素材，并遵循其中的进一步指引。

## 授权不可转让 {#non}

Go 商标的使用授权不能通过项目依赖关系继承；每一次使用都必须遵守适用指南，或事先获得明确的书面许可。

根据本指南获得授权的用户，不得授权第三方使用 Go 商标，也不得转让其任何授权或许可，或就此授予再许可。

## Go 商标的权利保护 {#enforce}

根据本指南获得授权的用户，不得自行主张 Go 商标权利；但发现任何疑似、被指控或实际发生的滥用、不当占用、侵权或其他违反 Go 商标要求的行为时，应通知 _trademark@golang.org_。

## 指南版本 {#version}

本商标指南为 1.0 版，今后可能发布后续版本。为使表述更清晰，指南可能进行编辑；当变更引入新要求、定义新标准或带来其他不向后兼容的变化时，将提高主版本号。

## 联系我们 {#contact}

如果不确定拟议的 Go 商标使用方式是否符合本指南，或需要申请 Go 商标的使用许可，请随时联系 _trademark@golang.org_，并清楚说明拟议用途和使用期限。谢谢。
