asm 命令

Asm 通常通过“go tool asm”调用，将源文件汇编为目标文件。目标文件以源文件的基本文件名加 .o 后缀命名，随后可与其他目标文件一起打包为包归档文件。

命令行

用法： 

go tool asm [flags] file

指定文件必须是 Go 汇编文件。所有目标操作系统和体系结构都使用同一个汇编器，通过 GOOS 和 GOARCH 环境变量指定目标平台。

标志参数： 

-D name[=value]
	预定义符号 name，可附带一个简单值。
	可重复使用，以定义多个符号。
-I dir1 -I dir2
	先在 $GOROOT/pkg/$GOOS_$GOARCH 中查找 #include 文件，
	再依次搜索 dir1、dir2 等目录。
-S
	输出汇编代码和机器码。
-V
	输出汇编器版本并退出。
-debug
	解析指令时转储指令。
-dynlink
	支持引用其他共享库中定义的 Go 符号。
-e
	不限制报告的错误数量。
-gensymabis
	将符号 ABI 信息写入输出文件，不执行汇编。
-o file
	将输出写入 file。对于 /a/b/c/foo.s，默认为 foo.o。
-p pkgpath
	将预期的包导入路径设为 pkgpath。
-shared
	生成可以链接到共享库的代码。
-spectre list
	启用 list 指定的 Spectre 缓解措施（all、ret）。
-trimpath prefix
	从记录的源文件路径中移除 prefix。
-v
	输出调试信息。

输入语言：

汇编器在所有体系结构上使用基本相同的语法，主要区别在于寻址模式。输入会经过一个简化的 C 预处理器，支持 #include、#define、#ifdef/endif，但不支持 #if 或 ##。

更多信息请参阅 https://golang.org/doc/asm。
