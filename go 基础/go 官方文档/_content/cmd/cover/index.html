cover 命令

Cover 用于分析“go test -coverprofile=cover.out”生成的覆盖率数据。

“go test -cover”也使用 cover 重写源代码，加入跟踪逻辑，记录各函数中哪些部分得到执行，这一过程称为“插桩”。Cover 可以在“旧模式”下每次处理一个 Go 源文件，也可以由 Go 工具调用，一次处理一个包中的全部源文件。包级插桩通过“-pkgcfg”选项启用。

生成插桩代码时，cover 通过分析源代码计算近似的基本块信息。因此，它比通过重写二进制文件实现的覆盖率工具更具可移植性，但功能也略有不足。例如，它不会探测 && 和 || 表达式内部的执行情况，单条语句中包含多个函数字面量时，也可能影响分析的准确性。

计算使用 cgo 的包的覆盖率时，必须将 cover 应用于 cgo 预处理的输出，而不能用于其输入，因为 cover 会删除对 cgo 有意义的注释。

用法信息请参阅： 

go help testflag
go tool cover -help
