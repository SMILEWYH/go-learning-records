pack 命令

Pack 是传统 Unix ar 工具的简化版本，仅实现 Go 所需的操作。

用法： 

go tool pack op file.a [name...]

Pack 对归档文件执行指定操作，并将 names 作为操作参数。

操作 op 由以下某个字母指定： 

c	将文件系统中的文件追加到新归档中
p	输出归档中的文件内容
r	将文件系统中的文件追加到归档中
t	列出归档中的文件
x	从归档中提取文件

c 命令的归档参数必须指向不存在的文件或有效的归档文件；添加新条目前，会清空已有归档。如果文件已存在但不是归档，则报错。

对于 p、t 和 x 命令，如果命令行未列出名称，则操作作用于归档中的所有文件。

与 Unix ar 不同，r 操作始终向归档追加文件，即使归档中已有同名文件。因此，pack 的 r 操作更接近 Unix ar 的 rq 操作。

在操作字母后添加 v（例如 pv 或 rv）可启用详细输出：c 和 r 在添加文件时输出名称；p 在每个文件内容之前单独输出一行文件名；t 的列表包含额外的文件元数据；x 在提取文件时输出名称。
