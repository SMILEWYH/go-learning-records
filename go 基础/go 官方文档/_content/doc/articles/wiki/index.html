简介

本教程涵盖以下内容：

  • 创建带有加载和保存方法的数据结构
  • 使用 net/http 包构建 Web 应用
  • 使用 html/template 包处理 HTML 模板
  • 使用 regexp 包验证用户输入
  • 使用闭包

学习本教程需要具备以下基础：

  • 有编程经验
  • 了解基本的 Web 技术（HTTP、HTML）
  • 了解一些 UNIX/DOS 命令行知识

认识函数字面量和闭包

在每个处理函数中检查错误，会引入大量重复代码。 能否用一个函数包装各个处理函数，在其中统一完成验证和错误检查？ Go 的函数字面量提供了强大的功能抽象方式，可以帮助我们做到这一点。

首先，修改每个处理函数的定义，让它们接收一个标题字符串： 

func viewHandler(w http.ResponseWriter, r *http.Request, title string)
func editHandler(w http.ResponseWriter, r *http.Request, title string)
func saveHandler(w http.ResponseWriter, r *http.Request, title string)

然后定义一个包装函数，接收一个上述类型的函数，返回一个 http.HandlerFunc 类型的函数， 这样返回值就可以传给 http.HandleFunc： 

func makeHandler(fn func (http.ResponseWriter, *http.Request, string)) http.HandlerFunc {
    return func(w http.ResponseWriter, r *http.Request) {
        // Here we will extract the page title from the Request,
        // and call the provided handler 'fn'
    }
}

返回的函数称为闭包，因为它捕获了在函数外部定义的值。 在这个例子中，闭包捕获了变量 fn，也就是 makeHandler 唯一的参数。 变量 fn 将是保存、编辑或查看页面的处理函数之一。

现在，可以稍作修改，将 getTitle 中的代码移到这里：

{{code "final.go" `/func makeHandler/` `/^}/`}}

makeHandler 返回的闭包接收一个 http.ResponseWriter 和一个指向 http.Request 的指针，因此符合 http.HandlerFunc 的签名。 闭包从请求路径中提取 title，并使用正则表达式 validPath 进行验证。 如果 title 无效，就通过 http.NotFound 函数向 ResponseWriter 写入错误。 如果 title 有效，就调用捕获的处理函数 fn，将 ResponseWriter、Request 指针和 title 作为参数传入。
