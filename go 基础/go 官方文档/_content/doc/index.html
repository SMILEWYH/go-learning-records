Go 编程语言是一个开源项目，旨在提高程序员的开发效率。

Go 表达力强、简洁清晰且高效。它的并发机制让你能够轻松编写充分利用多核与网络环境的程序；独特的类型系统则支持灵活的模块化程序设计。Go 能快速编译为机器码，同时提供垃圾回收的便利和运行时反射的强大能力。它是一门高效的静态类型编译型语言，却拥有动态类型解释型语言般的开发体验。

访问关系型数据库

Go 数据访问功能概览。

打开数据库句柄

通过 Go 数据库句柄执行数据库操作。使用数据库连接参数打开句柄后，该句柄代表一个由它代为管理的连接池。

执行不返回数据的 SQL 语句

对于可能修改数据库的 SQL 操作，包括 INSERT、UPDATE 和 DELETE，使用 Exec 方法。

查询数据

对于查询并返回数据的 SELECT 语句，使用 Query 或 QueryRow 方法。

使用预处理语句

定义可重复使用的预处理语句，可以避免每次执行数据库操作时重新创建语句的开销，从而提高代码运行效率。

执行事务

sql.Tx 导出具有事务语义的方法，包括 Commit 和 Rollback，同时提供执行常规数据库操作的方法。

取消正在进行的数据库操作

使用 context.Context，可以在不再需要处理结果时，让应用中的函数调用和服务提前停止并返回错误。

管理连接

在一些更复杂的程序中，你可能需要调整连接池参数，或显式操作连接。

避免 SQL 注入风险

将 SQL 参数值作为 sql 包函数的参数传入，可以避免 SQL 注入风险。
