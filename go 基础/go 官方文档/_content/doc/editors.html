简介

本文列出 Go 生态中常用的编辑器插件和 IDE，帮助你更高效、顺畅地进行 Go 开发。支持 Go 开发的编辑器与 IDE 完整列表见 Wiki。

可选工具

Go 生态提供多种编辑器插件和 IDE，改善日常的代码编辑、导航、测试与调试体验。

  • Visual Studio Code: Go 扩展提供 Go 编程语言支持
  • GoLand: GoLand 可作为独立 IDE 使用，也可作为 IntelliJ IDEA Ultimate 的插件使用
  • vim: vim-go 插件提供 Go 编程语言支持

以上只是几种常见选择。更完整、由社区维护的 IDE 与文本编辑器插件列表见 Wiki。
