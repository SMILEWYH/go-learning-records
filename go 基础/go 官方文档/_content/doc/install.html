安装 Go

在下方选择你所用操作系统的选项卡，然后按照对应说明安装。

  1. 删除已有的 /usr/local/go 目录（如果存在），以移除先前安装的 Go。然后将刚下载的压缩包解压到 /usr/local，在 /usr/local/go 中创建全新的 Go 目录树： 
          $ rm -rf /usr/local/go && tar -C /usr/local -xzf go1.14.3.linux-amd64.tar.gz

    （你可能需要以 root 身份或通过 sudo 分别运行各条命令，以获得所需权限。）

    不要将压缩包解压到已有的 /usr/local/go 目录树中，否则可能导致 Go 安装损坏。

  2. 将 /usr/local/go/bin 添加到 PATH 环境变量。

    在 $HOME/.profile 中添加以下内容；如果要对所有用户生效，则添加到 /etc/profile： 

              export PATH=$PATH:/usr/local/go/bin

    注意：对配置文件的修改可能要到下次登录计算机时才会生效。要立即生效，可以直接执行这些 shell 命令，或通过 source $HOME/.profile 等命令加载配置文件。

  3. 将 $HOME/go/bin（默认的 Go 可执行文件目录）添加到 PATH 环境变量，以便使用通过 go install 安装的工具。

    在 $HOME/.profile 或 $HOME/.bashrc 文件中添加以下内容： 

              export PATH="$PATH:$(go env GOPATH)/bin"
  4. 重新打开所有已打开的终端会话，使更改生效。

  5. 打开命令提示符，输入以下命令以验证 Go 是否安装成功： 
              $ go version
  6. 确认命令输出了已安装的 Go 版本。
  1. 打开下载的安装包，按照提示安装 Go。

    安装包会将 Go 安装到 /usr/local/go，并通过创建 /etc/paths.d/go 文件，将 /usr/local/go/bin 目录添加到 PATH 环境变量。

  2. 将 $HOME/go/bin（默认的 Go 可执行文件目录）添加到 PATH 环境变量，以便使用通过 go install 安装的工具。

    在 ~/.zshrc 或 ~/.bash_profile 文件中添加以下内容： 

              export PATH="$PATH:$(go env GOPATH)/bin"
  3. 重新打开所有已打开的终端会话，使更改生效。

  4. 打开一个新的终端会话，输入以下命令以验证 Go 是否安装成功： 
              $ go version
  5. 确认命令输出了已安装的 Go 版本。
  1. 打开下载的 MSI 文件，按照提示安装 Go。

    默认情况下，安装程序会将 Go 安装到 Program Files 或 Program Files (x86)，你可以按需修改安装位置。安装后，需要关闭并重新打开所有命令提示符窗口，使安装程序对环境变量的修改生效。

  2. 验证 Go 是否安装成功。
    1. 在 Windows 中，单击开始菜单。
    2. 在菜单的搜索框中输入 cmd，然后按 Enter 键。
    3. 在打开的命令提示符窗口中输入以下命令： 
                    $ go version
    4. 确认命令输出了已安装的 Go 版本。
