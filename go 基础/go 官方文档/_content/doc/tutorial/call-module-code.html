在上一节中，你创建了 greetings 模块。本节将编写代码，调用刚才创建的模块中的 Hello 函数。这段代码将作为应用程序运行，并调用 greetings 模块中的代码。

注意：本文是系列教程的一部分，起点是创建 Go 模块。
  1. 创建 hello 目录，用来存放 Go 模块的源代码。你将在这里编写调用方的代码。

    创建后，hello 和 greetings 目录应该位于同一级，如下所示： 

    <home>/
 |-- greetings/
 |-- hello/

    例如，如果命令行当前位于 greetings 目录，可以运行以下命令： 

    cd ..
mkdir hello
cd hello
  2. 为即将编写的代码启用依赖管理。

    要为代码启用依赖管理，请运行 go mod init 命令，并传入代码所属模块的名称。

    在本教程中，使用 example.com/hello 作为模块路径。 

    $ go mod init example.com/hello
go: creating new go.mod: module example.com/hello
  3. 在文本编辑器中，在 hello 目录下创建 hello.go 文件，用于编写代码。
  4. 编写代码，调用 Hello 函数并输出其返回值。

    将以下代码粘贴到 hello.go 中。 

    package main

import (
    "fmt"

    "example.com/greetings"
)

func main() {
    // Get a greeting message and print it.
    message := greetings.Hello("Gladys")
    fmt.Println(message)
}

    在这段代码中，你完成了以下操作：

    • 声明 main 包。在 Go 中，作为应用程序执行的代码必须位于 main 包中。
    • 导入两个包：example.com/greetings 和 fmt 包，以便访问其中的函数。导入 example.com/greetings（前面创建的模块中的包）后，就可以使用 Hello 函数。同时导入的 fmt 提供处理文本输入和输出的函数，例如向控制台输出文本。
    • 调用 greetings 包中的 Hello 函数，获取问候语。
  5. 修改 example.com/hello 模块，使其使用本地的 example.com/greetings 模块。

    在生产环境中，你会通过代码仓库发布 example.com/greetings 模块，并使用与发布地址一致的模块路径，让 Go 工具能够找到并下载它。目前模块尚未发布，因此需要调整 example.com/hello 模块，使其能够在本地文件系统中找到 example.com/greetings 的代码。

    为此，使用 go mod edit 命令修改 example.com/hello 模块，让 Go 工具将依赖的模块路径（目前尚未发布）重定向到实际存放代码的本地目录。

    1. 在 hello 目录的命令行中运行以下命令： 
      $ go mod edit -replace example.com/greetings=../greetings

      该命令指定：查找依赖时，用 ../greetings 替换 example.com/greetings 对应的来源。运行后，hello 目录中的 go.mod 文件应包含一条 replace 指令： 

      module example.com/hello

go 1.16

replace example.com/greetings => ../greetings
    2. 在 hello 目录的命令行中运行 go mod tidy 命令，同步 example.com/hello 模块的依赖，添加代码需要但模块中尚未记录的依赖。 
      $ go mod tidy
go: found example.com/greetings in example.com/greetings v0.0.0-00010101000000-000000000000

      命令执行完毕后，example.com/hello 模块的 go.mod 文件应如下所示： 

      module example.com/hello

go 1.16

replace example.com/greetings => ../greetings

require example.com/greetings v0.0.0-00010101000000-000000000000

      该命令在 greetings 目录中找到了本地代码，并添加了一条 require 指令，声明 example.com/hello 依赖 example.com/greetings。在 hello.go 中导入 greetings 包时，就建立了这个依赖关系。

      模块路径后面的版本号称为伪版本号。它是自动生成的版本号，用来代替模块目前还没有的语义化版本号。

      引用已发布的模块时，go.mod 文件通常不需要 replace 指令，而是在 require 指令末尾使用带有版本标签的版本号。 

      require example.com/greetings v1.1.0

      有关版本号的更多说明，请参阅模块版本编号。

  6. 在 hello 目录的命令行中运行代码，确认它能正常工作。 
    $ go run .
Hi, Gladys. Welcome!

恭喜！你已经编写了两个可以正常工作的模块。
