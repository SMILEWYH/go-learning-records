本教程将简要介绍 Go 编程。你将依次完成以下操作：

  • 安装 Go（如果尚未安装）。
  • 编写一个简单的“Hello, world”程序。
  • 使用 go 命令运行代码。
  • 使用 Go 包检索工具，查找可在自己的代码中使用的包。
  • 调用外部模块中的函数。
注意：其他教程请参阅教程列表。

准备工作

  • 具备一定的编程经验。本教程中的代码很简单，不过了解一些函数知识会有所帮助。
  • 代码编辑工具。任何文本编辑器都可以。大多数文本编辑器都能很好地支持 Go。常用的有 VSCode（免费）、GoLand（付费）和 Vim（免费）。
  • 命令行终端。Go 可以在 Linux 和 Mac 的各种终端，以及 Windows 的 PowerShell 或 cmd 中正常使用。

安装 Go

按照下载与安装中的步骤操作即可。

编写代码

从 Hello, World 开始。

  1. 打开命令行终端，使用 cd 切换到用户主目录。

    在 Linux 或 Mac 上： 

    cd

    在 Windows 上： 

    cd %HOMEPATH%
  2. 创建 hello 目录，用来存放你的第一个 Go 程序的源代码。

    例如，运行以下命令： 

    mkdir hello
cd hello
  3. 为代码启用依赖管理。

    当代码导入其他模块中的包时，你需要通过代码所属的模块来管理这些依赖。模块由 go.mod 文件定义，该文件记录了提供这些包的模块。go.mod 文件与代码存放在一起，也应一同纳入源代码仓库。

    要创建 go.mod 文件并启用依赖管理，请运行 go mod init 命令，并传入代码所属模块的名称。这个名称就是模块的模块路径。

    在实际开发中，模块路径通常是源代码仓库的地址。例如，模块路径可以是 github.com/mymodule。如果计划发布模块供他人使用，模块路径必须指向 Go 工具能够下载该模块的位置。有关通过模块路径为模块命名的更多说明，请参阅依赖管理。

    在本教程中，使用 example/hello 即可。 

    $ go mod init example/hello
go: creating new go.mod: module example/hello

  4. 在文本编辑器中创建 hello.go 文件，用于编写代码。

  5. 将以下代码粘贴到 hello.go 文件中，然后保存。

    package main

import "fmt"

func main() {
    fmt.Println("Hello, World!")
}

    这就是你的 Go 代码。在这段代码中，你完成了以下操作：

    • 声明 main 包（包用于组织相关函数，通常由同一目录下的源文件组成）。
    • 导入常用的 fmt 包。它提供格式化文本的函数，包括向控制台输出文本的函数。这个包属于安装 Go 时自带的标准库。
    • 实现 main 函数，将一条消息输出到控制台。运行 main 包时，程序会默认执行其中的 main 函数。

  6. 运行代码，查看问候语。

    $ go run .
Hello, World!

    go run 是 Go 开发中会用到的众多 go 命令之一。使用以下命令可以查看其他命令： 

    $ go help

调用外部包中的代码

当你需要实现某项功能，而其他人可能已经实现过时，可以查找提供相应函数的包，并在自己的代码中使用。

  1. 使用外部模块中的函数，让输出的消息更有意思。
    1. 访问 pkg.go.dev，搜索“quote”包。
    2. 在搜索结果中找到并点击 rsc.io/quote 包的 v1 版本（它应该列在 rsc.io/quote/v4 的“Other major versions（其他主版本）”中）。
    3. 在 Documentation（文档）部分的 Index（索引）下，可以看到代码中可调用的函数列表。接下来将使用 Go 函数。
    4. 注意页面顶部的说明：quote 包包含在 rsc.io/quote 模块中。

    你可以通过 pkg.go.dev 网站查找已发布的模块，使用其中的包所提供的函数。包以模块的形式发布，例如 rsc.io/quote，以供其他人使用。模块会随着时间推移发布改进后的新版本，你可以升级代码所使用的模块版本。

  2. 在 Go 代码中导入 rsc.io/quote 包，并添加对其中 Go 函数的调用。

    添加高亮显示的代码后，代码应如下所示： 

    package main

import "fmt"

import "rsc.io/quote"

func main() {
    fmt.Println(quote.Go())
}
  3. 添加新的模块依赖和校验和。

    Go 会将 quote 模块添加为依赖，并生成用于校验模块内容的 go.sum 文件。更多说明请参阅《Go 模块参考》中的模块校验。 

    $ go mod tidy
go: finding module for package rsc.io/quote
go: found rsc.io/quote in rsc.io/quote v1.5.2
  4. 运行代码，查看所调用函数生成的消息。 
    $ go run .
Don't communicate by sharing memory, share memory by communicating.

    可以看到，代码调用了 Go 函数，输出了一句关于通信的精妙表述。

    运行 go mod tidy 时，它会查找并下载包含所导入包的 rsc.io/quote 模块。在本例中，默认下载的最新版本为 v1.5.2。
