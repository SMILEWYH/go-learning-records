简介

本文演示如何在模块中开发一个简单的 Go 包，并介绍 go 工具，它是获取、构建和安装 Go 模块、包与命令的标准方式。

代码组织

Go 程序以包为单位组织。包（package）是同一目录中一起编译的一组源文件。某个源文件中定义的函数、类型、变量和常量，对同一个包中的其他源文件均可见。

一个代码仓库包含一个或多个模块。模块（module）是一组一起发布的相关 Go 包。一个 Go 仓库通常只包含一个模块，位于仓库根目录。根目录中的 go.mod 文件声明模块路径，也就是模块内所有包的导入路径前缀。模块包含 go.mod 所在目录及其子目录中的包，但不包含另一个 go.mod 所界定的子模块（如果存在）。

构建代码之前，无需先将其发布到远程仓库。模块可以在本地定义，并不一定属于某个仓库。不过，按照未来可能发布的方式组织代码是个好习惯。

模块路径不仅是其中各个包的导入路径前缀，也指示 go 命令应从哪里下载模块。例如，要下载 golang.org/x/tools 模块，go 命令会查询 https://golang.org/x/tools 指示的仓库，更多说明见这里。

导入路径是导入包时使用的字符串，由模块路径与包在模块内的子目录路径拼接而成。例如，模块 github.com/google/go-cmp 的 cmp/ 目录中有一个包，它的导入路径就是 github.com/google/go-cmp/cmp。标准库中的包没有模块路径前缀。

第一个程序

要编译并运行一个简单程序，先选择模块路径（这里使用 example/user/hello），并创建声明该路径的 go.mod 文件： 

$ mkdir hello # Alternatively, clone it if it already exists in version control.
$ cd hello
$ go mod init example/user/hello
go: creating new go.mod: module example/user/hello
$ cat go.mod
module example/user/hello

go 1.16
$

Go 源文件的第一条语句必须是 package name。可执行命令必须使用 package main。

接下来，在该目录中创建名为 hello.go 的文件，写入以下 Go 代码： 

package main

import "fmt"

func main() {
    fmt.Println("Hello, world.")
}

现在可以使用 go 工具构建并安装该程序： 

$ go install example/user/hello
$

此命令构建 hello 命令，生成可执行二进制文件，并将其安装为 $HOME/go/bin/hello；在 Windows 上则为 %USERPROFILE%\go\bin\hello.exe。

安装目录由 GOPATH 和 GOBIN 环境变量控制。如果设置了 GOBIN，可执行文件安装到该目录。如果未设置 GOBIN，但设置了 GOPATH，则安装到 GOPATH 列表中第一个目录的 bin 子目录。否则，安装到默认 GOPATH（$HOME/go 或 %USERPROFILE%\go）下的 bin 子目录。

可以使用 go env 命令，以跨平台的方式为后续 go 命令设置环境变量的默认值： 

$ go env -w GOBIN=/somewhere/else/bin
$

要清除此前通过 go env -w 设置的变量，使用 go env -u： 

$ go env -u GOBIN
$

go install 等命令在包含当前工作目录的模块上下文中运行。如果工作目录不在 example/user/hello 模块内，go install 可能失败。

为方便使用，go 命令接受相对于工作目录的路径；没有指定其他路径时，默认处理当前工作目录中的包。因此，在我们的工作目录下，以下命令等价： 

$ go install example/user/hello

$ go install .

$ go install

接下来运行程序，确认它能正常工作。为方便执行，将安装目录添加到 PATH： 

# Windows users should consult /wiki/SettingGOPATH
# for setting %PATH%.
$ export PATH=$PATH:$(dirname $(go list -f '{{"{{.Target}}"}}' .))
$ hello
Hello, world.
$

如果使用版本控制系统，现在可以初始化仓库、添加文件并提交第一次修改。再次说明，这一步是可选的：编写 Go 代码并不要求使用版本控制。 

$ git init
Initialized empty Git repository in /home/user/hello/.git/
$ git add go.mod hello.go
$ git commit -m "initial commit"
[master (root-commit) 0b4507d] initial commit
 1 file changed, 7 insertion(+)
 create mode 100644 go.mod hello.go
$

go 命令会请求模块路径对应的 HTTPS URL，并读取 HTML 响应中嵌入的元数据，以找到包含该模块的仓库，详见 go help importpath。许多代码托管服务已经为包含 Go 代码的仓库提供此类元数据，因此，让其他人能够使用模块的最简单方式，通常就是让模块路径与仓库 URL 对应。

导入当前模块中的包

下面编写一个 morestrings 包，并在 hello 程序中使用它。先为该包创建目录 $HOME/hello/morestrings，再在其中创建 reverse.go，内容如下： 

// Package morestrings implements additional functions to manipulate UTF-8
// encoded strings, beyond what is provided in the standard "strings" package.
package morestrings

// ReverseRunes returns its argument string reversed rune-wise left to right.
func ReverseRunes(s string) string {
    r := []rune(s)
    for i, j := 0, len(r)-1; i < len(r)/2; i, j = i+1, j-1 {
        r[i], r[j] = r[j], r[i]
    }
    return string(r)
}

由于 ReverseRunes 函数名以大写字母开头，它是导出的，因此其他导入 morestrings 包的包可以使用它。

用 go build 确认该包能够编译： 

$ cd $HOME/hello/morestrings
$ go build
$

这不会生成输出文件，而是将编译后的包保存在本地构建缓存中。

确认 morestrings 包可以构建后，在 hello 程序中使用它。修改原来的 $HOME/hello/hello.go，使其使用 morestrings 包： 

package main

import (
    "fmt"

    "example/user/hello/morestrings"
)

func main() {
    fmt.Println(morestrings.ReverseRunes("!oG ,olleH"))
}

安装 hello 程序： 

$ go install example/user/hello

运行新版程序后，应该可以看到反转后的新消息： 

$ hello
Hello, Go!

导入远程模块中的包

导入路径可以描述如何通过 Git 或 Mercurial 等版本控制系统获取包的源代码。go 工具利用这一特性，自动从远程仓库获取包。例如，要在程序中使用 github.com/google/go-cmp/cmp： 

package main

import (
    "fmt"

    "example/user/hello/morestrings"
    "github.com/google/go-cmp/cmp"
)

func main() {
    fmt.Println(morestrings.ReverseRunes("!oG ,olleH"))
    fmt.Println(cmp.Diff("Hello World", "Hello Go"))
}

现在程序依赖一个外部模块，需要下载该模块，并在 go.mod 文件中记录其版本。go mod tidy 命令会为已导入的包补充缺失的模块依赖，并移除不再使用的模块依赖。 

$ go mod tidy
go: finding module for package github.com/google/go-cmp/cmp
go: found github.com/google/go-cmp/cmp in github.com/google/go-cmp v0.5.4
$ go install example/user/hello
$ hello
Hello, Go!
  string(
-     "Hello World",
+     "Hello Go",
  )
$ cat go.mod
module example/user/hello

go 1.16

require github.com/google/go-cmp v0.5.4
$

模块依赖会自动下载到 GOPATH 环境变量指定目录下的 pkg/mod 子目录。某个模块特定版本的下载内容，会由所有通过 require 依赖该版本的模块共享，因此 go 命令会将这些文件和目录设为只读。要删除所有下载的模块，可以向 go clean 传入 -modcache 标志： 

$ go clean -modcache
$

测试

Go 提供轻量的测试框架，由 go test 命令和 testing 包组成。

编写测试时，创建以 _test.go 结尾的文件，其中定义名为 TestXXX、签名为 func (t *testing.T) 的函数。测试框架会运行每个这样的函数；如果函数调用了 t.Error 或 t.Fail 等失败报告方法，该测试就被视为失败。

创建文件 $HOME/hello/morestrings/reverse_test.go，写入以下 Go 代码，为 morestrings 包添加测试。 

package morestrings

import "testing"

func TestReverseRunes(t *testing.T) {
    cases := []struct {
        in, want string
    }{
        {"Hello, world", "dlrow ,olleH"},
        {"Hello, 世界", "界世 ,olleH"},
        {"", ""},
    }
    for _, c := range cases {
        got := ReverseRunes(c.in)
        if got != c.want {
            t.Errorf("ReverseRunes(%q) == %q, want %q", c.in, got, c.want)
        }
    }
}

然后使用 go test 运行测试： 

$ cd $HOME/hello/morestrings
$ go test
PASS
ok  	example/user/hello/morestrings 0.165s
$

运行 go help test，并查阅 testing 包文档，了解更多信息。
