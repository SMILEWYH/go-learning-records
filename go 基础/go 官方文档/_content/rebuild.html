从 Go 1.21 开始，任何人都可以在任意平台上，使用 golang.org/x/build/cmd/gorebuild 复现并验证 go.dev/dl/ 提供的 Go 二进制工具链。详情请参阅博文《完全可复现、经过验证的 Go 工具链》。

本页每日更新在 Ubuntu 虚拟机中运行 gorebuild 的结果，使用以下脚本： 

apt-get update &&
apt-get -y install software-properties-common &&
add-apt-repository universe &&
apt-get -y install golang-go git msitools &&
go run golang.org/x/build/cmd/gorebuild@latest -p=4

安装 git 后，gorebuild 就能从 Go 的官方 Git 仓库获取源代码；安装 msitools 后，gorebuild 就能检查 Windows MSI 安装文件的内容。-p=4 表示最多并行运行四次构建。
