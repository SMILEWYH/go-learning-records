type AlgorithmIdentifier

AlgorithmIdentifier 表示同名 ASN.1 结构。参见 RFC 5280 第 4.1.1.2 节。 

type AlgorithmIdentifier struct {
    Algorithm  asn1.ObjectIdentifier
    Parameters asn1.RawValue `asn1:"optional"`
}

type AttributeTypeAndValue

AttributeTypeAndValue 对应 RFC 5280 第 4.1.2.4 节中的同名 ASN.1 结构。

作为 crypto/x509 类型中 pkix.Name 结构的一部分进行解析时，Value 的类型如下：

  • ASN.1 类型为 PrintableString、IA5String、NumericString、BMPString、T61String 或 UTF8String 时，为 string；
  • ASN.1 类型为 INTEGER 时，为 int64；
  • ASN.1 类型为 BIT STRING 时，为 asn1.BitString；
  • ASN.1 类型为 OCTET STRING 时，为 []byte；
  • ASN.1 类型为 OBJECT IDENTIFIER 时，为 asn1.ObjectIdentifier；
  • ASN.1 类型为 UTCTIME 或 GENERALIZEDTIME 时，为 time.Time；
  • ASN.1 类型为 BOOLEAN 时，为 bool；
  • ASN.1 类型为 NULL 时，为 nil；
  • 其他情况为 asn1.RawValue。 
type AttributeTypeAndValue struct {
    Type  asn1.ObjectIdentifier
    Value any
}

type AttributeTypeAndValueSET 1.3

AttributeTypeAndValueSET 表示 RFC 2986（PKCS #10）中由 AttributeTypeAndValue 序列构成的 ASN.1 序列集合。 

type AttributeTypeAndValueSET struct {
    Type  asn1.ObjectIdentifier
    Value [][]AttributeTypeAndValue `asn1:"set"`
}

type Name

Name 表示 X.509 可辨别名称（DN），仅包含 DN 中的常见元素。注意，Name 只是对 X.509 结构的近似表示。如果需要精确表示，请使用 asn1.Unmarshal 将原始主体或颁发者解析为 RDNSequence。 

type Name struct {
    Country, Organization, OrganizationalUnit []string
    Locality, Province                        []string
    StreetAddress, PostalCode                 []string
    SerialNumber, CommonName                  string

    // Names 包含所有已解析的属性。解析可辨别名称时，
    // 可以用它提取本包不会专门解析的
    // 非标准属性。序列化为 RDNSequence 时，会忽略 Names 字段，
    // 参见 ExtraNames。
    Names []AttributeTypeAndValue

    // ExtraNames 包含在序列化可辨别名称时应原样复制的
    // 属性。这些值会覆盖具有相同 OID 的属性。
    // 解析时不会填充 ExtraNames 字段，参见 Names。
    ExtraNames []AttributeTypeAndValue // Go 1.5
}

func (*Name) FillFromRDNSequence 

func (n *Name) FillFromRDNSequence(rdns *RDNSequence)

FillFromRDNSequence 根据给定的 RDNSequence 填充 n。含多个条目的 RDN 会被展平，所有条目都添加到 n 的相应字段中，不保留分组。

func (Name) String 1.10 

func (n Name) String() string

String 返回 n 的字符串形式，大体遵循 RFC 2253 的可辨别名称语法。

func (Name) ToRDNSequence 

func (n Name) ToRDNSequence() (ret RDNSequence)

ToRDNSequence 将 n 转换为单个 RDNSequence。以下属性编码为多值 RDN：

  • Country
  • Organization
  • OrganizationalUnit
  • Locality
  • Province
  • StreetAddress
  • PostalCode

每个 ExtraNames 条目都编码为独立的 RDN。
