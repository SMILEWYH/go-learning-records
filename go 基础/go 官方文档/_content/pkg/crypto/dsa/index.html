dsa 包实现 FIPS 186-3 定义的数字签名算法（DSA）。

本包中的 DSA 操作并非使用常量时间算法实现。

已弃用：DSA 是传统算法，应改用现代替代算法，例如 crypto/ed25519 包实现的 Ed25519。模数为 1024 位的密钥（L1024N160 参数）在密码学上较弱，而更大的密钥又未得到广泛支持。注意，FIPS 186-5 已不再批准使用 DSA 生成签名。

func Sign 

func Sign(random io.Reader, priv *PrivateKey, hash []byte) (r, s *big.Int, err error)

Sign 使用私钥 priv 对任意长度的哈希值签名（此值应由较长的消息经哈希计算得到）。它以一对整数的形式返回签名。私钥的安全性取决于 rand 的熵。

注意，FIPS 186-3 第 4.6 节规定，哈希值应截断到子群的字节长度。此函数本身不会执行该截断。

自 Go 1.26 起，始终使用安全的随机字节源；除非设置 GODEBUG=cryptocustomrand=1，否则会忽略 Reader。此设置将在未来的 Go 版本中移除。请改用 testing/cryptotest.SetGlobalRandom。

请注意，使用攻击者控制的 PrivateKey 调用 Sign，可能消耗任意多的 CPU 资源。

func Verify 

func Verify(pub *PublicKey, hash []byte, r, s *big.Int) bool

Verify 使用公钥 pub 验证 r、s 所表示的 hash 的签名，报告签名是否有效。

注意，FIPS 186-3 第 4.6 节规定，哈希值应截断到子群的字节长度。此函数本身不会执行该截断。

type ParameterSizes

ParameterSizes 枚举一组 DSA 参数中素数可接受的位数。参见 FIPS 186-3 第 4.2 节。 

type ParameterSizes int
const (

    L2048N224
    L2048N256
    L3072N256

type Parameters

Parameters 表示密钥的域参数。这些参数可以由多个密钥共享。Q 的位数必须是 8 的倍数。 

type Parameters struct {

}
