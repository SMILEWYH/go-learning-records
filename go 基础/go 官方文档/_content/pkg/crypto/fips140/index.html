func Enabled 1.24 

func Enabled() bool

Enabled 报告密码库是否在 FIPS 140-3 模式下运行。

可通过 GODEBUG 设置 "fips140" 在运行时控制此模式。设为 "on" 时启用 FIPS 140-3 模式。设为 "only" 时，未获批准的密码函数还会返回错误或触发 panic。

程序启动后不能更改此设置。

func Enforced 1.26 

func Enforced() bool

Enforced 表示是否启用了严格的 FIPS 140-3 强制检查。当程序以 GODEBUG=fips140=only 运行，且未通过调用 WithoutEnforcement 禁用强制检查时，即启用严格检查。

func Version 1.26 

func Version() string

如果通过 GOFIPS140 使用冻结模块构建，Version 返回该模块安全策略中记载的 FIPS 140-3 Go 密码模块版本（例如 "v1.0.0"）。否则返回 "latest"。如果使用了别名（例如 "inprogress"），则返回实际解析得到的版本。

如果同一版本存在多份冻结模块，返回的版本可能无法唯一标识构建程序所用的冻结模块。可检查 runtime/debug.BuildInfo.Settings 中 GOFIPS140 设置的值，获取能够唯一标识模块的版本后缀。

func WithoutEnforcement 1.26 

func WithoutEnforcement(f func())

WithoutEnforcement 在执行 f 期间禁用严格的 FIPS 140-3 强制检查。如果尚未启用严格检查（未设置 GODEBUG=fips140=only，或已经位于 WithoutEnforcement 调用内部），调用 WithoutEnforcement 不产生额外作用。

执行 f 期间启动的所有 goroutine 都会继承 WithoutEnforcement 的效果。

由于此函数会禁用强制检查，应谨慎地将其用于范围严格受限的函数。
