概览 ▾

elliptic 包实现定义在素数域上的标准 NIST P-224、P-256、P-384 和 P-521 椭圆曲线。

除使用 P224、P256、P384 和 P521 值来调用 crypto/ecdsa 这一必要用途外，直接使用本包的方式已弃用。多数其他用途应迁移到更高效、更安全的 crypto/ecdh；更底层的功能则应使用第三方模块。

func GenerateKey 

func GenerateKey(curve Curve, rand io.Reader) (priv []byte, x, y *big.Int, err error)

GenerateKey 返回一对公钥和私钥。私钥使用给定 reader 生成，该 reader 必须返回随机数据。

已弃用：对于 ECDH，请使用 crypto/ecdh 包的 GenerateKey 方法；对于 ECDSA，请使用 crypto/ecdsa 包的 GenerateKey 函数。

func Marshal 

func Marshal(curve Curve, x, y *big.Int) []byte

Marshal 将曲线上的点转换为 SEC 1 第 2.0 版第 2.3.3 节规定的未压缩形式。如果点不在曲线上（或为约定表示的无穷远点），则行为未定义。

已弃用：对于 ECDH，请使用 crypto/ecdh 包。此函数返回的编码与 crypto/ecdh 中 PublicKey.Bytes 的编码等价。

func Unmarshal 

func Unmarshal(curve Curve, data []byte) (x, y *big.Int)

Unmarshal 将由 Marshal 序列化的点转换为 x、y 坐标对。如果点不是未压缩形式、不在曲线上，或为无穷远点，则视为错误。出错时，x = nil。

已弃用：对于 ECDH，请使用 crypto/ecdh 包。此函数接受的编码与 crypto/ecdh 中 NewPublicKey 方法接受的编码等价。

type Curve

Curve 表示 a=-3 的短 Weierstrass 形式曲线。

当输入不是曲线上的点时，Add、Double 和 ScalarMult 的行为未定义。

注意，约定表示的无穷远点 (0, 0) 不被视为曲线上的点，尽管 Add、Double、ScalarMult 或 ScalarBaseMult 可以返回它（但 Unmarshal 和 UnmarshalCompressed 函数不会返回它）。

除 P224、P256、P384 和 P521 返回的实现外，使用其他 Curve 实现的方式已弃用。 

type Curve interface {
    // Params 返回曲线参数。
    Params() *CurveParams

    // IsOnCurve 报告给定的 (x,y) 是否位于曲线上。
    //
    // 已弃用：这是不安全的底层 API。对于 ECDH，请使用 crypto/ecdh
    // 包。crypto/ecdh 中 NIST 曲线的 NewPublicKey 方法接受
    // 与 Unmarshal 函数相同的编码，并检查点是否在曲线上。
    IsOnCurve(x, y *big.Int) bool

    // Add 返回 (x1,y1) 与 (x2,y2) 的和。
    //
    // 已弃用：这是不安全的底层 API。
    Add(x1, y1, x2, y2 *big.Int) (x, y *big.Int)

    // Double 返回 2*(x,y)。
    //
    // 已弃用：这是不安全的底层 API。
    Double(x1, y1 *big.Int) (x, y *big.Int)

    // ScalarMult 返回 k*(x,y)，其中 k 是大端形式的整数。
    //
    // 已弃用：这是不安全的底层 API。对于 ECDH，请使用 crypto/ecdh
    // 包。多数 ScalarMult 用法可以替换为对 crypto/ecdh 中 NIST 曲线
    // 的 ECDH 方法的调用。
    ScalarMult(x1, y1 *big.Int, k []byte) (x, y *big.Int)

    // ScalarBaseMult 返回 k*G，其中 G 为群的基点，
    // k 为大端形式的整数。
    //
    // 已弃用：这是不安全的底层 API。对于 ECDH，请使用 crypto/ecdh
    // 包。多数 ScalarBaseMult 用法可以替换为对 crypto/ecdh 中
    // PrivateKey.PublicKey 方法的调用。
    ScalarBaseMult(k []byte) (x, y *big.Int)
}

func P224 

func P224() Curve

P224 返回实现 NIST P-224（FIPS 186-3 第 D.2.2 节）的 Curve，该曲线也称为 secp224r1。此 Curve 的 CurveParams.Name 为 "P-224"。

多次调用此函数会返回相同的值，因此可用于相等性检查和 switch 语句。

密码学操作使用常量时间算法实现。

type CurveParams

CurveParams 包含椭圆曲线参数，并提供 Curve 的通用非常量时间实现。

通用 Curve 实现已弃用；使用自定义曲线（即非 P224、P256、P384 和 P521 返回的曲线）不保证具有任何安全属性。 

type CurveParams struct {
    P       *big.Int // 底层域的阶
    N       *big.Int // 基点的阶
    B       *big.Int // 曲线方程的常数项
    Gx, Gy  *big.Int // 基点的 (x,y) 坐标
    BitSize int      // 底层域的位数
    Name    string   // 曲线的规范名称；Go 1.5 新增
}
