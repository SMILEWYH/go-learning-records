Reader 是密码学安全随机数生成器的全局共享实例，可以安全地并发使用。

  • 在 Linux、FreeBSD、Dragonfly 和 Solaris 上，Reader 使用 getrandom(2)。
  • 在旧版 Linux（< 3.17）上，Reader 在首次使用时打开 /dev/urandom。
  • 在 macOS、iOS 和 OpenBSD 上，Reader 使用 arc4random_buf(3)。
  • 在 NetBSD 上，Reader 使用 kern.arandom sysctl。
  • 在 Windows 上，Reader 使用 ProcessPrng API。
  • 在 js/wasm 上，Reader 使用 Web Crypto API。
  • 在 wasip1/wasm 上，Reader 使用 random_get。

在 FIPS 140-3 模式下，输出还会经过 SP 800-90A 修订版 1 定义的确定性随机比特生成器（DRBG）。

func Int 

func Int(rand io.Reader, max *big.Int) (n *big.Int, err error)

Int 返回 [0, max) 范围内的均匀随机值。如果 max <= 0，则触发 panic；如果 rand.Read 返回错误，则返回该错误。

func Prime
				
				
			

			
func Prime(r io.Reader, bits int) (*big.Int, error)

			
Prime 返回一个具有给定位数、以很高概率为素数的数。如果 rand.Read 返回任何错误，或 bits < 2，Prime 都会返回错误。

自 Go 1.26 起，始终使用安全的随机字节源；除非设置 GODEBUG=cryptocustomrand=1，否则会忽略 Reader。此设置将在未来的 Go 版本中移除。请改用 testing/cryptotest.SetGlobalRandom。

func Read
				
				
			

			
func Read(b []byte) (n int, err error)

			
Read 用密码学安全的随机字节填充 b。它从不返回错误，并始终完整填充 b。

Read 对 io.ReadFull 发起调用，读取 Reader；如果返回错误，就使程序发生不可恢复的崩溃。默认 Reader 使用操作系统 API；这些 API 的文档保证，除旧版 Linux 外，它们从不返回错误。

func Text() string

			
Text 使用 RFC 4648 标准 base32 字母表返回密码学随机字符串，适用于需要秘密字符串、令牌、密码或其他文本的场景。结果至少包含 128 位随机性，足以抵御暴力猜测攻击，并使碰撞概率极低。未来版本可能按需返回更长的文本，以维持这些性质。
