hmac 包实现美国《联邦信息处理标准》198 号（FIPS 198）定义的基于密钥哈希的消息认证码（HMAC）。HMAC 是一种使用密钥对消息进行签名的密码学哈希。接收方使用相同密钥重新计算哈希来验证它。

接收方应注意使用 Equal 比较 MAC，以避免计时侧信道： 

// ValidMAC 报告 messageMAC 是否为 message 的有效 HMAC 标签。
func ValidMAC(message, messageMAC, key []byte) bool {
	mac := hmac.New(sha256.New, key)
	mac.Write(message)
	expectedMAC := mac.Sum(nil)
	return hmac.Equal(messageMAC, expectedMAC)
}

func New 

func New(h func() hash.Hash, key []byte) hash.Hash

New 使用给定的 hash.Hash 类型和密钥返回新的 HMAC 哈希。crypto/sha256.New 等 New 函数可以用作 h。h 每次被调用时都必须返回新的 Hash。注意，与标准库中的其他哈希实现不同，返回的 Hash 不实现 encoding.BinaryMarshaler 或 encoding.BinaryUnmarshaler。
