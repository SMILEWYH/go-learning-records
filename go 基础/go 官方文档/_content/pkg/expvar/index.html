expvar 包为公开变量（例如服务器中的操作计数器）提供标准化接口。它通过 HTTP 在 /debug/vars 路径以 JSON 格式公开这些变量。从 Go 1.22 开始，对 /debug/vars 的请求必须使用 GET。

设置或修改这些公开变量的操作都是原子的。

除了添加 HTTP 处理器，本包还注册以下变量：

cmdline   os.Args
memstats  runtime.Memstats

有时导入本包只是为了注册 HTTP 处理器及上述变量的副作用。要以这种方式使用它，请将此包链接到程序中：

import _ "expvar"

type Var

Var 是所有导出变量的抽象类型。

type Var interface {
    // String 为变量返回有效的 JSON 值。
    // String 方法不能返回有效 JSON 的类型
    // （例如 time.Time）不得用作 Var。
    String() string
}
