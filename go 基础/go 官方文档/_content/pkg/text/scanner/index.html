scanner 包为 UTF-8 编码文本提供扫描器和词法分析器。它通过 io.Reader 接受源文本，随后可反复调用 Scan 函数将其划分为词法单元。为与现有工具兼容，不允许使用 NUL 字符。如果源文本的第一个字符是 UTF-8 编码的字节序标记（BOM），则将其丢弃。

默认情况下，Scanner 跳过空白和 Go 注释，并识别 Go 语言规范定义的所有字面量。可以对其定制，使它仅识别这些字面量的子集，或识别不同的标识符字符和空白字符。

用于控制词法单元识别的预定义模式位。例如，要将 Scanner 配置为仅识别（Go）标识符、整数并跳过注释，可将其 Mode 字段设为：

ScanIdents | ScanInts | ScanComments | SkipComments

除了在设置 SkipComments 时会跳过注释之外，未识别的词法单元不会被忽略。扫描器会返回相应的单个字符（也可能是较小的词法单元）。例如，如果模式为 ScanIdents（未启用 ScanStrings），字符串 "foo" 会被扫描为词法单元序列 '"' Ident '"'。

使用 GoTokens 可以将 Scanner 配置为接受所有 Go 字面量词法单元（包括 Go 标识符）。注释会被跳过。

const (
    ScanIdents     = 1 << -Ident
    ScanInts       = 1 << -Int
    ScanFloats     = 1 << -Float // 包括整数和十六进制浮点数
    ScanChars      = 1 << -Char
    ScanStrings    = 1 << -String
    ScanRawStrings = 1 << -RawString
    ScanComments   = 1 << -Comment
    SkipComments   = 1 << -skipComment // 如果与 ScanComments 一起设置，则将注释视为空白
    GoTokens       = ScanIdents | ScanFloats | ScanChars | ScanStrings | ScanRawStrings | ScanComments | SkipComments
)

Scan 的结果是这些词法单元之一或一个 Unicode 字符。

const (
    EOF = -(iota + 1)
    Ident
    Int
    Float
    Char
    String
    RawString
    Comment
)

GoWhitespace 是 Scanner 的 Whitespace 字段的默认值，它选中了 Go 的空白字符。

const GoWhitespace = 1<<'\t' | 1<<'\n' | 1<<'\r' | 1<<' '

type Scanner

Scanner 实现从 io.Reader 读取 Unicode 字符和词法单元。

type Scanner struct {

    // 每遇到一个错误都会调用 Error。如果未设置 Error
    // 函数，则向 os.Stderr 报告错误。
    Error func(s *Scanner, msg string)

    // 每遇到一个错误，ErrorCount 加 1。
    ErrorCount int

    // Mode 字段控制识别哪些词法单元。例如，
    // 要识别整数，可设置 Mode 中的 ScanInts 位。
    // 可以随时修改此字段。
    Mode uint

    // Whitespace 字段控制哪些字符被识别为空白。
    // 要将字符 ch <= ' ' 识别为空白，
    // 应设置 Whitespace 的第 ch 位（对于 ch > ' ' 的值，
    // Scanner 的行为未定义）。可以随时修改此字段。
    Whitespace uint64

    // IsIdentRune 是一个谓词，控制哪些字符可以
    // 作为标识符中的第 i 个 rune。有效字符的集合
    // 不得与空白字符集合相交。
    // 如果未设置 IsIdentRune 函数，则接受常规 Go 标识符。
    // 可以随时修改此字段。
    IsIdentRune func(ch rune, i int) bool // Go 1.4

    // 最近扫描的词法单元的起始位置，由 Scan 设置。
    // 调用 Init 或 Next 会使该位置失效（Line == 0）。
    // Scanner 始终不会修改 Filename 字段。
    // 如果通过 Error 报告错误时 Position 无效，
    // 则扫描器不在词法单元内部。此时可以调用 Pos 获取
    // 错误位置，或获取紧随最近扫描的
    // 词法单元之后的位置。
    Position
    // 包含已过滤或未导出的字段
}

func (*Scanner) Init 

func (s *Scanner) Init(src io.Reader) *Scanner

Init 使用新源文本初始化 Scanner 并返回 s。Scanner.Error 设为 nil，Scanner.ErrorCount 设为 0，Scanner.Mode 设为 GoTokens，Scanner.Whitespace 设为 GoWhitespace。

func (*Scanner) Next 

func (s *Scanner) Next() rune

Next 读取并返回下一个 Unicode 字符。在源文本末尾返回 EOF。如果 s.Error 非 nil，则调用它报告读取错误；否则向 os.Stderr 打印错误消息。Next 不更新 [Scanner.Position] 字段；应使用 Scanner.Pos() 获取当前位置。

func (*Scanner) Peek 

func (s *Scanner) Peek() rune

Peek 返回源文本中的下一个 Unicode 字符，但不推进扫描器。如果扫描器的位置位于源文本的最后一个字符，则返回 EOF。

func (*Scanner) Pos 

func (s *Scanner) Pos() (pos Position)

Pos 返回紧随上次 Scanner.Next 或 Scanner.Scan 调用所返回字符或词法单元之后的字符位置。最近扫描的词法单元的起始位置应使用 [Scanner.Position] 字段获取。

func (*Scanner) Scan 

func (s *Scanner) Scan() rune

Scan 从源文本读取并返回下一个词法单元或 Unicode 字符。它只识别在 Scanner.Mode 中设置了相应位 (1<<-t) 的词法单元 t。在源文本末尾返回 EOF。如果 s.Error 非 nil，则调用它报告扫描错误（读取错误和词法单元错误）；否则向 os.Stderr 打印错误消息。

func (*Scanner) TokenText 

func (s *Scanner) TokenText() string

TokenText 返回最近扫描的词法单元对应的字符串。在调用 Scanner.Scan 之后，以及在 Scanner.Error 调用期间有效。
