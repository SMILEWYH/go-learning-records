strconv 包实现基本数据类型与其字符串表示之间的转换。

数值转换

最常用的数值转换是 Atoi（字符串转 int）和 Itoa（int 转字符串）。 

i, err := strconv.Atoi("-42")
s := strconv.Itoa(-42)

它们使用十进制和 Go 的 int 类型。

ParseBool、ParseFloat、ParseInt 和 ParseUint 将字符串转换为相应的值： 

b, err := strconv.ParseBool("true")
f, err := strconv.ParseFloat("3.1415", 64)
i, err := strconv.ParseInt("-42", 10, 64)
u, err := strconv.ParseUint("42", 10, 64)

解析函数返回最宽的类型（float64、int64 和 uint64）。不过，如果位宽参数指定了较窄的类型，结果就可以无损转换为该类型： 

s := "2147483647" // 最大的 int32
i64, err := strconv.ParseInt(s, 10, 32)
...
i := int32(i64)

FormatBool、FormatFloat、FormatInt 和 FormatUint 将值转换为字符串： 

s := strconv.FormatBool(true)
s := strconv.FormatFloat(3.1415, 'E', -1, 64)
s := strconv.FormatInt(-42, 16)
s := strconv.FormatUint(42, 16)

AppendBool、AppendFloat、AppendInt 和 AppendUint 的作用类似，但会将格式化结果追加到目标切片中。

字符串转换

Quote 和 QuoteToASCII 将字符串转换为带引号的 Go 字符串字面量。后者会用 \u 转义非 ASCII 的 Unicode 字符，确保结果是 ASCII 字符串： 

q := strconv.Quote("Hello, 世界")
q := strconv.QuoteToASCII("Hello, 世界")

QuoteRune 和 QuoteRuneToASCII 的作用类似，但接收 rune，并返回带引号的 Go rune 字面量。

Unquote 和 UnquoteChar 解析 Go 字符串字面量和 rune 字面量中的引号及转义。

func FormatComplex 1.15 

func FormatComplex(c complex128, fmt byte, prec, bitSize int) string

FormatComplex 将复数 c 转换为 (a+bi) 形式的字符串，其中 a 和 b 分别为实部与虚部，按格式 fmt 和精度 prec 进行格式化。

fmt 和 prec 的含义与 FormatFloat 相同。舍入时假定原值来自 bitSize 位复数：complex64 必须使用 64，complex128 必须使用 128。

func FormatFloat 

func FormatFloat(f float64, fmt byte, prec, bitSize int) string

FormatFloat 按格式 fmt 和精度 prec，将浮点数 f 转换为字符串。舍入时假定原值来自 bitSize 位浮点数：float32 使用 32，float64 使用 64。

fmt 可以取以下格式之一：

  • 'b'：-ddddp±ddd，使用二进制指数。
  • 'e'：-d.dddde±dd，使用十进制指数。
  • 'E'：-d.ddddE±dd，使用十进制指数。
  • 'f'：-ddd.dddd，不使用指数。
  • 'g'：指数较大时使用 'e'，否则使用 'f'。
  • 'G'：指数较大时使用 'E'，否则使用 'f'。
  • 'x'：-0xd.ddddp±ddd，使用十六进制小数和二进制指数。
  • 'X'：-0Xd.ddddP±ddd，使用十六进制小数和二进制指数。

精度 prec 控制 'e'、'E'、'f'、'g'、'G'、'x' 和 'X' 格式输出的数字位数，不包括指数部分。对于 'e'、'E'、'f'、'x' 和 'X'，它表示小数点后的位数；对于 'g' 和 'G'，它表示有效数字的最大位数，末尾的零会被去掉。特殊精度 -1 会使用能够确保 ParseFloat 精确恢复 f 所需的最少数字位数。指数写为十进制整数；除 'b' 外，所有格式的指数至少有两位数字。

func ParseComplex 1.15 

func ParseComplex(s string, bitSize int) (complex128, error)

ParseComplex 将字符串 s 转换为复数，精度由 bitSize 指定：complex64 使用 64，complex128 使用 128。当 bitSize=64 时，结果类型仍为 complex128，但可转换为 complex64 而不改变其值。

s 表示的数必须采用 N、Ni 或 N±Ni 的形式，其中 N 是 ParseFloat 能识别的浮点数，i 表示虚数单位。如果第二个 N 不带符号，两个分量之间必须有 + 号，对应 ± 所在位置。如果第二个 N 是 NaN，则只允许使用 + 号。整个表达式可以用圆括号包围，但不能包含任何空格。结果复数由 ParseFloat 转换得到的两个分量组成。

ParseComplex 返回的错误的具体类型为 *NumError，其中 err.Num = s。

如果 s 不符合语法，ParseComplex 返回 err.Err = ErrSyntax。

如果 s 的语法正确，但任一分量超出其指定位宽所能表示的最大浮点数，且超出的距离大于 1/2 ULP，ParseComplex 返回 err.Err = ErrRange，并将相应分量设为 ±Inf。

func ParseFloat 

func ParseFloat(s string, bitSize int) (float64, error)

ParseFloat 将字符串 s 转换为浮点数，精度由 bitSize 指定：float32 使用 32，float64 使用 64。当 bitSize=32 时，结果类型仍为 float64，但可转换为 float32 而不改变其值。

ParseFloat 接受符合 Go 浮点数字面量语法的十进制和十六进制浮点数。如果 s 的格式正确，且接近一个有效浮点数，ParseFloat 按 IEEE754 无偏舍入规则，返回最接近的浮点数。（解析十六进制浮点值时，只有十六进制表示的位数超过尾数所能容纳的位数，才会发生舍入。）

ParseFloat 返回的错误的具体类型为 *NumError，其中 err.Num = s。

如果 s 不符合语法，ParseFloat 返回 err.Err = ErrSyntax。

如果 s 的语法正确，但超出指定位宽所能表示的最大浮点数，且超出的距离大于 1/2 ULP，ParseFloat 返回 f = ±Inf、err.Err = ErrRange。

ParseFloat 将字符串 "NaN" 以及可带符号的 "Inf" 和 "Infinity" 识别为对应的特殊浮点值。匹配时忽略大小写。

func ParseInt 

func ParseInt(s string, base int, bitSize int) (i int64, err error)

ParseInt 按给定进制（0，或 2 到 36）和位数（0 到 64）解析字符串 s，返回相应的值 i。

字符串可以以正负号开头，即 "+" 或 "-"。

如果 base 为 0，实际进制由可选正负号之后的前缀确定："0b" 表示二进制，"0" 或 "0o" 表示八进制，"0x" 表示十六进制，其他情况为十进制。此外，只有 base 为 0 时，才允许按 Go 整数字面量语法使用下划线。

bitSize 指定结果必须能够放入的整数类型。位数 0、8、16、32 和 64 分别对应 int、int8、int16、int32 和 int64。如果 bitSize 小于 0 或大于 64，返回错误。

ParseInt 返回的错误的具体类型为 *NumError，其中 err.Num = s。如果 s 为空或包含无效数位，err.Err = ErrSyntax，返回值为 0；如果 s 对应的数值无法由给定位数的有符号整数表示，err.Err = ErrRange，返回值为该 bitSize 下具有相应正负号、绝对值最大的整数。

func UnquoteChar 

func UnquoteChar(s string, quote byte) (value rune, multibyte bool, tail string, err error)

UnquoteChar 解码字符串 s 所表示的带转义字符串或字符字面量中的第一个字符或字节。它返回四个值：

  1. value：解码后的 Unicode 码点或字节值。
  2. multibyte：布尔值，表示解码后的字符是否需要多字节 UTF-8 表示。
  3. tail：该字符之后剩余的字符串。
  4. 错误值：如果字符语法有效，则为 nil。

第二个参数 quote 指定要解析的字面量类型，从而决定允许转义哪种引号。如果为单引号，则允许序列 \'，但不允许未转义的 '；如果为双引号，则允许 \"，但不允许未转义的 "；如果为零，则不允许这两种转义，但允许两种引号都以未转义形式出现。
