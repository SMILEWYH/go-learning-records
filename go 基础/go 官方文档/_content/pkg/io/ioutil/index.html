func NopCloser 

func NopCloser(r io.Reader) io.ReadCloser

NopCloser 包装提供的 Reader r，返回一个 Close 方法不执行任何操作的 ReadCloser。

已弃用：从 Go 1.16 开始，此函数仅调用 io.NopCloser。

func ReadAll 

func ReadAll(r io.Reader) ([]byte, error)

ReadAll 从 r 读取，直到遇到错误或 EOF，并返回读到的数据。调用成功时返回 err == nil，而不是 err == EOF。由于 ReadAll 的定义就是从 src 一直读取到 EOF，因此它不将 Read 返回的 EOF 视为需要报告的错误。

已弃用：从 Go 1.16 开始，此函数仅调用 io.ReadAll。

func ReadDir 

func ReadDir(dirname string) ([]fs.FileInfo, error)

ReadDir 读取 dirname 指定的目录，并返回目录内容的 fs.FileInfo 列表，按文件名排序。如果读取目录时发生错误，ReadDir 会返回错误且不返回任何目录条目。

已弃用：从 Go 1.16 开始，os.ReadDir 是更高效、更正确的选择：它返回 fs.DirEntry 列表而不是 fs.FileInfo 列表，并且在读取目录途中发生错误时返回部分结果。

如果必须继续获取 fs.FileInfo 列表，仍可这样做：

entries, err := os.ReadDir(dirname)
if err != nil { ... }
infos := make([]fs.FileInfo, 0, len(entries))
for _, entry := range entries {
	info, err := entry.Info()
	if err != nil { ... }
	infos = append(infos, info)
}

func TempDir
				
				
			

			
func TempDir(dir, pattern string) (name string, err error)

			
TempDir 在目录 dir 中创建新的临时目录。目录名通过在 pattern 末尾添加随机字符串生成。如果 pattern 包含 "*"，则随机字符串替换最后一个 "*"。TempDir 返回新目录的名称。如果 dir 为空字符串，则使用默认临时文件目录（参见 os.TempDir）。多个程序同时调用 TempDir 不会选择同一个目录。调用方有责任在不再需要时移除目录。
已弃用：从 Go 1.17 开始，此函数仅调用 os.MkdirTemp。

func TempFile
				
				
			

			
func TempFile(dir, pattern string) (f *os.File, err error)

			
TempFile 在目录 dir 中创建新的临时文件，以读写方式打开它，并返回所得的 *os.File。文件名通过在 pattern 末尾添加随机字符串生成。如果 pattern 包含 "*"，则随机字符串替换最后一个 "*"。如果 dir 为空字符串，则使用默认临时文件目录（参见 os.TempDir）。多个程序同时调用 TempFile 不会选择同一个文件。调用方可以使用 f.Name() 获取文件的路径名，并有责任在不再需要时移除文件。
已弃用：从 Go 1.17 开始，此函数仅调用 os.CreateTemp。

func WriteFile
				
				
			

			
func WriteFile(filename string, data []byte, perm fs.FileMode) error

			
WriteFile 将 data 写入 filename 指定的文件。如果文件不存在，则使用权限 perm（应用 umask 之前）创建；否则，写入前会截断文件，但不更改权限。
已弃用：从 Go 1.16 开始，此函数仅调用 os.WriteFile。
