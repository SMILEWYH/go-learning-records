crc32 包实现 32 位循环冗余校验（CRC-32）校验和。详见 https://en.wikipedia.org/wiki/Cyclic_redundancy_check。

多项式采用最低有效位优先（LSB-first）的形式表示，也称为反向表示法。

详见 https://en.wikipedia.org/wiki/Mathematics_of_cyclic_redundancy_checks#Reversed_representations_and_reciprocal_polynomials。

预定义的多项式。

const (
    // IEEE 是迄今最常用的 CRC-32 多项式。
    // 用于以太网（IEEE 802.3）、v.42、fddi、gzip、zip、png 等。
    IEEE = 0xedb88320

    // Castagnoli 多项式，用于 iSCSI。
    // 它的错误检测特性优于 IEEE。
    // https://dx.doi.org/10.1109/26.231911
    Castagnoli = 0x82f63b78

    // Koopman 多项式。
    // 它的错误检测特性也优于 IEEE。
    // https://dx.doi.org/10.1109/DSN.2002.1028931
    Koopman = 0xeb31d82e
)

func New 

func New(tab *Table) hash.Hash32

New 创建一个新的 hash.Hash32，使用 Table 表示的多项式计算 CRC-32 校验和。其 Sum 方法按大端字节序排列结果值。返回的 Hash32 还实现了 encoding.BinaryMarshaler 和 encoding.BinaryUnmarshaler，以序列化和反序列化哈希的内部状态。

func NewIEEE 

func NewIEEE() hash.Hash32

NewIEEE 创建一个新的 hash.Hash32，使用 IEEE 多项式计算 CRC-32 校验和。其 Sum 方法按大端字节序排列结果值。返回的 Hash32 还实现了 encoding.BinaryMarshaler 和 encoding.BinaryUnmarshaler，以序列化和反序列化哈希的内部状态。
