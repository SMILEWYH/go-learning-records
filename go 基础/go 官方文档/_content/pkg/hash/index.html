type Cloner 1.25

Cloner 是其状态可以被克隆的哈希函数，克隆结果具有等价且独立的状态。

除非设置了 GOFIPS140=v1.0.0，否则标准库中的所有 Hash 实现都实现此接口。

如果哈希只能在运行时确定自己是否可克隆（例如它包装了另一个哈希），则 Clone 可以返回包装了 errors.ErrUnsupported 的错误。否则，Clone 必须始终返回 nil 错误。

type Cloner interface {
    Hash
    Clone() (Cloner, error)
}

type Hash

Hash 是所有哈希函数实现的通用接口。

标准库中的 Hash 实现（例如 hash/crc32 和 crypto/sha256）实现了 encoding.BinaryMarshaler、encoding.BinaryAppender、encoding.BinaryUnmarshaler 和 Cloner 接口。序列化哈希实现可保存其内部状态，以便稍后继续处理，而无须重新写入先前已写入哈希的数据。哈希状态可能包含原始形式的部分输入，使用者应处理由此可能带来的安全影响。

兼容性：未来对 hash 或 crypto 包的更改会尽力保持与先前版本编码状态的兼容性。也就是说，在考虑安全修复等问题的前提下，这些包的任何已发布版本都应能够解码任意更早已发布版本写入的数据。背景信息见 Go 兼容性文档：https://golang.org/doc/go1compat。

type Hash interface {
    // Write（通过嵌入的 io.Writer 接口）将更多数据加入正在计算的哈希。
    // 它从不返回错误。
    io.Writer

    // Sum 将当前哈希值追加到 b，并返回所得切片。
    // 它不会改变底层哈希状态。
    Sum(b []byte) []byte

    // Reset 将 Hash 重置为初始状态。
    Reset()

    // Size 返回 Sum 将返回的字节数。
    Size() int

    // BlockSize 返回哈希的底层块大小。
    // Write 方法必须能够接受任意数量的
    // 数据，但如果每次写入的数据大小都是
    // 块大小的整数倍，执行效率可能更高。
    BlockSize() int
}

type XOF 1.25

XOF（可扩展输出函数）是输出长度任意或无限的哈希函数。

type XOF interface {
    // Write 将更多数据吸收进 XOF 的状态。如果在 Read
    // 之后调用，则会引发 panic。
    io.Writer

    // Read 从 XOF 读取更多输出。如果 XOF 的输出长度
    // 存在上限，则可能返回 io.EOF。
    io.Reader

    // Reset 将 XOF 重置为初始状态。
    Reset()

    // BlockSize 返回 XOF 的底层块大小。
    // Write 方法必须能够接受任意数量的
    // 数据，但如果每次写入的数据大小都是
    // 块大小的整数倍，执行效率可能更高。
    BlockSize() int
}
