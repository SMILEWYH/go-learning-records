type Handle

Handle 是某个 T 类型值的全局唯一标识。

两个句柄相等，当且仅当用于创建它们的两个值也相等。比较两个句柄的操作很简单，通常比比较用于创建它们的值高效得多。

type Handle[T comparable] struct {
    // 包含已过滤或未导出的字段
}

func Make 

func Make[T comparable](value T) Handle[T]

Make 为一个 T 类型的值返回全局唯一句柄。句柄相等，当且仅当生成它们的值相等。Make 可由多个 goroutine 安全地并发使用。

func (Handle[T]) Value 

func (h Handle[T]) Value() T

Value 返回创建该 Handle 的 T 值的浅拷贝。Value 可由多个 goroutine 安全地并发使用。
