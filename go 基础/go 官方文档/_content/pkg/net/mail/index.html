mail 包实现了邮件消息的解析。

本包大体遵循 RFC 5322 规定、并由 RFC 6532 扩展的语法。主要差异如下：

  • 不解析过时的地址格式，包括嵌入路由信息的地址。
  • 不支持所有空白形式（CFWS 语法元素），例如跨行书写地址。
  • 不执行 Unicode 规范化。
  • 允许开头出现 From 行，例如 mbox 格式（RFC 4155）中的情况。

func (Header) Get 

func (h Header) Get(key string) string

Get 获取给定键关联的第一个值。它不区分大小写，会使用 CanonicalMIMEHeaderKey 将给定键规范化。如果没有与该键关联的值，Get 返回空字符串。若要访问同一个键的多个值，或使用非规范形式的键，请直接访问映射。
