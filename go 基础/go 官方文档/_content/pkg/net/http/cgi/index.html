cgi 包实现了 RFC 3875 规定的 CGI（通用网关接口）。

注意，使用 CGI 意味着每个请求都会启动一个新进程来处理，通常比使用长期运行的服务器效率更低。本包主要用于兼容现有系统。

func Request 

func Request() (*http.Request, error)

Request 返回当前环境所表示的 HTTP 请求。它假定当前程序由 Web 服务器在 CGI 环境中运行。适用时，返回的 Request 会填充 Body。

RequestFromMap 从 CGI 变量创建一个 http.Request。返回的 Request 的 Body 字段不会被填充。

func Serve 

func Serve(handler http.Handler) error

Serve 对当前活动的 CGI 请求（如果存在）执行给定的 Handler。如果没有当前 CGI 环境，则返回错误。handler 可以为 nil，此时使用 http.DefaultServeMux。

type Handler

Handler 在带有 CGI 环境的子进程中运行可执行文件。 

type Handler struct {
    Path string // CGI 可执行文件的路径
    Root string // 处理器的根 URI 前缀，空值表示 "/"

    // Dir 指定 CGI 可执行文件的工作目录。
    // 如果 Dir 为空，则使用 Path 的所在目录。
    // 如果 Path 没有所在目录部分，
    // 则使用当前工作目录。
    Dir string

    Env        []string    // 要额外设置的环境变量（如果有），形式为 "key=value"
    InheritEnv []string    // 要从宿主继承的环境变量，形式为 "key"
    Logger     *log.Logger // 可选的错误日志记录器；nil 表示使用 log.Print
    Args       []string    // 可选的子进程参数
    Stderr     io.Writer   // 可选的子进程标准错误输出；nil 表示 os.Stderr；Go 1.7 新增

    // 按照 RFC 3875 第 6.3.2 节的规定，CGI 进程
    // 返回以 "/" 开头的 Location 头部值时，
    // PathLocationHandler 指定负责处理
    // 内部重定向的根 HTTP 处理器，
    // 通常为 http.DefaultServeMux。
    //
    // 如果为 nil，包含本地 URI 路径的 CGI 响应会直接
    // 返回客户端，而不会在内部重定向。
    PathLocationHandler http.Handler
}
