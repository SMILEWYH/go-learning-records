func NewRequestWithContext 1.23 

func NewRequestWithContext(ctx context.Context, method, target string, body io.Reader) *http.Request

NewRequestWithContext 返回新的服务端入站 Request，适合传给 http.Handler 进行测试。

target 是 RFC 7230 中的 request-target（请求目标），可以是路径或绝对 URL。如果是绝对 URL，就使用其中的主机名；否则使用 "example.com"。

如果 target 的协议方案为 "https"，TLS 字段会设为一个非 nil 的占位值。

Request.Proto 始终为 HTTP/1.1。

method 为空时表示 "GET"。

body 可以为 nil。如果 body 的类型是 bytes.Reader、strings.Reader、bytes.Buffer，或其值是 http.NoBody，就会设置 Request.ContentLength。

译注：原文使用类型名称指代这些读取器；源码实际匹配的是 *bytes.Reader、*strings.Reader 和 *bytes.Buffer 指针类型。

为方便测试使用，NewRequest 遇到错误时会触发 panic；在测试场景中，这种行为是可以接受的。

如果要生成客户端 HTTP 请求，而非服务端请求，请使用 net/http 包中的 NewRequest 函数。

type ResponseRecorder

ResponseRecorder 实现 http.ResponseWriter，记录对它的修改，以便测试随后检查。

type ResponseRecorder struct {
    // Code 是通过 WriteHeader 设置的 HTTP 响应状态码。
    //
    // 注意，如果 Handler 从未调用 WriteHeader 或 Write，
    // 此值最终可能是 0，而不是隐含的
    // http.StatusOK。若要获得隐含值，请使用 Result
    // 方法。
    Code int

    // HeaderMap 包含 Handler 显式设置的头字段。
    // 它属于内部实现细节。
    //
    // 已弃用：HeaderMap 是为历史兼容性而保留的，
    // 不应使用。要访问处理器返回的头字段，
    // 请使用 Result 方法返回的 Response.Header 映射。
    HeaderMap http.Header

    // Body 是接收 Handler 的 Write 调用所写数据的缓冲区。
    // 如果为 nil，写入会被静默丢弃。
    Body *bytes.Buffer

    // Flushed 表示 Handler 是否调用了 Flush。
    Flushed bool
    // 包含已过滤或未导出的字段
}

func (*ResponseRecorder) Result 1.7 

func (rw *ResponseRecorder) Result() *http.Response

Result 返回处理器生成的响应。

返回的 Response 至少填充 StatusCode、Header、Body，并可能填充 Trailer。未来可能填充更多字段，因此测试不应使用 DeepEqual 比较整个结果。

Response.Header 是第一次写入时响应头的快照；如果处理器从未写入，则是在调用 Result 时取得的快照。

保证 Response.Body 非 nil，且 Body.Read 不会返回 io.EOF 以外的错误。

只能在处理器运行结束后调用 Result。

type Server

Server 是用于 HTTP 端到端测试的 HTTP 服务器。

大多数测试应使用 NewTestServer 创建服务器。Server.Client 返回向该测试服务器发送请求的客户端。

// 创建测试服务器，并向它发送请求。
server := httptest.NewTestServer(t, handler)
resp, err := server.Client().Get("http://www.example.com/")

配置

测试可以在使用 Server 前修改其配置。一旦首次调用了 Server.Client、Server.Start 或 Server.StartTLS，就不能再修改配置。

// 使用之前先配置测试服务器。
server := httptest.NewTestServer(t, handler)
server.Config.MaxHeaderBytes = 1024
resp, err := server.Client().Get("http://www.example.com/")

测试行为

使用 NewTestServer 创建的服务器会：

  • 在服务器处理器触发 panic，且 panic 值不是 http.ErrAbortHandler 时，将测试标记为失败。
  • 注册 Cleanup 函数，在测试结束时关闭服务器。

通过其他方式创建的服务器，必须手动调用 Server.Close 关闭。

内存中的网络

Server 可以使用内存中的网络实现，也可以监听本地回环网络接口。大多数测试应使用内存网络，以避免端口耗尽等临时性网络问题；这种方式也适合与 testing/synctest 一起使用。

要使用内存网络，请通过 NewTestServer 创建服务器，并且不要调用 Server.Start 或 Server.StartTLS。

使用内存网络时，http.Client（由 Server.Client 返回）被配置为将所有请求发送到该服务器。无论目标地址或主机名是什么，HTTP 和 HTTPS 请求都会发送到该服务器。请求不必以 Server.URL 作为基础 URL。

server := httptest.NewTestServer(t, handler)
client := server.Client()

// 这些请求都会发送到测试服务器。
// https:// 请求在内存网络上使用 TLS。
_, _ = client.Get("http://www.example.com/")
_, _ = client.Get("https://go.dev/")
_, _ = client.Get("http://10.0.0.1/")

使用内存网络时，不会设置 Server.Listener 字段。

回环网络

要监听回环接口，请调用 Server.Start 或 Server.StartTLS。服务器会监听系统选择的端口。

回环服务器只提供一种协议：调用 Server.Start 启动时提供 HTTP，调用 Server.StartTLS 启动时提供 HTTPS。

使用回环网络时，http.Client（由 Server.Client 返回）被配置为将主机名为 "example.com" 或 ".example.com" 子域的请求发送到该服务器。

也可以向服务器的回环地址发送请求。Server.URL 字段会设置为包含服务器地址的基础 URL。

server := httptest.NewTestServer(t, handler)
server.Start()
client := server.Client()

// 此请求发送到测试服务器。
_, _ = server.Client().Get(server.URL + "/")

// 此请求（使用 http.DefaultClient）也会发送到测试服务器，
// 因为 server.URL 包含服务器的本地 IP 地址。
_, _ = http.Get(server.URL + "/")

type Server struct {
    // URL 是服务器的基础 URL，形式为 http://address:port，
    // 末尾不带斜杠。
    //
    // 首次调用 Client、Start 或 StartTLS 时会设置此字段。
    //
    // 对于监听回环地址的服务器，该地址是服务器的
    // 回环 IP 地址。
    //
    // 对于使用内存网络的服务器，该地址为 "example.com"。
    // 发往使用内存网络的服务器的请求可以使用任意地址，
    // 不必使用此基础 URL。
    URL string

    // Listener 是监听回环地址的服务器所使用的网络监听器。
    // 对于使用内存网络的服务器，不设置此字段。
    Listener net.Listener

    // EnableHTTP2 控制服务器是否启用 HTTP/2。
    // 必须在调用 Client、Start 或 StartTLS 之前设置。
    EnableHTTP2 bool // Go 1.14

    // TLS 是可选的 TLS 配置，启动 TLS 后会填入新的配置。
    // 如果在尚未启动的服务器上、调用 StartTLS 之前设置此字段，
    // 其中已有的字段会被复制到新配置中。
    TLS *tls.Config

    // 可以在调用 Client、Start 或 StartTLS 之前修改 Config。
    Config *http.Server
    // 包含已过滤或未导出的字段
}

func NewServer 

func NewServer(handler http.Handler) *Server

NewServer 启动并返回新的 Server，监听本地回环网络接口。它等价于先调用 NewUnstartedServer，再调用 Server.Start。

使用完毕后，调用方应调用 Server.Close 关闭服务器。

大多数用户应改用 NewTestServer。详见 Server 文档。

NewTestServer 为测试返回新的 Server，默认使用内存网络实现。

func NewUnstartedServer 

func NewUnstartedServer(handler http.Handler) *Server

NewUnstartedServer 返回新的 Server，监听本地回环网络接口，但不启动服务器。

修改服务器配置后，调用方应调用 Server.Start 或 Server.StartTLS。

使用完毕后，调用方应调用 Server.Close 关闭服务器。

大多数用户应改用 NewTestServer。详见 Server 文档。
