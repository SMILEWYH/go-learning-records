func ProcessEnv 1.9 

func ProcessEnv(r *http.Request) map[string]string

ProcessEnv 返回与请求 r 关联、但没有专门纳入请求本身的 FastCGI 环境变量；这些数据保存在请求的上下文中。例如，如果请求设置了 REMOTE_USER，它不会出现在 r 的任何字段中，但会通过 r 的上下文包含在 ProcessEnv 的返回结果里。

func Serve 

func Serve(l net.Listener, handler http.Handler) error

Serve 在监听器 l 上接收传入的 FastCGI 连接，并为每个连接创建一个新的 goroutine（轻量级协程）。该 goroutine 读取请求，再调用 handler 响应。如果 l 为 nil，Serve 从 os.Stdin 接收连接。如果 handler 为 nil，则使用 http.DefaultServeMux。
