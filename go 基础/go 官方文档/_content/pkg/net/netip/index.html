概览 ▾

netip 包定义了一种体积较小的 IP 地址值类型。在 Addr 类型的基础上，本包还定义了 AddrPort（IP 地址和端口）与 Prefix（IP 地址和以位数表示的前缀长度）。

与 net.IP 类型相比，Addr 类型占用更少内存、不可变且可比较（支持 ==，可作为映射的键）。

type Addr 1.18

Addr 表示一个 IPv4 或 IPv6 地址（可带或不带限定作用域的区域标识），类似于 net.IP 或 net.IPAddr。

与 net.IP 或 net.IPAddr 不同，Addr 是可比较的值类型（支持 ==，可作为映射的键），且不可变。

Addr 的零值不是有效的 IP 地址。Addr{} 与 0.0.0.0 和 :: 都不同。

    // 包含已过滤或未导出的字段
}

func (Addr) IsGlobalUnicast 1.18 

func (ip Addr) IsGlobalUnicast() bool

IsGlobalUnicast 报告 ip 是否为全局单播地址。

对于不在 IANA 当前分配的 2000::/3 全局单播空间内的 IPv6 地址，除链路本地地址空间外，它也返回 true。即使 ip 位于 IPv4 私有地址空间或 IPv6 唯一本地地址空间，它也返回 true。对于 Addr 的零值，它返回 false。

相关规范见 RFC 1122、RFC 4291 和 RFC 4632。

func (Addr) String 1.18 

func (ip Addr) String() string

String 返回 IP 地址 ip 的字符串形式，共有以下 5 种形式之一：

  • 如果 ip 是 Addr 的零值，返回“invalid IP”
  • IPv4 点分十进制形式（“192.0.2.1”）
  • IPv6 形式（“2001:db8::1”）

type Prefix 1.18

Prefix 是表示 IP 网络的 IP 地址前缀（CIDR）。

前 Prefix.Bits() 位由 Addr() 确定，其余位可以匹配任意地址。Bits() 的范围对于 IPv4 为 [0,32]，对于 IPv6 为 [0,128]。

func ParsePrefix 1.18 

func ParsePrefix(s string) (Prefix, error)

ParsePrefix 将 s 解析为 IP 地址前缀。字符串可以采用“192.168.1.0/24”或“2001:db8::/32”形式，即 RFC 4632 和 RFC 4291 定义的 CIDR 表示法。前缀中不允许 IPv6 区域标识；如果存在区域标识，则返回错误。

注意，掩码之外的地址位不会被清零。要清零这些位，请使用 Masked。

MarshalText 实现了 encoding.TextMarshaler 接口。编码与 Prefix.String 返回的相同，只有一个例外：如果 p 是 Prefix 的零值，编码为空字符串。

func (Prefix) Masked 1.18 

func (p Prefix) Masked() Prefix

Masked 返回 p 的规范形式，仅保留 p.Addr() 的高 p.Bits() 位，其余位均通过掩码清零。

如果 p 为零值或以其他方式无效，Masked 返回 Prefix 的零值。

func (Prefix) Overlaps 1.18 

func (p Prefix) Overlaps(o Prefix) bool

Overlaps 报告 p 和 o 是否包含任何共同的 IP 地址。

如果 p 和 o 属于不同地址族，或任一包含 IP 零值，则返回 false。与 Contains 方法一样，具有 IPv4 映射 IPv6 地址的前缀仍被视为 IPv6 掩码。

func (Prefix) String 1.18 

func (p Prefix) String() string

String 返回 p 的 CIDR 表示：“<ip>/<bits>”。

func (*Prefix) UnmarshalBinary 1.18 

func (p *Prefix) UnmarshalBinary(b []byte) error

UnmarshalBinary 实现了 encoding.BinaryUnmarshaler 接口。它要求数据采用 Prefix.MarshalBinary 生成的形式。

func (*Prefix) UnmarshalText 1.18 

func (p *Prefix) UnmarshalText(text []byte) error

UnmarshalText 实现了 encoding.TextUnmarshaler 接口。IP 地址必须采用 ParsePrefix 接受或 Prefix.MarshalText 生成的形式。
