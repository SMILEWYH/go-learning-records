smtp 包实现了 RFC 5321 定义的简单邮件传输协议，也实现了以下扩展： 

8BITMIME  RFC 1652
AUTH      RFC 2554
STARTTLS  RFC 3207

其他扩展可以由客户端自行处理。

smtp 包已冻结，不再接受新功能。一些外部包提供了更多功能。参见： 

https://godoc.org/?q=smtp

func SendMail
				
				
			

			
func SendMail(addr string, a Auth, from string, to []string, msg []byte) error

			
SendMail 连接到 addr 指定的服务器，在可能时切换到 TLS，在可能时使用可选的机制 a 进行认证，然后从地址 from 向地址列表 to 发送内容为 msg 的邮件。addr 必须包含端口，例如“mail.example.com:smtp”。

to 参数中的地址是 SMTP RCPT 地址。

msg 参数应是一封 RFC 822 风格的邮件，依次包含头部、一个空行和消息正文。msg 的每一行都应以 CRLF 结束。msg 头部通常应包含“From”、“To”、“Subject”和“Cc”等字段。发送“Bcc”密送邮件时，应将邮件地址包含在 to 参数中，但不将其包含在 msg 头部中。

SendMail 函数和 net/smtp 包属于底层机制，不支持 DKIM 签名、MIME 附件（参见 mime/multipart 包）或其他邮件功能。标准库之外有更高层的包可用。

type Auth
				
				
			

			
Auth 接口由 SMTP 认证机制实现。

			
type Auth interface {
    // Start 开始与服务器进行认证。
    // 它返回认证协议的名称，
    // 以及可选的数据，这些数据将包含在发送给服务器的
    // 初始 AUTH 消息中。
    // 如果返回非 nil 错误，SMTP 客户端会中止
    // 认证尝试并关闭连接。
    Start(server *ServerInfo) (proto string, toServer []byte, err error)

    // Next 继续认证。服务器刚刚发送了
    // fromServer 数据。如果 more 为 true，服务器预期收到
    // 响应，Next 应通过 toServer 返回该响应；否则
    // Next 应返回 toServer == nil。
    // 如果 Next 返回非 nil 错误，SMTP 客户端会中止
    // 认证尝试并关闭连接。
    Next(fromServer []byte, more bool) (toServer []byte, err error)
}


			

			

			

			
				
func CRAMMD5Auth
					
					
				

				
func CRAMMD5Auth(username, secret string) Auth

				
CRAMMD5Auth 返回一个实现 RFC 2195 定义的 CRAM-MD5 认证机制的 Auth。返回的 Auth 使用给定用户名和密钥，通过质询—响应机制向服务器进行认证。

				
			
				
func PlainAuth
					
					
				

				
func PlainAuth(identity, username, password, host string) Auth

				
PlainAuth 返回一个实现 RFC 4616 定义的 PLAIN 认证机制的 Auth。返回的 Auth 使用给定用户名和密码向 host 认证，并以 identity 指定的身份操作。identity 通常应为空字符串，表示使用 username 的身份。

仅当连接使用 TLS 或连接到 localhost 时，PlainAuth 才会发送凭据。否则认证会失败并返回错误，且不会发送凭据。

type Client

type Client struct {
    // Text 是 Client 使用的 textproto.Conn。导出它是为了允许

func Dial
					
					
				

				
func Dial(addr string) (*Client, error)

				
Dial 返回一个连接到 addr 所指定 SMTP 服务器的新 Client。addr 必须包含端口，例如“mail.example.com:smtp”。

				
			
				
func NewClient
					
					
				

				
func NewClient(conn net.Conn, host string) (*Client, error)

				
NewClient 使用现有连接返回一个新的 Client，并将 host 作为认证时使用的服务器名称。

				
			

			
				
func (*Client) Auth
					
					
				

				
func (c *Client) Auth(a Auth) error

				
Auth 使用给定的认证机制对客户端进行认证。认证失败会关闭连接。只有声明支持 AUTH 扩展的服务器才支持此功能。

				
			
				
func (*Client) Close
					
					1.2
				

				
func (c *Client) Close() error

				
Close 关闭连接。

				
			
				
func (*Client) Data
					
					
				

				
func (c *Client) Data() (io.WriteCloser, error)

				
Data 向服务器发送 DATA 命令，并返回一个可用于写入邮件头部和正文的写入器。调用者应在调用 c 的其他方法之前关闭该写入器。调用 Data 之前，必须已调用一次或多次 Client.Rcpt。

				
			
				
func (*Client) Extension
					
					
				

				
func (c *Client) Extension(ext string) (bool, string)

				
Extension 报告服务器是否支持某个扩展。扩展名称不区分大小写。如果支持该扩展，Extension 还会返回一个字符串，其中包含服务器为该扩展指定的所有参数。

				
			
				
func (*Client) Hello
					
					1.1
				

				
func (c *Client) Hello(localName string) error

				
Hello 以给定主机名向服务器发送 HELO 或 EHLO。只有当客户端需要控制所用主机名时，才需要调用此方法；否则客户端会自动以“localhost”介绍自己。如果要调用 Hello，必须在调用任何其他方法之前调用它。

				
			
				
func (*Client) Mail
					
					
				

				
func (c *Client) Mail(from string) error

				
Mail 使用给定的邮件地址向服务器发送 MAIL 命令。如果服务器支持 8BITMIME 扩展，Mail 会添加 BODY=8BITMIME 参数。如果服务器支持 SMTPUTF8 扩展，Mail 会添加 SMTPUTF8 参数。此操作发起一个邮件事务，之后应调用一次或多次 Client.Rcpt。

				
			
				
func (*Client) Noop
					
					1.10
				

				
func (c *Client) Noop() error

				
Noop 向服务器发送 NOOP 命令。除检查与服务器的连接是否正常外，不执行任何操作。

				
			
				
func (*Client) Quit
					
					
				

				
func (c *Client) Quit() error

				
Quit 发送 QUIT 命令并关闭与服务器的连接。

				
			
				
func (*Client) Rcpt
					
					
				

				
func (c *Client) Rcpt(to string) error

				
Rcpt 使用给定的邮件地址向服务器发送 RCPT 命令。调用 Rcpt 之前必须先调用 Client.Mail，之后可以调用 Client.Data 或再次调用 Rcpt。

				
			
				
func (*Client) Reset
					
					
				

				
func (c *Client) Reset() error

				
Reset 向服务器发送 RSET 命令，中止当前邮件事务。

				
			
				
func (*Client) StartTLS
					
					
				

				
func (c *Client) StartTLS(config *tls.Config) error

				
StartTLS 发送 STARTTLS 命令，并加密此后的所有通信。只有声明支持 STARTTLS 扩展的服务器才支持此功能。

				
			
				
func (*Client) TLSConnectionState
					
					1.5
				

				
func (c *Client) TLSConnectionState() (state tls.ConnectionState, ok bool)

				
TLSConnectionState 返回客户端的 TLS 连接状态。如果 Client.StartTLS 未成功，则返回各返回类型的零值。

				
			
				
func (*Client) Verify
					
					
				

				
func (c *Client) Verify(addr string) error

				
Verify 检查服务器上某个邮件地址是否有效。如果 Verify 返回 nil，该地址有效。返回非 nil 并不一定表示地址无效，因为许多服务器出于安全考虑不会验证地址。

				
			
		
			
			
type ServerInfo
				
				
			

			
ServerInfo 记录 SMTP 服务器的信息。

			
type ServerInfo struct {
    Name string   // SMTP 服务器名称
    TLS  bool     // 使用 TLS，且证书对 Name 有效
    Auth []string // 服务器声明支持的认证机制
}
