url 包用于解析 URL，并实现查询字符串的转义。

参见 RFC 3986。除为兼容性而作出的偏离外，本包总体上遵循 RFC 3986。IPv6 区域标识符字面量遵循 RFC 6874。

func PathUnescape 1.8 

func PathUnescape(s string) (string, error)

PathUnescape 执行 PathEscape 的逆变换，将每个形如 "%AB" 的 3 字节编码子串还原为十六进制字节 0xAB。如果任何 % 后面没有跟随两个十六进制数字，则返回错误。

PathUnescape 与 QueryUnescape 相同，但不会将 '+' 还原为 ' '（空格）。

type URL

URL 表示解析后的 URL（严格来说，是一个 URI 引用）。

其表示的一般形式为：

[scheme:][//[userinfo@]host][/]path[?query][#fragment]

如果 URL 的协议方案之后不是以斜杠开头，则解释为：

scheme:opaque[?query][#fragment]

Host 字段包含 URL 的主机和端口部分。端口存在时，以冒号与主机分隔。主机为 IPv6 地址时，必须用方括号包围，例如 "[fe80::1]:80"。net.JoinHostPort 将主机和端口组合成适合 Host 字段的字符串，并在需要时为主机加上方括号。

注意，Path 字段存储解码后的形式：/%47%6f%2f 会变成 /Go/。因此，无法仅从 Path 判断哪些斜杠来自原始 URL 中的斜杠，哪些来自 %2f。这一区别通常并不重要；如果需要区分，应使用 URL.EscapedPath，它会保留 Path 的原始编码。Fragment 字段也存储解码后的形式，可用 URL.EscapedFragment 获取原始编码。

URL.String 使用 URL.EscapedPath 获取路径。

type URL struct {
    Scheme   string
    Opaque   string    // 编码后的不透明数据
    User     *Userinfo // 用户名和密码信息
    Host     string    // "host" 或 "host:port"（参见 Hostname 和 Port 方法）
    Path     string    // 路径（相对路径可以省略开头的斜杠）
    Fragment string    // 引用的片段标识符（不包含 '#'）

    // RawQuery 包含编码后的查询值，不含开头的 '?'。
    // 使用 URL.Query 解码查询。
    RawQuery string

    // RawPath 是可选字段，包含编码后的路径提示。
    // 详情请参阅 EscapedPath 方法。
    //
    // 通常应调用 EscapedPath，而不是直接读取 RawPath。
    RawPath string // Go 1.5

    // RawFragment 是可选字段，包含编码后的片段提示。
    // 详情请参阅 EscapedFragment 方法。
    //
    // 通常应调用 EscapedFragment，而不是直接读取 RawFragment。
    RawFragment string // Go 1.15

    // ForceQuery 表示原始 URL 是否包含查询字符（'?'）。
    // 设置后，即使 RawQuery 为空，String 方法也会在结尾加上 '?'。
    ForceQuery bool // Go 1.7

    // OmitHost 表示 URL 的主机（authority 部分）为空。
    // 设置后，如果主机为空，String 方法就不会包含主机部分。
    OmitHost bool // Go 1.19
}

func Parse 

func Parse(rawURL string) (*URL, error)

Parse 将原始 url 解析为 URL 结构。

url 可以是相对地址（只有路径，没有主机），也可以是绝对地址（以协议方案开头）。不带协议方案的主机名与路径组合不属于有效输入，但由于解析可能存在歧义，尝试解析时不一定返回错误。

func ParseRequestURI 

func ParseRequestURI(rawURL string) (*URL, error)

ParseRequestURI 将原始 url 解析为 URL 结构。它假定 url 来自 HTTP 请求，因此只将其解释为绝对 URI 或绝对路径，并假定字符串不含 #fragment 后缀。（Web 浏览器在向服务器发送 URL 前会去掉 #fragment。）

func (*URL) EscapedFragment 1.15

EscapedFragment 返回 u.Fragment 的转义形式。一个片段通常存在多种有效的转义表示。如果 u.RawFragment 是 u.Fragment 的有效转义，便返回 u.RawFragment；否则忽略 u.RawFragment，自行计算转义结果。URL.String 使用 EscapedFragment 构造结果。通常应调用 EscapedFragment，而不是直接读取 u.RawFragment。

func (*URL) ResolveReference 

func (u *URL) ResolveReference(ref *URL) *URL

ResolveReference 按 RFC 3986 第 5.2 节，以绝对基础 URI u 为基准，将一个 URI 引用解析为绝对 URI。该引用可以是相对或绝对地址。ResolveReference 始终返回新的 URL 实例，即使结果与基础 URI 或引用完全相同。如果 ref 是绝对 URL，则忽略基础地址，返回 ref 的副本。

func (*URL) String 

func (u *URL) String() string

String 将 URL 重新组合为有效的 URL 字符串。结果的一般形式为以下之一：

scheme:opaque?query#fragment
scheme://userinfo@host/path?query#fragment

u.Opaque 非空时，String 使用第一种形式；否则使用第二种形式。主机部分的非 ASCII 字符都会被转义。路径通过 u.EscapedPath() 获取。

第二种形式遵循以下规则：

  • u.Scheme 为空时，省略 scheme:。
  • u.User 为 nil 时，省略 userinfo@。
  • u.Host 为空时，省略 host/。
  • u.Scheme 和 u.Host 均为空、且 u.User 为 nil 时，省略整个 scheme://userinfo@host/。
  • u.Host 非空且 u.Path 以 / 开头时，host/path 不再额外添加 /。
  • u.RawQuery 为空时，省略 ?query。
  • u.Fragment 为空时，省略 #fragment。

▸ 示例

▾ 示例

https://me:pass@example.com/foo/bar?x=1&y=2#anchor
https:opaque?x=1&y=2#anchor

}

func UserPassword 

func UserPassword(username, password string) *Userinfo

UserPassword 返回包含给定用户名和密码的 Userinfo。

此功能只应在兼容旧网站时使用。RFC 2396 警告，不建议以这种方式解释 Userinfo，因为以明文（例如 URI）传递身份验证信息，在几乎所有实际使用场景中都被证明存在安全风险。

func ParseQuery 

func ParseQuery(query string) (Values, error)

ParseQuery 解析经过 URL 编码的查询字符串，并返回一个映射，列出每个键对应的值。它始终返回非 nil 的映射，包含找到的全部有效查询参数；如果发生错误，err 描述遇到的第一个解码错误。

查询字符串应是以 & 分隔的一组 key=value 项。不含等号的项解释为对应键的值为空字符串。含有未经过 URL 编码的分号的项视为无效。
