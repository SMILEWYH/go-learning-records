structs 包定义了一些标记类型，可将它们用作结构体字段以修改结构体的属性。

按照惯例，标记类型应作为名为 "_" 的字段的类型，并放在结构体类型定义的开头。

type HostLayout

包源文件

doc.go hostlayout.go

type HostLayout 1.23

HostLayout 将结构体标记为使用宿主内存布局。带有 HostLayout 类型字段的结构体，将按照宿主的预期在内存中布局，通常遵循宿主的 C ABI。

HostLayout 不影响所在结构体中其他结构体类型字段的内部布局，也不影响包含此被标记结构体的外层结构体的布局。

按照惯例，HostLayout 应作为名为 "_" 的字段的类型，并放在结构体类型定义的开头。

type HostLayout struct {
    // 包含已过滤或未导出的字段
}
