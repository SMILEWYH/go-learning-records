unicode 包提供用于测试 Unicode 码点某些属性的数据和函数。

▸ 示例 (Is)

▾ 示例 (Is)

以 "Is" 开头的函数可以检查某个 rune 属于哪个范围表。注意，一个 rune 可能属于多个范围。

For '\b':
	is control rune
	is not printable rune
For '5':
	is digit rune
	is graphic rune
	is number rune
	is printable rune
For 'Ὂ':
	is graphic rune
	is letter rune
	is printable rune
	is upper case rune
For 'g':
	is graphic rune
	is letter rune
	is lower case rune
	is printable rune
For '̀':
	is graphic rune
	is mark rune
	is printable rune
For '9':
	is digit rune
	is graphic rune
	is number rune
	is printable rune
For '!':
	is graphic rune
	is printable rune
	is punct rune
For ' ':
	is graphic rune
	is printable rune
	is space rune
For '℃':
	is graphic rune
	is printable rune
	is symbol rune
For 'ᾭ':
	is graphic rune
	is letter rune
	is printable rune
	is title case rune
For 'G':
	is graphic rune
	is letter rune
	is printable rune
	is upper case rune

常量

const (
    MaxRune         = '\U0010FFFF' // 最大的有效 Unicode 码点。
    ReplacementChar = '\uFFFD'     // 表示无效码点。
    MaxASCII        = '\u007F'     // 最大的 ASCII 值。
    MaxLatin1       = '\u00FF'     // 最大的 Latin-1 值。
)

CaseRanges 内部 Delta 数组的索引，用于大小写映射。

const (
    UpperCase = iota
    LowerCase
    TitleCase
    MaxCase
)

如果 CaseRange 的 Delta 字段为 UpperLower，则此 CaseRange 表示形如 Upper Lower Upper Lower 的序列。

const (
    UpperLower = MaxRune + 1 // （不可能是有效的 delta。）
)

Version 表示这些表所依据的 Unicode 版本。

const Version = "17.0.0"

func SimpleFold 

func SimpleFold(r rune) rune

SimpleFold 遍历在 Unicode 定义的简单大小写折叠下等价的 Unicode 码点。在与 r 等价的码点（包括 r 自身）中，如果存在大于 r 的 rune，则 SimpleFold 返回其中最小的一个；否则返回其中大于等于 0 的最小 rune。如果 r 不是有效的 Unicode 码点，SimpleFold(r) 返回 r。

例如：

SimpleFold('A') = 'a'
SimpleFold('a') = 'A'

SimpleFold('K') = 'k'
SimpleFold('k') = '\u212A' (Kelvin symbol, K)
SimpleFold('\u212A') = 'K'

SimpleFold('1') = '1'

SimpleFold(-2) = -2

type CaseRange

CaseRange 表示用于简单大小写转换（一个码点到一个码点）的 Unicode 码点范围。范围从 Lo 到 Hi（含两端），固定步长为 1。Delta 是要加到码点上的数值，以得到该字符另一种大小写形式的码点。Delta 可以为负；如果为零，则表示字符已经处于对应的大小写形式。有一种特殊情况表示相对应的大写和小写字符交替出现的序列，其固定 Delta 为：

{UpperLower, UpperLower, UpperLower}

常量 UpperLower 的 delta 值在其他情况下不可能出现。

type CaseRange struct {
    Lo    uint32
    Hi    uint32
    Delta d
}

type Range16

Range16 表示一个 16 位 Unicode 码点范围，从 Lo 到 Hi（含两端），步长为指定值。

type Range16 struct {
    Lo     uint16
    Hi     uint16
    Stride uint16
}

type Range32

Range32 表示 Unicode 码点范围，用于一个或多个值无法用 16 位表示的情况。范围从 Lo 到 Hi（含两端），步长为指定值。Lo 和 Hi 必须始终 >= 1<<16。

type Range32 struct {
    Lo     uint32
    Hi     uint32
    Stride uint32
}

type RangeTable

RangeTable 通过列出集合内的码点范围，定义一组 Unicode 码点。为节省空间，这些范围存储在两个切片中：16 位范围切片和 32 位范围切片。两个切片都必须有序且不重叠。此外，R32 应仅包含 >= 0x10000 (1<<16) 的值。

type RangeTable struct {
    R16         []Range16
    R32         []Range32
    LatinOffset int // R16 中满足 Hi <= MaxLatin1 的条目数量；Go 1.1 添加
}
