const (

    RuneSelf  = 0x80         // 小于 RuneSelf 的字符直接以单字节表示自身。
    MaxRune   = '\U0010FFFF' // 最大的有效 Unicode 码点。
    UTFMax    = 4            // UTF-8 编码的 Unicode 字符所需的最大字节数。
)

func AppendRune 1.18 

func AppendRune(p []byte, r rune) []byte

AppendRune 将 r 的 UTF-8 编码追加到 p 末尾，并返回扩展后的缓冲区。如果该 rune 超出有效范围，则追加 RuneError 的编码。

func DecodeLastRune 

func DecodeLastRune(p []byte) (r rune, size int)

DecodeLastRune 解码 p 中最后一个 UTF-8 编码，返回对应的 rune 及其字节宽度。如果 p 为空，则返回 (RuneError, 0)。否则，如果编码无效，则返回 (RuneError, 1)。对于正确且非空的 UTF-8，这两种结果都不可能出现。

如果编码不是正确的 UTF-8、所编码的 rune 超出有效范围，或者不是该值最短的 UTF-8 编码，则该编码无效。不进行其他验证。

func EncodeRune 

func EncodeRune(p []byte, r rune) int

EncodeRune 将该 rune 的 UTF-8 编码写入 p（p 必须足够大）。如果该 rune 超出有效范围，则写入 RuneError 的编码。它返回写入的字节数。

func FullRune(p []byte) bool
