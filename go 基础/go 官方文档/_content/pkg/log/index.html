概览 ▾

log 包实现简单的日志功能。它定义了 Logger 类型，提供格式化输出的方法。它还预定义了一个“标准” Logger，可通过辅助函数 Print[f|ln]、Fatal[f|ln] 和 Panic[f|ln] 访问，比手动创建 Logger 更易使用。该日志器向标准错误写入，并打印每条日志消息的日期和时间。每条日志消息独占一行：如果待打印消息不以换行符结尾，日志器会自动添加一个。Fatal 函数在写入日志消息后调用 os.Exit(1)。Panic 函数在写入日志消息后调用 panic。

这些标志定义了 Logger 为每条日志添加哪些前缀文本。各标志位按位或组合，以控制打印内容。除 Lmsgprefix 标志外，不能控制它们的出现顺序（即此处列出的顺序）或呈现格式（如注释所述）。只有指定 Llongfile 或 Lshortfile 时，前缀后才会带冒号。例如，标志 Ldate | Ltime（或 LstdFlags）会产生：

2009/01/23 01:23:23 message

而标志 Ldate | Ltime | Lmicroseconds | Llongfile 会产生：

2009/01/23 01:23:23.123123 /a/b/c/d.go:23: message

const (
    Ldate         = 1 << iota     // 本地时区的日期：2009/01/23
    Ltime                         // 本地时区的时间：01:23:23
    Lmicroseconds                 // 微秒分辨率：01:23:23.123123。隐含 Ltime。
    Llongfile                     // 完整文件名和行号：/a/b/c/d.go:23
    Lshortfile                    // 文件名的最后一段和行号：d.go:23。覆盖 Llongfile
    LUTC                          // 如果设置了 Ldate 或 Ltime，则使用 UTC 而不是本地时区
    Lmsgprefix                    // 将“prefix”从行首移到消息之前
    LstdFlags     = Ldate | Ltime // 标准日志器的初始值
)

func Output 1.5 

func Output(calldepth int, s string) error

Output 写出一次日志事件的输出。字符串 s 包含要在 Logger 标志指定的前缀之后打印的文本。如果 s 的最后一个字符不是换行符，则追加换行符。设置 Llongfile 或 Lshortfile 后，Calldepth 表示计算文件名和行号时要跳过的栈帧数；值为 1 时，打印 Output 调用方的详细信息。

type Logger

Logger 表示一个活动的日志对象，向 io.Writer 逐行生成输出。每次日志操作只调用一次 Writer 的 Write 方法。多个 goroutine 可以同时使用同一个 Logger；它保证对 Writer 的访问串行执行。
