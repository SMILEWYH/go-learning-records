概览 ▾

syslog 包为系统日志服务提供简单接口。它可以通过 UNIX 域套接字、UDP 或 TCP 向 syslog 守护进程发送消息。

只需调用一次 Dial。写入失败时，syslog 客户端会尝试重新连接服务器并再次写入。

syslog 包已冻结，不再接受新功能。一些外部包提供了更多功能。参见：

https://godoc.org/?q=syslog

func NewLogger 

func NewLogger(p Priority, logFlag int) (*log.Logger, error)

NewLogger 创建一个 log.Logger，以指定的优先级将输出写入系统日志服务；该优先级由 syslog 的设施类别（facility）和严重级别（severity）组合而成。logFlag 实参是传给 log.New 以创建 Logger 的标志集合。

type Priority

Priority 由 syslog 的设施类别和严重级别组合而成。例如，LOG_ALERT | LOG_FTP 发送来自 FTP 设施、严重级别为 alert 的消息。默认严重级别为 LOG_EMERG；默认设施类别为 LOG_KERN。

type Priority int
const (

    // 来自 /usr/include/sys/syslog.h。
    // 这些值在 Linux、BSD 和 OS X 上相同。
    LOG_EMERG Priority = iota
    LOG_ALERT
    LOG_CRIT
    LOG_ERR
    LOG_WARNING
    LOG_NOTICE
    LOG_INFO
    LOG_DEBUG
)

    // 来自 /usr/include/sys/syslog.h。

    LOG_LOCAL1

func Dial 

func Dial(network, raddr string, priority Priority, tag string) (*Writer, error)

Dial 通过在指定 network 上连接地址 raddr，建立到日志守护进程的连接。向返回的写入器每写入一次，就会发送一条带有设施类别、严重级别（来自 priority）及 tag 的日志消息。如果 tag 为空，则使用 os.Args[0]。如果 network 为空，Dial 连接到本地 syslog 服务器。否则，network 和 raddr 的有效值请参见 net.Dial 的文档。

  • ☞ 
    本包未在 Windows 上实现。由于 syslog 包已冻结，建议 Windows 用户使用标准库之外的包。背景信息见 https://golang.org/issue/1108。
    • 
		
		
  • ☞ 
    本包未在 Plan 9 上实现。
    • 
		
		
  • ☞ 
    从 Darwin 的 macOS 12.X（Monterey）开始，Apple 的 syslog 守护进程不再监听 UNIX 域套接字，而是改用其专有的 Apple Unified Logging（AUL）系统，因此本包将无法再工作。参见 https://developer.apple.com/documentation/os/logging。
