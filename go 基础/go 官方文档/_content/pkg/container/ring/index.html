type Ring

Ring 是循环链表（也称为环）中的一个元素。环没有开头或结尾；指向任意环元素的指针都可作为对整个环的引用。空环用 nil 的 Ring 指针表示。Ring 的零值是仅含一个元素的环，该元素的 Value 为 nil。

    Value any // 供调用方使用；本库不会修改它

func (*Ring) Link 

func (r *Ring) Link(s *Ring) *Ring

Link 将环 r 与环 s 连接，使 r.Next() 变为 s，并返回 r.Next() 的原值。r 不得为空。

如果 r 和 s 指向同一个环，将它们连接会从环中移除 r 与 s 之间的元素。被移除的元素组成一个子环，返回结果是对该子环的引用（如果没有移除元素，结果仍为 r.Next() 的原值，而不是 nil）。

如果 r 和 s 指向不同的环，将它们连接会创建一个环，其中 s 的元素插入在 r 之后。返回结果指向插入后紧随 s 的最后一个元素的元素。

func (*Ring) Move 

func (r *Ring) Move(n int) *Ring

Move 在环中向后（n < 0）或向前（n >= 0）移动 n % r.Len() 个元素，并返回到达的环元素。r 不得为空。

func (*Ring) Unlink 

func (r *Ring) Unlink(n int) *Ring

Unlink 从 r.Next() 开始，从环 r 中移除 n % r.Len() 个元素。如果 n % r.Len() == 0，则 r 保持不变。结果是被移除的子环。r 不得为空。
