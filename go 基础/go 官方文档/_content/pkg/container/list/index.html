list 包实现双向链表。

遍历链表的方法如下（其中 l 为 *List）：

for e := l.Front(); e != nil; e = e.Next() {
	// 对 e.Value 执行一些操作
}

type Element

Element 是链表中的一个元素。

type Element struct {

    // 此元素存储的值。
    Value any
    // 包含已过滤或未导出的字段
}

func (*Element) Next 

func (e *Element) Next() *Element

Next 返回下一个链表元素或 nil。

func (*Element) Prev 

func (e *Element) Prev() *Element

Prev 返回上一个链表元素或 nil。

type List

List 表示双向链表。List 的零值是可直接使用的空链表。

type List struct {
    // 包含已过滤或未导出的字段
}

func New 

func New() *List

New 返回一个已初始化的链表。

func (*List) Back 

func (l *List) Back() *Element

Back 返回链表 l 的最后一个元素；如果链表为空，则返回 nil。

func (*List) Front 

func (l *List) Front() *Element

Front 返回链表 l 的第一个元素；如果链表为空，则返回 nil。

func (*List) Init 

func (l *List) Init() *List

Init 初始化或清空链表 l。

func (*List) InsertAfter 

func (l *List) InsertAfter(v any, mark *Element) *Element

InsertAfter 在 mark 紧后面插入一个值为 v 的新元素 e，并返回 e。如果 mark 不是 l 的元素，则不修改链表。mark 不得为 nil。

func (*List) InsertBefore 

func (l *List) InsertBefore(v any, mark *Element) *Element

InsertBefore 在 mark 紧前面插入一个值为 v 的新元素 e，并返回 e。如果 mark 不是 l 的元素，则不修改链表。mark 不得为 nil。

func (*List) Len 

func (l *List) Len() int

Len 返回链表 l 的元素数量。复杂度为 O(1)。

func (*List) MoveAfter 1.2 

func (l *List) MoveAfter(e, mark *Element)

MoveAfter 将元素 e 移到 mark 后面的新位置。如果 e 或 mark 不是 l 的元素，或者 e == mark，则不修改链表。元素 e 和 mark 都不得为 nil。

func (*List) MoveBefore 1.2 

func (l *List) MoveBefore(e, mark *Element)

MoveBefore 将元素 e 移到 mark 前面的新位置。如果 e 或 mark 不是 l 的元素，或者 e == mark，则不修改链表。元素 e 和 mark 都不得为 nil。

func (*List) MoveToBack 

func (l *List) MoveToBack(e *Element)

MoveToBack 将元素 e 移到链表 l 的末尾。如果 e 不是 l 的元素，则不修改链表。该元素不得为 nil。

func (*List) MoveToFront 

func (l *List) MoveToFront(e *Element)

MoveToFront 将元素 e 移到链表 l 的开头。如果 e 不是 l 的元素，则不修改链表。该元素不得为 nil。

func (*List) PushBack 

func (l *List) PushBack(v any) *Element

PushBack 在链表 l 的末尾插入一个值为 v 的新元素 e，并返回 e。

func (*List) PushBackList 

func (l *List) PushBackList(other *List)

PushBackList 将另一个链表的副本插入链表 l 的末尾。链表 l 和 other 可以相同。它们都不得为 nil。

func (*List) PushFront 

func (l *List) PushFront(v any) *Element

PushFront 在链表 l 的开头插入一个值为 v 的新元素 e，并返回 e。

func (*List) PushFrontList 

func (l *List) PushFrontList(other *List)

PushFrontList 将另一个链表的副本插入链表 l 的开头。链表 l 和 other 可以相同。它们都不得为 nil。

func (*List) Remove 

func (l *List) Remove(e *Element) any

如果 e 是链表 l 的元素，Remove 将其从 l 中移除。它返回元素的值 e.Value。该元素不得为 nil。
