big 包实现任意精度算术（大数运算），支持以下数值类型：

Int    带符号整数
Rat    有理数
Float  浮点数

Int、Rat 或 Float 的零值都表示 0。因此，可按通常的方式声明新值，无须进一步初始化即可表示 0：

var x Int        // &x 是值为 0 的 *Int
var r = &Rat{}   // r 是值为 0 的 *Rat
y := new(Float)  // y 是值为 0 的 *Float

也可以使用以下形式的工厂函数分配并初始化新值：

func NewT(v V) *T

例如，NewInt(x) 返回设为 int64 参数 x 的值的 *Int；NewRat(a, b) 返回设为分数 a/b 的 *Rat，其中 a 和 b 都是 int64；NewFloat(f) 返回用 float64 参数 f 初始化的 *Float。显式设置方法提供了更大的灵活性，例如：

var z1 Int
z1.SetUint64(123)                 // z1 := 123
z2 := new(Rat).SetFloat64(1.25)   // z2 := 5/4
z3 := new(Float).SetInt(z1)       // z3 := 123.0

设置方法、数值运算和谓词用以下形式的方法表示：

func (z *T) SetV(v V) *T          // z = v
func (z *T) Unary(x *T) *T        // z = 对 x 执行一元运算
func (z *T) Binary(x, y *T) *T    // z = 对 x 和 y 执行二元运算
func (x *T) Pred() P              // p = pred(x)

其中 T 是 Int、Rat 或 Float 之一。对于一元和二元运算，接收者保存结果（此时通常命名为 z，见下文）；如果接收者也是操作数 x 或 y 之一，可以安全地覆盖它（并复用其内存）。

算术表达式通常写成一系列独立的方法调用，每次调用对应一次运算。接收者表示结果，方法参数是运算的操作数。例如，给定三个 *Int 值 a、b 和 c，调用

c.Add(a, b)

会计算 a + b 的和，并将结果存入 c，覆盖 c 原先保存的值。除非另有说明，运算允许参数指向同一个值，因此可以放心地写成

sum.Add(sum, x)

将各个 x 累加到 sum 中。

（始终通过接收者传入结果值，可以更好地控制内存使用。运算无须为每个结果分配新内存，而是可以复用为结果值分配的空间，并在计算过程中用新结果覆盖原值。）

命名约定：API 对传入的方法参数（包括接收者）采用一致的命名，以明确其用途。传入的操作数通常命名为 x、y、a、b 等，但绝不用 z。用于指定结果的参数命名为 z（通常就是接收者）。

例如，(*Int).Add 的参数命名为 x 和 y，而接收者指定结果的存放位置，因此命名为 z：

func (z *Int) Add(x, y *Int) *Int

这类方法通常还返回传入的接收者，以便进行简单的链式调用。

不需要传入结果值的方法（例如 Int.Sign）直接返回结果。此时，接收者通常是第一个操作数，命名为 x：

func (x *Int) Sign() int

多种方法支持字符串与对应数值之间的双向转换：*Int、*Rat 和 *Float 实现了 Stringer 接口，用于生成值的默认字符串表示；它们还提供 SetString 方法，支持从多种格式的字符串初始化值（参见相应 SetString 的文档）。

最后，*Int、*Rat 和 *Float 都满足用于扫描输入的 fmt.Scanner 接口；除 *Rat 外，它们还满足用于格式化输出的 Formatter 接口。

type Float 1.5

非零的有限 Float 表示如下形式的多精度浮点数：

sign × mantissa × 2**exponent

其中 0.5 <= mantissa < 1.0，且 MinExp <= exponent <= MaxExp。Float 也可以是零（+0、-0）或无穷大（+Inf、-Inf）。所有 Float 都可以比较大小，两个 Float 值 x 和 y 的顺序由 x.Cmp(y) 定义。

每个 Float 值还具有精度、舍入模式和准确度。精度是可用于表示该值的尾数二进制位的最大数量。舍入模式指定如何对结果舍入，使其适合这些尾数位；准确度描述结果与精确结果之间的舍入误差。

除非另有说明，所有用 *Float 变量指定结果的运算（包括设置方法）都按照结果变量的精度和舍入模式对数值结果进行舍入。结果通常通过接收者指定，Float.MantExp 除外。

如果传入的结果精度为 0（见下文），则在进行任何舍入前，将其设为各参数中最大的精度，舍入模式保持不变。因此，作为结果参数传入的未初始化 Float，其精度会被设为由操作数决定的合理值，而舍入模式则为 RoundingMode 的零值 ToNearestEven。

将所需精度设为 24 或 53，并采用相匹配的舍入模式（通常为 ToNearestEven）时，对于对应于正规（即非次正规）float32 或 float64 数的操作数，Float 运算会得到与相应 IEEE 754 float32 或 float64 算术相同的结果。由于 Float 的指数范围大得多，指数下溢和上溢产生 0 或无穷大的临界值与 IEEE 754 不同。

Float 的零值（未初始化的值）可直接使用，精确表示 +0.0，精度为 0，舍入模式为 ToNearestEven。

运算始终使用指针参数 *Float，而不是 Float 值；每个独立的 Float 值都需要自己的 *Float 指针。要“复制” Float 值，必须使用 Float.Set 方法为已有或新分配的 Float 设置新值；不支持 Float 的浅拷贝，浅拷贝可能导致错误。

func (*Float) Add 1.5 

func (z *Float) Add(x, y *Float) *Float

Add 将 z 设为 x+y 舍入后的和，并返回 z。如果 z 的精度为 0，则在运算前将其改为 x 和 y 两者中较大的精度。舍入遵循 z 的精度和舍入模式；z 的准确度报告结果相对于精确（未经舍入）结果的误差。如果 x 和 y 是符号相反的无穷大，Add 会引发 ErrNaN panic，此时 z 的值未定义。

func (*Float) Parse 1.5 

func (z *Float) Parse(s string, base int) (f *Float, b int, err error)

Parse 解析 s。s 必须是一个浮点数的文本表示，尾数使用给定的转换进制（指数始终为十进制），或者是表示无穷大的字符串。

当 base 为 0 时，进制前缀与相邻数字之间以及连续数字之间可以出现下划线“_”；下划线不改变数值或返回的数字个数。如果不存在其他错误，下划线位置不正确会作为错误报告。当 base != 0 时，不识别下划线，它与其他既不是有效小数点又不是有效数字的字符一样，会终止扫描。

Parse 将 z 设为相应浮点数的值（可能经过舍入），并返回 z、实际进制 b，以及错误 err（如有）。只有消耗整个字符串，而不只是其前缀，才算成功。如果 z 的精度为 0，则在舍入前将其设为 64。数字必须具有如下形式：

number    = [ sign ] ( float | "inf" | "Inf" ) .
sign      = "+" | "-" .
float     = ( mantissa | prefix pmantissa ) [ exponent ] .
prefix    = "0" [ "b" | "B" | "o" | "O" | "x" | "X" ] .
mantissa  = digits "." [ digits ] | digits | "." digits .
pmantissa = [ "_" ] digits "." [ digits ] | [ "_" ] digits | "." digits .
exponent  = ( "e" | "E" | "p" | "P" ) [ sign ] digits .
digits    = digit { [ "_" ] digit } .
digit     = "0" ... "9" | "a" ... "z" | "A" ... "Z" .

base 参数必须为 0、2、8、10 或 16。无效的 base 参数会引发运行时 panic。

当 base 为 0 时，由数字前缀决定实际进制：“0b”或“0B”表示二进制，“0o”或“0O”表示八进制，“0x”或“0X”表示十六进制。否则实际进制为十进制，且不接受前缀。不支持八进制前缀“0”（开头的“0”仅作为普通数字 0）。

指数标记“p”或“P”表示以 2 为底（而非以 10 为底）的指数；例如在 base 为 0 时，“0x1.fffffffffffffp1023”表示最大的 float64 值。对于十六进制尾数，如果有指数，其标记必须是 'p' 或 'P'（因为无法区分指数标记“e”或“E”与尾数中的数字）。

如果报告错误，返回的 *Float f 为 nil，z 的值仍有效但未定义。

func (*Int) ProbablyPrime 

func (x *Int) ProbablyPrime(n int) bool

ProbablyPrime 报告 x 是否可能为素数。它使用 n 个伪随机选择的底数进行 Miller-Rabin 检验，并执行一次 Baillie-PSW 检验。

如果 x 是素数，ProbablyPrime 返回 true。如果 x 是随机选择的非素数，ProbablyPrime 很可能返回 false。对于随机选择的非素数，返回 true 的概率至多为 ¼ⁿ。

ProbablyPrime 不适合判断可能由攻击者特意构造、用来欺骗检验的数是否为素数。

从 Go 1.8 起，允许调用 ProbablyPrime(0)，此时仅执行 Baillie-PSW 检验。Go 1.8 之前，ProbablyPrime 只执行 Miller-Rabin 检验，ProbablyPrime(0) 会引发 panic。
