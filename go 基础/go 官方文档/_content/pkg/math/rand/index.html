概览 ▾

rand 包实现适用于模拟等任务的伪随机数生成器，但不应将其用于安全敏感的工作。

随机数由 Source 生成，通常包装在 Rand 中。这两种类型同一时间都应仅由一个 goroutine 使用；多个 goroutine 共享时需要某种同步机制。

顶层函数（例如 Float64 和 Int）可以安全地由多个 goroutine 并发使用。

无论如何设置种子，本包的输出都可能很容易被预测。对于适用于安全敏感工作的随机数，请参阅 crypto/rand 包。

func ExpFloat64() float64

sample = ExpFloat64() / desiredRateParameter

sample = NormFloat64() * desiredStdDev + desiredMean

func Read
				
				1.6
			

			
func Read(p []byte) (n int, err error)

			
Read 从默认 Source 生成 len(p) 个随机字节，并写入 p。它始终返回 len(p) 和 nil 错误。与 Rand.Read 方法不同，Read 可以安全地并发使用。
已弃用：对于几乎所有用例，crypto/rand.Read 都更合适。如果需要确定性的随机源，请使用 math/rand/v2.ChaCha8.Read。
func Seed
				
				
			

			
func Seed(seed int64)

			
Seed 使用给定种子值，将默认 Source 初始化为确定的状态。除以 2³¹-1 后余数相同的种子值，会生成相同的伪随机序列。与 Rand.Seed 方法不同，Seed 可以安全地并发使用。
如果未调用 Seed，生成器会在程序启动时使用随机种子初始化。
在 Go 1.20 之前，生成器在程序启动时的初始化方式相当于 Seed(1)。要强制使用旧行为，请在程序启动时调用 Seed(1)。也可以在调用本包中的任何函数之前，在环境中设置 GODEBUG=randautoseed=0。
已弃用：自 Go 1.20 起，没有必要再以随机值调用 Seed。若程序使用已知值调用 Seed，以获得特定的结果序列，应使用 New(NewSource(seed)) 来取得一个局部随机数生成器。
自 Go 1.24 起，Seed 不再执行任何操作。要恢复先前的行为，请设置 GODEBUG=randseednop=0。

type Source
				
				
			

			
Source 表示一种随机源，可生成在 [0, 1<<63) 范围内均匀分布的伪随机 int64 值。
Source 不能安全地由多个 goroutine 并发使用。
type Source interface {
    Int63() int64
    Seed(seed int64)
}


			

			

			

			
				
func NewSource
					
					
				

				
func NewSource(seed int64) Source

				
NewSource 返回使用给定值作为种子初始化的新伪随机 Source。与顶层函数使用的默认 Source 不同，此随机源不能安全地由多个 goroutine 并发使用。返回的 Source 实现了 Source64。
type Source64
				
				1.8
			

			
Source64 是一种 Source，还能直接生成在 [0, 1<<64) 范围内均匀分布的伪随机 uint64 值。如果 Rand r 的底层 Source s 实现了 Source64，那么 r.Uint64 会返回调用一次 s.Uint64 的结果，而不是调用两次 s.Int63。
type Source64 interface {
    Source
    Uint64() uint64
}

func NewZipf(r *Rand, s float64, v float64, imax uint64) *Zipf

				
NewZipf 返回一个 Zipf 随机变量生成器。它生成 k ∈ [0, imax] 的值，使 P(k) 与 (v + k) ** (-s) 成正比。要求 s > 1 且 v >= 1。
