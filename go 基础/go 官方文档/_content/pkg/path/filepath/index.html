filepath 包提供操作文件名路径的实用函数，其行为与目标操作系统定义的文件路径规则兼容。

filepath 包根据操作系统使用正斜杠或反斜杠。如果要处理 URL 等无论操作系统为何都使用正斜杠的路径，请参阅 path 包。

func Abs 

func Abs(path string) (string, error)

Abs 返回 path 的绝对路径表示。如果 path 不是绝对路径，就将其与当前工作目录拼接，得到绝对路径。不保证同一个文件的绝对路径名是唯一的。Abs 会对结果调用 Clean。

func Base 

func Base(path string) string

Base 返回 path 的最后一个路径元素。提取前会先去掉末尾的路径分隔符。如果 path 为空，返回 "."。如果 path 完全由分隔符组成，返回单个分隔符。

func Clean 

func Clean(path string) string

Clean 仅进行词法处理，返回与 path 等价的最短路径名。它反复应用以下规则，直到无法继续简化：

  1. 将连续多个 Separator 替换为一个。
  2. 删除所有 . 路径元素，即当前目录。
  3. 删除路径内部的每个 .. 元素（父目录），以及它前面不是 .. 的那个路径元素。
  4. 删除从根开始的路径开头的 .. 元素：假设 Separator 为 '/'，即将路径开头的 "/.." 替换为 "/"。

仅当返回路径表示根目录时，末尾才会保留斜杠，例如 Unix 上的 "/" 或 Windows 上的 `C:\`。

最后，将所有正斜杠替换为 Separator。

如果处理结果为空字符串，Clean 返回字符串 "."。

在 Windows 上，除了将 "/" 替换为 `\`，Clean 不会修改卷名。例如，Clean("//host/share/../x") 返回 `\\host\share\x`。

另请参阅 Rob Pike 的论文《Lexical File Names in Plan 9 or Getting Dot-Dot Right》（Plan 9 中的词法文件名：正确处理 ..）：https://9p.io/sys/doc/lexnames.html。

func Dir 

func Dir(path string) string

Dir 返回去掉最后一个路径元素后的 path，通常就是路径对应的目录。去掉最后一个元素后，Dir 会对路径调用 Clean，并移除末尾的斜杠。如果 path 为空，返回 "."。如果 path 完全由分隔符组成，返回单个分隔符。除根目录外，返回的路径不会以分隔符结尾。

在 Windows 上，对于 "C:" 这样的纯卷名，Dir 返回 "C:."，表示 C 盘上的当前目录。要得到该驱动器的根目录 "C:\"，请将 VolumeName 的结果与分隔符组合。

func EvalSymlinks 

func EvalSymlinks(path string) (string, error)

EvalSymlinks 返回解析了所有符号链接之后的路径名。如果 path 是相对路径，结果也相对于当前目录，除非某个路径组件是指向绝对路径的符号链接。EvalSymlinks 会对结果调用 Clean。

func Ext 

func Ext(path string) string

Ext 返回 path 所用的文件扩展名。扩展名是最后一个路径元素中从最后一个点开始的后缀；如果没有点，就返回空字符串。

func FromSlash 

func FromSlash(path string) string

FromSlash 将 path 中的每个正斜杠（'/'）替换为路径分隔符，并返回结果。多个正斜杠会被替换为相同数量的分隔符。

另请参阅 Localize 函数，它将 io/fs 包使用的正斜杠分隔路径转换为操作系统路径。

func Glob 

func Glob(pattern string) (matches []string, err error)

Glob 返回所有与 pattern 匹配的文件名；没有匹配文件时返回 nil。模式语法与 Match 相同。模式可以描述多级路径，例如 /usr/*/bin/ed（假设 Separator 为 '/'）。

Glob 忽略文件系统错误，例如读取目录时的 I/O 错误。唯一可能返回的错误是模式格式不正确时的 ErrBadPattern。

func IsLocal 1.20 

func IsLocal(path string) bool

IsLocal 仅通过词法分析，报告 path 是否同时具有以下所有性质：

  • 位于解析 path 时所依据目录的子树内。
  • 不是绝对路径。
  • 不为空。
  • 在 Windows 上，不是 "NUL" 等保留名称。

如果 IsLocal(path) 返回 true，Join(base, path) 得到的路径就始终位于 base 内，而 Clean(path) 得到的路径始终不从根开始，且不包含 ".." 路径元素。

IsLocal 是纯词法操作。特别是，它不会考虑文件系统中可能存在的符号链接的影响。

func Join 

func Join(elem ...string) string

Join 将任意数量的路径元素拼接为单个路径，使用操作系统特定的 Separator 分隔。空元素会被忽略，结果会经过 Clean 处理。不过，如果参数列表为空，或所有元素都为空，Join 返回空字符串。在 Windows 上，只有第一个非空元素是 UNC 路径时，结果才会是 UNC 路径。

func Localize 1.23 

func Localize(path string) (string, error)

Localize 将正斜杠分隔的路径转换为操作系统路径。输入必须是 io/fs.ValidPath 判定为有效的路径。

如果操作系统无法表示该路径，Localize 返回错误。例如，Windows 上会拒绝路径 a\b，因为 \ 是分隔符，不能作为文件名的一部分。

Localize 返回的路径始终是 IsLocal 判定为本地的路径。

func Match 

func Match(pattern, name string) (matched bool, err error)

Match 报告 name 是否匹配 shell 文件名模式 pattern。模式语法如下： 

pattern:
	{ term }
term:
	'*'         matches any sequence of non-Separator characters
	'?'         matches any single non-Separator character
	'[' [ '^' ] { character-range } ']'
	            character class (must be non-empty)
	c           matches character c (c != '*', '?', '\\', '[')
	'\\' c      matches character c (except on Windows)

character-range:
	c           matches character c (c != '\\', '-', ']')
	'\\' c      matches character c (except on Windows)
	lo '-' hi   matches character c for lo <= c <= hi

模式中的路径段必须由 Separator 分隔。上表中，* 匹配任意长度的非分隔符字符序列，? 匹配一个非分隔符字符；方括号定义非空字符类，可用 ^ 取反。普通字符 c 匹配自身，反斜杠可转义字符（Windows 除外）；lo-hi 匹配满足 lo <= c <= hi 的字符。字符类外的普通字符不能是 *、?、反斜杠或 [；字符范围中的普通字符不能是反斜杠、- 或 ]。

Match 要求 pattern 匹配整个 name，而不只是其子串。唯一可能返回的错误是模式格式不正确时的 ErrBadPattern。

在 Windows 上不支持转义，'\\' 被用作路径分隔符。

func Rel 

func Rel(basePath, targPath string) (string, error)

Rel 返回一个相对路径，将它通过分隔符与 basePath 拼接后，在词法上等价于 targPath。也就是说，Join(basePath, Rel(basePath, targPath)) 与 targPath 本身等价。

即使 basePath 与 targPath 没有共同的路径元素，返回路径也始终相对于 basePath。Rel 会对结果调用 Clean。

如果无法将 targPath 表示为相对于 basePath 的路径，或者计算时必须知道当前工作目录，就返回错误。

func Split(path string) (dir, file string)

func ToSlash(path string) string

ToSlash 将 path 中的每个路径分隔符替换为正斜杠（'/'），并返回结果。多个分隔符会被替换为相同数量的正斜杠。

func VolumeName 

func VolumeName(path string) string

VolumeName 返回路径开头的卷名。在 Windows 上，传入 "C:\foo\bar" 返回 "C:"，传入 "\\host\share\foo" 返回 "\\host\share"。在其他平台上返回 ""。

func Walk 

func Walk(root string, fn WalkFunc) error

Walk 遍历以 root 为根的文件树，对树中的每个文件或目录调用 fn，包括 root 本身。

访问文件和目录时出现的所有错误都由 fn 处理；详见 WalkFunc 文档。

文件按字典序遍历，因此输出具有确定性，但也要求 Walk 在开始遍历一个目录之前，先将该目录的全部条目读入内存。

Walk 不会跟随符号链接。

Walk 的效率低于 Go 1.16 引入的 WalkDir；后者避免了对访问的每个文件或目录都调用 os.Lstat。

func WalkDir 1.16 

func WalkDir(root string, fn fs.WalkDirFunc) error

WalkDir 遍历以 root 为根的文件树，对树中的每个文件或目录调用 fn，包括 root 本身。

访问文件和目录时出现的所有错误都由 fn 处理；详见 fs.WalkDirFunc 文档。

文件按字典序遍历，因此输出具有确定性，但也要求 WalkDir 在开始遍历一个目录之前，先将该目录的全部条目读入内存。

WalkDir 不会跟随符号链接。

WalkDir 调用 fn 时传入的路径采用操作系统对应的分隔符。这与始终使用正斜杠分隔路径的 io/fs.WalkDir 不同。

type WalkFunc

WalkFunc 是 Walk 访问每个文件或目录时调用的函数类型。

path 参数以传给 Walk 的路径为前缀。例如，以 root 参数 "dir" 调用 Walk，并在该目录下找到名为 "a" 的文件时，会将 "dir/a" 作为参数传给遍历函数。

目录和文件名使用 Join 拼接，因此目录名可能被简化：如果 Walk 的 root 参数为 "x/../dir"，并在该目录下找到名为 "a" 的文件，传给遍历函数的参数是 "dir/a"，而不是 "x/../dir/a"。

info 参数是给定路径对应的 fs.FileInfo。

函数返回的错误决定 Walk 如何继续。如果返回特殊值 SkipDir，Walk 会跳过当前目录：info.IsDir() 为 true 时是 path 本身，否则是 path 的父目录。如果返回特殊值 SkipAll，Walk 会跳过剩余所有文件和目录。除此之外，如果函数返回非 nil 错误，Walk 会完全停止，并返回该错误。

err 参数报告与 path 有关的错误，表示 Walk 不会进入该目录。函数可以决定如何处理错误；如前所述，将该错误返回会使 Walk 停止遍历整棵树。

有两种情况下，Walk 会使用非 nil 的 err 参数调用该函数。

第一种情况：对根目录或树中的任何目录、文件调用 os.Lstat 失败。此时，Walk 调用函数，path 为相应目录或文件的路径，info 为 nil，err 为 os.Lstat 返回的错误。

第二种情况：某个目录的 Readdirnames 方法失败。此时，Walk 调用函数，path 为该目录的路径，info 为描述该目录的 fs.FileInfo，err 为 Readdirnames 返回的错误。 

type WalkFunc func(path string, info fs.FileInfo, err error) error
