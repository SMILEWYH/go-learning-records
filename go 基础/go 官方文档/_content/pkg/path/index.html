path 包提供操作斜杠分隔路径的工具函数。

path 包应仅用于以正斜杠分隔的路径，例如 URL 中的路径。本包不处理带盘符或反斜杠的 Windows 路径；要操作操作系统路径，请使用 path/filepath 包。

func Base(path string) string

func Clean 

func Clean(path string) string

Clean 通过纯词法处理，返回与 path 等价的最短路径名。它反复应用以下规则，直到无法继续处理：

  1. 将连续的多个斜杠替换为一个斜杠。
  2. 移除每个 . 路径元素（当前目录）。
  3. 移除每个内部的 .. 路径元素（父目录），以及紧邻其前面的非 .. 元素。
  4. 移除从根开始的路径开头的 .. 元素，也就是将路径开头的 "/.." 替换为 "/"。

返回路径仅在它是根路径 "/" 时才以斜杠结尾。

如果此处理得到空字符串，则 Clean 返回字符串 "."。

另见 Rob Pike 的《Lexical File Names in Plan 9 or Getting Dot-Dot Right》：https://9p.io/sys/doc/lexnames.html。

▸ 示例

▾ 示例

Clean("a/c") = "a/c"
Clean("a//c") = "a/c"
Clean("a/c/.") = "a/c"
Clean("a/c/b/..") = "a/c"
Clean("../a/c") = "../a/c"
Clean("../a/b/../././/c") = "../a/c"
Clean("/../a/c") = "/a/c"
Clean("/../a/b/../././/c") = "/a/c"
Clean("") = "."

func Dir 

func Dir(path string) string

Dir 返回 path 中除最后一个元素之外的部分，通常即路径的目录部分。使用 Split 去掉最后一个元素后，会对路径执行 Clean 并移除末尾斜杠。如果路径为空，Dir 返回 "."。如果路径由一串斜杠后跟若干非斜杠字节组成，Dir 返回单个斜杠。其他情况下，返回路径不以斜杠结尾。

func Match 

func Match(pattern, name string) (matched bool, err error)

Match 报告 name 是否匹配 shell 模式。模式语法如下：

pattern:
	{ term }
term:
	'*'         匹配任意长度的非 / 字符序列
	'?'         匹配任意单个非 / 字符
	'[' [ '^' ] { character-range } ']'
	            字符类（必须非空）
	c           匹配字符 c（c != '*', '?', '\\', '['）
	'\\' c      匹配字符 c

character-range:
	c           匹配字符 c（c != '\\', '-', ']'）
	'\\' c      匹配字符 c
	lo '-' hi   匹配满足 lo <= c <= hi 的字符 c

Match 要求 pattern 匹配整个 name，而不只是其中的子串。唯一可能返回的错误是模式格式有误时的 ErrBadPattern。

func Split 

func Split(path string) (dir, file string)

Split 在 path 的最后一个斜杠之后将其分割为目录和文件名两部分。如果 path 中没有斜杠，Split 返回空 dir，并将 file 设为 path。返回值满足 path = dir+file。

▸ 示例

▾ 示例

path.Split("static/myfile.css") = dir: "static/", file: "myfile.css"
path.Split("myfile.css") = dir: "", file: "myfile.css"
path.Split("") = dir: "", file: ""
