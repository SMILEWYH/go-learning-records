fmt 包提供格式化 I/O，函数与 C 的 printf 和 scanf 类似。格式“动词”源自 C，但规则更简单。

格式化输出

按照输出目标，输出函数分为四组：Print、Println 和 Printf 写入 os.Stdout；Sprint、Sprintln 和 Sprintf 返回字符串；Fprint、Fprintln 和 Fprintf 写入 io.Writer；Append、Appendln 和 Appendf 将输出追加到字节切片。

每组函数的格式化方式由名称后缀决定。Print、Sprint、Fprint 和 Append 对每个参数使用默认格式，仅当相邻两个操作数都不是字符串时，才在它们之间添加空格。Println、Sprintln、Fprintln 和 Appendln 总是在操作数之间添加空格，并在末尾追加换行符。Printf、Sprintf、Fprintf 和 Appendf 则通过一系列格式动词控制输出。

格式动词如下：

通用： 

%v	值的默认格式
	输出结构体时，加号标志（%+v）会额外输出字段名
%#v	值的 Go 语法表示
	（浮点数的无穷值和 NaN 分别输出为 ±Inf 和 NaN）
%T	值的类型的 Go 语法表示
%%	字面量百分号，不消耗任何操作数

布尔值： 

%t	单词 true 或 false

整数： 

%b	二进制
%c	对应 Unicode 码点表示的字符
%d	十进制
%o	八进制
%O	带 0o 前缀的八进制
%q	按 Go 语法安全转义、以单引号包围的 rune 字面量
%x	十六进制，使用小写字母 a-f
%X	十六进制，使用大写字母 A-F
%U	Unicode 格式：U+1234，等同于 "U+%04X"

浮点数，以及复数的实部和虚部： 

%b	尾数不带小数点、指数部分表示 2 的幂的科学计数法，
	与 strconv.FormatFloat 的 'b' 格式相同，
	例如 -123456p-78
%e	科学计数法，例如 -1.234456e+78
%E	科学计数法，例如 -1.234456E+78
%f	带小数点，不带指数，例如 123.456
%F	与 %f 相同
%g	指数较大时使用 %e，否则使用 %f；精度规则见下文
%G	指数较大时使用 %E，否则使用 %F
%x	十六进制表示，指数以十进制书写、以 2 为底，例如 -0x1.23abcp+20
%X	大写的十六进制表示，例如 -0X1.23ABCP+20

指数始终写为十进制整数。
除 %b 外，其他格式的指数至少包含两位数字。

字符串和字节切片（对以下动词，两者的处理方式相同）： 

%s	字符串或切片中未经解释的原始字节
%q	按 Go 语法安全转义、以双引号包围的字符串
%x	小写十六进制，每个字节输出两个字符
%X	大写十六进制，每个字节输出两个字符

切片： 

%p	第 0 个元素的地址，使用带 0x 前缀的十六进制表示

指针： 

%p	带 0x 前缀的十六进制表示
%b、%d、%o、%x 和 %X 也适用于指针，
会将指针值完全按照整数进行格式化。

%v 对各类型使用的默认格式如下： 

bool:                    %t
int, int8 等:            %d
uint, uint8 等:          %d；使用 %#v 输出时为 %#x
float32, complex64 等:   %g
string:                  %s
chan:                    %p
指针:                    %p

对于复合对象，递归地按照这些规则输出各元素，布局如下： 

结构体:             {field0 field1 ...}
数组、切片:         [elem0 elem1 ...]
映射:               map[key1:value1 key2:value2 ...]
指向上述对象的指针: &{}, &[], &map[]

宽度由紧邻动词之前的可选十进制数指定。如果未指定，就使用表示该值所需的宽度。精度位于可选宽度之后，由一个点和后面的十进制数指定。没有点时使用默认精度；有点但后面没有数字时，精度为零。例如： 

%f     默认宽度，默认精度
%9f    宽度 9，默认精度
%.2f   默认宽度，精度 2
%9.2f  宽度 9，精度 2
%9.f   宽度 9，精度 0

宽度和精度以 Unicode 码点（即 rune）为单位，这与始终以字节为单位的 C printf 不同。宽度或精度中的任意一个或两个都可以用字符 '*' 替代，此时相应数值取自下一个操作数，该操作数位于待格式化值之前，且必须为 int 类型。

对大多数值，宽度表示最少输出的 rune 数；不足时会用空格填充格式化结果。

但对于字符串、字节切片和字节数组，精度限制的是待格式化输入的长度，而不是输出的大小，必要时会截断输入。通常以 rune 为单位，但使用 %x 或 %X 格式处理这些类型时，以字节为单位。

对于浮点数，宽度设置输出字段的最小宽度，精度通常设置小数点后的位数；但 %g/%G 的精度设置的是有效数字的最大位数，并会移除末尾的零。例如，对 12.345 使用 %6.3f 会输出 12.345，而 %.3g 会输出 12.3。%e、%f 和 %#g 的默认精度为 6；%g 则采用能唯一确定该值所需的最少数字位数。

对于复数，宽度和精度分别应用于实部和虚部，结果以圆括号包围。因此，对 1.2+3.4i 使用 %f，会得到 (1.200000+3.400000i)。

使用 %q 格式化单个整数码点或 rune 序列（[]rune）时，无效 Unicode 码点会像 strconv.QuoteRune 一样，被替换为 Unicode 替换字符 U+FFFD。

其他标志： 

'+'	对数值始终输出正负号；
	对 %q 保证只输出 ASCII 字符（%+q）
'-'	在右侧而非左侧补空格，即字段左对齐
'#'	使用替代格式：二进制加前缀 0b（%#b），八进制加 0（%#o），
	十六进制加 0x 或 0X（%#x 或 %#X）；对 %p 去掉 0x（%#p）；
	对 %q，如果 [strconv.CanBackquote] 返回 true，
	则输出反引号包围的原始字符串；
	对 %e、%E、%f、%F、%g 和 %G 始终输出小数点；
	对 %g 和 %G 不移除末尾的零；
	对 %U，如果字符可打印，则输出例如 U+0078 'x'（%#U）
' '	空格标志：为数值中省略的正号保留一个空格（% d）；
	以十六进制输出字符串或切片时，在字节之间加空格（% x、% X）
'0'	在前面补零，而不是补空格；
	对数值，填充的零位于正负号之后

不支持某个标志的动词会忽略它。例如，十进制没有替代格式，因此 %#d 与 %d 行为相同。

每个类似 Printf 的函数，都有一个不接收格式字符串的 Print 版本，等价于对每个操作数使用 %v。另一个变体 Println 则在操作数之间插入空格，并在末尾追加换行符。

无论使用哪种动词，如果操作数是接口值，实际格式化的都是其中的具体值，而不是接口本身。因此： 

var i interface{} = 23
fmt.Printf("%v\n", i)

会输出 23。

除使用 %T 和 %p 输出外，对于实现了特定接口的操作数，会按以下顺序应用特殊格式化规则：

1. 如果操作数是 reflect.Value，将其替换为它持有的具体值，再继续应用下一条规则。

2. 如果操作数实现了 Formatter 接口，就调用该接口。此时动词和标志的解释方式由该实现决定。

3. 如果使用带 # 标志的 %v（即 %#v），且操作数实现了 GoStringer 接口，就调用该接口。

如果格式适用于字符串（%s、%q、%x、%X），或格式为 %v 而非 %#v，则应用下面两条规则（Println 等函数隐式使用 %v）：

4. 如果操作数实现了 error 接口，就调用 Error 方法将对象转换为字符串，再按动词要求进行格式化（如果有动词）。

5. 如果操作数实现了 String() string 方法，就调用该方法将对象转换为字符串，再按动词要求进行格式化（如果有动词）。

对于切片、结构体等复合操作数，格式递归地应用于各个元素，而不是整个操作数。因此，%q 会为字符串切片的每个元素加引号，%6.2f 会控制浮点数数组中每个元素的格式。

但使用字符串类动词（%s、%q、%x、%X）输出字节切片时，会将它作为单个整体，按与字符串相同的方式处理。

为避免以下情况发生递归： 

type X string
func (x X) String() string { return Sprintf("<%s>", x) }

应在再次调用格式化函数之前转换值的类型： 

func (x X) String() string { return Sprintf("<%s>", string(x)) }

具有 String 方法的自引用数据结构也可能触发无限递归，例如将自身作为元素的切片。这种异常情况比较少见，本包不提供防护。

输出结构体时，fmt 无法调用未导出字段上的 Error、String 等格式化方法，因此不会调用它们。

显式参数索引

在 Printf、Sprintf、Fprintf 和 Appendf 中，默认情况下各格式动词依次使用调用时传入的参数。不过，在动词前紧接 [n] 可以指定改为格式化第 n 个参数，索引从 1 开始。将同样的写法放在宽度或精度的 '*' 前，可指定提供该数值的参数索引。处理完 [n] 后，后续动词依次使用第 n+1、n+2 等参数，除非再次显式指定。

例如， 

fmt.Sprintf("%[2]d %[1]d\n", 11, 22)

会得到 "22 11"，而 

fmt.Sprintf("%[3]*.[2]*[1]f", 12.0, 2, 6)

等价于 

fmt.Sprintf("%6.2f", 12.0)

会得到 " 12.00"。由于显式索引会影响后续动词，可以通过将索引重置为要重复输出的第一个参数，来多次输出同一组值： 

fmt.Sprintf("%d %d %#[1]x %#x", 16, 17)

会得到 "16 17 0x10 0x11"。

格式错误

如果传给动词的参数无效，例如向 %d 传入字符串，生成的字符串会包含问题说明，如下例所示： 

类型错误或未知动词：%!verb(type=value)
	Printf("%d", "hi"):        %!d(string=hi)
参数过多：%!(EXTRA type=value)
	Printf("hi", "guys"):      hi%!(EXTRA string=guys)
参数过少：%!verb(MISSING)
	Printf("hi%d"):            hi%!d(MISSING)
宽度或精度不是 int：%!(BADWIDTH) 或 %!(BADPREC)
	Printf("%*s", 4.5, "hi"):  %!(BADWIDTH)hi
	Printf("%.*s", 4.5, "hi"): %!(BADPREC)hi
参数索引无效或用法无效：%!(BADINDEX)
	Printf("%*[2]d", 7):       %!d(BADINDEX)
	Printf("%.[2]d", 7):       %!d(BADINDEX)

所有错误都以字符串 "%!" 开头，后面有时会跟一个字符（格式动词），最后是圆括号包围的说明。

如果输出函数调用 Error 或 String 方法时触发了 panic，fmt 包会重新格式化 panic 中的错误消息，并添加标记，说明它经过了 fmt 包。例如，如果 String 方法调用 panic("bad")，最终格式化消息会类似于： 

%!s(PANIC=bad)

%!s 只表示出错时正在使用的格式动词。不过，如果 panic 是由 Error、String 或 GoString 方法的 nil 接收者引起的，则输出不带额外标记的字符串 "<nil>"。

很多涉及字符串格式化的包都会提供类似 Print、Printf 和 Println 的三个函数。例如，log.Print、log.Printf 和 log.Println 会把参数转发给本包中的对应函数。为避免混淆，其他包装函数也应遵循本包建立的命名和行为约定。特别是，不应让同一个函数根据参数个数，在直接输出（如 Print）与格式化输出（如 Printf）之间选择；应分别提供函数。

格式化扫描

另一组对应函数用于扫描格式化文本并取得值。Scan、Scanf 和 Scanln 从 os.Stdin 读取；Fscan、Fscanf 和 Fscanln 从指定的 io.Reader 读取；Sscan、Sscanf 和 Sscanln 从传入的字符串读取。

Scan、Fscan 和 Sscan 将输入中的换行符视为空白。

Scanln、Fscanln 和 Sscanln 在换行符处停止扫描，并要求最后一项之后紧跟换行符或 EOF。

Scanf、Fscanf 和 Sscanf 根据格式字符串解析参数，格式与 Printf 类似。下文中的“空白”指除换行符外的任意 Unicode 空白字符。

在格式字符串中，以 % 开头的动词会消耗并解析输入，其详细规则见下文。格式中除 %、空白和换行符以外的字符，会恰好消耗输入中的同一个字符，且该字符必须存在。格式字符串中，一个换行符及其前面的零个或多个空白，会消耗输入中的零个或多个空白，再匹配一个换行符或输入结束。格式字符串中紧跟换行符的空白，会消耗输入中的零个或多个空白。其他情况下，格式字符串中连续的一个或多个空白，会尽可能多地消耗输入中的空白。除非这段格式空白紧邻换行符，否则它必须至少消耗输入中的一个空白，或遇到输入结束。

空白和换行符的处理与 C 的 scanf 系列不同：在 C 中，换行符与其他空白一视同仁，而且格式字符串中的连续空白即使在输入中找不到可消耗的空白，也不会出错。

动词行为与 Printf 中类似。例如，%x 将整数按十六进制扫描，%v 按该值的默认表示扫描。不支持 Printf 中的 %p、%T 动词以及 #、+ 标志。对于浮点数和复数，所有有效动词（%b、%e、%E、%f、%F、%g、%G、%x、%X 和 %v）都等价，既接受十进制，也接受十六进制表示，例如 "2.3e+7"、"0x4.5p-8"，还接受用于分隔数位的下划线，例如 "3.14159_26535_89793"。

动词处理的输入隐式以空白分隔：除 %c 外，每个动词都会先丢弃剩余输入开头的空白；%s（以及将数据读入字符串的 %v）在第一个空白或换行符处停止消耗输入。

在不指定格式或使用 %v 动词扫描整数时，可以使用常见的进制前缀：0b 表示二进制，0o 和 0 表示八进制，0x 表示十六进制，也允许用下划线分隔数位。

宽度作用于输入文本，但扫描不支持精度语法，只能写 %5f，不能写 %5.2f。如果指定宽度，它在去掉前导空白后生效，限制该动词最多读取的 rune 数。例如， 

Sscanf(" 1234567 ", "%5s%d", &s, &i)

会将 s 设为 "12345"、i 设为 67，而 

Sscanf(" 12 34 567 ", "%5s%d", &s, &i)

会将 s 设为 "12"、i 设为 34。

所有扫描函数都将紧接换行符的回车符视为普通换行的一部分，即 \r\n 与 \n 含义相同。

在所有扫描函数中，如果操作数实现了 Scan 方法，也就是实现了 Scanner 接口，就会使用该方法为此操作数扫描文本。此外，如果成功扫描的参数个数少于传入的参数个数，会返回错误。

所有接收扫描结果的参数都必须是指向基本类型的指针，或者是实现了 Scanner 接口的值。

与 Scanf 和 Fscanf 一样，Sscanf 不必消耗全部输入。无法获知 Sscanf 究竟使用了输入字符串中的多少内容。

注意：Fscan 等函数可能在返回的数据之后额外读取一个字符（rune），因此循环调用扫描函数可能跳过部分输入。通常只有输入值之间没有空白时，这才会成为问题。如果传给 Fscan 的读取器实现了 ReadRune，就会用该方法读取字符。如果还实现了 UnreadRune，则会用它回退额外读取的字符，连续调用时就不会丢失数据。对于没有这些能力的读取器，可以用 bufio.NewReader 包装，为其添加 ReadRune 和 UnreadRune 方法。

type ScanState

ScanState 表示传给自定义扫描器的扫描状态。扫描器可以逐个 rune 扫描，也可以让 ScanState 查找下一个空白分隔的 token。ReadRune 从输入读取下一个 Unicode 码点；在 Scanln、Fscanln 或 Sscanln 中，它会在返回第一个 \n 之后，或读取超出指定宽度时返回 EOF。UnreadRune 使下一次 ReadRune 返回同一个 rune。SkipSpace 跳过输入空白，并按当前扫描操作的规则处理换行符。Token 在 skipSpace 为 true 时先跳过空白，再返回连续满足 f(c) 的码点；f 为 nil 时使用 !unicode.IsSpace(c)，即返回非空白字符，换行符仍按当前操作的规则处理。Token 返回的切片指向共享数据，可能在下一次 Token 调用、以此 ScanState 为输入的 Scan 函数调用，或调用它的 Scan 方法返回时被覆盖。Width 返回宽度及其是否已设置，单位为 Unicode 码点。由于接口已经实现 ReadRune，扫描函数不应调用 Read；有效的 ScanState 实现可以让 Read 始终返回错误。 

type ScanState interface {
    // ReadRune 从输入读取下一个 rune（Unicode 码点）。
    // 如果在 Scanln、Fscanln 或 Sscanln 期间调用，ReadRune()
    // 会在返回第一个 '\n' 之后，或者读取超出
    // 指定宽度时，返回 EOF。
    ReadRune() (r rune, size int, err error)
    // UnreadRune 使下一次 ReadRune 调用返回同一个 rune。
    UnreadRune() error
    // SkipSpace 跳过输入中的空白。换行符会根据当前
    // 执行的操作作相应处理；更多信息请参阅
    // 包文档。
    SkipSpace()
    // 如果 skipSpace 为 true，Token 先跳过输入中的空白，然后返回
    // 满足 f(c) 的连续 Unicode 码点 c。如果 f 为 nil，
    // 则使用 !unicode.IsSpace(c)；也就是说，返回的 token
    // 包含非空白字符。换行符会根据当前执行的操作
    // 作相应处理；更多信息请参阅包文档。
    // 返回的切片指向共享数据；这些数据可能在下次调用 Token、
    // 调用以此 ScanState 作为输入的 Scan 函数，
    // 或者当前 Scan 方法返回时被覆盖。
    Token(skipSpace bool, f func(rune) bool) (token []byte, err error)
    // Width 返回宽度选项的值，以及该选项是否已经设置。
    // 宽度的单位是 Unicode 码点。
    Width() (wid int, ok bool)
    // 由于该接口已经实现 ReadRune，扫描例程不应
    // 调用 Read；合法的 ScanState 实现可以选择
    // 始终从 Read 返回错误。
    Read(buf []byte) (n int, err error)
}

type Scanner interface {

type State

State 表示传给自定义格式化器的输出状态。它提供 io.Writer 接口，以及操作数格式说明中的标志和选项信息。Write 用于写出格式化后的内容；Width 返回宽度及其是否已设置；Precision 返回精度及其是否已设置；Flag 报告字符 c 对应的标志是否已设置。 

type State interface {
    // Write 用于写出待打印的格式化输出。

    Width() (wid int, ok bool)

    Flag(c int) bool
}
