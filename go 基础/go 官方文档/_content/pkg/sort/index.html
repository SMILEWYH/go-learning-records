func Find 1.19 

func Find(n int, cmp func(int) int) (i int, found bool)

Find 使用二分查找，查找并返回 [0, n) 中满足 cmp(i) <= 0 的最小索引 i。如果不存在这样的索引 i，Find 返回 i = n。当 i < n 且 cmp(i) == 0 时，返回值 found 为 true。Find 只会对 [0, n) 范围内的 i 调用 cmp(i)。

为支持二分查找，Find 要求：在该范围的前缀部分 cmp(i) > 0，中间部分 cmp(i) == 0，后缀部分 cmp(i) < 0。（各个子范围都可以为空。）通常可以这样满足此条件：将 cmp(i) 解释为目标值 t 与底层可索引数据结构 x 的第 i 个元素之间的比较；当 t < x[i]、t == x[i]、t > x[i] 时，分别返回小于 0、等于 0、大于 0 的值。

例如，要在已排序、支持随机访问的字符串列表中查找某个字符串：

i, found := sort.Find(x.Len(), func(i int) int {
    return strings.Compare(target, x.At(i))
})
if found {
    fmt.Printf("found %s at entry %d\n", target, i)
} else {
    fmt.Printf("%s not found, would insert at %d", target, i)
}

func Search 

func Search(n int, f func(int) bool) int

Search 使用二分查找，查找并返回 [0, n) 中使 f(i) 为 true 的最小索引 i，前提是在 [0, n) 范围内，f(i) == true 意味着 f(i+1) == true。也就是说，Search 要求 f 在输入范围 [0, n) 的某个前缀部分（可以为空）为 false，随后在剩余部分（也可以为空）为 true；Search 返回第一个使其为 true 的索引。如果不存在这样的索引，Search 返回 n。（注意，“未找到”时的返回值并非 strings.Index 等函数使用的 -1。）Search 只会对 [0, n) 范围内的 i 调用 f(i)。

Search 的常见用途是在数组或切片等已排序且可索引的数据结构中，查找值 x 的索引 i。这时参数 f 通常是一个闭包，它捕获待查找的值，以及该数据结构的索引方式和排序方式。

例如，对于按升序排列的切片 data，调用 Search(len(data), func(i int) bool { return data[i] >= 23 }) 会返回满足 data[i] >= 23 的最小索引 i。如果调用方想知道切片中是否存在 23，还必须单独检查 data[i] == 23。

查找按降序排列的数据时，应使用 <= 运算符代替 >= 运算符。

将上述示例补全后，下面的代码尝试在按升序排列的整数切片 data 中查找值 x：

x := 23
i := sort.Search(len(data), func(i int) bool { return data[i] >= x })
if i < len(data) && data[i] == x {
	// x 位于 data[i]
} else {
	// data 中不存在 x，
	// 但 i 是应插入它的索引。
}

再看一个更有趣的例子：这个程序会猜出你想的数字：

func GuessingGame() {
	var s string
	fmt.Printf("Pick an integer from 0 to 100.\n")
	answer := sort.Search(100, func(i int) bool {
		fmt.Printf("Is your number <= %d? ", i)
		fmt.Scanf("%s", &s)
		return s != "" && s[0] == 'y'
	})
	fmt.Printf("Your number is %d.\n", answer)
}

func Slice 1.8 

func Slice(x any, less func(i, j int) bool)

Slice 根据提供的 less 函数对切片 x 排序。如果 x 不是切片，则会引发 panic。

此排序不保证稳定：相等元素的相对顺序可能与原顺序相反。要进行稳定排序，请使用 SliceStable。

less 函数必须满足与 Interface 类型的 Less 方法相同的要求。

注意：在许多情况下，较新的 slices.SortFunc 函数更易用，运行速度也更快。

func Sort 

func Sort(data Interface)

Sort 按 Less 方法确定的升序对 data 排序。它调用一次 data.Len 来确定 n，并调用 O(n*log(n)) 次 data.Less 和 data.Swap。此排序不保证稳定。

注意：在许多情况下，较新的 slices.SortFunc 函数更易用，运行速度也更快。

func Stable 1.2 

func Stable(data Interface)

Stable 按 Less 方法确定的升序对 data 排序，同时保持相等元素的原始顺序。

它调用一次 data.Len 来确定 n，调用 O(n*log(n)) 次 data.Less，以及 O(n*log(n)*log(n)) 次 data.Swap。

注意：在许多情况下，较新的 slices.SortStableFunc 函数更易用，运行速度也更快。

func (Float64Slice) Less 

func (x Float64Slice) Less(i, j int) bool

Less 按照 sort 的 Interface 要求，报告 x[i] 是否应排在 x[j] 之前。注意，浮点比较本身并不是传递关系：对于非数（NaN）值，它不能给出一致的顺序。此 Less 实现通过以下方式将 NaN 值排在所有其他值之前：

x[i] < x[j] || (math.IsNaN(x[i]) && !math.IsNaN(x[j]))

type Interface

实现了 Interface 的类型可以使用本包中的例程进行排序。这些方法通过整数索引引用底层集合中的元素。

type Interface interface {
    // Len 是集合中的元素数量。
    Len() int

    // Less 报告索引为 i 的元素
    // 是否必须排在索引为 j 的元素之前。
    //
    // 如果 Less(i, j) 和 Less(j, i) 均为 false，
    // 则索引为 i 和 j 的元素被视为相等。
    // Sort 可以在最终结果中以任意顺序放置相等元素，
    // 而 Stable 会保持相等元素在输入中的原始顺序。
    //
    // Less 必须描述严格弱序（[Strict Weak Ordering]）。例如：
    //  - 如果 Less(i, j) 和 Less(j, k) 均为 true，则 Less(i, k) 也必须为 true。
    //  - 如果 Less(i, j) 和 Less(j, k) 均为 false，则 Less(i, k) 也必须为 false。
    //
    // 注意，浮点比较（float32 或 float64 值上的 < 运算符）
    // 在涉及非数（NaN）值时并不构成严格弱序。
    // 浮点值的正确实现请参见 Float64Slice.Less。
    //
    // [Strict Weak Ordering]: https://en.wikipedia.org/wiki/Weak_ordering#Strict_weak_orderings
    Less(i, j int) bool

    // Swap 交换索引为 i 和 j 的元素。
    Swap(i, j int)
}
