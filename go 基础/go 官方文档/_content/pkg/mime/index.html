func AddExtensionType 

func AddExtensionType(ext, typ string) error

AddExtensionType 将扩展名 ext 关联的 MIME 类型设为 typ。扩展名应以点开头，例如 ".html"。

func ExtensionsByType 1.5 

func ExtensionsByType(typ string) ([]string, error)

ExtensionsByType 返回已知与 MIME 类型 typ 关联的扩展名。每个返回的扩展名都以点开头，例如 ".html"。如果 typ 没有关联扩展名，ExtensionsByType 返回 nil 切片。

内建表较小，但在 Unix 上，如果以下一个或多个路径存在本地系统的 MIME-info 数据库或 mime.types 文件，则会用它们补充该表：

/usr/local/share/mime/globs2
/usr/share/mime/globs2
/etc/mime.types
/etc/apache2/mime.types
/etc/apache/mime.types
/etc/httpd/conf/mime.types

在 Windows 上，从注册表提取扩展名。

func FormatMediaType 

func FormatMediaType(t string, param map[string]string) string

FormatMediaType 将媒体类型 t 和参数 param 序列化为符合 RFC 2045 与 RFC 2616 的媒体类型。类型名和参数名会写为小写。如果任何实参导致违反标准，FormatMediaType 返回空字符串。

func ParseMediaType 

func ParseMediaType(v string) (mediatype string, params map[string]string, err error)

ParseMediaType 按照 RFC 1521 解析媒体类型值及所有可选参数。媒体类型是 Content-Type 和 Content-Disposition 首部中的值（RFC 2183）。成功时，ParseMediaType 返回转换为小写且去除首尾空白的媒体类型，以及一个非 nil 映射。如果解析可选参数时发生错误，则返回媒体类型及 ErrInvalidMediaParameter 错误。返回的映射 params 将小写属性名映射到保留大小写的属性值。

▸ 示例

▾ 示例

type: text/html
charset: utf-8

func TypeByExtension 

func TypeByExtension(ext string) string

TypeByExtension 返回与文件扩展名 ext 关联的 MIME 类型。扩展名 ext 应以点开头，例如 ".html"。如果 ext 没有关联类型，TypeByExtension 返回 ""。

查找扩展名时，先区分大小写查找，再忽略大小写查找。

内建表较小，但在 Unix 上，如果以下一个或多个路径存在本地系统的 MIME-info 数据库或 mime.types 文件，则会用它们补充该表：

/usr/local/share/mime/globs2
/usr/share/mime/globs2
/etc/mime.types
/etc/apache2/mime.types
/etc/apache/mime.types
/etc/httpd/conf/mime.types

在 Windows 上，从注册表提取 MIME 类型。

文本类型的 charset 参数默认设为 "utf-8"。

type WordDecoder 1.5

WordDecoder 解码包含 RFC 2047 编码词（encoded-word）的 MIME 首部。

type WordDecoder struct {
    // CharsetReader 如果非 nil，则定义一个生成字符集转换
    // 读取器的函数，将提供的字符集
    // 转换为 UTF-8。
    // 字符集名称始终为小写。默认会处理 utf-8、iso-8859-1 和 us-ascii
    // 字符集。
    // CharsetReader 的结果值中必须有一个非 nil。
    CharsetReader func(charset string, input io.Reader) (io.Reader, error)
}

func (WordEncoder) Encode 1.5 

func (e WordEncoder) Encode(charset, s string) string

Encode 返回 s 的编码词形式。如果 s 为不含特殊字符的 ASCII 字符串，则原样返回。提供的 charset 是 s 的 IANA 字符集名称，不区分大小写。
