func TestFS 1.16 

func TestFS(fsys fs.FS, expected ...string) error

TestFS 测试文件系统实现。它遍历 fsys 中的整个文件树，打开并检查每个文件的行为是否正确。它不跟随符号链接，但如果文件系统实现了 fs.ReadLinkFS，会检查符号链接的 Lstat 值。它还会检查文件系统是否至少包含预期的文件。有一个特殊情况：如果没有列出预期文件，则 fsys 必须为空。否则，fsys 至少必须包含列出的文件，也可以包含其他文件。不得在 TestFS 执行期间并发修改 fsys 的内容。

如果 TestFS 发现任何不正确的行为，它会返回第一个错误或一个错误列表。可使用 errors.Is 或 errors.AsType 检查。

测试中的典型用法如下：

if err := fstest.TestFS(myFS, "file/that/should/be/present"); err != nil {
	t.Fatal(err)
}

type MapFS 1.16

MapFS 是一个用于测试的简单内存文件系统，以映射表示：键是路径名（Open 的实参），值是该路径所表示的文件、目录或符号链接的信息。

映射无须包含其中各文件的父目录；必要时会自动合成这些目录。不过，仍可以通过设置 MapFile.Mode 的 fs.ModeDir 位来显式包含目录；这可能是精确控制目录的 fs.FileInfo 或创建空目录所必需的。

文件系统操作直接读取映射，因此可以按需编辑映射来改变文件系统。这意味着文件系统操作不得与映射修改并发执行，否则会发生竞态。另一方面，打开或读取目录需要遍历整个映射，因此 MapFS 通常应用于条目数或目录读取次数不超过几百的场景。

func (MapFS) Lstat 1.25 

func (fsys MapFS) Lstat(name string) (fs.FileInfo, error)

Lstat 返回描述指定文件的 FileInfo。如果该文件是符号链接，返回的 FileInfo 描述该符号链接本身。Lstat 不会尝试跟随链接。

type MapFile 1.16

MapFile 描述 MapFS 中的单个文件。

type MapFile struct {
    Data    []byte      // 文件内容或符号链接目标
    Mode    fs.FileMode // fs.FileInfo.Mode
    ModTime time.Time   // fs.FileInfo.ModTime
    Sys     any         // fs.FileInfo.Sys
}
