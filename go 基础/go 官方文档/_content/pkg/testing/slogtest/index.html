func Run(t *testing.T, newHandler func(*testing.T) slog.Handler, result func(*testing.T) map[string]any)

			
Run 使用与 TestHandler 相同的测试用例测试 slog.Handler，但将每个用例放在子测试中运行。对于每个用例，它先调用 newHandler 获取被测处理器实例，再运行测试用例，最后调用 result 获取结果。如果用例失败，则调用 t.Error。
func TestHandler
				
				1.21
			

			
func TestHandler(h slog.Handler, results func() []map[string]any) error

			
TestHandler 测试 slog.Handler。如果发现任何不正确的行为，它会为每个问题返回一个错误，并通过 errors.Join 合并为单个错误。
TestHandler 将给定 Handler 安装到一个 slog.Logger 中，并多次调用该 Logger 的输出方法。Handler 应启用 Info 及以上级别。
所有这些调用完成后，会调用 results 函数。它应返回 map[string]any 的切片，每个元素对应一次 Logger 输出方法调用。映射的键和值应与 Handler 输出中的键和值对应。输出中的每个组都应表示为各自嵌套的 map[string]any。应使用标准键 slog.TimeKey、slog.LevelKey 和 slog.MessageKey。
如果 Handler 输出 JSON，则以 `map[string]any` 调用 encoding/json.Unmarshal 会创建正确的数据结构。
如果 Handler 有意丢弃某个测试会检查的属性，则 results 函数应检查该属性确实缺失，并将其添加到返回的映射中。
