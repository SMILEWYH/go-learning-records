func ClearCounters 1.20 

func ClearCounters() error

ClearCounters 清除或重置当前运行程序中的所有覆盖率计数器变量。如果程序构建时未使用“-cover”标志，则返回错误。不使用原子计数器模式的程序也不支持清除覆盖率计数器；原因见下方更详细的注释。

func WriteCounters 1.20 

func WriteCounters(w io.Writer) error

WriteCounters 将当前运行程序的覆盖率计数器数据写入写入器 w。如果无法成功完成操作，例如当前程序构建时未使用“-cover”，或者写入失败，则返回错误。写出的计数器数据是在调用时取得的快照。

func WriteCountersDir 1.20 

func WriteCountersDir(dir string) error

WriteCountersDir 将当前运行程序的覆盖率计数器数据文件写入 dir 指定的目录。如果无法成功完成操作，例如当前程序构建时未使用“-cover”，或者目录不存在，则返回错误。写出的计数器数据是在调用时取得的快照。

func WriteMeta 1.20 

func WriteMeta(w io.Writer) error

WriteMeta 将当前运行程序的元数据内容（通常写入元数据文件的有效载荷）写入写入器 w。如果无法成功完成操作，例如当前程序构建时未使用“-cover”，或者写入失败，则返回错误。

func WriteMetaDir 1.20 

func WriteMetaDir(dir string) error

WriteMetaDir 将当前运行程序的覆盖率元数据文件写入 dir 指定的目录。如果无法成功完成操作，例如当前程序构建时未使用“-cover”，或者目录不存在，则返回错误。
