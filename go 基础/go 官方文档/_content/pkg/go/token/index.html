type File

File 是属于某个 FileSet 的文件句柄。File 包含名称、大小和行偏移表。

使用 FileSet.AddFile 创建 File。一个 File 可以属于多个 FileSet；参见 FileSet.AddExistingFiles。

type FileSet

FileSet 表示一组源文件。文件集的方法会进行同步；多个 goroutine 可以并发调用它们。

文件集中每个文件的字节偏移量会映射到互不相交的整数区间，每个文件对应一个区间 [base, base+size]。FileSet.Base 表示文件的第一个字节，size 是相应的文件大小。Pos 值是此类区间内的值。通过确定 Pos 值所属的区间，可以计算出文件、文件基准偏移量，进而计算该 Pos 值所表示的字节偏移量（位置）。

添加新文件时，必须提供文件基准偏移量。它可以是大于文件集中所有已有文件的任何区间终点的任意整数。为方便使用，FileSet.Base 提供了这样的值，即最近添加文件的 Pos 区间终点加一。除非需要稍后扩展某个区间，否则应使用 FileSet.Base 作为 FileSet.AddFile 的参数。

当不再需要某个 File 时，可以将它从 FileSet 中移除。这可以减少长期运行应用程序的内存占用。

    // 包含已过滤或未导出的字段
}

AddExistingFiles 将指定文件添加到 FileSet 中，但已存在的文件不会重复添加。调用方必须确保最终 FileSet 中任意两个 File 的位置区间都不重叠。

func (*FileSet) AddFile 

func (s *FileSet) AddFile(filename string, base, size int) *File

AddFile 根据给定的文件名、基准偏移量和文件大小，将新文件添加到文件集 s，并返回该文件。多个文件可以同名。基准偏移量不能小于 FileSet.Base，size 不能为负数。特殊情况下，如果提供负数 base，则改用 FileSet.Base 的当前值。

添加文件会将文件集的 FileSet.Base 设置为 base + size + 1，作为下一个文件的最小基准偏移量。给定文件偏移量 offs 与其 Pos 值 p 之间有如下关系：

int(p) = base + offs

其中 offs 位于区间 [0, size]，因此 p 位于区间 [base, base+size]。为方便使用，可以通过 File.Pos 根据文件偏移量创建该文件特定的位置值。

type Pos

Pos 是文件集内源代码位置的紧凑编码。它可以转换为 Position，后者使用更方便，但占用的空间大得多。

给定文件的 Pos 值是区间 [base, base+size] 中的数字，其中 base 和 size 在将文件加入文件集时指定。Pos 值与相应文件基准偏移量之差，对应该位置相对于文件起点的字节偏移量。因此，文件基准偏移量就是表示文件第一个字节的 Pos 值。

要为特定源代码偏移量（以字节计）创建 Pos 值，应先使用 FileSet.AddFile 将相应文件加入当前文件集，然后对该文件调用 File.Pos(offset)。给定特定文件集 fset 中的 Pos 值 p，可以通过调用 fset.Position(p) 获得对应的 Position 值。

Pos 值可以直接使用通常的比较运算符进行比较：如果两个 Pos 值 p 和 q 位于同一文件中，比较 p 和 q 等价于比较相应的源文件偏移量。如果 p 和 q 位于不同文件中，那么当 p 对应的文件比 q 对应的文件更早加入相应文件集时，p < q 为 true。

type Pos int

Pos 的零值是 NoPos；它不关联任何文件和行信息，且 NoPos.IsValid() 为 false。NoPos 始终小于任何其他 Pos 值。NoPos 对应的 Position 值是 Position 的零值。

const NoPos Pos = 0

type Position

Position 描述任意源代码位置，包括文件、行和列。如果行号 > 0，则 Position 有效。

type Position struct {
    Filename string // 文件名（如果有）
    Offset   int    // 偏移量，从 0 开始
    Line     int    // 行号，从 1 开始
    Column   int    // 列号，从 1 开始（按字节计数）
}
