parser 包实现 Go 源文件的语法分析器。

ParseFile 函数从 string、[]byte 或 io.Reader 读取文件输入，生成表示整个文件抽象语法树的 ast.File。

ParseExprFrom 函数读取一个源代码层面的表达式，生成该表达式的语法树 ast.Expr。

为简化实现，并提高存在语法错误时的健壮性，分析器接受的语法范围比 Go 语言规范所允许的更宽。例如，方法声明中的接收者按普通参数列表处理，因此可以包含多个条目，而规范只允许一个。因此，AST 中对应的字段 ast.FuncDecl.Recv 也不限制为一个条目。

需要解析一个或多个完整 Go 源代码包的应用，可能更适合使用 golang.org/x/tools/go/packages 包中的 Load 函数，而非直接调用语法分析器。

func ParseDir 

func ParseDir(fset *token.FileSet, path string, filter func(fs.FileInfo) bool, mode Mode) (pkgs map[string]*ast.Package, first error)

ParseDir 对 path 指定目录下所有名称以“.go”结尾的文件调用 ParseFile，返回一个包含所有找到的包的映射：包名 -> 包 AST。

如果 filter != nil，则只处理 fs.FileInfo 条目通过过滤器且名称以“.go”结尾的文件。mode 位原样传给 ParseFile。位置信息记录在 fset 中，fset 不能为 nil。

如果目录无法读取，则返回 nil 映射及相应错误。如果发生解析错误，则返回非 nil 但不完整的映射，以及遇到的第一个错误。

已弃用：ParseDir 将文件归入包时不考虑构建标签。如需准确了解包和文件的对应关系，请使用 golang.org/x/tools/go/packages；它还可以按需解析文件并进行类型检查。

func ParseExprFrom 1.5 

func ParseExprFrom(fset *token.FileSet, filename string, src any, mode Mode) (expr ast.Expr, err error)

ParseExprFrom 是解析表达式的便捷函数。实参的含义与 ParseFile 相同，但源代码必须是有效的 Go 类型表达式或值表达式。特别是，fset 不能为 nil。

如果源代码无法读取，则返回 nil AST，并通过错误说明具体原因。如果源代码成功读取但发现语法错误，则返回部分 AST，使用 ast.Bad* 节点表示有错误的源代码片段。多个错误通过按源代码位置排序的 scanner.ErrorList 返回。

func ParseFile 

func ParseFile(fset *token.FileSet, filename string, src any, mode Mode) (f *ast.File, err error)

ParseFile 解析单个 Go 源文件的代码，返回对应的 ast.File 节点。可以通过源文件名提供源代码，也可以通过 src 参数提供。

如果 src != nil，ParseFile 从 src 解析源代码，filename 仅用于记录位置信息。src 参数的实参类型必须为 string、[]byte 或 io.Reader。如果 src == nil，则解析 filename 指定的文件。

mode 参数控制解析的源文本范围及其他可选功能。如果设置了 SkipObjectResolution 模式位（推荐），则跳过解析中的对象解析阶段，使 File.Scope、File.Unresolved 及所有 Ident.Obj 字段均为 nil。这些字段已弃用，详情见 ast.Object。

位置信息记录在文件集 fset 中，fset 不能为 nil。

如果源代码无法读取，则返回 nil AST，并通过错误说明具体原因。如果源代码成功读取但发现语法错误，则返回部分 AST，使用 ast.Bad* 节点表示有错误的源代码片段。多个错误通过按源代码位置排序的 scanner.ErrorList 返回。

type Mode

Mode 值是一组标志（也可以为 0），用于控制解析的源代码范围及其他可选的分析器功能。

type Mode uint
const (
    PackageClauseOnly    Mode             = 1 << iota // 解析完 package 子句后停止
    ImportsOnly                                       // 解析完导入声明后停止
    ParseComments                                     // 解析注释并将其加入 AST
    Trace                                             // 打印所解析语法产生式的跟踪信息
    DeclarationErrors                                 // 报告声明错误
    SpuriousErrors                                    // 与 AllErrors 相同，用于向后兼容
    SkipObjectResolution                              // 跳过已弃用的标识符解析；见 ParseFile
    AllErrors            = SpuriousErrors             // 报告全部错误，而不只是在不同行中出现的前 10 个错误
)
