comment 包实现 Go 文档注释的解析和重新格式化。文档注释是紧挨在 package、const、func、type 或 var 顶层声明之前的注释。

Go 文档注释语法是 Markdown 的简化子集，支持链接、标题、段落、列表（不支持嵌套）以及预格式化文本块。语法详情见 https://go.dev/doc/comment。

要解析文档注释对应的文本（去除注释标记后），请使用 Parser：

var p comment.Parser
doc := p.Parse(text)

结果是一个 *Doc。要将其重新格式化为文档注释、HTML、Markdown 或纯文本，请使用 Printer：

var pr comment.Printer
os.Stdout.Write(pr.Text(doc))

Parser 和 Printer 类型都是结构体，可以修改其字段来自定义操作。详情请参阅这些类型的文档。

如果用例需要更精细地控制重新格式化过程，可以直接检查解析后的语法并实现自己的逻辑。有关概览及其他类型的链接，请参阅 Doc、Block 和 Text 的文档。

func DefaultLookupPackage 1.19 

func DefaultLookupPackage(name string) (importPath string, ok bool)

DefaultLookupPackage 是默认的包查找函数，在 Parser.LookupPackage 为 nil 时使用。它能够识别导入路径只有一个元素的标准库包名，例如 math；否则这些包将无法用名称引用。

注意，go/doc 包提供了更完善的查找方式，它会依据当前包所使用的导入进行查找。

type DocLink 1.19

DocLink 是指向 Go 包或符号文档的链接。

type DocLink struct {
    Text []Text // 链接文本

    // ImportPath、Recv 和 Name 标识作为链接目标的
    // Go 包或符号。非空字段
    // 可能存在以下组合：
    //  - ImportPath：链接到另一个包
    //  - ImportPath、Name：链接到另一个包中的 const、func、type 或 var
    //  - ImportPath、Recv、Name：链接到另一个包中的方法
    //  - Name：链接到当前包中的 const、func、type 或 var
    //  - Recv、Name：链接到当前包中的方法
    ImportPath string // 导入路径
    Recv       string // 方法的接收者类型，不包含指针星号
    Name       string // const、func、type、var 或方法的名称
}

func (*DocLink) DefaultURL 1.19 

func (l *DocLink) DefaultURL(baseURL string) string

DefaultURL 构造并返回 l 的文档 URL，并将 baseURL 用作指向其他包的链接前缀。

DefaultURL 可能返回以下形式：

  • baseURL/ImportPath：链接到另一个包
  • baseURL/ImportPath#Name：链接到另一个包中的 const、func、type 或 var
  • baseURL/ImportPath#Recv.Name：链接到另一个包中的方法
  • #Name：链接到当前包中的 const、func、type 或 var
  • #Recv.Name：链接到当前包中的方法

如果 baseURL 以斜杠结尾，那么对于带锚点的形式，DefaultURL 会在 ImportPath 和 # 之间插入斜杠。例如，以下是一些 baseURL 值及其可以生成的 URL：

"/pkg/" → "/pkg/math/#Sqrt"
"/pkg"  → "/pkg/math#Sqrt"
"/"     → "/math/#Sqrt"
""      → "/math#Sqrt"

func (*Heading) DefaultID 1.19 

func (h *Heading) DefaultID() string

DefaultID 返回标题 h 的默认锚点 ID。

默认锚点 ID 的构造方式为：将每个非 ASCII 字母或数字的 rune 转换成下划线，再添加前缀“hdr-”。例如，如果标题文本为“Go Doc Comments”，默认 ID 就是“hdr-Go_Doc_Comments”。

type List 1.19

List 是一个有序列表或无序列表。列表始终非空：len(Items) > 0。在有序列表中，每个 Items[i].Number 都是非空字符串。在无序列表中，每个 Items[i].Number 都是空字符串。

type List struct {
    // Items 是列表项。
    Items []*ListItem

    // ForceBlankBefore 表示重新格式化注释时，
    // 列表之前必须有一个空行，
    // 从而覆盖通常的条件。参见 BlankBefore 方法。
    //
    // 对于前面有空行的任意列表，注释解析器
    // 都会设置 ForceBlankBefore，确保
    // 输出时保留该空行。
    ForceBlankBefore bool

    // ForceBlankBetween 表示重新格式化注释时，
    // 列表项之间必须以空行分隔，
    // 从而覆盖通常的条件。参见 BlankBetween 方法。
    //
    // 对于任意两个列表项之间有空行的列表，
    // 注释解析器都会设置 ForceBlankBetween，确保
    // 输出时保留这些空行。
    ForceBlankBetween bool
}

func (*List) BlankBefore 1.19 

func (l *List) BlankBefore() bool

BlankBefore 报告重新格式化注释时，是否应在列表前包含空行。默认规则与 [BlankBetween] 相同：如果列表项内容中含有任何空行（意味着至少一项有多个段落），那么列表本身前面必须有空行。可以设置 List.ForceBlankBefore 来强制在前面添加空行。

func (*List) BlankBetween 1.19 

func (l *List) BlankBetween() bool

BlankBetween 报告重新格式化注释时，是否应在每两个列表项之间包含空行。默认规则是：如果列表项内容中含有任何空行（意味着至少一项有多个段落），那么列表项之间也必须以空行分隔。可以设置 List.ForceBlankBetween 来强制用空行分隔。

type Parser 1.19

Parser 是文档注释解析器。可以在调用 Parser.Parse 之前设置结构体中的字段，以自定义解析过程的细节。

type Parser struct {
    // Words 是 Go 标识符单词的映射，
    // 这些单词应显示为斜体，并且可能附带链接。
    // 如果 Words[w] 为空字符串，则单词 w
    // 仅显示为斜体。否则，会为它创建链接，
    // 以 Words[w] 作为链接目标。
    // Words 对应 [go/doc.ToHTML] 的 words 参数。
    Words map[string]string

    // LookupPackage 将包名解析为导入路径。
    //
    // 如果 LookupPackage(name) 返回 ok == true，则 [name]
    // （或 [name.Sym] 或 [name.Sym.Method]）
    // 会被视为指向 importPath 对应包文档的文档链接。
    // 可以返回 "", true，此时 name 被视为
    // 引用当前包。
    //
    // 如果 LookupPackage(name) 返回 ok == false，
    // 则 [name]（或 [name.Sym] 或 [name.Sym.Method]）
    // 不会被视为文档链接，
    // 但 name 是标准库包的完整（且仅含一个元素的）导入路径时除外，
    // 例如 [math] 或 [io.Reader]。
    // 对于这些名称，仍会调用 LookupPackage，
    // 以便允许引用所导入的其他包，
    // 即使这些包具有相同的包名。
    //
    // 将 LookupPackage 设为 nil，等价于将它设置为
    // 始终返回 "", false 的函数。
    LookupPackage func(name string) (importPath string, ok bool)

    // LookupSym 报告某个符号名或方法名
    // 是否存在于当前包中。
    //
    // 如果 LookupSym("", "Name") 返回 true，则 [Name]
    // 被视为指向 const、func、type 或 var 的文档链接。
    //
    // 类似地，如果 LookupSym("Recv", "Name") 返回 true，
    // 则 [Recv.Name] 被视为指向
    // 类型 Recv 的 Name 方法的文档链接。
    //
    // 将 LookupSym 设为 nil，等价于将它设置为
    // 始终返回 false 的函数。
    LookupSym func(recv, name string) (ok bool)
}

type Printer 1.19

Printer 是文档注释格式化器。可以在调用任意输出方法之前设置结构体中的字段，以自定义格式化过程的细节。

type Printer struct {
    // HeadingLevel 是用于 HTML 和 Markdown
    // 标题的嵌套级别。
    // 如果 HeadingLevel 为零，则默认为 3 级，
    // 即使用 <h3> 和 ###。
    HeadingLevel int

    // HeadingID 是用于计算标题 ID（锚点标签）的函数，
    // 生成 HTML 和 Markdown 时，会为标题 h
    // 调用它。如果 HeadingID 返回空字符串，
    // 则省略标题 ID。
    // 如果 HeadingID 为 nil，则使用 h.DefaultID。
    HeadingID func(h *Heading) string

    // DocLinkURL 是计算给定 DocLink 的 URL 的函数。
    // 如果 DocLinkURL 为 nil，则使用 link.DefaultURL(p.DocLinkBaseURL)。
    DocLinkURL func(link *DocLink) string

    // 当 DocLinkURL 为 nil 时，使用 DocLinkBaseURL，
    // 将它传给 [DocLink.DefaultURL] 来构造 DocLink 的 URL。
    // 详情请参阅该方法的文档。
    DocLinkBaseURL string

    // TextPrefix 是通过 Text 方法生成文本输出时，
    // 在每行开头输出的前缀。
    TextPrefix string

    // TextCodePrefix 是生成文本输出时，在每个
    // 预格式化行（代码块行）开头输出的前缀，
    // 它会替换 TextPrefix，而不是追加到 TextPrefix 后面。
    // 如果 TextCodePrefix 为空字符串，则默认为 TextPrefix+"\t"。
    TextCodePrefix string

    // TextWidth 是生成文本行的最大宽度，
    // 以 Unicode 码点数衡量，
    // 不包括 TextPrefix 和换行符。
    // 如果 TextWidth 为零，则默认为 80 减去 TextPrefix 中的码点数。
    // 如果 TextWidth 为负数，则不限制宽度。
    TextWidth int
}
