constant 包实现用于表示 Go 无类型常量的 Value 及其相应操作。

如果因错误而无法确定某个值，可以使用特殊的 Unknown 值。除非另有说明，对未知值的操作会产生未知值。

func Float32Val 1.5 

func Float32Val(x Value) (float32, bool)

Float32Val 与 Float64Val 类似，但针对 float32 而非 float64。

func Float64Val 1.5 

func Float64Val(x Value) (float64, bool)

Float64Val 返回最接近 x 的 Go float64 值，以及结果是否精确；x 必须是数值或 Unknown，但不能是 Complex。对于小到无法表示为 float64 的值（过于接近 0），Float64Val 会静默下溢为 0。结果的符号始终与 x 的符号相同，即使结果为 0 也如此。如果 x 为 Unknown，结果为 (0, false)。

func Int64Val 1.5 

func Int64Val(x Value) (int64, bool)

Int64Val 返回 x 对应的 Go int64 值，以及结果是否精确；x 必须为 Int 或 Unknown。如果结果不精确，其值未定义。如果 x 为 Unknown，结果为 (0, false)。

func Sign 1.5 

func Sign(x Value) int

Sign 根据 x < 0、x == 0 或 x > 0 分别返回 -1、0 或 1；x 必须是数值或 Unknown。对于复数 x，如果 x == 0，符号为 0，否则符号 != 0。如果 x 为 Unknown，结果为 1。

func Val 1.13 

func Val(x Value) any

Val 返回给定常量的底层值。由于返回值是接口，调用方需要通过类型断言将结果转换为预期的类型。可能返回的动态类型如下：

x 的 Kind          结果的类型
-----------------------------------------
Bool               bool
String             string
Int                int64 或 *big.Int
Float              *big.Float 或 *big.Rat
其他所有种类       nil

type Kind 1.5

Kind 指定 Value 所表示值的种类。

type Kind int
const (
    // 未知值
    Unknown Kind = iota

    // 非数值
    Bool
    String

    // 数值
    Int
    Float
    Complex
)

func (Kind) String 1.18 

func (i Kind) String() string

type Value 1.5

Value 表示一个 Go 常量的值。

type Value interface {
    // Kind 返回值的种类。
    Kind() Kind

    // String 返回值的简短形式，带引号且便于人类阅读。
    // 对于数值，结果可能是近似值；
    // 对于 String 值，结果可能是缩短后的字符串。
    // 要获得精确表示值的字符串，请使用 ExactString。
    String() string

    // ExactString 返回值的精确形式，带引号且便于人类阅读。
    // 如果 Value 的 Kind 为 String，请使用 StringVal 获取不带引号的字符串。
    ExactString() string
    // 包含已过滤或未导出的方法
}

func BinaryOp 1.5 

func BinaryOp(x_ Value, op token.Token, y_ Value) Value

BinaryOp 返回二元表达式 x op y 的结果。该运算必须对这些操作数有定义。如果其中一个操作数为 Unknown，结果为 Unknown。BinaryOp 不处理比较或移位；请改用 Compare 或 Shift。

要强制对 Int 操作数进行整数除法，应使用 op == token.QUO_ASSIGN，而非 token.QUO；在这种情况下，保证结果为 Int。除以零会引发运行时 panic。

func Num 1.5 

func Num(x Value) Value

Num 返回 x 的分子；x 必须为 Int、Float 或 Unknown。如果 x 为 Unknown，或者大到或小到无法表示为分数，结果为 Unknown。否则，结果是一个符号与 x 相同的 Int。

func Real(x Value) Value

func Shift 1.5 

func Shift(x Value, op token.Token, s uint) Value

Shift 返回移位表达式 x op s 的结果，其中 op == token.SHL 或 token.SHR（<< 或 >>）。x 必须为 Int 或 Unknown。如果 x 为 Unknown，结果为 x。

func ToInt 1.6

func UnaryOp 1.5 

func UnaryOp(op token.Token, y Value, prec uint) Value

UnaryOp 返回一元表达式 op y 的结果。该运算必须对该操作数有定义。如果 prec > 0，则指定 ^（异或）运算结果的位数。如果 y 为 Unknown，结果为 Unknown。
