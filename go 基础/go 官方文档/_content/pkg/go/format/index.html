format 包实现 Go 源代码的标准格式化。

Go 源代码的格式化规则会随时间变化。因此，依赖一致格式的工具应执行特定版本的 gofmt 二进制程序，而不是使用本包。这样既能保持格式稳定，也不必在 gofmt 每次变化时重新编译工具。

例如，直接使用本包的提交前检查，会因各开发者使用的 Go 版本不同而表现不同，导致检查本身不可靠。

func Node(dst io.Writer, fset *token.FileSet, node any) error

Node 按规范的 gofmt 风格格式化 node，并将结果写入 dst。

node 的类型必须是 *ast.File、*printer.CommentedNode、[]ast.Decl、[]ast.Stmt，或可赋值给 ast.Expr、ast.Decl、ast.Spec 或 ast.Stmt。Node 不会修改 node。对于表示部分源文件的节点，不会排序导入声明，例如节点既不是 *ast.File，也不是包装了 *ast.File 的 *printer.CommentedNode 时。

此函数可能在全部结果写出之前提前返回，并报告格式化错误，例如 AST 不正确时。

func Source(src []byte) ([]byte, error)

Source 按规范的 gofmt 风格格式化 src，并返回结果或 I/O／语法错误。src 应当是语法正确的 Go 源文件，或一组 Go 声明或语句。

如果 src 只是部分源文件，结果会保留 src 开头和结尾的空白，并使用与 src 中第一个包含代码的行相同的缩进量。对于部分源文件，不会排序导入声明。
