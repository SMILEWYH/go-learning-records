type Color

Color 可以将自身转换为每通道 16 位、经过 alpha 预乘的 RGBA。该转换可能有损。

type Color interface {
    // RGBA 返回该颜色经过 alpha 预乘的红、绿、蓝和 alpha 值。
    // 各值的范围均为 [0, 0xffff]，但使用 uint32 表示，
    // 以便与最大为 0xffff 的混合因子相乘时
    // 不会溢出。
    //
    // 经过 alpha 预乘的颜色分量 c 已按 alpha（a）缩放，
    // 因此有效值满足 0 <= c <= a。
    RGBA() (r, g, b, a uint32)
}

type YCbCr

YCbCr 表示完全不透明的 24 位 Y'CbCr 颜色，一个亮度信号分量和两个色度分量各占 8 位。

JPEG、VP8、MPEG 系列以及其他编解码器使用此颜色模型。这些编解码器常混用 YUV 和 Y'CbCr 两个术语，但严格而言，YUV 仅适用于模拟视频信号，而 Y'（luma，亮度信号）是对 Y（luminance，亮度）应用伽马校正后的结果。

RGB 与 Y'CbCr 之间的转换有损，并且两者间有多种略有不同的转换公式。本包遵循 JFIF 规范：https://www.w3.org/Graphics/JPEG/jfif3.pdf。

type YCbCr struct {

}
