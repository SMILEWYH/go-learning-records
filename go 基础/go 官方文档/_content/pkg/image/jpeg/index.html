func DecodeConfig 

func DecodeConfig(r io.Reader) (image.Config, error)

DecodeConfig 返回 JPEG 图像的颜色模型和尺寸，而不解码整个图像。

func Encode 

func Encode(w io.Writer, m image.Image, o *Options) error

Encode 使用给定选项，以 JPEG 4:2:0 基线格式将图像 m 写入 w。如果传入 nil 的 *Options，则使用默认参数。

type Options

Options 表示编码参数。Quality 的范围为 1 到 100（含两端），值越高质量越好。

type Options struct {
    Quality int
}

type Reader

已弃用：image/jpeg 包不使用 Reader，其他代码也不应使用它。保留此类型是为了兼容性。

type Reader interface {
    io.ByteReader
    io.Reader
}
