image 包实现基本的二维图像库。

核心接口名为 Image。Image 包含颜色，其定义见 image/color 包。

可以调用 NewRGBA、NewPaletted 等函数创建 Image 接口值，也可以对包含 GIF、JPEG 或 PNG 等格式图像数据的 io.Reader 调用 Decode。解码某种图像格式之前，必须先注册解码函数。注册通常作为对应格式包初始化的副作用自动完成，因此要解码 PNG 图像，只需在程序的 main 包中加入

import _ "image/png"

即可。_ 表示仅为执行包初始化的副作用而导入该包。

更多信息参见“Go 的 image 包”：https://golang.org/doc/articles/image_package.html

安全注意事项

image 包可以解析任意大的图像，如果机器内存不足以存储图像，可能导致资源耗尽。处理任意图像时，应先调用 DecodeConfig，再调用 Decode，让程序根据返回的图像头判断能否使用现有资源安全解码该图像。如果 Decode 产生极大的图像，而其大小与 DecodeConfig 返回的图像头一致，无论图像本身是否格式错误，都不视为安全问题。如果 DecodeConfig 返回的图像头与 Decode 返回的图像不一致，则可能被视为安全问题，应按 Go 安全政策报告。

func RegisterFormat
				
				
			

			
func RegisterFormat(name, magic string, decode func(io.Reader) (Image, error), decodeConfig func(io.Reader) (Config, error))

			
RegisterFormat 注册图像格式，供 Decode 使用。name 是格式名称，例如 "jpeg" 或 "png"。magic 是标识该格式编码的魔数前缀。魔数字符串可以包含 "?" 通配符，每个通配符匹配任意一个字节。Decode 是解码图像数据的函数。DecodeConfig 是仅解码其配置信息的函数。
type Alpha
				
				
			

			
Alpha 是内存图像，其 At 方法返回 color.Alpha 值。
type Alpha struct {
    // Pix 以 alpha 值保存图像像素。位于
    // (x, y) 的像素从 Pix[(y-Rect.Min.Y)*Stride + (x-Rect.Min.X)*1] 开始。
    Pix []uint8
    // Stride 是垂直相邻像素在 Pix 中的步长（字节数）。
    Stride int
    // Rect 是图像的边界。
    Rect Rectangle
}

func DecodeConfig

type YCbCr
				
				
			

			
YCbCr 是采用 Y′CbCr 颜色的内存图像。每个像素有一个 Y 样本，但每个 Cb 和 Cr 样本可以覆盖一个或多个像素。YStride 是垂直相邻像素在 Y 切片中的索引差。CStride 是映射到不同色度样本的垂直相邻像素在 Cb 和 Cr 切片中的索引差。虽然并非硬性要求，但 YStride 和 len(Y) 通常为 8 的倍数，而且：
对于 4:4:4, CStride == YStride/1 && len(Cb) == len(Cr) == len(Y)/1.
对于 4:2:2, CStride == YStride/2 && len(Cb) == len(Cr) == len(Y)/2.
对于 4:2:0, CStride == YStride/2 && len(Cb) == len(Cr) == len(Y)/4.
对于 4:4:0, CStride == YStride/1 && len(Cb) == len(Cr) == len(Y)/2.
对于 4:1:1, CStride == YStride/4 && len(Cb) == len(Cr) == len(Y)/4.
对于 4:1:0, CStride == YStride/4 && len(Cb) == len(Cr) == len(Y)/8.



			
type YCbCr struct {
    Y, Cb, Cr      []uint8
    YStride        int
    CStride        int
    SubsampleRatio YCbCrSubsampleRatio
    Rect           Rectangle
}
