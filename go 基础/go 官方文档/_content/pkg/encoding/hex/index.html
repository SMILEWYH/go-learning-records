AppendDecode 将 src 经十六进制解码后的结果追加到 dst，并返回扩展后的缓冲区。如果输入格式有误，它会返回 src 已成功解码的部分以及一个错误。

func Decode 

func Decode(dst, src []byte) (int, error)

Decode 将 src 解码为 DecodedLen(len(src)) 个字节，并返回实际写入 dst 的字节数。

Decode 要求 src 仅包含十六进制字符，且长度为偶数。如果输入格式有误，Decode 返回错误发生前已解码的字节数。

func Encode 

func Encode(dst, src []byte) int

Encode 将 src 编码为 dst 中的 EncodedLen(len(src)) 个字节。为方便使用，它返回写入 dst 的字节数，但该值始终为 EncodedLen(len(src))。Encode 实现了十六进制编码。
