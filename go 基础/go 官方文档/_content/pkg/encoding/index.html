encoding 包定义了其他包共用的接口，这些包在数据与字节级表示或文本表示之间进行转换。检查这些接口的包包括 encoding/gob、encoding/json 和 encoding/xml。因此，只需实现一次接口，就可以让某个类型适用于多种编码。实现了这些接口的标准类型包括 time.Time 和 net.IP。这些接口成对出现，分别用于生成和读取编码后的数据。

为现有类型添加编码或解码方法可能构成破坏性变更，因为这些方法可能用于序列化，并与使用不同版本库编写的程序通信。Go 项目维护的包遵循这样的政策：只有在不存在合理的现有序列化方式时，才允许添加序列化函数。

type BinaryAppender 1.24

BinaryAppender 接口由能够追加自身二进制表示的对象实现。如果某个类型同时实现了 BinaryAppender 和 BinaryMarshaler，则 v.MarshalBinary() 在语义上必须与 v.AppendBinary(nil) 完全相同。 

type BinaryAppender interface {
    // AppendBinary 将自身的二进制表示追加到 b 的末尾
    // （必要时分配更大的切片），并返回更新后的切片。
    //
    // 实现不得保留 b，也不得修改 b[:len(b)] 中的任何字节。
    AppendBinary(b []byte) ([]byte, error)
}

type BinaryMarshaler 1.2

BinaryMarshaler 接口由能够将自身序列化为二进制形式的对象实现。

MarshalBinary 将接收者编码为二进制形式并返回结果。 

type BinaryMarshaler interface {
    MarshalBinary() (data []byte, err error)
}

type BinaryUnmarshaler 1.2

BinaryUnmarshaler 接口由能够从自身的二进制表示进行反序列化的对象实现。

UnmarshalBinary 必须能够解码 MarshalBinary 生成的形式。如果需要在返回后保留数据，UnmarshalBinary 必须复制这些数据。 

type BinaryUnmarshaler interface {
    UnmarshalBinary(data []byte) error
}
