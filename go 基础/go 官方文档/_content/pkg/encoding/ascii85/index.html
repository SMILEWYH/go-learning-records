func Decode 

func Decode(dst, src []byte, flush bool) (ndst, nsrc int, err error)

Decode 将 src 解码到 dst，同时返回写入 dst 的字节数和从 src 消耗的字节数。如果 src 包含无效的 ascii85 数据，Decode 会返回成功写入的字节数和一个 CorruptInputError。Decode 会忽略 src 中的空白字符和控制字符。ascii85 编码的数据通常由 <~ 和 ~> 符号包裹。Decode 要求调用者已去除这些符号。

如果 flush 为 true，Decode 会假定 src 已到达输入流末尾，并完整处理它，而不会等待另一个 32 位块补齐。

NewDecoder 为 Decode 封装了一个 io.Reader 接口。

func Encode 

func Encode(dst, src []byte) int

Encode 将 src 编码到 dst，最多写入 MaxEncodedLen(len(src)) 个字节，并返回实际写入的字节数。

该编码按 4 字节块处理，并对末尾的片段使用特殊编码，因此 Encode 不适合逐块处理大型数据流。此时应使用 NewEncoder。

ascii85 编码的数据通常由 <~ 和 ~> 符号包裹。Encode 不会添加这些符号。

func MaxEncodedLen 

func MaxEncodedLen(n int) int

MaxEncodedLen 返回 n 个源字节编码后的最大长度。

func NewEncoder 

func NewEncoder(w io.Writer) io.WriteCloser

NewEncoder 返回一个新的 ascii85 流编码器。写入所返回写入器的数据会先经过编码，再写入 w。ascii85 编码按 32 位块处理；完成写入后，调用者必须对返回的编码器调用 Close，以刷新末尾可能存在的不完整块。
