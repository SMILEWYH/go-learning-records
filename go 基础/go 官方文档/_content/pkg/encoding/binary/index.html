binary 包实现了数值与字节序列之间的简单转换，以及变长整数（varint）的编码和解码。

数值转换通过读写固定大小的值实现。固定大小的值可以是固定大小的算术类型（bool、int8、uint8、int16、float32、complex64 等），也可以是仅包含固定大小值的数组或结构体。

varint 函数使用变长编码对单个整数值进行编码和解码；较小的值所需字节更少。相关规范见 https://developers.google.com/protocol-buffers/docs/encoding。

本包优先考虑简单性，而非效率。需要高性能序列化，尤其是处理大型数据结构的使用者，应考虑更完善的方案，如 encoding/gob 包或用于 Protocol Buffers 的 google.golang.org/protobuf。

func Read 

func Read(r io.Reader, order ByteOrder, data any) error

Read 从 r 读取结构化的二进制数据并写入 data。data 必须是指向固定大小值的指针，或由固定大小值组成的切片。从 r 读取的字节按指定字节序解码，并依次写入 data 的各个字段。解码布尔值时，零字节解码为 false，其他任何非零字节解码为 true。读入结构体时，会跳过空白字段名（_）对应的字段数据；也就是说，可以使用空白字段名进行填充。读入结构体时，所有非空白字段都必须是导出的，否则 Read 可能引发 panic。

只有一个字节也没读到时，错误才会是 io.EOF。如果读入部分但尚未读完全部字节时遇到 io.EOF，Read 会返回 io.ErrUnexpectedEOF。

ReadUvarint 从 r 读取一个编码后的无符号整数，并以 uint64 返回。只有一个字节也没读到时，错误才会是 io.EOF。如果读入部分但尚未读完全部字节时遇到 io.EOF，ReadUvarint 会返回 io.ErrUnexpectedEOF。

func ReadVarint 

func ReadVarint(r io.ByteReader) (int64, error)

ReadVarint 从 r 读取一个编码后的有符号整数，并以 int64 返回。只有一个字节也没读到时，错误才会是 io.EOF。如果读入部分但尚未读完全部字节时遇到 io.EOF，ReadVarint 会返回 io.ErrUnexpectedEOF。

func Size 

func Size(v any) int

Size 返回 Write 对值 v 编码时会生成的字节数。v 必须是固定大小的值、由固定大小值组成的切片，或指向此类数据的指针。如果 v 不属于这些情况，Size 返回 -1。

func Uvarint 

func Uvarint(buf []byte) (uint64, int)

Uvarint 从 buf 解码一个 uint64，并返回该值和读取的字节数（> 0）。如果发生错误，返回值为 0，字节数 n 为 <= 0，其含义为：

  • n == 0：buf 太小；
  • n < 0：值超过 64 位（溢出），-n 是读取的字节数。

func Write 

func Write(w io.Writer, order ByteOrder, data any) error

Write 将 data 的二进制表示写入 w。data 必须是固定大小的值、由固定大小值组成的切片，或指向此类数据的指针。布尔值编码为一个字节：true 为 1，false 为 0。写入 w 的字节依次取自 data 的各个字段，并按指定的字节序编码。写入结构体时，空白字段名（_）对应的字段会写入零值。

type AppendByteOrder 1.19

AppendByteOrder 指定如何将 16、32 或 64 位无符号整数追加到字节切片。

它由 LittleEndian、BigEndian 和 NativeEndian 实现。 

type AppendByteOrder interface {
    AppendUint16([]byte, uint16) []byte
    AppendUint32([]byte, uint32) []byte
    AppendUint64([]byte, uint64) []byte
    String() string
}

type ByteOrder

ByteOrder 指定如何将字节切片转换为 16、32 或 64 位无符号整数。

它由 LittleEndian、BigEndian 和 NativeEndian 实现。 

type ByteOrder interface {
    Uint16([]byte) uint16
    Uint32([]byte) uint32
    Uint64([]byte) uint64
    PutUint16([]byte, uint16)
    PutUint32([]byte, uint32)
    PutUint64([]byte, uint64)
    String() string
}
