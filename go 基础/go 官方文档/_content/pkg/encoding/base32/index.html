type Encoding

Encoding 是由一个包含 32 个字符的字母表定义的 32 进制编码和解码方案。最常用的是为 SASL GSSAPI 引入、并由 RFC 4648 标准化的“base32”编码。另一种“base32hex”编码用于 DNSSEC。

}

func NewEncoding 

func NewEncoding(encoder string) *Encoding

NewEncoding 返回由给定字母表定义的、带填充的 Encoding。字母表必须是长度为 32 字节的字符串，各字节值互不相同，且不能包含填充字符、回车或换行字符（'\r'、'\n'）。字母表被视为一系列字节值，不会对多字节 UTF-8 做特殊处理。返回的 Encoding 使用默认填充字符（'='），可通过 Encoding.WithPadding 修改或禁用。

func (*Encoding) AppendDecode 1.22 

func (enc *Encoding) AppendDecode(dst, src []byte) ([]byte, error)

AppendDecode 将 src 经 base32 解码后的结果追加到 dst，并返回扩展后的缓冲区。如果输入格式有误，它会返回 src 已成功解码的部分以及一个错误。换行字符（\r 和 \n）会被忽略。

func (*Encoding) Decode 

func (enc *Encoding) Decode(dst, src []byte) (n int, err error)

Decode 使用编码 enc 解码 src。它最多向 dst 写入 Encoding.DecodedLen(len(src)) 个字节，并返回写入的字节数。调用者必须确保 dst 足够大，能够容纳全部解码后的数据。如果 src 包含无效的 base32 数据，它会返回成功写入的字节数和 CorruptInputError。换行字符（\r 和 \n）会被忽略。

func (*Encoding) Encode 

func (enc *Encoding) Encode(dst, src []byte)

Encode 使用编码 enc 对 src 进行编码，并向 dst 写入 Encoding.EncodedLen(len(src)) 个字节。

该编码将输出填充为 8 字节的整数倍，因此 Encode 不适合逐块处理大型数据流。此时应使用 NewEncoder。

func (Encoding) WithPadding 1.9 

func (enc Encoding) WithPadding(padding rune) *Encoding

WithPadding 创建一个新的编码，它与 enc 相同，但使用指定的填充字符；指定 NoPadding 可禁用填充。填充字符不能为 '\r' 或 '\n'，不能包含在编码字母表中，不能为负数，且必须是小于等于 '\xff' 的 rune。大于 '\x7f' 的填充字符会编码为其确切的字节值，而不是该码点的 UTF-8 表示。
