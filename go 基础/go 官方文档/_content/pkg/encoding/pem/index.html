pem 包实现了 PEM 数据编码，它起源于 Privacy Enhanced Mail。目前，PEM 编码最常用于 TLS 密钥和证书。参见 RFC 1421。

func EncodeToMemory 

func EncodeToMemory(b *Block) []byte

EncodeToMemory 返回 b 的 PEM 编码。

如果 b 的头部无效、无法编码，EncodeToMemory 会返回 nil。如果需要报告这种错误的详细信息，应使用 Encode。

type Block

Block 表示一个 PEM 编码的结构。

其编码形式为： 

-----BEGIN Type-----
Headers
base64-encoded Bytes
-----END Type-----

其中 Block.Headers 是一组 Key: Value 行，可以为空。 

type Block struct {
    Type    string            // 类型，取自起始标记（例如 "RSA PRIVATE KEY"）。
    Headers map[string]string // 可选的头部。
    Bytes   []byte            // 内容解码后的字节。通常是 DER 编码的 ASN.1 结构。
}

func Decode 

func Decode(data []byte) (p *Block, rest []byte)

Decode 在输入中查找下一个 PEM 格式的块（证书、私钥等），并返回该块和剩余输入。如果未找到 PEM 数据，p 为 nil，rest 返回全部输入。块必须从行首开始，并在行尾结束。
