type LineTable

LineTable 是将程序计数器映射到行号的数据结构。

在 Go 1.1 及更早版本中，每个函数（由 Func 表示）都有自己的 LineTable，行号则对应整个程序跨所有文件的源代码行的统一编号。随后还需要单独将这种绝对行号转换为文件名及文件内行号。

Go 1.2 更改了数据格式，整个程序只有一个由所有 Func 共享的 LineTable，不再使用绝对行号，而只使用特定文件内的行号。

通常，LineTable 的方法应视为本包内部实现细节；调用方应改用 Table 上的方法。

type LineTable struct {
    Data []byte
    PC   uint64
    Line int
    // 包含已过滤或未导出的字段
}

func NewLineTable 

func NewLineTable(data []byte, text uint64) *LineTable

NewLineTable 返回与编码数据对应的新程序计数器／行号表。text 必须是对应代码段的起始地址，其精确值保存在“runtime.text”符号中。如果二进制文件构建时启用了 cgo，该值可能不同于代码段的起始地址。

LineToPC 返回给定行号对应的程序计数器，只考虑 maxpc 之前的程序计数器。

type Obj

Obj 表示符号表中的一组函数。

将二进制文件划分为多个 Obj 的具体方式，是符号表格式的内部细节。

早期 Go 版本中，每个源文件对应一个独立的 Obj。

在 Go 1 和 Go 1.1 中，每个包的全部 Go 源文件产生一个 Obj，每个 C 源文件分别产生一个 Obj。

在 Go 1.2 中，整个程序只有一个 Obj。

type Obj struct {
    // Funcs 是 Obj 中的函数列表。
    Funcs []Func

    // 在 Go 1.1 及更早版本中，Paths 是一组符号，
    // 对应生成该 Obj 的各个源文件名。
    // 在 Go 1.2 中，Paths 为 nil。
    // 使用 Table.Files 的键获取源文件列表。
    Paths []Sym // 元信息
}

type Sym

Sym 表示一个符号表条目。

type Sym struct {
    Value  uint64
    Type   byte
    Name   string
    GoType uint64
    // 如果此符号是函数符号，则为其对应的 Func
    Func *Func
    // 包含已过滤或未导出的字段
}

type Table

Table 表示 Go 符号表。它存储从程序解码得到的全部符号，并提供在符号、名称和地址之间转换的方法。

type Table struct {
    Syms  []Sym // 对于 Go 1.3 及更高版本的二进制文件，为 nil
    Funcs []Func
    Files map[string]*Obj // Go 1.2 及更高版本中，所有文件都映射到同一个 Obj
    Objs  []Obj           // Go 1.2 及更高版本中，切片中只有一个 Obj
    // 包含已过滤或未导出的字段
}

func NewTable 

func NewTable(symtab []byte, pcln *LineTable) (*Table, error)

NewTable 解码 Go 符号表（ELF 中的“.gosymtab”节），返回其内存表示。从 Go 1.3 开始，Go 符号表不再包含符号数据，调用方应为 symtab 参数传入 nil。
