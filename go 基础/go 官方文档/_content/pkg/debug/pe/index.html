pe 包提供对 PE（Microsoft Windows 可移植可执行文件）文件的访问。

安全性

本包未针对恶意输入进行安全加固，也不属于 https://go.dev/security/policy 的适用范围。特别是，解析目标文件时只会进行基本验证。因此，解析不可信输入时应保持谨慎，因为解析格式错误的文件可能消耗大量资源，或引发 panic。

func (*COFFSymbol) FullName 1.8 

func (sym *COFFSymbol) FullName(st StringTable) (string, error)

FullName 查找符号 sym 的实际名称。名称通常存储在 sym.Name 中，但如果名称超过 8 个字符，则改为存储在 COFF 字符串表 st 中。

type COFFSymbolAuxFormat5 1.19

COFFSymbolAuxFormat5 描述附加在节定义符号上的辅助符号应有的格式。PE 格式定义了多种辅助符号格式：格式 1 用于函数定义，格式 2 用于 .be 和 .ef 符号，依此类推。格式 5 保存与节定义关联的额外信息，包括重定位条目数、行号条目数和 COMDAT 信息。详情参见 https://docs.microsoft.com/en-us/windows/win32/debug/pe-format#auxiliary-format-5-section-definitions。

type COFFSymbolAuxFormat5 struct {
    Size           uint32
    NumRelocs      uint16
    NumLineNumbers uint16
    Checksum       uint32
    SecNum         uint16
    Selection      uint8
    // 包含已过滤或未导出的字段
}

func (*File) COFFSymbolReadSectionDefAux 1.19 

func (f *File) COFFSymbolReadSectionDefAux(idx int) (*COFFSymbolAuxFormat5, error)

COFFSymbolReadSectionDefAux 返回节定义符号的辅助信息块（包括 COMDAT 信息）。这里的 idx 是该 File 的主 COFFSymbol 数组中节符号的索引。返回值是指向相应辅助符号结构体的指针。更多信息参见：

辅助符号：https://docs.microsoft.com/en-us/windows/win32/debug/pe-format#auxiliary-symbol-records COMDAT 节：https://docs.microsoft.com/en-us/windows/win32/debug/pe-format#comdat-sections-object-only 节定义的辅助信息：https://docs.microsoft.com/en-us/windows/win32/debug/pe-format#auxiliary-format-5-section-definitions

type Section

Section 提供对 PE COFF 节的访问。

type Section struct {
    SectionHeader
    Relocs []Reloc // Go 1.8

    // 嵌入 ReaderAt 以提供 ReadAt 方法。
    // 不直接嵌入 SectionReader，
    // 以避免引入 Read 和 Seek 方法。
    // 如果调用方需要 Read 和 Seek，必须使用
    // Open()，以避免与其他调用方
    // 争用定位偏移量。
    io.ReaderAt
    // 包含已过滤或未导出的字段
}

func (*Section) Data 

func (s *Section) Data() ([]byte, error)

Data 读取并返回 PE 节 s 的内容。

如果 s.Offset 为 0，则该节没有内容，Data 将始终返回非 nil 错误。

func (*Section) Open 

func (s *Section) Open() io.ReadSeeker

Open 返回一个新的 ReadSeeker，用于读取 PE 节 s。

如果 s.Offset 为 0，则该节没有内容，对返回的读取器的所有调用都会返回非 nil 错误。
