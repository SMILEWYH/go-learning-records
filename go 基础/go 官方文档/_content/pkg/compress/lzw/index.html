概览 ▾

lzw 包实现 Lempel-Ziv-Welch 压缩数据格式，该格式见 T. A. Welch 的论文《A Technique for High-Performance Data Compression》，发表于 Computer，17(6)（1984 年 6 月），第 8–19 页。

具体而言，它实现 GIF 和 PDF 文件格式使用的 LZW：编码宽度可变，最多为 12 位，前两个非字面值编码分别是清除码和 EOF 码。

TIFF 文件格式使用的是一种相似但不兼容的 LZW 算法版本。其实现见 golang.org/x/image/tiff/lzw 包。

func NewReader 

func NewReader(r io.Reader, order Order, litWidth int) io.ReadCloser

NewReader 创建一个新的 io.ReadCloser。从返回的 io.ReadCloser 读取，会从 r 读取并解压缩数据。如果 r 没有同时实现 io.ByteReader，解压缩器从 r 读取的数据可能多于实际所需的数据。调用方有责任在读取结束后调用 ReadCloser 的 Close。字面值编码使用的位数 litWidth 必须在 [2,8] 范围内，通常为 8。它必须与压缩时使用的 litWidth 相同。

保证返回的 io.ReadCloser 的底层类型为 *Reader。

func NewWriter 

func NewWriter(w io.Writer, order Order, litWidth int) io.WriteCloser

NewWriter 创建一个新的 io.WriteCloser。写入返回的 io.WriteCloser 的数据会被压缩并写入 w。调用方有责任在写入结束后调用 WriteCloser 的 Close。字面值编码使用的位数 litWidth 必须在 [2,8] 范围内，通常为 8。输入字节必须小于 1<<litWidth。

保证返回的 io.WriteCloser 的底层类型为 *Writer。

type Order

Order 指定 LZW 数据流中的位顺序。

type Order int
const (
    // LSB 表示最低有效位优先，GIF 文件格式使用此顺序。
    LSB Order = iota
    // MSB 表示最高有效位优先，TIFF 和 PDF
    // 文件格式使用此顺序。
    MSB
)
