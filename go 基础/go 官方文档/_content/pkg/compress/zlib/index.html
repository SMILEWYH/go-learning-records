zlib 包实现 RFC 1950 规定的 zlib 格式压缩数据的读写。

此实现提供在读取时解压缩、在写入时压缩的过滤器。例如，将压缩数据写入缓冲区：

var b bytes.Buffer
w := zlib.NewWriter(&b)
w.Write([]byte("hello, world\n"))
w.Close()

再将这些数据读回来：

r, err := zlib.NewReader(&b)
io.Copy(os.Stdout, r)
r.Close()

func NewReader 

func NewReader(r io.Reader) (io.ReadCloser, error)

NewReader 创建一个新的 ReadCloser。从返回的 ReadCloser 读取，会从 r 读取并解压缩数据。如果 r 没有实现 io.ByteReader，解压缩器从 r 读取的数据可能多于实际所需的数据。调用方有责任在使用结束后调用 ReadCloser 的 Close。

NewReader 返回的 io.ReadCloser 还实现了 Resetter。

func NewReaderDict 

func NewReaderDict(r io.Reader, dict []byte) (io.ReadCloser, error)

NewReaderDict 类似于 NewReader，但使用预设字典。如果压缩数据未引用该字典，NewReaderDict 会忽略字典。如果压缩数据引用了不同的字典，NewReaderDict 返回 ErrDictionary。

NewReaderDict 返回的 ReadCloser 还实现了 Resetter。

type Resetter 1.4

Resetter 重置 NewReader 或 NewReaderDict 返回的 ReadCloser，使其切换到新的底层 Reader。这样可以复用 ReadCloser，无须分配新的实例。

type Resetter interface {
    // Reset 丢弃所有已缓冲的数据，并重置 Resetter，
    // 使其就像刚刚使用给定读取器初始化的一样。
    Reset(r io.Reader, dict []byte) error
}

type Writer

Writer 接收写入的数据，并将这些数据的压缩形式写入底层写入器（参见 NewWriter）。

type Writer struct {

func NewWriter 

func NewWriter(w io.Writer) *Writer

NewWriter 创建一个新的 Writer。写入返回的 Writer 的数据会被压缩并写入 w。

调用方有责任在使用结束后调用 Writer 的 Close。写入的数据可能被缓冲，直到 Close 才刷新。

注意，写入 w 的确切字节内容不在 Go 1 兼容性承诺范围内。调用方（包括测试）不应依赖实际写入的精确字节内容。

func NewWriterLevel 

func NewWriterLevel(w io.Writer, level int) (*Writer, error)

NewWriterLevel 类似于 NewWriter，但可以指定压缩级别，而不是采用 DefaultCompression。

压缩级别可以是 DefaultCompression、NoCompression、HuffmanOnly，或者 BestSpeed 与 BestCompression 之间的任意整数（含两端）。如果级别有效，返回的错误为 nil。

注意，写入 w 的确切字节内容不在 Go 1 兼容性承诺范围内。调用方（包括测试）不应依赖实际写入的精确字节内容。

func NewWriterLevelDict 

func NewWriterLevelDict(w io.Writer, level int, dict []byte) (*Writer, error)

NewWriterLevelDict 类似于 NewWriterLevel，但指定了压缩使用的字典。

字典可以为 nil。如果不为 nil，则在 Writer 关闭之前不应修改其内容。

注意，写入 w 的确切字节内容不在 Go 1 兼容性承诺范围内。调用方（包括测试）不应依赖实际写入的精确字节内容。

func (*Writer) Close 

func (z *Writer) Close() error

Close 关闭 Writer，将所有尚未写出的数据刷新到底层 io.Writer，但不关闭底层 io.Writer。

func (*Writer) Flush 

func (z *Writer) Flush() error

Flush 将 Writer 中的数据刷新到底层 io.Writer。

func (*Writer) Reset 1.2 

func (z *Writer) Reset(w io.Writer)

Reset 清除 Writer z 的状态，使其等价于由 NewWriterLevel 或 NewWriterLevelDict 创建时的初始状态，但改为向 w 写入。

func (*Writer) Write 

func (z *Writer) Write(p []byte) (n int, err error)

Write 将 p 的压缩形式写入底层 io.Writer。压缩后的字节可能要等到 Writer 关闭或显式刷新时才会刷新。
