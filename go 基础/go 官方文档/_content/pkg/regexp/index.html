regexp 包实现正则表达式搜索。

所接受的正则表达式语法与 Perl、Python 等语言使用的通用语法相同。更准确地说，除 \C 外，它采用 RE2 接受的语法，说明见 https://golang.org/s/re2syntax。语法概览参见 regexp/syntax 包。

本包提供的正则表达式实现保证运行时间与输入大小呈线性关系。（大多数开源正则表达式实现并不保证这一性质。）有关这一性质的更多信息，参见 https://swtch.com/~rsc/regexp/regexp1.html 或任何自动机理论书籍。

所有字符都是以 UTF-8 编码的码点。遵循 utf8.DecodeRune 的规则，无效 UTF-8 序列中的每个字节都被视为编码了 utf8.RuneError（U+FFFD）。

Regexp 有 24 个方法用于匹配正则表达式并确定匹配到的文本。它们的名称符合以下正则表达式：

(All|Find|FindAll)(String)?(Submatch)?(Index)?

带 “All” 的变体返回一个迭代器，遍历整个表达式连续、不重叠的匹配。带 “FindAll” 的变体则返回这些匹配组成的切片。紧邻前一个匹配的空匹配会被忽略。“FindAll” 变体还接受一个额外的整数参数 n。如果 n >= 0，函数最多返回 n 个匹配及其子匹配；否则返回所有匹配。

“Find” 变体仅返回 All 或 FindAll 所返回的第一个匹配。

如果名称中包含 “String”，参数就是字符串；否则为 []byte。

默认情况下，每个返回的匹配由匹配正则表达式的子串表示，其类型根据参数类型而为 string 或 []byte。如果名称中包含 “Submatch”，每个匹配则由一个切片表示，其中包含匹配该正则表达式的各个括号子表达式（也称捕获组）的子串；按左括号出现的先后顺序从左到右编号。子匹配 0 对应整个表达式，子匹配 1 对应第一个括号子表达式，依此类推。如果名称中包含 “Index”，每个子串则由输入字符串中的一对字节索引表示。索引为负数或子串为 nil，表示该子表达式未匹配输入中的任何字符串。对于 “String” 版本，空字符串既可能表示没有匹配，也可能表示空匹配。

部分方法也适用于从 io.RuneReader 读取的文本：Regexp.MatchReader、Regexp.FindReaderIndex、Regexp.FindReaderSubmatchIndex。注意，正则表达式匹配可能需要检查返回的匹配文本之外的文本，因此从 io.RuneReader 匹配文本的方法在返回前，可能向后读取任意多的输入。

（还有少数方法的名称不符合上述模式。）

func Compile 

func Compile(expr string) (*Regexp, error)

Compile 解析正则表达式，成功时返回可用于匹配文本的 Regexp 对象。

匹配文本时，正则表达式返回在输入中尽可能早开始的匹配（最左匹配）；在这些匹配中，选择回溯搜索会最先找到的那个。这种所谓的“最左优先”匹配与 Perl、Python 等实现使用的语义相同，但本包实现它时无需承担回溯的开销。POSIX 的“最左最长”匹配参见 CompilePOSIX。

func CompilePOSIX 

func CompilePOSIX(expr string) (*Regexp, error)

CompilePOSIX 类似于 Compile，但将正则表达式限制为 POSIX ERE（egrep）语法，并将匹配语义改为“最左最长”。

也就是说，匹配文本时，正则表达式返回在输入中尽可能早开始的匹配（最左匹配）；在这些匹配中，选择尽可能长的匹配。这种所谓的“最左最长”匹配与早期正则表达式实现以及 POSIX 规定的语义相同。

不过，可能存在多个最左最长匹配，其子匹配选择各不相同；在这一点上，本包与 POSIX 不同。在所有可能的最左最长匹配中，本包选择回溯搜索会最先找到的那个，而 POSIX 规定选择的匹配应使第一个子表达式的长度最大，然后是第二个，依此从左到右。POSIX 规则的计算开销难以承受，甚至其定义也不够明确。详情参见 https://swtch.com/~rsc/regexp/regexp2.html#posix。

func (*Regexp) Expand 

func (re *Regexp) Expand(dst []byte, template []byte, src []byte, match []int) []byte

Expand 将 template 追加到 dst 并返回结果；追加过程中，Expand 将模板中的变量替换为从 src 提取的相应匹配。match 切片应由 Regexp.FindSubmatchIndex 返回。

在模板中，变量用 $name 或 ${name} 形式的子串表示，其中 name 是由字母、数字和下划线组成的非空序列。$1 这样的纯数字名称引用对应索引的子匹配；其他名称引用使用 (?P<name>...) 语法命名的捕获括号。引用越界或未匹配的索引，或者正则表达式中不存在的名称时，会被替换为空切片。

在 $name 形式中，会尽可能取最长的 name：$1x 等价于 ${1x}，而不是 ${1}x；$10 等价于 ${10}，而不是 ${1}0。

要在输出中插入字面字符 $，请在模板中使用 $$。

func (*Regexp) Split 1.1 

func (re *Regexp) Split(s string, n int) []string

Split 以该表达式的匹配为分隔符切分 s，返回这些匹配之间的子串组成的切片。

此方法返回的切片包含 s 中所有未包含在 Regexp.FindAllString 返回切片中的子串。如果表达式不包含元字符，则等价于 strings.SplitN。

示例：

s := regexp.MustCompile("a*").Split("abaabaccadaaae", 5)
// s: ["", "b", "b", "c", "cadaaae"]

计数参数决定返回的子串数量：

  • n > 0：最多返回 n 个子串；最后一个子串是未继续切分的剩余部分；
  • n == 0：结果为 nil（零个子串）；
  • n < 0：返回所有子串。
