builtin.go

常量

true 和 false 是两个无类型布尔值。

const (
    true  = 0 == 0 // 无类型布尔值。
    false = 0 != 0 // 无类型布尔值。
)

iota 是预声明标识符，表示当前 const 规格在一个 const 声明（通常带括号）中的序号，类型为无类型整数。序号从零开始。

const iota = 0 // 无类型整数。

变量

nil 是预声明标识符，表示指针、通道、函数、接口、映射或切片类型的零值。

var nil Type // Type 必须是指针、通道、函数、接口、映射或切片类型

func append 

func append(slice []Type, elems ...Type) []Type

内建函数 append 将元素追加到切片末尾。如果容量足够，会重新切片以容纳新元素；如果容量不足，则分配新的底层数组。append 返回更新后的切片。因此必须保存 append 的结果，通常存入原来保存该切片的变量：

slice = append(slice, elem1, elem2)
slice = append(slice, anotherSlice...)

有一种特殊情况：允许将字符串追加到字节切片，如下所示：

slice = append([]byte("hello "), "world"...)

func cap 

func cap(v Type) int

内建函数 cap 根据 v 的类型返回其容量：

  • 数组：v 中的元素数量（与 len(v) 相同）。
  • 数组指针：*v 中的元素数量（与 len(v) 相同）。
  • 切片：重新切片时可达到的最大长度；如果 v 为 nil，则 cap(v) 为零。
  • 通道：通道缓冲区容量，以元素数量计；如果 v 为 nil，则 cap(v) 为零。

对于某些实参（例如简单的数组表达式），结果可以是常量。详见 Go 语言规范的“长度与容量”一节。

func clear 

func clear[T ~[]Type | ~map[Type]Type1](t T)

内建函数 clear 清空映射和切片。对于映射，clear 删除所有条目，得到空映射。对于切片，clear 将切片长度范围内的所有元素设为相应元素类型的零值。如果实参类型是类型参数，则该类型参数的类型集合只能包含映射或切片类型，且 clear 执行由类型实参决定的操作。如果 t 为 nil，则 clear 不执行任何操作。

func close 

func close(c chan<- Type)

内建函数 close 关闭通道，该通道必须是双向通道或仅发送通道。它只应由发送方执行，绝不应由接收方执行；其效果是在最后一个已发送值被接收后结束通道。从已关闭通道 c 接收完最后一个值之后，对 c 的任何接收都会立即成功而不阻塞，并返回通道元素类型的零值。以下形式

x, ok := <-c

对于已关闭且为空的通道，还会将 ok 设为 false。

func complex 

func complex(r, i FloatType) ComplexType

内建函数 complex 从两个浮点值构造复数值。实部和虚部必须具有相同大小，均为 float32 或均为 float64（或可赋值给它们），返回值为对应的复数类型（float32 对应 complex64，float64 对应 complex128）。

func copy 

func copy(dst, src []Type) int

内建函数 copy 将源切片的元素复制到目标切片。（有一种特殊情况：也可以将字符串的字节复制到字节切片。）源和目标可以重叠。copy 返回复制的元素数量，即 len(src) 和 len(dst) 中的较小值。

func delete 

func delete(m map[Type]Type1, key Type)

内建函数 delete 从映射中删除指定键的元素（m[key]）。如果 m 为 nil 或不存在该元素，则 delete 不执行任何操作。

func imag 

func imag(c ComplexType) FloatType

内建函数 imag 返回复数 c 的虚部。返回值具有与 c 的类型对应的浮点类型。

func len 

func len(v Type) int

内建函数 len 根据 v 的类型返回其长度：

  • 数组：v 中的元素数量。
  • 数组指针：*v 中的元素数量（即使 v 为 nil 也是如此）。
  • 切片或映射：v 中的元素数量；如果 v 为 nil，则 len(v) 为零。
  • 字符串：v 中的字节数。
  • 通道：通道缓冲区中排队（尚未读取）的元素数量；如果 v 为 nil，则 len(v) 为零。

对于某些实参（例如字符串字面量或简单的数组表达式），结果可以是常量。详见 Go 语言规范的“长度与容量”一节。

func make 

func make(t Type, size ...IntegerType) Type

内建函数 make 分配并初始化 slice、map 或 chan 类型的对象（仅限这三种类型）。与 new 一样，第一个实参是类型而不是值。与 new 不同，make 返回的类型就是实参所指定的类型，而不是指向它的指针。结果的具体含义取决于类型：

  • 切片：size 指定长度，容量等于长度。可以提供第二个整数实参，指定不同的容量；该容量不得小于长度。例如，make([]int, 0, 10) 分配大小为 10 的底层数组，并返回由该数组支持、长度为 0、容量为 10 的切片。
  • 映射：分配空映射，并提供足够存放指定数量元素的空间。可以省略大小，此时分配较小的初始空间。
  • 通道：按指定缓冲容量初始化通道缓冲区。如果容量为零或省略大小，则通道无缓冲。

func max 

func max[T cmp.Ordered](x T, y ...T) T

内建函数 max 返回固定数量的 cmp.Ordered 类型实参中的最大值。必须至少提供一个实参。如果 T 是浮点类型，且任一实参为 NaN，则 max 返回 NaN。

func min 

func min[T cmp.Ordered](x T, y ...T) T

内建函数 min 返回固定数量的 cmp.Ordered 类型实参中的最小值。必须至少提供一个实参。如果 T 是浮点类型，且任一实参为 NaN，则 min 返回 NaN。

func new 

func new(TypeOrExpr) *Type

内建函数 new 分配一个已初始化的新变量，并返回指向它的指针。它接受单个实参，可以是类型或表达式。如果实参是类型 T，则 new(T) 分配一个初始化为零值的 T 类型变量。否则，实参是表达式 x，new(x) 分配一个类型与 x 相同、初始化为 x 的值的变量。如果该值是无类型常量，则先隐式转换为其默认类型。

func panic 

func panic(v any)

内建函数 panic 停止当前 goroutine 的正常执行。当函数 F 调用 panic 时，F 的正常执行立即停止。F 所延迟执行的函数按通常方式运行，随后 F 返回其调用方。对于调用方 G，F 的调用此时如同一次 panic 调用，会终止 G 的执行并运行其延迟函数。此过程逆序持续进行，直到当前 goroutine 中的所有函数都停止。此时，程序以非零退出码终止。这一终止过程称为 panicking，可通过内建函数 recover 控制。

从 Go 1.21 开始，以 nil 接口值或无类型 nil 调用 panic 会导致运行时错误（一个不同的 panic）。GODEBUG 设置 panicnil=1 会禁用此运行时错误。

func print 

func print(args ...Type)

内建函数 print 按实现特定的方式格式化实参，并将结果写入标准错误。print 适用于自举和调试；不保证它会继续保留在语言中。

func println 

func println(args ...Type)

内建函数 println 按实现特定的方式格式化实参，并将结果写入标准错误。实参之间始终添加空格，并在末尾追加换行符。println 适用于自举和调试；不保证它会继续保留在语言中。

func real 

func real(c ComplexType) FloatType

内建函数 real 返回复数 c 的实部。返回值具有与 c 的类型对应的浮点类型。

func recover 

func recover() any

内建函数 recover 允许程序管理正在发生 panic 的 goroutine 的行为。在延迟函数内部（但不能在它调用的其他函数内）调用 recover，会通过恢复正常执行来停止 panic 过程，并获取传给 panic 的错误值。如果在延迟函数之外调用 recover，则不会停止 panic 过程。在这种情况下，或 goroutine 没有处于 panic 过程中时，recover 返回 nil。

在 Go 1.21 之前，如果以 nil 实参调用 panic，recover 也会返回 nil。详见 [panic]。

type comparable

comparable 是所有可比较类型（布尔、数值、字符串、指针、通道、元素类型可比较的数组，以及所有字段类型均可比较的结构体）实现的接口。comparable 接口只能用作类型参数约束，不能用作变量类型。

type comparable interface{ comparable }
