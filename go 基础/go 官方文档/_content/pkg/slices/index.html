func BinarySearch 

func BinarySearch[S ~[]E, E cmp.Ordered](x S, target E) (int, bool)

BinarySearch 在已排序的切片中搜索 target，返回 target 首次出现的位置，或按排序顺序它应出现的位置；同时返回一个布尔值，表示是否确实在切片中找到了 target。切片必须已按递增顺序排序。

▾ 示例

func BinarySearchFunc 

func BinarySearchFunc[S ~[]E, E, T any](x S, target T, cmp func(E, T) int) (int, bool)

BinarySearchFunc 的作用与 BinarySearch 相同，但使用自定义比较函数。切片必须已按递增顺序排序，其中“递增”由 cmp 定义。如果切片元素匹配目标，cmp 应返回 0；如果元素排在目标之前，应返回负数；如果排在目标之后，应返回正数。cmp 必须与切片使用相同的排序关系，也就是说，如果 cmp(a, t) < 0 且 cmp(b, t) >= 0，那么 a 在切片中必须位于 b 之前。

▾ 示例

Bob: 1 true

func Chunk 

func Chunk[Slice ~[]E, E any](s Slice, n int) iter.Seq[Slice]

Chunk 返回一个迭代器，依次产生 s 中每段最多包含 n 个元素的连续子切片。除最后一个子切片外，其余子切片的长度均为 n。所有子切片的容量都被限制为等于其长度。如果 s 为空，序列也为空，不会包含空切片。如果 n 小于 1，Chunk 会触发 panic。

▸ 示例

▾ 示例

[{Bob 5} {Vera 24}]
[{Zac 15}]

func Compare 

func Compare[S ~[]E, E cmp.Ordered](s1, s2 S) int

Compare 使用 cmp.Compare 逐对比较 s1 和 s2 中的元素。从索引 0 开始依次比较，直到遇到一对不相等的元素，返回这一对元素的比较结果。如果直到其中一个切片结束，对应元素都相等，则较短的切片小于较长的切片。s1 == s2 时结果为 0，s1 < s2 时为 -1，s1 > s2 时为 +1。

func Delete 

func Delete[S ~[]E, E any](s S, i, j int) S

Delete 原地修改 s，移除元素 s[i:j]，并返回修改后的切片。如果 j > len(s)，或 s[i:j] 不是 s 的有效切片，Delete 会触发 panic。Delete 的时间复杂度为 O(len(s)-i)，因此若需删除多个元素，最好通过一次调用一起删除，而非逐个删除。Delete 会将 s[len(s)-(j-i):len(s)] 中的元素置为零值。如果结果为空，其是否为 nil 与 s 保持一致。

▸ 示例

▾ 示例

func Equal 

func Equal[S ~[]E, E comparable](s1, s2 S) bool

Equal 报告两个切片是否相等，即长度相同且所有对应元素均相等。如果长度不同，Equal 返回 false；否则按索引递增的顺序比较元素，遇到第一对不相等的元素时停止。空切片和 nil 切片视为相等。浮点数 NaN 不视为相等。

func Insert 

func Insert[S ~[]E, E any](s S, i int, v ...E) S

Insert 原地修改 s，在索引 i 处插入值 v...，并返回修改后的切片。s[i:] 中的元素向后移动，以腾出空间。在返回的切片 r 中，r[i] == v[0]；如果 i < len(s)，则 r[i+len(v)] 等于原来 s[i] 的值。如果 i > len(s)，Insert 会触发 panic。此函数的时间复杂度为 O(len(s) + len(v))。如果结果为空，其是否为 nil 与 s 保持一致。

func SortFunc 

func SortFunc[S ~[]E, E any](x S, cmp func(a, b E) int)

SortFunc 按 cmp 函数确定的升序排列切片 x。此排序不保证稳定。a < b 时，cmp(a, b) 应返回负数；a > b 时应返回正数；a == b，或 a 与 b 在严格弱序意义下不可比较时，应返回零。

SortFunc 要求 cmp 定义严格弱序。参见 https://en.wikipedia.org/wiki/Weak_ordering#Strict_weak_orderings。对于不可比较的元素，该函数应返回 0。
